| 第三 摩怯                                    | 3. 摩伽經                                                    |
| 尔时，世尊住舍卫城……                         | 起源於舍衛城。                                               |
| 时，摩怯天子于黎明往诣世尊处。其胜光偏只园， | 那時，在夜已深時，容色絕佳的摩伽天子使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                   | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之摩怯天子，向世尊唱偈曰：           | 在一旁站立的摩伽天子以偈頌對世尊說：                         |
| 1 杀何乐寝卧                                 | 「切斷什麼後睡得安樂呢？                                     |
| 2 杀何而不悲                                 | 切斷什麼後不憂愁呢？                                         |
| 3 杀害何一法                                 | 對哪一法的殺害，                                             |
| 4 瞿昙卿称赞                                 | 喬達摩同意呢？」                                             |
| [世尊：]                                     |                                                              |
| 1 杀忿乐寝卧                                 | 「切斷憤怒後睡得安樂，                                       |
| 2 杀忿而不悲                                 | 切斷憤怒後不憂愁，                                           |
| 3 诸天以毒根                                 | 阿修羅的征服者！                                             |
| 4 忿为最上蜜                                 | 對端為蜜，對根為毒的憤怒，                                   |
| 5 圣赞此忿杀                                 | 聖者們稱讚殺害，                                             |
| 6 杀之不悲伤                                 | 因為切斷它後不憂愁。」                                       |
