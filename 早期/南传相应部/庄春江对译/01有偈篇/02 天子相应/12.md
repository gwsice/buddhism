| 立于一面之毗纽天子，于世尊前，唱此偈曰： | 在一旁站立的毘紐天子在世尊面前說這偈頌： |
| 4 实是幸福焉                             | 「那些人正是快樂的：                     |
| 1 奉侍于善逝                             | 侍奉善逝後，                             |
| 2 顺从瞿昙教                             | 在喬達摩的教說中努力後，                 |
| 3 学不放逸人                             | 不放逸地隨學。」                         |
| [世尊呼曰：毗纽!]                        | (世尊：「毘紐！」)                       |
| 1 从我所说教                             | 「凡在教誡之句被我宣說時，               |
| 2 学句入禅定                             | 禪修者們隨學，                           |
| 3 始终不放逸                             | 那些常常不放逸者，                       |
| 4 不入死魔领                             | 不會是到達死亡控制者。」                 |
