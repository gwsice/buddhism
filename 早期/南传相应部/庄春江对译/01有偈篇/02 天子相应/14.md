| 第四 难陀那天子                        | 14. 難陀經                           |
| 立于一面之难陀那天子，向世尊唱偈曰：   | 在一旁站立的難陀天子以偈頌對世尊說： |
| 1 大智之瞿昙 3 奉问于世尊 4 大雄智见者 | 「喬達摩！我問你、廣慧者：           |
| 2 无有盖覆事                           | 世尊的智見是不被覆蓋的，             |
| 5 何等持戒者                           | 什麼類型者他們說持戒者？             |
| 6 何等智慧者                           | 什麼類型者他們說有慧者？             |
| 7 何等超苦人                           | 什麼類型者超越苦後行動？             |
| 8 诸天崇何人                           | 什麼類型者諸天敬奉？」               |
| [世尊：]                               |                                      |
| 1 具戒有智慧 2 勤修于心意              | 「凡持戒者、有慧者、已自我修習者，   |
| 3 寂静而禅乐                           | 得定者、愛好禪者、有念者，           |
| 4 正念舍诸愁                           | 一切愁已消失者、已捨斷者，           |
| 5 诸漏皆尽已 6 最后身之人              | 漏已滅盡者、持最後身者，             |
| 7 如是之行人 8 称为持戒者              | 像那種類型者他們說持戒者，           |
| 9 如是之行人 10 称为智慧者             | 像那種類型者他們說有慧者。           |
| 11 如是超苦人                          | 像那種類型者超越苦後行動，           |
| 12 是人诸天敬                          | 像那種類型者諸天敬奉。」             |
