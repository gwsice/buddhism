| 第六 赤马                                                    | 26. 赤馬經                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| [尔时，世尊]住舍卫城……。                                     | 起源於舍衛城。                                               |
| 立于一面之赤马天子，向世尊言此曰：                           | 在一旁站立的赤馬天子對世尊說這個：                           |
| ‘世尊!于此不生[何物]、不衰、不死、无生起之处，               | 「大德！不被生、不衰老、不死亡、不死沒、不再生之處，         |
| 步行之而知、或见、或得到彼世界之边极耶?’                     | 大德！那個世界的邊(終結)能以行走知道，或看到，或到達嗎？」   |
| [世尊曰:]‘友!我不诣于此不生[何物]，不衰、不死、不没、步行之即得知、得见、得到达不生起彼世界之边极。’ | 「朋友！不被生、不衰老、不死亡、不死沒、不再生之處，我不說：『世界的邊以行走能被知道、能被看見、能被到達。』」 |
| [天子曰:]‘世尊!希有、得未曾有。世尊!此实是由世尊所语：‘友!我不语于此不生[何物]，不衰、不死、不没、步行之即得知、得见、得到达不生起彼世界之边极。’ | 「不可思議啊，大德！未曾有啊，大德！大德！這被世尊多麼善說：『朋友！不被生、不衰老、不死亡、不死沒、不再生之處，我不說：『世界的邊以行走能被知道、能被看見、能被到達。」』 |
| 世尊!我往昔名为赤马仙人，普奢之子，而有飞行于空中之神通。    | 大德！從前，我是名為赤馬的仙人，伯渣的兒子，有神通者，空中行走者。 |
| 世尊!我有如是迅速之力：譬如精巧练习、熟练，取弓于轻矢，其[速力]如以超越射透多罗树之叶荫。 | 大德！那個我有像這樣的速度：猶如有強弓的、善學的、熟練的、已訓練的、擅長弓術的弓箭手以輕的箭就少困難地橫向射穿棕櫚樹影。 |
| 世尊!斯我一足之幅度，有如由东海至西海之广。                  | 大德！那個我有像這樣的步幅：猶如從東海到西海。               |
| 于我起如是愿：我于步行，得到世界之边极。                     | 大德！那個我的像這樣欲求樣貌生起：『我將以行走到達世界的邊。』 |
| 世尊!我具有如是速力，于如是足幅，于饭食之外，大小便之外，睡以治疲劳外，行我寿命百岁之间，未达世界之边极，中途而死。 | 大德！具備像這樣的速度與那樣的步幅，那個我除了吃、喝、嚼、嘗，除了大小便事務，除了睡覺、疲勞之排除外，一百年的壽命；一百年活著的；走一百年後，沒到達世界的邊後，途中就命終。 |
| 世尊!希有，得未曾有也。世尊!此实是由世尊所语：‘我不语于此不生[何物]，不衰、不死、不没，步行而得知、得见、得到达不生起彼世界之边极。’’ | 不可思議啊，大德！未曾有啊，大德！大德！這被世尊多麼善說：『朋友！不被生、不衰老、不死亡、不死沒、不再生之處，我不說：『世界的邊以行走能被知道、能被看見、能被到達。」』」 |
| [世尊曰：]友!我非说不达世界之边极而成苦恼之边极。            | 「朋友！然而，我說，不到達世界的邊後，沒有苦的作終結。       |
| 友!我说示：于此一寻之有想有意之身体上、到达世界与世界之果、世界之灭与世界之灭道。 | 朋友！而是，就在這一噚之長，有想、有心的身體上，我安立世界、世界集、世界滅、導向世界滅道跡。」 |
| 1步行于世界                                                  | 「不能被行走到達：                                           |
| 2不得达边极                                                  | 任何時候世界的邊，                                           |
| 3不达世边极                                                  | 但不到達世界的邊後，                                         |
| 4不以脱苦恼                                                  | 沒有使從苦的釋放。                                           |
| 5是故实贤者 6及世间解者                                      | 因此確實世間知者、極聰明者，                                 |
| 7达世界边极 8终以成梵行                                      | 到達世界邊者、梵行已完成，                                   |
| 9恶之澄静者 10知世之边极                                     | 寂靜者知道世界的邊後，                                       |
| 11此世及后世 12无有所求者                                    | 對這個世間與其它的不希求。」                                 |
