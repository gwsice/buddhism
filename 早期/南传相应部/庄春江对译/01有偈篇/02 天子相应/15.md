| 第五 称檀                          | 15. 檀香經                           |
| 立于一面之栴檀天子，向世尊唱偈曰： | 在一旁站立的檀香天子以偈頌對世尊說： |
| 4 以何超瀑流                       | 「{如何}[誰]渡暴流：                 |
| 1 日夜不惰怠                       | 日夜不倦怠地呢？                     |
| 2 无有立足基 3 亦无攀着处          | 在無立足處的、無支持的中，           |
| 5 何人不深沉                       | 誰在深處不沈沒？」                   |
| [世尊：]                           |                                      |
| 1 常于戒具足                       | 「於一切時戒具足者，                 |
| 2 智慧善静心                       | 有慧者、善得定者，                   |
| 3 精进不挠人                       | 活力已發動者、自我努力者，           |
| 4 渡难超瀑流                       | 渡難渡的暴流。                       |
| 5 远离于欲想                       | 已從欲想脫離者，                     |
| 6 越色之系缚                       | 已超越色結者，                       |
| 7 已尽喜贪人                       | 貪之歡喜已遍滅盡者，                 |
| 8 是为不深沉                       | 在深處不沈沒。」                     |
