| 第四 摩揭陀                          | 4. 摩伽大經                            |
|                                      | 起源於舍衛城。                         |
| 立于一面之摩揭陀天子，向世尊唱偈曰： | 在一旁站立的摩伽大天子以偈頌對世尊說： |
| 1 世有几多光                         | 「世間中有多少燈火，                   |
| 2 偏照此世间                         | 以該者們世間變明亮？                   |
| 3 我等问世尊                         | 我們來問世尊，                         |
| 4 如何得知此                         | 我們應該如何知道它？」                 |
| [世尊：]                             |                                        |
| 1 世有四种光                         | 「世間中有四種燈火，                   |
| 2 此无第五光                         | 第五種在這裡沒被發現，                 |
| 3 昼乃太阳辉                         | 太陽在白天照亮，                       |
| 4 夜乃月光照                         | 月亮在晚上發亮，                       |
| 5 时火于日夜                         | 而火在白天與晚上，                     |
| 6 彼此相偏照                         | 到處變明亮，                           |
| 7 正觉最胜火                         | 正覺者是照亮者中最勝的，               |
| 8 此为无上光                         | 那是無上的光明。」                     |
