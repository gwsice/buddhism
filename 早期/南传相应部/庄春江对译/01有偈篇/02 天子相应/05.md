| 第五 陀摩利                                        | 5. 大嘛哩經                                                  |
| [尔时，世尊]在舍卫城……                             | 起源於舍衛城。                                               |
| 时，陀摩利天子于黎明，其胜光偏照只园，往诣世尊处。 | 那時，在夜已深時，容色絕佳的大嘛哩天子使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                         | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之陀摩利天子，于世尊前，唱此偈曰：         | 在一旁站立的大嘛哩天子在世尊的面前說這偈頌：                 |
| 4 婆罗门所行                                       | 「這應該被婆羅門做：                                         |
| 1 精进勿倦怠                                       | 以不疲倦的勤奮，                                             |
| 2 以舍离爱欲                                       | 以對諸欲的捨斷，                                             |
| 3 依此不欲有                                       | 因此他不希望有。」                                           |
| (世尊曰：陀摩利!)                                  | (世尊：「大嘛哩！」)                                         |
| 1 此婆罗门者 2 无有之所行                          | 「沒有婆羅門應該作的，                                       |
| 3 婆罗门应作 4 一切终已办                          | 因為婆羅門應該被作的已作。                                   |
| 7 亦为流所冲 5 人不得足基                          | 只要在河中未得到立足處，                                     |
| 6 四肢虽勤动                                       | 人以全部的肢體努力，                                         |
| 8 得立土足基                                       | 但凡得到立足處後在陸地上住立者，                             |
| 9 彼到于彼岸 10 不为流所动                         | 他不努力因為他就是已到達彼岸者。                             |
| 11 天子陀摩利                                      | 大嘛哩！這是對婆羅門，                                       |
| 12 此乃诸漏尽 13 贤善于禅思 14 以喻婆罗门          | 對漏已滅盡者、明智者、禪修者的比喻，                         |
| 15 彼达生老终                                      | 到達生死的結束後，                                           |
| 16 以立于彼岸 17 不为所流逝                        | 他不努力因為他就是已到達彼岸者。」                           |
