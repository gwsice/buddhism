| 第三 种种外道品                                | 3.種種外道品                                                 |
| 第一 湿婆                                      | 21. 濕婆經                                                   |
| 如是我闻，                                     | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。               | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时湿婆天子于黎明，其胜光偏照只园，往诣世尊处， | 那時，在夜已深時，容色絕佳的濕婆天子使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                     | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之湿婆天子，于世尊前，唱此偈曰：       | 在一旁站立的濕婆天子在世尊的面前說這些偈頌：                 |
| 1只与善人坐                                    | 「只應該與善人們結交，                                       |
| 2只与善人交                                    | 應該與善人們作親密交往，                                     |
| 3知善人正法                                    | 了知善的正法後，                                             |
| 4为善不为恶                                    | 成為更好的、非惡的。                                         |
| 5只与善人坐                                    | 只應該與善人們結交，                                         |
| 6只与善人交                                    | 應該與善人們作親密交往，                                     |
| 7知善人正法                                    | 了知善的正法後，                                             |
| 8依他不能得 9而得之智慧                        | 慧被得到而非從其他的。                                       |
| 10只与善人坐                                   | 只應該與善人們結交，                                         |
| 11只与善人交                                   | 應該與善人們作親密交往，                                     |
| 12知善人正法                                   | 了知善的正法後，                                             |
| 13悲中无有悲                                   | 在憂愁中不憂愁。                                             |
| 14只与善人坐                                   | 只應該與善人們結交，                                         |
| 15只与善人交                                   | 應該與善人們作親密交往，                                     |
| 16知善人正法                                   | 了知善的正法後，                                             |
| 17辉耀亲族中                                   | 在親族中輝耀。                                               |
| 18只与善人坐                                   | 只應該與善人們結交，                                         |
| 19只与善人交                                   | 應該與善人們作親密交往，                                     |
| 20知善人正法                                   | 了知善的正法後，                                             |
| 21人人行善趣                                   | 眾生到善趣。                                                 |
| 22只与善人坐                                   | 只應該與善人們結交，                                         |
| 23只与善人交                                   | 應該與善人們作親密交往，                                     |
| 24知善人正法                                   | 了知善的正法後，                                             |
| 25人人有幸福                                   | 眾生經常地住立。」                                           |
| 时世尊以偈答湿婆天子曰：                       | 那時，世尊以偈頌回答濕婆天子：                               |
| 1只与善人坐                                    | 「只應該與善人們結交，                                       |
| 2只与善人交                                    | 應該與善人們作親密交往，                                     |
| 3知善人正法                                    | 了知善的正法後，                                             |
| 4可脱一切苦                                    | 從一切苦被釋放。」                                           |
