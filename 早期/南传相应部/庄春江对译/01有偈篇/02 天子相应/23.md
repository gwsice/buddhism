| 第三 世理                                                    | 23. 悉梨經                                                   |
| 立于一面之世理天子，向世尊唱此偈曰：                         | 在一旁站立的悉梨天子以偈頌對世尊說：                         |
| 2皆以食为乐                                                  | 「他們都歡喜食物：                                           |
| 1不论天及人                                                  | 諸天與人們兩者，                                             |
| 4夜叉实何者                                                  | 還有那個名為夜叉[眾生-㊟]，                                  |
| 3时有不喜食                                                  | 凡不歡喜食物呢？」                                           |
| [世尊：]                                                     |                                                              |
| 1信仰清净心                                                  | 「凡他們以信，                                               |
| 2行施食之人                                                  | 以明淨心施與那個者，                                         |
| 4皆可得其食                                                  | 食物就服侍他，                                               |
| 3此世及后世                                                  | 在這個與下一個世間。                                         |
| 5是故调伏悭                                                  | 因此調伏慳吝後，                                             |
| 6善施即胜垢                                                  | 征服垢者應該施與布施，                                       |
| 7功德乃人人                                                  | 福德在其他世間(來世)中，                                     |
| 8后世渡津头                                                  | 是有生命者們的依止。                                         |
| [天子曰：]                                                   |                                                              |
| ‘世尊!希有，得未曾有。’                                      | 「不可思議啊，大德！未曾有啊，大德！                         |
| 实是世尊之善说：                                             | 大德！這被世尊多麼善說：                                     |
| 1信仰清净心                                                  | 『凡他們以信，                                               |
| 2行施食之人                                                  | 以明淨心施與那個者，                                         |
| 4皆可得其食                                                  | 食物就服侍他，                                               |
| 3此世及后世                                                  | 在這個與下一個世間。                                         |
| 5是故调伏悭                                                  | 因此調伏慳吝後，                                             |
| 6善施克服垢                                                  | 征服垢者應該施與布施，                                       |
| 7功德乃人人                                                  | 福德在其他世間(來世)中，                                     |
| 8后世渡津头                                                  | 是有生命者們的依止。』                                       |
| 世尊，昔我是施者、施主，布施之赞叹者，名为世理王。           | 大德！從前，我是名叫悉梨國王的施與者、施主、布施的稱讚者，   |
| 世尊!我于四门，施与沙门、婆罗门、可怜之人众、旅行者、无宿之人等、求乞者。 | 大德！那個我的布施在四個門被施與沙門、婆羅門、貧民、旅人、流浪者、乞丐。 |
| 时，世尊!妃妾等来言我曰：                                    | 大德！那時，後宮婦女們來見我後，說這個：                     |
| ‘陛下之行施与，我等不行施与，我等亦依陛下得行施与之功德者，即何善焉?’ | 『陛下的布施被施與，無我們的布施被施與，如果我們也依陛下的支持施與布施、作福德，那就好了！』 |
| 世尊!我如是思之：我是施者、施主、施之赞叹者。我对于言‘我等亦应行布施’者，当作如何说耶? | 大德！我想這個：『我是施與者、施主、布施的稱讚者，當她們說：「我們要施與布施。」時，我能說什麼？』 |
| 世尊!如是我于第一门以与妃妾等，于此妃妾等行布施，超越我之施与。 | 大德！那第一個門我給後宮婦女們，在那裡，後宮婦女們的布施被施與，我的布施退減。 |
| 时，世尊!侍者之刹帝利等，来言我曰：                          | 大德！那時，隨侍的剎帝利們來見我後，說這個：                 |
| ‘陛下之施与，妃妾等之施与，我等不施与，我等亦依陛下得行施与之功德者，即何善焉?’ | 『陛下的布施被施與，後宮婦女們的布施被施與，無我們的布施被施與，如果我們也依陛下的支持施與布施、作福德，那就好了！』 |
| 世尊!我如是思之：我是施者、施主、施之赞叹者。对于言‘我等亦行布施’者，当如何说耶? | 大德！我想這個：『我是施與者、施主、布施的稱讚者，當他們說：「我們要施與布施。」時，我能說什麼？』 |
| 世尊!如是我于第二门，以与侍者之刹帝利等，彼等于此行布施，超越我之施与。 | 大德！那第二個門我給隨侍的剎帝利們，在那裡，隨侍的剎帝利們的布施被施與，我的布施退減。 |
| 时，世尊!军队来说我……[乃至]……                                | 大德！那時，軍人們來見我後，說這個：『陛下的布施被施與，後宮婦女們的布施被施與，隨侍的剎帝利們的布施被施與，無我們的布施被施與，如果我們也依陛下的支持施與布施、作福德，那就好了！』 |
|                                                              | 大德！我想這個：『我是施與者、施主、布施的稱讚者，當他們說：「我們要施與布施。」時，我能說什麼？』 |
| 世尊!如是我于第三门与军队，与彼等于此行布施，超越我之施与。  | 大德！那第三個門我給軍人們，在那裡，軍人們的布施被施與，我的布施退減。 |
| 时，世尊!婆罗门家主等来言我……[乃至]……                        | 大德！那時，婆羅門、屋主們來見我後，說這個：『陛下的布施被施與，後宮婦女們的布施被施與，隨侍的剎帝利們的布施被施與，軍人們的布施被施與，無我們的布施被施與，如果我們也依陛下的支持施與布施、作福德，那就好了！』 |
|                                                              | 大德！我想這個：『我是施與者、施主、布施的稱讚者，當他們說：「我們要施與布施。」時，我能說什麼？』 |
| 世尊!如是我于第四门，与婆罗门家主等，彼等于此行布施、超越我之施与。 | 大德！那第四個門我給婆羅門、屋主們，在那裡，婆羅門、屋主們的布施被施與，我的布施退減。 |
| 世尊!时，人人来说我曰：‘今陛下任何皆不施与。’                | 大德！那時，男子們來見我後，說這個：『現在無陛下的任何布施被施與。』 |
| 世尊!如是言云，我即向彼众人曰：‘然则，从城外诸州所收益之中，一半纳于宫庭，一半施与沙门、婆罗门、可怜之人众、旅行者、无宿之人、求乞者等。’ | 大德！在這麼說時，我對那些男子們說這個：『那樣的話，我說，凡收益在外國被生產者，請你們從那裡使一半進入內宮，一半就在那裡請你們對沙門、婆羅門、貧民、旅人、流浪者、乞丐施與布施。』 |
| 世尊，于是我如是长久所行之功德，如是长久所行之善，未达某终极。 | 大德！我不到達這樣長久所作福德、這樣長久所作諸善法的盡頭[，說]： |
| 有此诸功德，此诸功德之果，此诸之间当于天界[其无终极。]       | 『有這麼多福德。』或『有這麼多福德果報。』或『能使之這麼久地被存續於天界。』 |
| 世尊!希有、是最胜。                                          | 不可思議啊，大德！未曾有啊，大德！                           |
| 此依世尊实是善说：                                           | 大德！這被世尊多麼善說：                                     |
| 1信仰清净心                                                  | 『凡他們以信，                                               |
| 2行施食之人                                                  | 以明淨心施與那個者，                                         |
| 4皆可得其食                                                  | 食物就服侍他，                                               |
| 3此世及后世                                                  | 在這個與下一個世間。                                         |
| 5是故调伏悭                                                  | 因此調伏慳吝後，                                             |
| 6善施克服垢                                                  | 征服垢者應該施與布施，                                       |
| 7功德乃人人                                                  | 福德在其他世間(來世)中，                                     |
| 8后世渡津头                                                  | 是有生命者們的依止。』」                                     |
