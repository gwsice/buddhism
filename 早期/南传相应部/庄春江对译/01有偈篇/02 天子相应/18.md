| 第八 觉陀                                            | 18. 葛古踏經                                                 |
| 如是我闻，                                           | 被我這麼聽聞：                                               |
| 尔时，世尊，住沙计多安阇那林之鹿野苑。               | 有一次，世尊住在娑雞多城漆黑林的鹿園。                       |
| 时，觉陀天子于黎明，其胜光偏照安阇那林，往诣世尊处。 | 那時，在夜已深時，容色絕佳的葛古踏天子使整個漆黑林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                           | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之觉陀天子，向世尊言此曰：                   | 在一旁站立的葛古踏天子對世尊說這個：                         |
| ‘比丘!汝欢喜否?’                                     | 「沙門！你歡喜嗎？」                                         |
| [世尊曰]：                                           |                                                              |
| ‘友!得到何耶?’                                       | 「朋友！得到什麼後呢？」                                     |
| 天子曰：                                             |                                                              |
| ‘比丘，然而悲否?’                                    | 「沙門！那樣的話，你憂愁嗎？」                               |
| [世尊曰：]                                           |                                                              |
| ‘友!失落何耶?’                                       | 「朋友！失去什麼呢？」                                       |
| [天子曰：]                                           |                                                              |
| ‘比丘!然而汝亦不喜，亦不悲乎?’                       | 「沙門！那樣的話，你既不歡喜也不憂愁嗎？」                   |
| [世尊曰:]                                            |                                                              |
| ‘友!唯然!。’                                         | 「是的，朋友！」                                             |
| [天子：]                                             |                                                              |
| 1 比丘汝不悲                                         | 「比丘！希望你是無痛苦的，                                   |
| 2 汝亦不欢喜                                         | 希望歡喜不被發現，                                           |
| 3 唯独寂寞坐                                         | 希望對單獨坐的你，                                           |
| 4 不足思不着                                         | 不喜樂不撒布。」                                             |
| [世尊：]                                             |                                                              |
| 1 夜叉我不悲                                         | 「夜叉！我確是無痛苦的，                                     |
| 2 亦无有欢喜                                         | 還有歡喜不被發現，                                           |
| 3 唯独寂静坐                                         | 還有單獨坐的我，                                             |
| 4 无着思不足                                         | 不喜樂不撒布。」                                             |
| [天子：]                                             |                                                              |
| 1 比丘何不悲                                         | 「比丘！你如何是無痛苦的？                                   |
| 2 如何亦不喜                                         | 如何歡喜不被發現？                                           |
| 3 唯独寂寞坐                                         | 如何單獨坐的你，                                             |
| 4 不足思不着                                         | 不喜樂不撒布？」                                             |
| [世尊：]                                             |                                                              |
| 1有悲者有喜                                          | 「生起痛苦者確實有歡喜，                                     |
| 2有喜者有悲                                          | 生起歡喜者確實有痛苦，                                       |
| 3比丘无喜悲                                          | 無歡喜的、無痛苦的比丘，                                     |
| 4如是友当知                                          | 朋友！請你這麼知道。」                                       |
| [天子：]                                             |                                                              |
| 4实久我所见                                          | 「終於我確實看見，                                           |
| 3涅盘婆罗门                                          | 般涅槃的婆羅門：                                             |
| 1无喜亦无悲                                          | 無歡喜、無痛苦的比丘，                                       |
| 2超爱世比丘                                          | 已度脫世間中的執著。」                                       |
