| 第七 须梵                           | 17. 善梵經                           |
| 立于一面之须梵天子 ，向世尊唱偈曰： | 在一旁站立的善梵天子以偈頌對世尊說： |
| 1 此心常怖畏                        | 「這個心常被驚嚇，                   |
| 2 此意常颤栗                        | 這個意常被震驚，                     |
| 4 不起亦恐惧                        | 在未生起的苦難上，                   |
| 3 起时甚恐惧                        | 還有在已發生的上，                   |
| 5 若有免畏道                        | 如果有不被驚嚇的，                   |
| 6 愿请以指教                        | 請被詢問的你為我告知那個。」         |
| [世尊:]                             |                                      |
| 1 菩提分之外 2 勤修行之外           | 「非從覺[支]、苦行之外，             |
| 3 制诸根之外                        | 非從根的自制之外，                   |
| 4 一切放弃外                        | 非從一切的放捨之外，                 |
| 5 我不得窥见 6 众生之平安           | 我看見有生命者的平安。」             |
|                                     | [世尊]說這個……（中略）就在那裡消失。 |
