| 立于一面之难陀天子，于世尊前，唱此偈曰： | 在一旁站立的難陀天子在世尊面前說這些偈頌： |
| 1时过日夜移                              | 「時間流逝夜匆匆，                         |
| 2青春弃我等                              | 種種年齡次第地拋棄[人]，                   |
| 3观死此恐怖                              | 觀看這在死亡上的恐怖者，                   |
| 4齍乐积功德                              | 應該作帶來樂的福德。」                     |
| [世尊：]                                 |                                            |
