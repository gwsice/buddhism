| 第八 难提毗舍罗                          | 28. 廣歡喜經                                 |
| 立于一面之难提毗舍罗天子，向世尊语偈曰： | 在一旁站立的廣歡喜天子在世尊面前說這些偈頌： |
| 1四轮九门孔                              | 「四輪與九門，                               |
| 2污秽满贪欲                              | 被貪充滿、結縛，                             |
| 3乃是不净性                              | 污泥所生，                                   |
| 4大雄从如何 5有此之出口                  | 大英雄！要如何行去[離開-㊟]？」              |
| [世尊：]                                 |                                              |
| 2乃至绳与网                              | 「切斷皮帶與細繩，                           |
| 1以断恶欲贪                              | 及惡欲求與貪後，                             |
| 3拔弃渴爱根                              | 連根拔除渴愛後，                             |
| 4如是有出口                              | 這樣將有行去。」                             |
