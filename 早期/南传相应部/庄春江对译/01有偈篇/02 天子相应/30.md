| 第十 种种之外道师                                            | 30. 種種外道弟子經                                           |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时世尊住王舍城竹林栗鼠养饵处。                             | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 时，众多之种种外道弟子之天子等，                             | 那時，在夜已深時，容色絕佳的眾多種種外道弟子的天子：         |
| 阿舍摩、舍波利、任迦、阿考吒迦、吠坦婆利、摩纳婆伽弥耶，于黎明往诣世尊处，其胜光偏照竹林。 | 阿色麼、色喝哩、尼迦、阿勾得迦、威格玻哩、麻那哇格米雅使整個竹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                                   | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之阿舍摩天子，关于富兰那迦叶，于世尊前，唱此偈曰．   | 在一旁站立的阿色麼天子關於富蘭那迦葉在世尊的面前說這偈頌：   |
| 1世间之割杀                                                  | 「這裡在砍殺中，                                             |
| 2以及害与夺                                                  | 在殺戮強奪中-迦葉，                                          |
| 3迦叶谓非恶                                                  | 不認為是惡的，                                               |
| 4不见自功德                                                  | 又或是自己的福德，                                           |
| 5彼述实自信                                                  | 他確實告知安心，                                             |
| 6相应为师尊                                                  | 大師值得尊敬。」                                             |
| 时舍波利天子，关于末伽梨瞿舍罗，于世尊前，唱此偈曰：         | 那時，色喝哩天子關於末迦利瞿舍羅在世尊的面前說這偈頌：       |
| 1苦行与厌离 2以善自制伏                                      | 「以苦行與嫌惡成為自己善防護者，                             |
| 3与人语止争 4离于有罪语                                      | 捨斷與人諍論的言語後，                                       |
| 5平等于语实                                                  | 離含不實者、實語者，                                         |
| 6何以彼如是 7不为其恶耶                                      | 像這樣者確實不作惡的。」                                     |
| 时，任迦天子，关于尼乾陀若提子，于世尊前，唱此偈曰：         | 那時，尼迦天子關於尼乾陀若提子在世尊的面前說這偈頌：         |
| 1厌离巧比丘                                                  | 「比丘是謹慎者、審慎者，                                     |
| 2制御四种身                                                  | 四禁戒善防護者，                                             |
| 3开显彼见闻                                                  | 他告知所見與所聞，                                           |
| 4彼何无罪过                                                  | 確實不會是罪行者。」                                         |
| 时，阿考吒迦天子，关于种种之外道师，于世尊前，唱此偈曰：     | 那時，阿勾得迦天子關於種種外道在世尊的面前說這偈頌：         |
| 1据陀迦栴延 2乃至尼乾陀                                      | 「浮陀迦[旃延]、葛低亞那、尼乾陀，                           |
| 3又此末迦梨 4以及富兰那                                      | 以及凡這末迦利、富蘭那，                                     |
| 5为人人之师 6达沙门果人                                      | 群眾的大師已到達沙門身分，                                   |
| 7如何于彼等 8远离善人焉                                      | 他們確實離善人不遠。」                                       |
| 时，吠坦婆利天子，以偈答阿考吒迦天子曰：                     | 那時，威格玻哩天子以偈頌回答阿勾得迦天子：                   |
| 1号吼卑野干 2毕竟是野干                                      | 「卑微的狐狼以一起行，                                       |
| 3不管于如何 4难等于狮子                                      | 狐狼任何時候都不是等同獅子者，                               |
| 5裸形而妄语 6以为众之师                                      | 裸體、妄語的群眾之大師，                                     |
| 7疑讶之行为 8难等于善人                                      | 引起懷疑的所行者與善者是不相同的。」                         |
| 时，恶魔波旬，随从吠坦婆利天子而入，于世尊前，唱此偈曰．     | 那時，魔波旬佔有威格玻哩天子後，在世尊的面前說這偈頌：       |
| 1苦行与厌离                                                  | 「熱心投入於苦行與嫌惡者，                                   |
| 2守远离生活                                                  | 使遠離被守護者，                                             |
| 3物质入于心                                                  | 以及凡在諸色上住立者，                                       |
| 4以乐喜天界                                                  | 在天界大歡喜者，                                             |
| 6彼等正教诲                                                  | 他們確實正確地教誡：                                         |
| 5不导人他界                                                  | 對其他世界不免一死的人。」                                   |
| 时，世尊知此恶魔波旬，以偈答恶魔波旬曰：                     | 那時，世尊知道：「這是魔波旬。」後，以偈頌回應魔：           |
| 2不管任何色 1此世及彼世                                      | 「凡任何色在這裡或在他世，                                   |
| 3光显辉中空 4此等皆是实$$\color{red}（这一句没有吗？）$$     | 以及凡在空中美麗容色者，                                     |
| 5那牟尼$$\color{red}（牟尼还是恶魔？）$$所赞                 | 惡魔！那一切就被你稱讚，                                     |
| 6如对鱼于饵 7因为是不杀 8而可令投弃                          | 如為了魚的殺害投擲的餌。」                                   |
| 时，摩纳婆伽弥耶天子，关于世尊，于世尊前，唱此偈曰：         | 那時，麻那哇格米雅天子關於世尊在世尊的面前說這偈頌：         |
| 1王舍城诸山 2尾布罗最胜                                      | 「毘富羅在王舍城中，被說是最勝的山，                         |
| 3雪山之诸山 白山为最胜                                       | 謝達是喜馬拉雅山中最勝的，                                   |
| 5行于空中者 6太阳为最胜                                      | 天空行走者中是太陽。                                         |
| 7海为水中胜                                                  | 大海是海洋中最勝的，                                         |
| 8月为星中胜                                                  | 而星宿中是月亮，                                             |
| 9世界及天界                                                  | 包括天的世間中，                                             |
| 10云佛是第一                                                 | 佛陀被說是最高的。」                                         |
