| 元亨寺                                                   | 庄春江                                                       |
| -------------------------------------------------------- | ------------------------------------------------------------ |
| 第十 日天子                                              | 10. 日經                                                     |
|                                                          | 起源於舍衛城。                                               |
| 其时，阿修罗王罗喉又捕日天子，                           | 當時，日天子被羅侯阿修羅王抓住。                             |
| 日天子忆念佛陀，其时唱此偈曰：                           | 那時，隨念(回憶)世尊的日天子在那時候說這個偈頌：             |
| 2 我归依于卿                                             | 「願禮敬你，                                                 |
| 1 佛陀大雄者                                             | 佛陀！英雄！                                                 |
| 3 卿障皆解脱                                             | 你於一切處已解脫，                                           |
| 4 我今落障碍                                             | 我有行道的阻礙，                                             |
| 5 然则从此我 6 置于归依处                                | 為了那個願你成為我的歸依。」                                 |
| 时，世尊关于日天子，以偈向阿修罗王罗喉曰：               | 那時，世尊以偈頌對羅侯阿修羅王說關於日天子：                 |
| 1 日天子今乃 2 归依于如来 3 应供正觉者                   | 「日已歸依，如來、阿羅漢，                                   |
| 4 罗喉以放日                                             | 羅侯！請你釋放日，                                           |
| 5 佛陀怜世间                                             | 諸佛是世間的憐愍者。                                         |
| 6 彼耀默闇中                                             | 凡在黑暗闇黑中帶來光者：                                     |
| 8 炽燃炎热火 7 偏照而周圆                                | 偉大火燄圓輪的日(毘盧遮那)，                                 |
| 10 彼之飞空行 9 罗喉不得吞                               | 羅侯！在虛空行走者不要吞掉日，                               |
| 11 罗喉以放我 12 弟子日天子                              | 羅侯！請你釋放我的人。」                                     |
| 时，阿修罗王罗喉以放日天子，即颤栗而诣阿修罗王吠波质底。 | 時，羅侯阿修羅王釋放日天子後，形色匆匆地去見毘摩質多阿修羅王。 |
| 诣已，恐怖，毛发竖立，而立于一面。                       | 抵達後，驚怖、生起身毛豎立地在一旁站立。                     |
| 阿修罗王吠波质底对立于一面之阿修罗王罗喉语偈曰：         | 在一旁站立的毘摩質多阿修羅王以偈頌對羅侯阿修羅王說：         |
| 1 罗喉何怖惧                                             | 「羅侯！為何你就匆忙地，                                     |
| 2 为放日者乎                                             | 釋放日呢？                                                   |
| 3 汝今惧颤来                                             | 形色驚慌地到來後，                                           |
| 4 何恐而立此                                             | 你為何就驚恐地站著？」                                       |
| [罗喉：]                                                 |                                                              |
| 3 我头割为七                                             | 「我的頭會七片地破裂，                                       |
| 4 不得生安乐                                             | 活著時不會得到安樂，                                         |
| 1 我畏佛陀偈                                             | 在佛陀誦偈頌時，                                             |
| 2 若我不放日                                             | 如果沒釋放日。」                                             |
