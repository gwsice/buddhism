| 第六 迦摩陀                         | 6. 葛麼大經                          |
|                                     | 起源於舍衛城。                       |
| 立于一面之迦摩陀天子，以此白世尊曰: | 在一旁站立的葛麼大天子對世尊說這個： |
| ‘世尊，是者难为。                   | 「世尊！難做的，                     |
| 世尊，是甚难。’                     | 世尊！極難做的。」                   |
| (世尊曰：迦摩陀!)                   | (世尊：「葛麼大！」)                 |
| 1 难为彼等为                        | 「他們也做難作的：                   |
| 2 有学而依戒                        | 戒等持的有學，                       |
| 3 寂静又确立 4 于出家之人           | 對自我住立的進入無家者，             |
| 5 致安乐知足                        | 成為滿足者、帶來樂者。」             |
| ‘世尊!知足甚难得。’                 | 「世尊！難得到的，即：滿足者。」     |
| (世尊曰：迦摩陀!)                   | (世尊：「葛麼大！」)                 |
| 1 难得彼等得                        | 「他們也得到難得到的：               |
| 2 乐心寂静人                        | 樂於心寂靜者，                       |
| 3 其心日或夜                        | 日與夜，                             |
| 4 悦乐于修习                        | 他們的意(心)樂於修習者。」           |
| ‘世尊!心实难静。’                   | 「世尊！難集中(定)的，即：心。」     |
| (世尊曰：迦摩陀!)                   | (世尊：「葛麼大！」)                 |
| 1 难静彼等静                        | 「他們也集中難集中的，               |
| 2 诸根寂静乐                        | 樂於諸根寂靜者，                     |
| 3 彼破死魔网                        | 他們切斷死神之網後，                 |
| 4 迦摩陀天子 5 为圣者所行           | 葛麼大！聖者們走。」                 |
| ‘世尊!此道崄难行。’                 | 「世尊！道路是難走的、不平坦的。」   |
| [世尊：]                            |                                      |
| 1 虽崄虽难行                        | 「在難走的、不平坦的上，             |
| 2 迦摩陀天子 3 圣者乃乐行           | 葛麼大！聖者們也走，                 |
| 4 非圣于崄道                        | 非聖者們在難走的、不平坦的道路上，   |
| 5 彼等头倒下                        | 頭向下地倒下，                       |
| 6 圣者之道平                        | 聖者們的道路是平坦的，               |
| 8 圣者乃乐行 7 不分崄与平           | 因為聖者們在不平坦中是平坦的。」     |
