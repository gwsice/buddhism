| 第二 差摩                                | 22. 安穩經                                 |
| 立于一面之差摩天子，于世尊前，唱此偈曰： | 在一旁站立的安穩天子在世尊面前說這些偈頌： |
| 1鲁钝无智慧                              | 「劣智慧的愚者們實行：                     |
| 2行为如自敌                              | 如以自己為敵人，                           |
| 3以作诸恶业                              | 做惡業者們，                               |
| 4以结苦痛果                              | 有該辛辣結果。                             |
| 5不行其善业                              | 那是不好的所作業：                         |
| 6终为而苦恼                              | 做該者後他後悔，                           |
| 7咽鸣泪哭泣                              | 淚流滿面地哭泣者，                         |
| 8以受其苦果                              | 承受該者的果報。                           |
| 9若行其善业                              | 但那是好的所作業：                         |
| 10行讫无苦恼                             | 做該者後他不後悔，                         |
| 11欢喜心意乐                             | 喜悅的快樂者，                             |
| 12以受其乐果                             | 承受該者的果報。[」]                       |
| 15而作行准备                             | 「他應該提前就做：                         |
| 13为于自己知                             | 凡會知道對自己有利益的，                   |
| 16如是不若彼 17车力者之思                | 不以車夫的思惟：                           |
| 14智者及贤者 18勇猛精进之                | 考量後明智者應該努力。                     |
| 19宛如车力者                             | 如車夫，                                   |
| 20离于平大道                             | 捨棄整平的、平坦的大道後，                 |
| 21入于不平路                             | 登上不平坦的道路後，                       |
| 22毁轴如沉思                             | 就沈思斷裂的車軸。                         |
| 23如是法不进                             | 像這樣離開法後，                           |
| 24从于不法故                             | 順從非法後，                               |
| 25怠者到魔口                             | 到達死亡口的愚鈍者，                       |
| 26如毁轴沉思                             | 就沈思斷裂的車軸。」                       |
