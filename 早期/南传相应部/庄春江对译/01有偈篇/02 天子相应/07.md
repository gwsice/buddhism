| 第七 般阇罗旃陀                                | 7. 般闍羅健達經                                  |
|                                                | 起源於舍衛城。                                   |
| 立于一面之般阇罗旃陀天子，于世尊前，唱此偈曰： | 在一旁站立的般闍羅健達天子在世尊的面前說這偈頌： |
| 2 障中知余地                                   | 「在障礙中確實有空間，                           |
| 1 有大智慧人                                   | 廣智慧者發現，                                   |
| 5 佛陀知禅定                                   | 凡佛陀自覺禪，                                   |
| 3 无有所着者 4 无比之圣者                      | 獨處的人牛王、牟尼。」                           |
| (世尊曰：般阇罗旃陀!)                          | (世尊：「般闍羅健達！」)                         |
| 1 彼等于障中                                   | 「在障礙中或甚至他們發現，                       |
| 2 知到涅盘法                                   | 為了到達涅槃的法，                               |
| 3 以得正念人                                   | 凡得到念，                                       |
| 4 善正心寂静                                   | 他們是完全善入定者。」                           |
