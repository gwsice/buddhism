| 第九 月天子                                                  | 9. 月經                                                      |
| [尔时，世尊]住舍卫城……。                                     | 起源於舍衛城。                                               |
| 其时，月天子被阿修罗王罗喉所捕。                             | 當時，月天子被羅侯阿修羅王抓住。                             |
| 月天子乃忆念世尊，而唱此偈曰：                               | 那時，隨念(回憶)世尊的月天子在那時說這個偈頌：               |
| 1 我归依于卿 2 佛陀大雄者                                    | 「願禮敬你，佛陀！英雄！                                     |
| 3 卿障皆解脱                                                 | 你於一切處已解脫，                                           |
| 4 我今落障碍                                                 | 我有行道的阻礙，                                             |
| 5 然则从此我 6 置于归依处                                    | 為了那個願你成為我的歸依。」                                 |
| 时，世尊关于月天子，以偈向阿修罗王罗喉曰：                   | 那時，世尊以偈頌對羅侯阿修羅王說關於月天子：                 |
| 1 月天子今乃 2 归依于如来 3 应供正觉者                       | 「月已歸依，如來、阿羅漢，                                   |
| 4 罗喉以放月                                                 | 羅侯！請你釋放月，                                           |
| 5 诸佛怜世间                                                 | 諸佛是世間的憐愍者。」                                       |
| 时，阿修罗王罗喉以放月天子，有所顾虑，而诣阿修罗王吠波质底。 | 那時，羅侯阿修羅王釋放月天子後，形色匆匆地去見毘摩質多阿修羅王。 |
| 诣已，恐怖，毛发竖立，立于一面，                             | 抵達後，驚怖、生起身毛豎立地在一旁站立。                     |
| 阿修罗王吠波质底，对于立于一面之阿修罗王罗喉说偈曰．         | 在一旁站立的毘摩質多阿修羅王以偈頌對羅侯阿修羅王說：         |
| 1 罗喉何恐怖                                                 | 「羅侯！為何你就匆忙地，                                     |
| 2 为放月者乎                                                 | 釋放月呢？                                                   |
| 3 汝今惧颤来                                                 | 形色驚慌地到來後，                                           |
| 4 惧何而立此                                                 | 你為何就驚恐地站著？」                                       |
| [罗喉：]                                                     |                                                              |
| 3 我头割为七                                                 | 「我的頭會七片地破裂，                                       |
| 4 不得生安乐                                                 | 活著時不會得到安樂，                                         |
| 1 我惧佛陀偈                                                 | 在佛陀誦偈頌時，                                             |
| 2 若我不放月                                                 | 如果沒釋放月。」                                             |
