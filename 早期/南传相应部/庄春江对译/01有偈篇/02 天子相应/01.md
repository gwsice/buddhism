| 元亨寺                                              | 庄春江                                                       |
| --------------------------------------------------- | ------------------------------------------------------------ |
| 第一 迦叶品                                         | 1.第一品                                                     |
| 第一 迦叶(其一)                                     | 1. 迦葉經第一                                                |
| 如是我闻。                                          | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。                    | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 其时，迦叶天子 于黎明，其胜光偏照只园，往诣世尊处。 | 那時，在夜已深時，容色絕佳的迦葉天子使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                          | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之迦叶天子，向世尊谓曰：                    | 在一旁站立的迦葉天子對世尊說這個：                           |
| ‘世尊 请以比丘之教，                                | 「世尊說明比丘，                                             |
| 开示比丘及我等。’                                   | 但無對比丘的教誡。」                                         |
| ‘迦叶!善哉!                                         | 「迦葉！那樣的話，                                           |
| 然则当为汝说能起之事。’                             | 就這情況請你說明。」                                         |
| 1 以修说微妙                                        | 「他應該學習被善說的，                                       |
| 2 以修沙门行                                        | 與沙門的訓練，                                               |
| 3 独住于一座                                        | 單獨座位與孤獨處，                                           |
| 4 静心以修法                                        | 以及心的寂靜。」                                             |
| 迦叶天子作如是言，请大师嘉赏。                      | 迦葉天子說這個，大師是認可者。                               |
| 迦叶天子知受大师之嘉赏，                            | 那時，迦葉天子[想]：「大師是我的認可者。」                   |
| 礼敬世尊，右绕而形没于其处。                        | 向世尊問訊、作右繞後，就在那裡消失。                         |
