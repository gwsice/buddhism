| 第八 多耶那                                                  | 8. 德亞那經                                                  |
|                                                              | 起源於舍衛城。                                               |
| 时，原本是外道师之多耶那天子 ，于黎明其胜光偏照只园，往诣世尊处。 | 那時，在夜已深時，容色絕佳的德亞那天子，之前為宗派始祖，使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。                                   | 抵達後，向世尊問訊後，在一旁站立。                           |
| 立于一面之多耶那天子，于世尊前，唱此偈曰：                   | 在一旁站立的德亞那天子在世尊的面前說這些偈頌：               |
| 1 婆罗门断流                                                 | 「努力後切斷流，婆羅門！                                     |
| 2 精进灭爱欲                                                 | 請你除去諸欲，                                               |
| 3 牟尼未离欲                                                 | 未捨斷諸欲後，                                               |
| 4 不入于禅定                                                 | 牟尼不往生單一性。                                           |
| 5 欲作应作者                                                 | 如果以應該做的他做，                                         |
| 6 精进而行此                                                 | 應該堅固地努力，                                             |
| 7 出家若疏漫                                                 | 因為鬆弛的遊行者，                                           |
| 8 愈益散尘垢                                                 | 散播更多的塵。                                               |
| 9 不为胜恶行                                                 | 惡作不被作是比較好的，                                       |
| 10 行恶后受苦                                                | 惡作之後他苦惱，                                             |
| 11 行善者为胜                                                | 善作被作是比較好的，                                         |
| 12 行善无有苦                                                | 作那個後不後悔。                                             |
| 13 宛如握恶草                                                | 如茅草被惡捉取，                                             |
| 14 因之手受伤                                                | 就割手，                                                     |
| 15 沙门生活恶                                                | 惡執取沙門身分者，                                           |
| 16 因之入奈落                                                | 拉到地獄。                                                   |
| 17 疏漫所作业                                                | 凡任何鬆弛的行為，                                           |
| 18 污染于禁戒                                                | 以及凡被污染的誓戒(禁制)，                                   |
| 19 怀疑于梵行                                                | 引起懷疑的梵行，                                             |
| 20 无有随大果                                                | 那個沒有大果。」                                             |
| 多耶那天子作此言已，礼敬、右绕世尊，体形没于此处。           | 德亞那天子說這個，說這個後，德亞那天子向世尊問訊、作右繞後，就在那裡消失。 |
| 时，世尊其夜过后，呼[集]比丘等。                             | 那時，那夜過後，世尊召喚比丘們：                             |
| ‘诸比丘!此夜名为多耶那，本是外道师之天子，于黎明时，其胜光偏照只园。 | 「比丘們！這夜，在夜已深時，容色絕佳的德亞那天子，之前為宗派始祖，使整個祇樹林發光後，來見我。 |
| 诣佛处，诣已，礼敬世尊、立于一面。                           | 抵達後，向我問訊後，在一旁站立。                             |
| 立于一面[之天子]，于佛前唱此偈曰：                           | 比丘們！在一旁站立的德亞那天子在我面前說這些偈頌：           |
| 1 婆罗门断流                                                 | 「努力後切斷流，婆羅門！                                     |
| 2 精进灭爱欲                                                 | 請你除去諸欲，                                               |
| 3 牟尼未离欲                                                 | 未捨斷諸欲後，                                               |
| 4 不入于禅定                                                 | 牟尼不往生單一性。                                           |
| 5 欲作应作者                                                 | 如果應該做、這個被做，                                       |
| 6 精进而行此                                                 | 堅固地努力這個，                                             |
| 7 出家若疏漫                                                 | 因為鬆弛的遊行者，                                           |
| 8 愈益散尘垢                                                 | 散播更多的塵。                                               |
| 9 不为胜恶行                                                 | 不做惡作者是更好的，                                         |
| 10 行恶后受苦                                                | 惡作之後苦惱，                                               |
| 11 行善者为胜                                                | 而做善作者是更好的，                                         |
| 12 行善无有苦                                                | 作該者後不後悔(隨苦惱)。                                     |
| 13 宛如握恶草                                                | 如茅草被惡捉取，                                             |
| 14 因之手受伤                                                | 就割手，                                                     |
| 15 沙门生活恶                                                | 惡執取沙門身分者，                                           |
| 16 因之入奈落                                                | 拉到地獄。                                                   |
| 17 疏漫所作业                                                | 凡任何鬆弛的行為，                                           |
| 18 污染于禁戒                                                | 以及凡被污染的誓戒(禁制)，                                   |
| 19 怀疑于梵行                                                | 可疑的梵行，                                                 |
| 20 无有随大果                                                | 那個沒有大果。」                                             |
| 诸比丘!多耶那天子作此言已，礼敬、围绕世尊，形体没于其处。    | 德亞那天子說這個，說這個後，德亞那天子向我問訊、作右繞後，就在那裡消失。 |
| 诸比丘!应暗[诵]多耶那偈。                                    | 比丘們！請你們學習德亞那天子的偈頌，                         |
|                                                              | 比丘們！請你們學得德亞那天子的偈頌，                         |
|                                                              | 比丘們！請你們憶持德亞那天子的偈頌，                         |
| 诸比丘!多耶那偈具足利义，属最初之梵行。’                     | 比丘們！德亞那天子的偈頌是伴隨利益的梵行基礎的。」           |
