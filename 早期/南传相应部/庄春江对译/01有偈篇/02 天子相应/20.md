| 元亨寺                                                       | 庄春江                                                       |

| 第十 给孤独                                                  | 20. 給孤獨經                                                 |
| 立于一面之给孤独天子，于世尊前，唱此偈曰：                   | 在一旁站立的給孤獨天子在世尊的面前說這些偈頌：               |
| 1此乃彼只园                                                  | 「這裡確實是那個祇樹林，                                     |
| 2圣僧伽住处                                                  | 仙人僧團經常來往的，                                         |
| 3法王请住此                                                  | 被法王居住，                                                 |
| 4思念我生喜                                                  | 我有喜的產生。                                               |
| 5善意智法定                                                  | 行為、明與法，                                               |
| 6以及戒正命                                                  | 戒、最上的活命，                                             |
| 7依此人清净                                                  | 不免一死的人們以這些變純淨，                                 |
| 8又依姓氏富 9非得于清净                                      | 非以種姓或以財產。                                           |
| 10是故贤智者                                                 | 因此確實賢智的人，                                           |
| 11以思自己利                                                 | 自己利益的看見者，                                           |
| 12并思择正法                                                 | 應該如理檢擇法，                                             |
| 13如是其清净                                                 | 這樣在那裡變成清淨。                                         |
| 16犹如舍利弗 14依于戒智慧                                    | 如舍利弗以慧，                                               |
| 15乃至于寂静                                                 | 以戒以寂靜，                                                 |
| 17比丘到彼岸                                                 | 凡即使到彼岸的比丘，                                         |
| 18应当是最胜                                                 | 最高者會是這樣程度的。」                                     |
| 给孤独天子言此已、敬礼、右绕世尊、体形没于其处。             | 給孤獨天子說這個，說這個後，向世尊問訊、作右繞後，就在那裡消失。 |
| 时，世尊于其夜过后，集比丘等：                               | 那時，那夜過後，世尊召喚比丘們：                             |
| ‘诸比丘!此夜有一天子，其胜光偏照只园，于黎明诣我住处。       | 「比丘們！這夜，在夜已深時，容色絕佳的某位天子使整個祇樹林發光後，來見我。 |
| 诣已，礼敬我而立于一面，                                     | 抵達後，向我問訊後，在一旁站立。                             |
| 比丘等!立于一面其天子、于我面前，唱此偈曰：                  | 比丘們！在一旁站立的那位天子在我面前說這些偈頌：             |
| 1此乃彼只园                                                  | 『這裡確實是那個祇樹林，                                     |
| 2圣僧伽住处                                                  | 仙人僧團經常來往的，                                         |
| 3法王请住此                                                  | 被法王居住，                                                 |
| 4思念我生喜                                                  | 我有喜的產生。                                               |
| 5善意智法定                                                  | 行為、明與法，                                               |
| 6以及戒正命                                                  | 戒、最上的活命，                                             |
| 7依此人清净                                                  | 不免一死的人們以這些變純淨，                                 |
| 8又依姓氏富 9非得于清净                                      | 非以種姓或以財產。                                           |
| 10是故贤智者                                                 | 因此確實賢智的人，                                           |
| 11以思自己利                                                 | 自己利益的看見者，                                           |
| 12并思择正法                                                 | 應該如理檢擇法，                                             |
| 13如是其清净                                                 | 這樣在那裡變成清淨。                                         |
| 16犹如舍利弗 14依于戒智慧                                    | 舍利弗就以慧，                                               |
| 15乃至于寂静                                                 | 以戒與以寂靜，                                               |
| 17比丘到彼岸                                                 | 凡即使到彼岸的比丘，                                         |
| 18应当是最胜                                                 | 最高者會是這樣程度的。』                                     |
| 比丘等!其天子作此语已，敬礼、右绕于我，体形没于其处。        | 那位天子說這個，說這個後，向我問訊、作右繞後，就在那裡消失。」 |
| 如是语已，尊者阿难，以此告世尊曰：                           | 在這麼說時，尊者阿難對世尊說這個：                           |
| ‘世尊，或许彼[天子]，乃给孤独天子。给孤独长者，信乐于尊者舍利弗。’ | 「大德！他必定是給孤獨天子，屋主給孤獨對尊者舍利弗是極淨信者。」 |
| ‘善哉!善哉阿难!只要依寻求终可得，即依汝可使得。              | 「阿難！好！好！凡推論之所及，阿難！你已到達，               |
| 阿难!其实乃给孤独天子。’                                     | 阿難！他確實是給孤獨天子。」                                 |
