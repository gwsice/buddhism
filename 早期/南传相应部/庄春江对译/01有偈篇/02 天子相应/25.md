| 第五 姜睹                                                    | 25. 遮堵經                                                   |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，众多比丘等，住于拘萨罗国雪山侧之森林小屋。掉举而高慢、多辩饶舌、忘念、不正知、心不安静、散乱、不制伏诸根。 | 有一次，掉舉的、傲慢的、浮躁的、饒舌的、言語散亂的、念已忘失的、不正知的、不得定的、散亂心的、根不控制的眾多比丘住在憍薩羅國喜馬拉雅山山腹的林野小屋中。 |
| 时，姜睹天子，于其布萨十五日，诣其比丘等[处]，               | 那時，遮堵天子在十五那個布薩日去見那些比丘。                 |
| 诣已，向比丘等言偈曰：                                       | 抵達後，以偈頌對那些比丘說：                                 |
| 2弟子比丘等 3而住于安乐                                      | 「之前比丘們是快樂生活者：                                   |
| 1往昔彼瞿昙                                                  | 喬達摩的弟子們，                                             |
| 4乞食无求心                                                  | 無欲求的食物尋求者，                                         |
| 5无求之心住                                                  | 無欲求的臥坐處[尋求者]，                                     |
| 6知世之无常                                                  | 知道世間中無常性後，                                         |
| 7彼等苦恼尽                                                  | 他們作苦的終結。                                             |
| 8今之比丘等 9恶向于自己                                      | 置(作)自己為難養者後，                                       |
| 10如村长于村                                                 | 在諸村落中如村長們，                                         |
| 12食餐而寝卧                                                 | 一再吃後他們躺臥，                                           |
| 11心夺他家富                                                 | 在諸他人家中被迷昏頭。                                       |
| 13僧伽无合掌                                                 | 對僧團作合掌後，                                             |
| 14此有人礼我                                                 | 這裡我說某些人，                                             |
| 15被弃无主人                                                 | 他們是被拋棄者、無庇護者，                                   |
| 16宛如于死尸                                                 | 就像那樣如那些亡者。                                         |
| 17对放逸之人                                                 | 凡住於放逸者們，                                             |
| 18我乃以语彼                                                 | 關於他們被我說，                                             |
| 19住不放逸者                                                 | 凡住於不放逸者們，                                           |
| 20我乃行归依                                                 | 我要對他們作禮敬。                                           |
