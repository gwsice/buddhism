| 第九 憍陈如                                                  | 9.憍陳如經                                                   |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 时，尊者阿若憍陈如，其久始诣世尊处。                         | 那時，尊者阿若憍陳如隔了很久後去見世尊。                     |
| 诣而五体投地于世尊足，以口接吻世尊之足，手磨而呼自名曰：     | 抵達後，以頭落在世尊的腳上，並以嘴遍吻世尊的腳，又以手遍擦拭，以及告知名字： |
| ‘世尊!我是憍陈如；善逝!我是憍陈如。’                         | 「世尊！我是憍陳如，善逝！我是憍陳如。」                     |
| 时，尊者婆耆沙如是思念：                                     | 那時，尊者婆耆舍想這個：                                     |
| ‘此尊者阿若憍陈如，其久始诣世尊处，                          | 「這位尊者阿若憍陳如隔了很久後去見世尊。                     |
| 诣而五体投地于世尊之足，以口接吻世尊之足，手磨自呼名曰：     | 抵達後，以頭落在世尊的腳上，並以嘴遍吻世尊的腳，又以手遍擦拭，以及告知名字： |
| ‘世尊!我是憍陈如；善逝!我是憍陈如。’                         | 『世尊！我是憍陳如，善逝！我是憍陳如。』                     |
| 今尊者阿若憍陈如，于世尊面前，我以适当之偈赞叹。’            | 讓我在世尊的面前以適合的偈頌稱讚尊者阿若憍陳如。」           |
| 时，尊者婆耆沙，即从座起，一肩着衣，合掌礼世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念；善逝，我涌思念。’                            | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙!请说。’                                      | 「婆耆舍！請你說明。」世尊說。                               |
| 时，尊者婆耆沙对尊者阿若憍陈如，于世尊面前，以适当之偈赞曰： | 那時，尊者婆耆舍在世尊的面前以適合的偈頌稱讚尊者阿若憍陳如： |
| 1上座憍陈如 2随顺佛所证                                      | 「那位佛陀隨覺的上座，                                       |
| 3虔诚出离者                                                  | 極精勤的憍陳如，                                             |
| 4屡屡快乐于                                                  | 是安樂的住處，                                               |
| 5远离之乐住                                                  | 經常獨處的利得者。                                           |
| 7弟子之所达                                                  | 凡應該被弟子達成的：                                         |
| 6行如师之教                                                  | 以大師的教說作的，                                           |
| 9一切以达此                                                  | 那一切被他達到：                                             |
| 8学于不放逸                                                  | 對不放逸的學習者。                                           |
| 10有具大威力 11到达于三明                                    | 大威力者、三明者，                                           |
| 12巧于他心智                                                 | 知他心的熟練者，                                             |
| 13法嗣憍陈如                                                 | 憍陳如-佛陀的繼承者，                                        |
| 14今头礼师足                                                 | 在大師的腳上禮拜。」                                         |
