| 第三 轻蔑温和者                                              | 3. 美善者經                                                  |
| 尔时，尊者婆耆沙与乃师尊者尼俱律陀劫波，共住于阿腊毗之阿伽罗婆奢提[庙]。 | 有一次，尊者婆耆舍與尊者尼拘律葛波和尚，共住在阿羅婆的阿格羅婆塔廟。 |
| 其时，尊者婆耆沙以夸自己之顿才，轻蔑其他温和比丘等。         | 當時，尊者婆耆舍以自己的辯才輕蔑其他美善比丘們。             |
| 时，尊者婆耆沙生如是思念：                                   | 那時，尊者婆耆舍想這個：                                     |
|                                                              | 「確實是我的無利得，確實不是我的利得；                       |
|                                                              | 確實是我的惡得的，確實不是我的善得的：                       |
| ‘以夸自己之顿才，轻蔑其他温和比丘等。                        | 我以自己的辯才輕蔑其他美善比丘們。」                         |
| 对我真是甚悲痛。’                                            |                                                              |
| 如是尊者婆耆沙，自己省悔，其时唱此偈曰：                     | 那時，尊者婆耆舍就以自己對自己的懊悔生起後，那時候說這些偈頌： |
| 1舍慢瞿昙徒                                                  | 「喬達摩！請你捨斷慢，                                       |
| 2无余离慢道                                                  | 以及請你無殘餘地捨斷慢的道路，                               |
| 3昏醉于慢道                                                  | 在慢的道路上，                                               |
| 4悔之焉不久                                                  | 癡迷的你長久是後悔者。                                       |
| 5覆覆于慢行                                                  | 被詆毀塗污的人們，                                           |
| 6人人堕地狱                                                  | 被慢殺害者們跌落地獄，                                       |
| 8长夜于悲痛                                                  | 人們長久地憂愁：                                             |
| 7慢堕地狱者                                                  | 往生地獄的被慢殺害者們。                                     |
| 10正行者比丘 11何时皆不悲                                    | 比丘任何時候確實都不憂愁：                                   |
| 9道之胜利者                                                  | 道的勝利者、正行者，                                         |
| 12以受誉安乐                                                 | 經驗名聲與安樂，                                             |
| 13彼实法乐者                                                 | 他們說那位自我努力者是『法的看見者』。                       |
| 14于世不固陋                                                 | 因此這裡不頑固者、勤奮者，                                   |
| 15精进离盖障                                                 | 捨斷諸蓋後成為清淨者，                                       |
| 16清拂无余慢                                                 | 而無餘地捨斷慢後，                                           |
| 17依智慧灭尽 18烦恼寂静者                                    | 成為以明作終結的寂靜者。」                                   |
