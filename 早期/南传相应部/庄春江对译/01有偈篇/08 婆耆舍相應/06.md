| 第六 舍利弗                                                  | 6.舍利弗經                                                   |
| 尔时，尊者舍利弗住舍卫城只树给孤独园。                       | 有一次，尊者舍利弗住在舍衛城祇樹林給孤獨園。                 |
| 其时，尊者舍利弗以和蔼语、明了、无浊声，使明知意义之法语、教示、利益、鼓励诸比丘。 | 當時，尊者舍利弗以法說，以優雅的、明瞭的、清晰的、義理令知的話語對比丘們開示、勸導、鼓勵、使歡喜。 |
| 彼等诸比丘，深切注意，虔诚，心意集中，倾耳闻法。             | 而那些比丘作目標後、作意後、全心注意後傾耳聽法。             |
| 时尊者婆耆沙生如是思念：                                     | 那時，尊者婆耆舍想這個：                                     |
| ‘此尊者舍利弗，以和蔼之语，明了、无浊声，使明知意义之法语，教示、利益、鼓励诸比丘。 | 「這位尊者舍利弗以法說，以優雅的、明瞭的、清晰的、義理令知的話語對比丘們開示、勸導、鼓勵、使歡喜。 |
| 彼等诸比丘，深切注意，虔诚，心意集中，倾耳闻法。             | 而那些比丘作目標後、作意後、全心注意後傾耳聽法，             |
| 我今向尊者舍利弗，应以适当之偈赞叹。’                        | 讓我當面以適合的偈頌稱讚尊者舍利弗。」                       |
| 时，尊者婆耆沙则从座起，一肩着衣，合掌礼尊者舍利弗，以此称尊者舍利弗： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向尊者舍利弗合掌鞠躬後，對尊者舍利弗說這個： |
| ‘吾友舍利弗!我涌思念!吾友舍利弗!我涌思念。’                  | 「舍利弗學友！它在我心中出現；舍利弗學友！它在我心中出現。」 |
| ‘吾友婆耆沙!请说。’                                          | 「婆耆舍學友！請你說明。」                                   |
| 时，尊者婆耆沙以适当之偈，向尊者舍利弗赞叹曰：               | 那時，尊者婆耆舍當面以適合的偈頌稱讚尊者舍利弗：             |
| 1智慧深而贤                                                  | 「深慧者、有智慧者，                                         |
| 2巧分道非道                                                  | 道非道的熟知者，                                             |
| 3大智舍利弗                                                  | 大慧的舍利弗，                                               |
| 4说法诸比丘                                                  | 為比丘們教導法。                                             |
| 5略说又广说                                                  | 既簡要地教導，                                               |
|                                                              | 也詳細地說，                                                 |
| 6如舍利鸟声                                                  | 如九官鳥的聲音，                                             |
|                                                              | 他說辯才。                                                   |
| 7无浊妙辩涌                                                  | 當他教導那個時，                                             |
| 8其声犹如蜜                                                  | 他們聽聞如蜜的話語，                                         |
| 9快乐耳爽美                                                  | 以誘人的聲音，                                               |
|                                                              | 以悅耳的以可愛的，                                           |
| 10说而心跃欢                                                 | 踊躍心地、喜悅地，                                           |
| 12比丘等听闻 11注意以倾耳                                    | 比丘們傾耳。」                                               |
