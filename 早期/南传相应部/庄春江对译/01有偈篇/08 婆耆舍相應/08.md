| 第八 千以上                                                  | 8.超過一千經                                                 |
| 尔时，世尊与千二百五十人比丘，俱住舍卫城只树给孤独园。       | 有一次，世尊與一千二百五十位比丘的大比丘僧團，住在舍衛城祇樹林給孤獨園。 |
| 其时，世尊依导引涅盘 之法语，教示、利益、鼓励诸比丘。        | 當時，世尊以涅槃關聯的法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，深切注意，虔诚、心意集中、倾耳闻法。             | 而那些比丘作目標後、作意後、全心注意後傾耳聽法。             |
| 时，尊者婆耆沙如是思念：                                     | 那時，尊者婆耆舍想這個：                                     |
| ‘今世尊依导引涅盘之法语，教示、利益、鼓励诸比丘。            | 「這位世尊以涅槃關聯的法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，深切注意，虔诚、心意集中，倾耳闻法。             | 而那些比丘作目標後、作意後、全心注意後傾耳聽法，             |
| 我今以适当之偈，向世尊赞叹。’                                | 讓我以適合的偈頌當面稱讚世尊。」                             |
| 时，尊者婆耆沙即从座起，一肩着衣，合掌礼敬世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念，善逝!我涌思念。’                             | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙，请说。’                                     | 「婆耆舍！請你說明。」世尊說。                               |
| 时，尊者婆耆沙，以适当之偈，向世尊赞叹曰：                   | 那時，尊者婆耆舍以適合的偈頌當面稱讚世尊：                   |
| 1千以上比丘                                                  | 「超過一千位比丘，                                           |
| 5应供善逝尊                                                  | 侍奉善逝：                                                   |
| 2以离尘垢法                                                  | 離塵之法，                                                   |
| 3何处均无怖 4礼敬说涅盘                                      | 哪裡都不害怕的涅槃教導者。                                   |
| 7无有垢秽法                                                  | 聽聞離垢之法：                                               |
| 6正觉者所说                                                  | 被遍正覺者教導的，                                           |
| 10实正觉者光                                                 | 正覺者確實輝耀：                                             |
| 9比丘众围绕                                                  | 被比丘僧團置於前面者。                                       |
| 11世尊实龙象                                                 | 世尊！你的名字是龍，                                         |
| 12第七之圣者                                                 | 仙人中第七仙人，                                             |
| 13犹如大雨降                                                 | 如大雨雲生成後，                                             |
| 14弟子等受润                                                 | 下雨到諸弟子。                                               |
| 16从日住出来                                                 | 從白天的住處出來後，                                         |
| 15为奉见我师                                                 | 想要看見大師者，                                             |
| 17弟子之一人 18我是婆耆沙                                    | 大英雄！弟子婆耆舍，                                         |
| 19礼敬大雄足                                                 | 禮拜在你的腳上。」                                           |
| ‘婆耆沙!此等偈乃汝以前所作耶?或汝立即忆起者耶?’              | 「婆耆舍！是否這些偈頌之前已遍尋思，或者僅立即在你心中出現呢？」 |
| ‘世尊!此等偈非以前之作，乃我当今立即所现。’                  | 「大德！這些偈頌非之前已遍尋思，反而僅立即在我心中出現。」   |
| ‘然则，婆耆沙!既非以前所作者，即更再多说。’                  | 「婆耆舍！那樣的話，令更多非之前已遍尋思的偈頌在你心中出現。」 |
| ‘唯然!世尊!’尊者婆耆沙奉答世尊，即说更多偈赞世尊：           | 「是的，大德！」尊者婆耆舍回答世尊後，以更多非之前已遍尋思的偈頌當面稱讚世尊： |
| 1胜恶魔邪路                                                  | 「征服魔的邪道之路後，                                       |
| 2行破诸障碍                                                  | 破壞諸{荒蕪}後實行，                                         |
| 3结缚切断者                                                  | 請你們看那位繫縛的令脫者，                                   |
| 4分别说清法                                                  | 不依止者、部分地分別者。                                     |
| 5我等度瀑流                                                  | 為了暴流的渡過，                                             |
| 6说示种种道                                                  | 告知各種的道，                                               |
| 7于所说不死                                                  | {如果}[而]在那個不死被告知時，                               |
| 8我等法见者 9树立不运去                                      | 法的看見者們成為不能被動搖的住立者。                         |
| 10贯串光作者                                                 | 光明的作者洞察後，                                           |
| 11过一切见处 12以见于涅盘                                    | 看見一切住止的超越，                                         |
| 13自知并自证                                                 | 知道後與作證後，                                             |
| 14其最上之法 15我等说十处                                    | 他對五位教導最上的。                                         |
| 16于所善说法                                                 | 在法被這麼善教導時，                                         |
| 17知法之学者 18无放逸余地                                    | 了知法者有什麼放逸？                                         |
| 19依此世尊法                                                 | 因此確實在那位世尊的教說上，                                 |
| 20常在不放逸 21礼敬而修学                                    | 應該經常不放逸地、禮敬地隨學。」                             |
