| 第二 不快                                                    | 2. 不喜樂經                                                  |
| 尔时……乃至……                                                 | 有一次……（中略）。                                           |
| 尊者婆耆沙与乃师尼俱律陀劫波，共住于阿腊毗之阿伽罗婆奢提耶。 | 尊者婆耆舍與尊者尼拘律葛波和尚，共住在阿羅婆的阿格羅婆塔廟。 |
| 其时，尊者尼俱律陀劫波，从乞食归，食后而入室 ，至夕夜，或至翌日早皆不出户门。 | 當時，尊者尼拘律葛波餐後已從施食返回，進入住處，或傍晚時出來，或在隔天時。 |
| 其时尊者婆耆沙生不快，贪欲污其心。                           | 當時，尊者婆耆舍的不喜樂被生起，貪使心墮落。                 |
| 时婆耆沙生如是思念：                                         | 那時，尊者婆耆舍想這個：                                     |
|                                                              | 「確實是我的無利得，確實不是我的利得；                       |
|                                                              | 確實是我的惡得的，確實不是我的善得的：                       |
| ‘我心生不快，贪欲污我心。                                    | 我的不喜樂被生起，貪使心墮落。                               |
| 对我甚实悲痛。                                               |                                                              |
|                                                              | 在這裡，那如何可得：                                         |
| 别人无从灭我心之不快而生愉悦，                               | 凡其他人為我除去不喜樂後，能使喜樂生起。                     |
| 我须自灭我之不快，而令生愉悦。                               | 讓我就自己為自己除去不喜樂後，能使喜樂生起。」               |
| 时，尊者婆耆沙，自灭自己之不快，令生愉悦。其时唱此等偈曰：   | 那時，尊者婆耆舍就自己為自己除去不喜樂後，使喜樂生起後，那時候說這些偈頌： |
| 1思快不快者                                                  | 「完全捨斷不喜樂與喜樂，                                     |
| 2舍诸着家念                                                  | 以及掛慮家的尋後，                                           |
| 3不欲住何处 4离欲之住处                                      | 無論何處都不應該作欲林，                                     |
| 5无有欲之思 6此则是比丘                                      | 無欲林者、不喜樂者他確實是比丘。                             |
| 7地载空所覆                                                  | 這裡凡大地與虛空，                                           |
| 8世间诸一切                                                  | 色之類與進入世界者，                                         |
| 9悉是无常老                                                  | 無論什麼都衰損-一切是無常的，                                |
| 10有智悟此住                                                 | 有所覺者們這麼知道後實行。                                   |
| 12皆悉依执着                                                 | 被繫縛在依著上的人們：                                       |
| 11人见闻触思                                                 | 在所見、所聞、有對與所覺上，                                 |
| 13除此依欲念                                                 | 在這裡除去意欲後成為不動者，                                 |
| 14无污无染者 15是云为牟尼                                    | 凡在這裡確實不沾染-他們說他是牟尼。                          |
| 16凡常者易陷 17六十之依着                                    | 而依止六十的有尋者們：                                       |
| 18不法之觉想                                                 | 在人們中個個是非法的固執者，                                 |
| 20任何之部类 19此等不行往                                    | 但對無論在哪裡非入群者，                                     |
| 21不语恶语者 22此则是比丘                                    | 又非粗惡語者他是比丘。                                       |
| 23有天禀之资 24长夜心寂静                                    | 有能力者、長久得定者，                                       |
| 25无欺无欲念 26贤达寂静道                                    | 非詭計者、明智者、無熱望者，                                 |
| 28以灭除烦恼                                                 | 緣於牟尼到達寂靜境界，                                       |
| 27牟尼依涅盘                                                 | 般涅槃者等待死時。」                                         |
