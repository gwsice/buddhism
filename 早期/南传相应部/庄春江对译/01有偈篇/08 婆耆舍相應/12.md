| 第十二 婆耆沙                                                | 12.婆耆舍經                                                  |
| 尔时，世尊住舍卫城只树给孤独园。                             | 有一次，尊者婆耆舍住在舍衛城祇樹林給孤獨園。                 |
| 其时，尊者婆耆沙，得阿罗汉果不久，耽味于解脱乐，其时，唱此偈曰： | 當時，尊者婆耆舍成為到達阿羅漢境界者後不久，在那時候感受解脫樂地說這些偈頌： |
| 1我昔耽作诗                                                  | 「以前陶醉在詩中的我們走動，                                 |
| 2村庄市里游                                                  | 從村到村從城到城，                                           |
| 3时见正觉者                                                  | 然後我們看見正覺者，                                         |
| 4我于生正信                                                  | 我們的信生起。                                               |
| 5佛陀为我说                                                  | 他為我教導法：                                               |
| 6蕴处界等法                                                  | 蘊、處、界，                                                 |
| 7我闻如是法                                                  | 聽聞他的法後，                                               |
| 8无家而出家                                                  | 我出家成為非家者。                                           |
| 12利益成正觉                                                 | 確實為了許多[眾生]的利益，                                   |
| 9实于圣者见                                                  | 牟尼到達覺(菩提)，                                           |
| 11比丘比丘尼                                                 | 為了比丘與比丘尼們：                                         |
| 10入其道之道                                                 | 凡到達決定的看見者。                                         |
| 14实是善来者                                                 | 確實是我的善來到的：                                         |
| 13我来于佛前                                                 | 對我在佛陀的面前，                                           |
| 15到达于三明                                                 | 三明已抵達，                                                 |
| 16遂行如佛教                                                 | 佛陀的教說已做。                                             |
| 18以知于宿命                                                 | 我知道前世住處，                                             |
| 17我得清天眼                                                 | 天眼已淨化，                                                 |
| 19得三明神通                                                 | 我是三明者、得到神通者，                                     |
| 20巧知于他心                                                 | 知他心的熟練者。」                                           |
