| 第七 自恣                                                    | 7.自恣經                                                     |
| 尔时，世尊与五百比丘众共住舍卫城东园鹿子母讲堂。皆是阿罗汉。 | 有一次，世尊與約五百位比丘全部都是阿羅漢的大比丘僧團，住在舍衛城東園鹿母講堂。 |
| 其时，世尊是日布萨自恣之日，为比丘众所围绕，坐于露地。       | 當時，在十五那個布薩自恣日，世尊被比丘僧團圍繞，坐在屋外。   |
| 时，世尊默然，还视比丘众，言诸比丘：                         | 那時，世尊環視沈默的比丘僧團後，召喚比丘們：                 |
| 诸比丘!我今自恣。汝等对我身语，有否云何非难耶?’              | 「比丘們！來吧，現在我邀請你們：但是否你們呵責我任何與身體有關的或與言語有關的呢？」 |
| 如是言已。尊者舍利弗即从座起，一肩着衣，合掌礼世尊，以此白曰： | 在這麼說時，尊者舍利弗從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘否也!世尊。我等于世尊之身上，不见有可非议者。               | 「大德！我們不呵責世尊任何與身體有關的或與言語有關的。       |
| 世尊!世尊令未生之道生，令知未知之道，说未说之法。道之知者，是道之了者，道之巧者。 | 因為，世尊是未生起道的使生起者，未出生道的使出生者，未宣說道的宣說者、道的知者、道的熟練者、道的熟知者，大德！ |
| 今弟子等顺从道，而后能其有道者。                             | 而且，現在弟子們住於道的跟隨者，之後為具備者。               |
| 世尊!我亦向世尊自恣。世尊!我之身语，有否云何可非难耶?’       | 大德！而我邀請世尊：但是否世尊呵責我任何與身體有關的或與言語有關的呢？」 |
| ‘否也。舍利弗!我对汝之身语，亦无何可非难。                   | 「舍利弗！我不呵責你任何與身體有關的或與言語有關的。         |
| 舍利弗!汝是贤者、大智者、广智者、捷智者、锐智者，贯通智者。  | 舍利弗！你是賢智者；舍利弗！你是大慧者；舍利弗！你是博慧者；舍利弗！你是捷慧者；舍利弗！你是速慧者；舍利弗！你是利慧者；舍利弗！你是洞察慧者。 |
| 舍利弗!犹如转轮王之长子，以正转父王所转之车轮。              | 舍利弗！猶如轉輪王的長子，使被父親轉起的輪子完全地隨轉動(持續轉動)。 |
| 舍利弗!如是汝正转我所转之无上法轮。’                         | 同樣的，舍利弗！你使被我轉起的無上法輪完全地隨轉動。」       |
| ‘世尊!若于我身语，皆无可非难者，                             | 「大德！如果世尊不呵責我任何與身體有關的或與言語有關的，     |
| 此五百比丘众之身语，尚有何可予非难耶?’                       | 大德！那麼是否世尊呵責這五百位比丘任何與身體有關的或與言語有關的呢？」 |
| ‘舍利弗!此五百比丘之身语，我无可非难。                       | 「舍利弗！我不呵責這五百位比丘任何與身體有關的或與言語有關的。 |
| 舍利弗!此五百比丘中，有六十比丘是三明者，六十比丘是六通者，六十比丘是俱解脱者，其他是慧解脱者。’ | 舍利弗！因為這五百位比丘中，六十位比丘是三明者，六十位比丘是六神通者，六十位比丘是俱分解脫者，而其他是慧解脫者。」 |
| 时，尊者婆耆沙即从座起，一肩着衣，合掌礼世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念。善逝，我涌思念!’                             | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙，请说。’                                     | 「婆耆舍！請你說明。」世尊說。                               |
| 时，尊者婆耆沙，以适当之偈，向世尊赞叹曰:                    | 那時，尊者婆耆舍以適合的偈頌當面稱讚世尊：                   |
| 1今乃十五夜 2为众之清净                                      | 「在十五的今日為了清淨，                                     |
| 3五百比丘集                                                  | 五百位比丘已聚集：                                           |
| 4无污断结缚                                                  | 結繫縛切斷的無惱亂的，                                       |
| 5无后有圣者                                                  | 再有已盡的仙人。                                             |
| 6犹如转轮王                                                  | 如轉輪王，                                                   |
| 7大臣等围绕                                                  | 被大臣圍繞，                                                 |
| 8譬如限大海                                                  | 繞著全部，                                                   |
| 9惠偏此大地                                                  | 海洋為邊界的這個大地走。                                     |
| 10如是战胜者                                                 | 像這樣戰場勝利者，                                           |
| 11无上商队主                                                 | 無上的商隊領袖，                                             |
| 13弟子等敬礼                                                 | 弟子們侍奉：                                                 |
| 12三明灭死魔                                                 | 三明者、死亡的捨棄者們。                                     |
| 14此等世尊子                                                 | 全部是世尊之子，                                             |
| 15于此不曾弄 16无用之辩者                                    | 在這裡閒聊不被發現，                                         |
| 17拔去渴爱箭                                                 | 對渴愛刺箭的破壞者，                                         |
| 18敬礼日种佛                                                 | 對太陽族人-我應該禮拜。」                                    |
