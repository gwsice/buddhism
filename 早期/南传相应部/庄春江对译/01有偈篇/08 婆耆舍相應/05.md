| 元亨寺                                                       | 庄春江                                                       |

| 第五 善说                                                    | 5. 善說經                                                    |
|                                                              | 起源於舍衛城。                                               |
| [尔时，世尊]住舍卫城只树给孤独园……                           | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 于此，世尊呼诸比丘：‘诸比丘!’                                | 在那裡，世尊召喚比丘們：「比丘們！」                         |
| ‘唯然，世尊!’，彼等诸比丘奉答世尊。                          | 「尊師！」那些比丘回答世尊。                                 |
| 世尊以此宣说：                                               | 世尊說這個：                                                 |
| ‘诸比丘!四支具足之语，乃善说而非恶说。无罪垢，不令识者非难。四支者何? | 「比丘們！具備四支的言語是善說的；非惡說的，是無過失的與不能被智者們斥責的。哪四個？ |
| 诸比丘!于此语善说而非恶说。                                  | 比丘們！這裡，比丘只說善說的；非惡說的、                     |
| 语法而非不法。                                               | 只說法；非非法、                                             |
| 语爱语而非非爱语。                                           | 只說可愛的；非不可愛的、                                     |
| 语真实而非虚假。                                             | 只說真實；非虛偽。                                           |
| 诸比丘!此四支具足之语，乃善说而非恶说。无罪垢，不令识者非难。’ | 比丘們！具備這四支的言語是善說的；非惡說的，是無過失的與不能被智者們斥責的。」 |
| 世尊以此宣说，善逝以此宣说，又作如是言曰：                   | 世尊說這個，說這個後，善逝、大師又更進一步說這個：           |
| 1为善人所云 2第一语于美                                      | 「善人們說-善說的是最上的，                                  |
| 3第二语如法 4勿语不如法                                      | 應該說法、非非法-那是第二的，                                |
| 5第三语优美 6勿以语粗犷                                      | 應該說可愛的、非不可愛的那是第三的，                         |
| 7第四语真实 8勿以语虚伪                                      | 應該說真實、非虛偽那是第四的。」                             |
| 时尊者婆耆沙，即从座起，一肩着衣，合掌礼拜世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念!善逝!我涌思念!’                               | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙!请调。’                                      | 「婆耆舍！請你說明。」世尊說。                               |
| 时尊者婆耆沙白世尊，以适当之偈予奉赞：                       | 那時，尊者婆耆舍以適合的偈頌當面稱讚世尊：                   |
| 1人以语其语                                                  | 「只應該說那個言語：                                         |
| 2勿令自己苦                                                  | 以該者不會使自己苦惱，                                       |
| 3亦无害他语                                                  | 以及不會傷害他人，                                           |
| 4此为语善语                                                  | 那確實是善說的言語。                                         |
| 5人语善故事                                                  | 只應該說可愛的言語：                                         |
| 6其语以快耳                                                  | 凡受歡迎的言語，                                             |
| 7不语他人恶                                                  | 凡不取諸惡的後，                                             |
| 8此则云善美                                                  | 說對他人可愛的。                                             |
| 9真实甘露语                                                  | 真實確實是不死的言語，                                       |
| 10此乃从古法                                                 | 這是永遠的法，                                               |
| 11以请真义法                                                 | 諸義理與諸法，                                               |
| 12善人悉确立                                                 | 善人們說被住立在真實上。                                     |
| 13佛陀所说语                                                 | 凡佛陀說言語：                                               |
| 14达涅盘安稳                                                 | 為了安穩涅槃的到達，                                         |
| 15以至尽苦边                                                 | 為了苦的作終結，                                             |
| 16此实无上语                                                 | 那確實是言語中最上的。」                                     |
