| 第十 目犍连                                                  | 10.目揵連經                                                  |
| 尔时，世尊与五百比丘众，俱住王舍城伊师耆利山侧黑曜岩，皆是阿罗汉。 | 有一次，世尊與約五百位比丘全部都是阿羅漢的大比丘僧團，住在王舍城仙吞山坡的黑岩處。 |
| 时，尊者大目犍连，以验彼等之心，解脱而无亿波提。             | 尊者大目揵連以心探查他們的心：[他們]是解脫者、無依著者。     |
| 时，尊者婆耆沙作如是思念：                                   | 那時，尊者婆耆舍想這個：                                     |
| ‘今世尊与五百比丘众，俱住王舍城伊师耆利山侧黑曜岩，皆是阿罗汉。 | 「這位世尊與約五百位比丘全部都是阿羅漢的大比丘僧團，住在王舍城仙吞山坡的黑岩處， |
| 尊者大目犍连，以验彼等之心，悉解脱而无亿波提。               | 尊者大目揵連以心探查他們的心：[他們]是解脫者、無依著者，     |
| 今尊者大目犍连于世尊之面前，我以适当之偈赞叹。’              | 讓我在世尊的面前以適合的偈頌稱讚尊者大目揵連。」             |
| 时，尊者婆耆沙，即从座起，一肩着衣，合掌礼世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念；善逝!我涌思念。’                             | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙!请说。’                                      | 「婆耆舍！請你說明。」世尊說。                               |
| 时，尊者婆耆沙对尊者大目犍连，于世尊面前，以适当之偈赞曰：   | 那時，尊者婆耆舍在世尊的面前以適合的偈頌稱讚尊者大目揵連：   |
| 2坐山侧圣者                                                  | 「對坐在山坡者，                                             |
| 1达苦恼彼岸                                                  | 對到達苦的彼岸的牟尼，                                       |
| 4弟子等礼敬                                                  | 弟子們侍奉：                                                 |
| 3胜死达三明                                                  | 三明者、死亡的捨棄者們。                                     |
| 6验他诸人心                                                  | 以心繞著他們走：                                             |
| 5大神力目连                                                  | 大神通力的目揵連，                                           |
| 7彼等心解脱                                                  | 他們的心探查者：                                             |
| 8知无有余依                                                  | 解脫者、無依著者。                                           |
| 10具足一切支                                                 | 像這樣具足所有部分者：                                       |
| 9达苦恼彼岸                                                  | 到達苦的彼岸的牟尼，                                         |
| 11成满种种相                                                 | 具足種種行相者：                                             |
| 12彼礼敬瞿昙                                                 | 他們侍奉喬達摩。」                                           |
