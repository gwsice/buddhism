| 第八 婆耆沙长老相应                                          | 8.婆耆舍相應                                                 |
| 第一 出离                                                    | 1. 已出離經                                                  |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，尊者婆耆沙与乃师尊者尼俱律陀劫波，共住于阿腊毗之阿伽罗婆奢提耶。 | 有一次，尊者婆耆舍與尊者尼拘律葛波和尚，共住在阿羅婆處的阿格羅婆塔廟。 |
| 其时，尊者婆耆沙乃出家不久之新比丘，被留作精舍之看守人。     | 當時，尊者婆耆舍是新學、出家不久者、守護住處的留守者。       |
| 其时众多妇人为参观精舍，装饰打扮而来阿兰若。                 | 那時，眾多女子極好裝飾後，為了觀看住處(精舍)去阿格羅婆的園林。 |
| 时尊者婆耆沙，见彼等妇人而生不快，贪欲污其心。               | 那時，看見那些女人後，尊者婆耆舍的不喜樂被生起，貪使心墮落。 |
| 时尊者婆耆沙如是思念：                                       | 那時，尊者婆耆舍想這個：                                     |
|                                                              | 「確實是我的無利得，確實不是我的利得；                       |
|                                                              | 確實是我的惡得的，確實不是我的善得的：                       |
| ‘我心生不快，贪欲污我心，                                    | 我的不喜樂被生起，貪使心墮落。                               |
| 对我实是其悲痛。                                             |                                                              |
|                                                              | 在這裡，那如何可得：                                         |
| 别人无从灭我心之不快而令愉悦。                               | 凡其他人為我除去不喜樂後，能使喜樂生起。                     |
| 我自灭我心之不快、令生愉快。’                                | 讓我就自己為自己除去不喜樂後，能使喜樂生起。」               |
| 时，尊者婆耆沙，自灭自己之不快而生愉悦，其时以唱此偈曰：     | 那時，尊者婆耆舍就自己為自己除去不喜樂後，使喜樂生起後，那時候說這些偈頌： |
| 2于我之出离                                                  | 「對確實已出離的我，                                         |
| 1由家而无家                                                  | 對從在家成為非家者，                                         |
| 4无法之思起                                                  | 諸尋圍繞：                                                   |
| 3实是从黑闇                                                  | 這些從黑暗[來]的大膽者。                                     |
| 5然其生世高 6以习强弓法                                      | 顯貴之子們、大弓箭手們，                                     |
| 7不知于退屈                                                  | 已學得者們、堅固法者們，                                     |
| 8千人弓术者                                                  | 一千位不逃跑者，                                             |
| 9一时周放矢                                                  | 如果他們到處包圍。                                           |
| 10多比于其数                                                 | 即使如果比這更多的，                                         |
| 11妇女子等来                                                 | 女人們將到來，                                               |
| 12不能乱我心                                                 | 確實將不使我動搖：                                           |
| 13我强立于法                                                 | 對諸法在自己上住立者。                                       |
| 14我一度于彼                                                 | 因為這個被我當面聽聞：                                       |
| 15日种之佛陀                                                 | 對太陽族人的佛陀，                                           |
| 16所说导涅盘                                                 | 導向涅槃之道，                                               |
| 17依此以开导 18我心乐于此                                    | 在那裡我的意(心)喜好的。                                     |
| 19如是我居住                                                 | 如果對這樣住的我，                                           |
| 20波旬来则来                                                 | 波旬！你靠近，                                               |
| 21恶魔我亦应 22扬拂之令汝                                    | 死神！我將像這樣做，                                         |
| 23不能寻觅出 24我所行之道                                    | 你甚至沒看見我的道。」                                       |
