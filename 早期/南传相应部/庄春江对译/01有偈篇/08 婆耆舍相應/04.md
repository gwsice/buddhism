| 第四 阿难                                                  | 4. 阿難經                                                    |
| 尔时，尊者阿难住舍卫城只树给孤独园。                       | 有一次，尊者阿難住在舍衛城祇樹林給孤獨園。                   |
| 时，尊者阿难，清晨着衣持钵，尊者婆耆沙为随侍入舍卫城乞食。 | 那時，尊者阿難午前時穿衣、拿起衣鉢後，以尊者婆耆舍為隨從沙門，為了托鉢進入舍衛城。 |
| 其时，尊者婆耆沙生不快，贪欲污其心。                       | 當時，尊者婆耆舍的不喜樂被生起，貪使心墮落。                 |
| 时，尊者婆耆沙以偈白阿难曰：                               | 那時，尊者婆耆舍以偈頌對尊者阿難說：                         |
| 1我为贪欲烧                                                | 「我被欲貪燃燒，                                             |
| 2我乃心炎燃                                                | 我的心被遍燃燒，                                             |
| 3瞿曼哀怜我                                                | 喬達摩！請你出於憐愍，                                       |
| 4请说消火法                                                | 說使之熄滅的事那就好了。」                                   |
| [阿难：]                                                   |                                                              |
| 1依于颠倒想                                                | 「以想的顛倒，                                               |
| 2汝心之炎燃                                                | 你的心被遍燃燒，                                             |
| 4令止见净相                                                | 請你避開相：                                                 |
| 3以呼起贪欲                                                | 淨的(美的)、伴隨貪的。                                       |
| 5见诸行无常                                                | 請你視諸行為另一邊的，                                       |
| 6苦恼非自己                                                | 為苦的以及不要[視]為我，                                     |
| 7消灭大贪火                                                | 請你使大貪熄滅，                                             |
| 8勿为屡次烧                                                | 你不要一再地被燃燒。                                         |
| 11依于不净想 12令修自己心                                  | 請你以不淨的修習心：                                         |
| 9集心于一点 10令其住静寂                                   | 一境地、善得定地，                                           |
| 13有于身念住                                               | 請你有身至念，                                               |
| 14以满厌恶情                                               | 請你成為多厭者。                                             |
| 15习修于无相                                               | 以及請你修習無相，                                           |
| 16消灭慢随眠                                               | 請你捨棄慢煩惱潛在趨勢，                                     |
| 17依其慢现观                                               | 之後以慢的止滅，                                             |
| 18得行于寂静                                               | 你將寂靜地行。」                                             |
