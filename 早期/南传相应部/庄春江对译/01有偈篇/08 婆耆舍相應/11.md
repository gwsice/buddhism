| 第十一 伽伽罗池                                              | 11.伽伽羅經                                                  |
| 尔时，世尊住瞻波伽伽罗之莲池岸边。有五百比丘众，七百优婆塞，七百优婆夷，数千之诸天俱， | 有一次，世尊與約五百位比丘的大比丘僧團、七百位優婆塞、七百位優婆夷、好幾千位天神， |
| 世尊依其光颜，依其名声，光辉胜越彼等。                       | 共住在瞻波城伽伽羅蓮花池邊，世尊以容色與名聲比他們更輝耀。   |
| 时，尊者婆耆沙作如是思念：                                   | 那時，尊者婆耆舍想這個：                                     |
| ‘今世尊住瞻波伽伽罗之莲池岸边。有五百比丘众，七百优婆塞，七百优婆夷，数千之诸天俱。 | 「這位世尊與約五百位比丘的大比丘僧團、七百位優婆塞、七百位優婆夷、好幾千位天神， |
| 世尊依其光颜，依其名声，光辉胜越彼等。今于世尊面前，我以适当之偈赞叹。’ | 共住在瞻波城伽伽羅蓮花池邊，世尊以容色與名聲比他們更輝耀，讓我以適合的偈頌當面稱讚世尊。」 |
| 时，尊者婆耆沙即从座起，一肩着衣，合掌礼世尊，以此白世尊曰： | 那時，尊者婆耆舍從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!我涌思念；善逝!我涌思念。’                             | 「世尊！它在我心中出現；善逝！它在我心中出現。」             |
| 世尊曰：‘婆耆沙!请说。’                                      | 「婆耆舍！請你說明。」世尊說。                               |
| 时，尊者婆耆沙于世尊面前，以适当之偈赞曰：                   | 那時，尊者婆耆舍以適合的偈頌當面稱讚世尊：                   |
| 1如无云空月                                                  | 「如月在雲被驅離的天空，                                     |
| 2无云太阳耀                                                  | 如離垢的太陽照耀，                                           |
| 3鸯耆罗牟尼                                                  | 放光者！也像這樣你是大牟尼，                                 |
| 4荣光耀世界                                                  | 你以名聲極照耀一切世間。」                                   |
