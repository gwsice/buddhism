| 第六 遮罗                                                | 6. 遮羅經                                                    |
| 舍卫城因缘。                                             | 起源於舍衛城。                                               |
| 时，遮罗比丘尼清晨入舍卫城乞食……乃至……为日住而坐树下。   | 那時，遮羅比丘尼午前時穿好衣服後……（中略）坐在某棵樹下為了白天的住處。 |
| 时，恶魔波旬诣遮罗比丘尼处。诣已，谓遮罗比丘尼曰：       | 那時，魔波旬去見遮羅比丘尼。抵達後，對遮羅比丘尼說這個：     |
| ‘比丘尼!汝不喜者何?’                                     | 「比丘尼！你不同意什麼呢？」                                 |
| ‘友!我不喜生!’                                           | 「朋友！我不同意出生。」                                     |
| ‘何故不喜生?’                                            | 「你為何不同意出生？                                         |
| ‘生者乃受用乐欲。’                                       | 被出生者享受諸欲，                                           |
| ‘谁以此教汝?                                             | 誰使你接受這個：                                             |
| ‘比丘尼!不喜生!’’                                        | 『比丘尼！你不要喜歡出生！』呢？」                           |
| [比丘尼]                                                 |                                                              |
| 1有生者有死                                              | 「被出生者有死亡，                                           |
| 2生即见苦恼                                              | 被出生者接觸諸苦：                                           |
| 3缚杀其他祸                                              | 繫縛、殺害、苦難，                                           |
| 4是故不乐生                                              | 因此不應該喜歡出生。                                         |
| 5佛陀施说法                                              | 佛陀教導法：                                                 |
| 6以导超此生                                              | 為了出生的超越，                                             |
| 7舍离一切苦                                              | 為了捨斷一切苦，                                             |
| 8我入于真实                                              | 他使我在真理上住立。                                         |
| 9上色界众生                                              | 凡進入色的眾生，                                             |
| 10往无色众生                                             | 與凡住於無色的，                                             |
| 11是故不知灭                                             | 不知道滅者，                                                 |
| 12以是为再来                                             | 為返回再有者。」                                             |
| 时，恶魔波旬苦恼以：‘遮罗比丘尼已知我。’萎身隐没其身形。 | 那時，魔波旬：「遮羅比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
