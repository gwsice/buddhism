| 第二 苏摩                                                | 2. 受摩經                                                    |
| 舍卫城因缘。                                             | 起源於舍衛城。                                               |
| 时，苏摩比丘尼清晨，着衣持钵，入舍卫城乞食。             | 那時，受摩比丘尼午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。 |
| 于舍卫城乞食后，收钵，为日住 来至暗林。                  | 在舍衛城為了托鉢行走後，餐後已從施食返回，為了白天的住處去盲者的樹林。 |
| 入暗林已，于树下为日住而坐。                             | 進入往盲者的樹林後，坐在某棵樹下為了白天的住處。             |
| 时，恶魔波旬欲令苏摩比丘尼生恐怖，毛发竖立，             | 那時，魔波旬想要使受摩比丘尼生出害怕、僵硬狀態、身毛豎立的； |
| 以弃禅定，而诣苏摩比丘尼处。诣已，以偈语苏摩比丘尼曰：   | 想要使她從定撤退而去見受摩比丘尼。抵達後，以偈頌對受摩比丘尼說： |
| 1圣者所至处                                              | 「凡那個能被仙人到達處，                                     |
| 2是处甚难至                                              | 是難達到的，                                                 |
| 3非女二指智                                              | 那個以女人二指慧，                                           |
| 4能待至彼处                                              | 不能夠到達。」                                               |
| 时，苏摩比丘尼，生如是思惟：                             | 那時，受摩比丘尼想這個：                                     |
| ‘是语此偈者，谁耶?人耶非人耶?’                           | 「誰說偈頌？這位是人或非人？」                               |
| 时，苏摩比丘尼生如是思惟：                               | 那時，受摩比丘尼想這個：                                     |
| ‘此恶魔波旬欲令我生恐怖，毛发竖立以弃禅定而唱此偈。’     | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，苏摩比丘尼，知是恶魔波旬，以偈答恶魔波旬曰：         | 那時，受摩比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 2女形复何障                                              | 「女人的狀態會作什麼差別？                                   |
| 1心入于寂静                                              | 在心已善入定時，                                             |
| 3智慧已显现                                              | 在智轉起中時：                                               |
| 4即见无上法                                              | 對法正確作觀者。                                             |
| 5我若思男女                                              | 確實該者會這麼想：                                           |
| 6思此为何物                                              | 『我是女人或男人』，                                         |
| 7心感于如是                                              | 又或我是其他任何者，                                         |
| 8即应恶魔语                                              | 魔適合說那個。」                                             |
| 时，恶魔波旬苦恼以：‘苏摩比丘尼已知我。’萎身隐没其身形。 | 那時，魔波旬：「受摩比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
