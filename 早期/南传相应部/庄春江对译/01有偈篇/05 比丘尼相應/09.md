| 第九 世罗                                                   | 9. 謝勒經                                                    |
| [尔时，世尊]住舍卫城……。                                    | 起源於舍衛城。                                               |
| 时，世罗比丘尼，清晨入舍卫城乞食……乃至……为日住坐于树下。    | 那時，謝勒比丘尼午前時穿好衣服後……（中略）坐在某棵樹下為了白天的住處。 |
| 时，恶魔波旬欲令世罗比丘尼生恐怖……乃至……以偈语世罗比丘尼曰: | 那時，魔波旬想要使謝勒比丘尼生出害怕、僵硬狀態、身毛豎立的……（中略）以偈頌對謝勒比丘尼說： |
| 1谁作此身体                                                 | 「這個形體被誰造作？                                         |
| 2作者于何处                                                 | 形體的作者在哪裡呢？                                         |
| 3何处生身体                                                 | 形體在哪裡被生起呢？                                         |
| 4何处身体灭                                                 | 形體在哪裡被滅呢？」                                         |
| 时，世罗比丘尼生如是思惟：                                  | 那時，謝勒比丘尼想這個：                                     |
| ‘唱此偈者是人?非人耶?’                                      | 「誰說偈頌？這位是人或非人？」                               |
| 时，世罗比丘尼，生如是思惟：                                | 那時，謝勒比丘尼想這個：                                     |
| ‘此恶魔波旬欲令我生恐怖，毛发竖立，以弃禅定，而唱此偈!’     | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，世罗比丘尼知是恶魔波旬，以偈答恶魔波旬曰：              | 那時，謝勒比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 1此身非自作                                                 | 「這個形體不是自己作的，                                     |
| 2亦非于他作                                                 | 這個痛苦不是其他者作的，                                     |
| 3依于因而生                                                 | 是緣於因生成的，                                             |
| 4依于因而灭                                                 | 以因的壞滅被滅。                                             |
| 5犹如诸种子                                                 | 如某顆種子，                                                 |
| 6移植于田园                                                 | 被播種在田中生長：                                           |
| 7地味及温味                                                 | 由於地味，                                                   |
| 8依二萌芽出                                                 | 與溼潤那兩者。                                               |
| 9是五蕴四大                                                 | 這樣蘊與界，                                                 |
| 10及此等六处                                                | 以及這六處，                                                 |
| 11依于因而生                                                | 是緣於因生成的，                                             |
| 12因坏即消灭                                                | 以因的壞滅被滅。」                                           |
| 时，恶魔波旬苦恼以：‘世罗比丘尼已知我。’萎身隐没其身形。    | 那時，魔波旬：「謝勒比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
