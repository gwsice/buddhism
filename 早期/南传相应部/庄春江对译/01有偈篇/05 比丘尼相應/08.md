| 第八 尸须波遮罗                                              | 8. 尸蘇波遮羅經                                              |
| [尔时，世尊]住舍卫城……。                                     | 起源於舍衛城。                                               |
| 时尸须波遮罗比丘尼，清晨入舍卫城乞食……乃至……为日住坐于树下。 | 那時，尸蘇波遮羅比丘尼午前時穿好衣服後……（中略）坐在某棵樹下為了白天的住處。 |
| 时，恶魔波旬诣尸须波遮罗比丘尼处。诣已，谓尸须波遮罗比丘尼曰： | 那時，魔波旬去見尸蘇波遮羅比丘尼。抵達後，對尸蘇波遮羅比丘尼說這個： |
| ‘比丘尼!汝喜谁之教见 ?’                                      | 「比丘尼！你同意誰的教條呢？」                               |
| ‘友!我不喜任何人之教见!’                                     | 「朋友！我不同意任何教條。」                                 |
| [恶魔：]                                                     |                                                              |
| 1汝依谁圆顶                                                  | 「指定誰後你成為剃頭者呢？                                   |
| 2成如此尼耶                                                  | 如沙門尼你被看見，                                           |
| 3不喜教见者                                                  | 而你在教條上不同意，                                         |
| 4是如何之愚                                                  | 為何極愚的你行這個？」                                       |
| [比丘尼]                                                     |                                                              |
| 1佛外之教见                                                  | 「從這裡外的諸教條，                                         |
| 2异见诸缠缚$$\color{red}（翻译好像不一致）$$                 | 他們在見上淨信，                                             |
| 3我不喜此法                                                  | 我不同意他們的法，                                           |
| 4正法彼不知                                                  | 他們是法的不熟知者。                                         |
| 5生于释种家                                                  | 有在釋迦家出生的，                                           |
| 6证悟无比人                                                  | 無與倫比的佛陀，                                             |
| 7总服拂恶魔                                                  | 是戰勝一切者、驅逐魔者，                                     |
| 8何处无不破                                                  | 在一切處不敗者，                                             |
| 9无执悉解脱                                                  | 在一切處解脫的不依止者，                                     |
| 10有眼见一切                                                 | 有眼者看見一切。                                             |
| 11灭尽一切业                                                 | 是到達一切業滅盡者，                                         |
| 12解脱尽诸依                                                 | 在依著之盡滅上解脫者，                                       |
| 13我师彼世尊                                                 | 那位世尊是我的大師，                                         |
| 14其教我欢喜                                                 | 我同意他的教說。」                                           |
| 时，恶魔波旬……乃至……隐没其身形。                             | 那時，魔波旬：「尸蘇波遮羅比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
