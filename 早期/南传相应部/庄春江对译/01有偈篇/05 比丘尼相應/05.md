| 第五 莲华色                                                  | 5. 蓮華色經                                                  |
| 舍卫城因缘，                                                 | 起源於舍衛城。                                               |
| 时，莲华色比丘尼，清晨入舍卫城乞食……乃至……立于开美华之沙罗树下。 | 那時，蓮華色比丘尼午前時穿好衣服後……（中略）站在某棵盛開花朵的沙羅樹下。 |
| 时，恶魔波旬欲令莲华色比丘尼，生恐怖，毛发竖立，             | 那時，魔波旬想要使蓮華色比丘尼生出害怕、僵硬狀態、身毛豎立的； |
| 以弃禅定，而诣莲华色比丘尼处。诣已，以偈语莲华色比丘尼曰：   | 想要使她從定撤退而去見蓮華色比丘尼。抵達後，以偈頌對蓮華色比丘尼說： |
| 1上下开美华                                                  | 「比丘尼！走進頂端盛開花朵的後，                             |
| 3汝唯一人立 2来沙罗树下                                      | 你單獨站在沙羅樹下，                                         |
| 4汝美无伦比                                                  | 而你的美麗外表是無雙的，                                     |
| 5愚人之汝心 6不惧恶者否                                      | 傻姑娘！你不怕壞人？」                                       |
| 时，莲华色比丘尼，生如是思惟：                               | 那時，蓮華色比丘尼想這個：                                   |
| ‘语此偈者是人?非人耶?’                                       | 「誰說偈頌？這位是人或非人？」                               |
| 时，莲华色比丘尼生如是思惟：                                 | 那時，蓮華色比丘尼想這個：                                   |
| ‘此恶魔波旬……乃至……语偈。’                                   | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，莲华色比丘尼知是恶魔波旬，以偈答恶魔波旬曰：             | 那時，蓮華色比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 2百千来于此                                                  | 「即使如果有十萬個壞人，                                     |
| 1心恶如汝者                                                  | 像那樣的到達這裡者，                                         |
| 3不动我一毛                                                  | 我不動搖身毛、不驚怖，                                       |
| 4我一不怖汝                                                  | 魔！我一個人也不怕你。」                                     |
| [恶魔：]                                                     |                                                              |
| 1我于此没形                                                  | 「這個我隱沒，                                               |
| 2入汝之腹中                                                  | 或進入你的肚子，                                             |
| 3或立汝眉间                                                  | 甚至對在睫毛中間，                                           |
| 4汝不得见我                                                  | 站立的我你沒看見。」                                         |
| [比丘尼]                                                     |                                                              |
| 1我心得自在                                                  | 「我是在心上已成為自在者，                                   |
| 2善修如意足                                                  | 神足已善修習者，                                             |
| 3解脱诸结缚                                                  | 我是已解脫一切繫縛者，                                       |
| 4我实不怖汝                                                  | 我不怕你-朋友！」                                            |
| 时，恶魔波旬苦恼以：‘莲华色比丘尼已知我。’萎身隐没其身形。   | 那時，魔波旬：「蓮華色比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
