| 第十 金刚                                                | 10. 金剛經                                                   |
| [尔时，世尊]住舍卫城……。                                 | 起源於舍衛城。                                               |
| 时，金刚比丘尼清晨，着衣持钵，入舍卫城乞食，             | 那時，金剛比丘尼午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。 |
| 于舍卫城乞食后，收钵为日住而至暗林。                     | 在舍衛城為了托鉢行走後，餐後已從施食返回，為了白天的住處去盲者的樹林。 |
| 入暗林已，为日住坐于树下。                               | 進入盲者的樹林後，坐在某棵樹下為了白天的住處。               |
| 时，恶魔波旬欲令金刚比丘尼生恐怖，毛发竖立，             | 那時，魔波旬想要使金剛比丘尼生出害怕、僵硬狀態、身毛豎立的； |
| 以弃禅定，而诣金刚比丘尼处。诣已，以偈谓金刚比丘尼曰：   | 想要使她從定撤退而去見金剛比丘尼。抵達後，以偈頌對金剛比丘尼說： |
| 1谁作此众生                                              | 「這眾生被誰造作？                                           |
| 2作者于何处                                              | 眾生的作者在哪裡呢？                                         |
| 3何处生众生                                              | 眾生在哪裡被生起呢？                                         |
| 4何处众生灭                                              | 眾生在哪裡被滅呢？」                                         |
| 时，金刚比丘尼生如是思惟：                               | 那時，金剛比丘尼想這個：                                     |
| ‘唱此偈者是人?非人耶?’                                   | 「誰說偈頌？這位是人或非人？」                               |
| 时，金刚比丘尼生如是思惟：                               | 那時，金剛比丘尼想這個：                                     |
| ‘此恶魔波旬欲令我生恐怖，毛发竖立，以弃禅定，而唱此偈。’ | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，金刚比丘尼知是恶魔波旬，以偈答恶魔波旬曰：           | 那時，金剛比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 1汝何言众生                                              | 「為何你相信『眾生』呢？                                     |
| 2汝行于魔见                                              | 魔！那是你的惡見嗎？                                         |
| 3此唯聚诸行                                              | 這是單純的行之堆積，                                         |
| 4众生不可得                                              | 這裡眾生不被得到。                                           |
| 5犹如诸支集                                              | 如因為以各部分的結合，                                       |
| 6而起车之名                                              | 有『車子』的話語，                                           |
| 7因于有五蕴                                              | 這樣在有諸蘊時，                                             |
| 8而有众生名                                              | 有『眾生』的俗稱。                                           |
| 9有起是苦恼                                              | 確實僅苦生成，                                               |
| 10停灭且苦恼                                             | 苦存續與消失，                                               |
| 11苦恼外不生                                             | 無除苦生成外的，                                             |
| 12苦恼外不灭                                             | 無除苦被滅外的。」                                           |
| 时，恶魔波旬苦恼以：‘金刚比丘尼已知我。’萎身隐没其身形。 | 那時，魔波旬：「金剛比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
