| 第四 毗阇耶 | 04. 毘闍耶經 |
| 舍卫城因缘。 | 起源於舍衛城。 |
| 时，毗阇耶比丘尼于舍卫城乞食，食后收钵，为日住而坐于树下。 | 那時，毘闍耶比丘尼午前時穿好衣服後……（中略）坐在某棵樹下為了白天的住處。 |
| 时，恶魔波旬欲令毗阇耶比丘尼，生恐怖，毛发竖立， | 那時，魔波旬想要使毘闍耶比丘尼生出害怕、僵硬狀態、身毛豎立的； |
| 以弃禅定，而诣毗阇耶比丘尼处，诣已语偈曰： | 想要使她從定撤退而去見毘闍耶比丘尼。抵達後，以偈頌對毘闍耶比丘尼說： |
| 1汝今美年经 | 「你是年輕美女， |
| 2我亦是年少 | 而我是年輕青年， |
| 3贵女来此处 | 以五種樂器， |
| 4共受五种乐 | 來！聖尼！讓我們尋歡。」 |
| 时，毗阇耶比丘尼作如是思惟： | 那時，毘闍耶比丘尼想這個： |
| ‘语此偈者是人?非人耶?’ | 「誰說偈頌？這位是人或非人？」 |
| 时，毗阇耶比丘尼，生如是思惟： | 那時，毘闍耶比丘尼想這個： |
| ‘此恶魔波旬……乃至……语偈。’ | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，毗阇耶比丘尼，知是恶魔波旬，以偈答曰． | 那時，毘闍耶比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 2香味触五法 | 「諸色、聲音、氣味、味道， |
| 1以意乐色声 | 諸所觸與諸悅意的， |
| 3我悉还与汝 | 我就贈與你， |
| 4此等非我须 | 魔！我不是以那個希求者。 |
| 6对此污秽身 | 以這個腐爛的， |
| 5危脆易破碎 | 破壞的、易壞的身體， |
| 7我唯耻厌恶 | 我困擾、羞恥， |
| 8拔除爱欲根 | 欲、渴愛已根除。 |
| 9上色界众生 | 凡走進色的眾生， |
| 10行无色众生 | 與凡住於無色的， |
| 11此众善获得 | 以及凡寂靜等至的： |
| 12我悉除迷闇 | 在一切處黑暗已破壞。」 |
| 时，恶魔波旬苦恼以：‘毗阇耶比丘尼已知我。’萎身隐没其身形。 | 那時，魔波旬：「毘闍耶比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
