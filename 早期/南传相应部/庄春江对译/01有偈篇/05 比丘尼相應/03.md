| 第三 瞿昙弥                                                  | 3. 居沙喬達彌經                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，吉离舍瞿昙弥比丘尼，清晨着衣持钵，入舍卫城乞食。         | 那時，居沙喬達彌比丘尼午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。 |
| 于舍卫城乞食后，收钵，为日住以至暗林。                       | 在舍衛城為了托鉢行走後，餐後已從施食返回，為了白天的住處去盲者的樹林。 |
| 至暗林已，于树下为日住而坐。                                 | 進入往盲者的樹林後，坐在某棵樹下為了白天的住處。             |
| 时，恶魔波旬欲令吉离舍瞿昙弥比丘尼生恐怖，毛发竖立，         | 那時，魔波旬想要使居沙喬達彌比丘尼生出害怕、僵硬狀態、身毛豎立的； |
| 以弃禅定，而诣吉离舍瞿昙弥比丘尼处。诣已，以偈语吉离舍瞿昙弥比丘尼曰： | 想要使她從定撤退而去見居沙喬達彌比丘尼。抵達後，以偈頌對居沙喬達彌比丘尼說： |
| 1汝何丧其子                                                  | 「為何你如死去兒子者呢？                                     |
| 2涕泣而独忧                                                  | 獨自有哭泣的臉，                                             |
| 3独入坐暗林                                                  | 獨自進入林園，                                               |
| 4为求男子否                                                  | 你尋求男人嗎？」                                             |
| 时，吉离舍瞿昙弥比丘尼，生如是思惟：                         | 那時，居沙喬達彌比丘尼想這個：                               |
| ‘语此偈者是人?非人耶?’                                       | 「誰說偈頌？這位是人或非人？」                               |
| 时，吉离舍瞿昙弥比丘尼，生如是思惟：                         | 那時，居沙喬達彌比丘尼想這個：                               |
| ‘此恶魔波旬欲令我生恐怖，毛发竖立，以弃禅定，而语此偈。’     | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從定撤退而說偈頌。」 |
| 时，吉离舍瞿昙弥比丘尼，知是恶魔波旬，以偈答曰：             | 那時，居沙喬達彌比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 1丧子日已过                                                  | 「我是死去兒子的終結者，                                     |
| 2亦无男子想                                                  | 為這個之男人們的結束者，                                     |
| 3我不复悲泣                                                  | 我不憂愁我不哭泣，                                           |
| 4无烦汝顾为                                                  | 我不怕你-朋友！                                              |
| 5以舍浮世乐                                                  | 到處歡喜已破壞，                                             |
| 6破一切闇冥                                                  | 黑闇聚已碎破，                                               |
| 7及破死魔军                                                  | 征服死神軍後，                                               |
| 8我住尽诸漏                                                  | 我住於無漏。」                                               |
| 时，恶魔波旬苦恼以：‘吉离舍瞿昙弥比丘尼已知我。’萎身，隐没其身形。 | 那時，魔波旬：「居沙喬達彌比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
