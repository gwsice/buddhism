| 第五 比丘尼相应                                              | 5.比丘尼相應                                                 |
| 第一 阿罗毗迦                                                | 1. 阿羅毘迦經                                                |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。                             | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时，阿罗毗迦 比丘尼清晨，若衣持钵，入舍卫城乞食。            | 那時，阿羅毘迦比丘尼午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。 |
| 于舍卫城乞食后，收钵，入于暗林以求远离。                     | 在舍衛城為了托鉢行走後，餐後已從施食返回，獨處欲求者去盲者的樹林。 |
| 时，恶魔波旬欲令阿罗毗迦比丘尼生恐怖，毛发竖立，以舍远离，而诣阿罗毗迦比丘尼之处， | 那時，魔波旬想要阿羅毘迦比丘尼生出害怕、僵硬狀態、身毛豎立的；想要使她從獨處撤退而去見阿羅毘迦比丘尼。 |
| 诣已以偈语阿罗毗迦比丘尼曰：                                 | 抵達後，以偈頌對阿羅毘迦比丘尼說：                           |
| 1世间无由出                                                  | 「世間中沒有出離，                                           |
| 2远离欲何为                                                  | 你以獨處將做什麼？                                           |
| 3还味诸欲乐                                                  | 請你享受欲的喜樂，                                           |
| 4勿至后成悔                                                  | 不要以後成為後悔者。」                                       |
| 时，阿罗毗迦比丘尼作如是思惟：                               | 那時，阿羅毘迦比丘尼想這個：                                 |
| ‘语此偈是谁?人耶非人耶?’                                     | 「誰說偈頌？這位是人或非人？」                               |
| 时阿罗毗迦比丘尼作如是思惟：                                 | 那時，阿羅毘迦比丘尼想這個：                                 |
| ‘此恶魔波旬，令我起毛发竖立之恐怖，欲使去远离，而唱偈。’     | 「這是魔波旬，他想要使我生出害怕、僵硬、身毛豎立；想要使我從獨處撤退而說偈頌。」 |
| 时，阿罗毗迦比丘尼知是恶魔波旬，以偈答恶魔波旬曰：           | 那時，阿羅毘迦比丘尼知道：「這是魔波旬。」後，以偈頌回應魔波旬： |
| 1世间有出离                                                  | 「世間中有出離，                                             |
| 2依智我自达                                                  | 被我以慧善觸達，                                             |
| 3放逸恶波旬                                                  | 波旬！放逸者的親族！                                         |
| 4汝不知其道                                                  | 你不知道那個境界(足跡)。                                     |
| 5欲乐如剑枪                                                  | 諸欲是如劍戟的，                                             |
| 6诸蕴断头台                                                  | 這些的聚集是斷頭台，                                         |
| 7汝云味欲乐                                                  | 你說凡欲的喜樂，                                             |
| 8于我非为乐                                                  | 對我那是不喜樂。」                                           |
| 时，恶魔波旬苦恼以‘阿罗毗迦比丘尼已知我。’萎身隐没其身形。   | 那時，魔波旬：「阿羅毘迦比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
