| 第七 优波遮罗                                            | 7. 優波遮羅經                                                |
| [尔时，世尊]住舍卫城……。                                 | 起源於舍衛城。                                               |
| 时，优波遮罗比丘尼清晨入舍卫乞食……乃至……为日住坐于树下。 | 那時，優波遮羅比丘尼午前時穿好衣服後……（中略）坐在某棵樹下為了白天的住處。 |
| 恶魔波旬如是谓优波遮罗比丘尼曰：                         | 那時，魔波旬去見優波遮羅比丘尼。抵達後，對優波遮羅比丘尼說這個： |
| ‘比丘尼!汝欲生于何处?’                                   | 「比丘尼！你想要往生哪裡？」                                 |
| ‘友!我不欲生于何处!’                                     | 「朋友！我不想往生任何地方。」                               |
| [恶魔：]                                                 |                                                              |
| 1三三炎摩天                                              | 「三十三與夜摩，                                             |
| 2或是兜率天                                              | 還有兜率天神，                                               |
| 3或是化乐天                                              | 化樂天神，                                                   |
| 4他化自在天                                              | 凡自在天神們，                                               |
| 5愿心以向此                                              | 在那裡請你定置心，                                           |
| 6当得受此乐                                              | 你將體驗喜樂。」                                             |
| [比丘尼]                                                 |                                                              |
| 1三三炎摩天                                              | 「三十三與夜摩，                                             |
| 2或是兜率天                                              | 還有兜率天神，                                               |
| 3或是化乐天                                              | 化樂天神，                                                   |
| 4他化自在天                                              | 凡自在天神們，                                               |
| 5此等爱欲缚                                              | 他們被欲的繫縛繫縛，                                         |
| 6再行魔领域                                              | 再來到魔的控制。                                             |
| 7世间一切燃                                              | 一切世界已燃燒，                                             |
| 8世间一切烟                                              | 一切世界已冒煙，                                             |
| 9世间悉吐炎                                              | 一切世界已熾然，                                             |
| 10世间悉震动                                             | 一切世界已顫抖。                                             |
| 11不震不动处                                             | 不搖動的、不熾然的，                                         |
| 12凡常人不到                                             | 非一般人(凡夫)親近的，                                       |
| 13非恶魔行处                                             | 在魔的不去之處，                                             |
| 14于此我心乐                                             | 在那裡是我的意(心)喜好的。」                                 |
| 时，恶魔波旬……乃至……苦恼萎身，隐没其身形。               | 那時，魔波旬：「優波遮羅比丘尼知道我。」痛苦地、不快樂地就在那裡消失。 |
