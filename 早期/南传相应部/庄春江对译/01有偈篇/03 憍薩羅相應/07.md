| 第七 裁断                                                    | 7. 法庭經                                                    |
|                                                              | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王白世尊曰：                         | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!我坐于裁判之座，见有大富、有大财大产、甚多资财、甚多财谷之刹帝利、婆罗门、家主等，自知为欲乐，依于欲乐，欲乐之故而语妄语。 | 「大德！這裡，當坐在法庭時，我看見富有的、大富的、大財富的、多金銀的、多財產資具的、多財穀的剎帝利富翁、婆羅門富翁、屋主富翁，欲之因、欲之因由、因為欲故意虛妄地說， |
| 故我生如是思念：‘我今有充分裁断，今当依裁断以显贤面 。’      | 大德！那個我想這個：『現在，我受夠了法庭，現在賢面將被法庭被看到。』」 |
|                                                              | 「（這是這樣，大王！這是這樣，大王！）                       |
| ‘大王!有大富，有大财大产，甚多金银，甚多资财，甚多财谷之刹帝利、婆罗门、家主等，自知为欲乐，依于欲乐，欲乐之故而语妄语，彼等应长时之不利苦恼。’ | 大王！凡那些富有的、大富的、大財富的、多金銀的、多財產資具的、多財穀的剎帝利富翁、婆羅門富翁、屋主富翁，欲之因、欲之因由、因為欲故意虛妄地說，那對他們將有長久的不利、苦。」 |
| [世尊宣说此已……乃至……]                                       | 世尊說這個……（中略）：                                       |
| 1富迷于欲乐                                                  | 「在受用諸欲上貪著者們，                                     |
| 2贪欲以夺心                                                  | 在諸欲上貪求者們、迷昏頭者們，                               |
| 3不知于道外                                                  | 他們越界不覺醒，                                             |
| 4如鱼被网罗$$\color{red}（不知道是谁错了）$$                 | 如鹿對佈置陷阱的詐欺者，                                     |
| 5彼等后苦涩                                                  | 之後他們有苦澀的，                                           |
| 6其果即是恶                                                  | 因為那個的果報是惡的。                                       |
