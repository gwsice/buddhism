| 第六 公主                                        | 16. 茉莉經                                                   |
| 舍卫城因缘。                                     | 起源於舍衛城。                                               |
| 时，拘萨罗国之波斯匿王，往诣世尊处，             | 那時，憍薩羅國波斯匿王去見世尊。                             |
| 诣已，礼敬世尊，坐于一面。                       | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 时，有一人，坐近拘萨罗国之波斯匿王，             | 那時，某位男子去見憍薩羅國波斯匿王。                         |
| 进而耳语于拘萨罗国波斯匿王告曰:                  | 抵達後，在憍薩羅國波斯匿王的耳朵處通知：                     |
| ‘王!末利夫人生王女。’                            | 「陛下！茉莉皇后已生女兒。」                                 |
| 如是云时，拘萨罗国之波斯匿王不喜。               | 在這麼說時，憍薩羅國波斯匿王成為不悅意的。                   |
| 时，世尊，知拘萨罗国波斯匿王之不喜，于是唱偈曰． | 那時，世尊知道憍薩羅國波斯匿王成為不悅意的後，那時候說這些偈頌： |
| 1人主或妇人                                      | 「某一類女性確實，                                           |
| 2胜比于男子                                      | 比男人是比較好的，王！                                       |
| 3有智慧全戒                                      | 有智慧者、持戒者，                                           |
| 4敬姑及事夫                                      | 婆婆當天神者、對丈夫忠貞者。                                 |
| 5以生其子者                                      | 凡被她生的男子，                                             |
| 6英雄地上主                                      | 成為英雄、諸方之主，                                         |
| 7实如贤妻子                                      | 像那樣好妻子的兒子，                                         |
| 8亦教导王国                                      | 教誡王國。」                                                 |
