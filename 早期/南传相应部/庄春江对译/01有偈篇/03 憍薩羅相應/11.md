| 第二 拘萨罗品                                                | 2.第二品                                                     |
| 第一 结发行者                                                | 11. 七位結髮者經                                             |
| 尔时，世尊住舍卫城东园鹿子母讲堂。                           | 有一次，世尊住在舍衛城東園鹿母講堂。                         |
| 又，其时将日暮世尊从独坐静观起座，出而坐于门外之小屋。       | 當時，世尊傍晚時，從獨坐出來，坐在外面的門屋。               |
| 时，拘萨罗国之波斯匿王诣世尊处。                             | 那時，憍薩羅國波斯匿王去見世尊。                             |
| 诣已，礼敬世尊，坐于一面。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 其时有七名结发行者，七名尼乾陀徒，七名裸行者，七名一衣者，七人名游行者等，其腋下毛或身毛均长，爪亦长持游方者之用具，通过离世尊不远之处。 | 當時，有七位結髮者、七位尼乾陀、七位裸行者、七位一衣者、七位遊行者，長的腋毛、指甲、體毛，拿起一佉梨重荷物的扁擔後，從世尊不遠處走過。 |
| 时，拘萨罗国之波斯匿王，即从座起立，着上衣、偏袒一肩、右膝着地、向七名结发行者，七名尼乾陀徒，七名裸行者，七名一衣者，七名游方者合掌，三次称呼其名： | 那時，憍薩羅國波斯匿王從座位起來、置(作)上衣到一邊肩膀、右膝觸地後，向那七位結髮者、七位尼乾陀、七位裸行者、七位一衣者、七位遊行者合掌鞠躬後，告知名字三次： |
| ‘尊者!我乃拘萨罗国之波斯匿王，尊者!我乃拘萨罗国之波斯匿王。’ | 「大德！我是憍薩羅國波斯匿王……（中略）大德！我是憍薩羅國波斯匿王。」 |
| 时，拘萨罗国之波斯匿王，离开彼等七名结发行者，七名尼乾陀徒，七名裸行者，七名一衣者，七名游行者去后，直诣世尊之处。 | 那時，在那七位結髮者、七位尼乾陀、七位裸行者、七位一衣者、七位遊行者離開不久，憍薩羅國波斯匿王去見世尊。 |
| 诣已，礼敬世尊，坐于一面。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之拘萨罗国波斯匿王，白世尊曰：                       | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!此等之诸人，于此世间，为阿罗汉，或具足阿罗汉之诸人中耶?’ | 「大德！凡世間中阿羅漢，或進入阿羅漢道，這些是他們中之一。」 |
| ‘大王!此等诸人是阿罗汉耶?为具足阿罗汉道者耶?即如王者之在家受用欲乐，住于子嗣之障碍中，即使用迦尸国之栴檀，用华鬘、香、涂料，贮蓄金银者亦不易知。 | 「大王！以在家受用欲的，以居住兒子擁擠床的，以享用迦尸的檀香的，以持有花環、香料、塗油的，以受用金銀的你，這是難知的： |
|                                                              | 『這些是阿羅漢，或這些是進入阿羅漢道者。』                   |
| 大王!彼之戒依于共住而且非短时，依长时而非不思惟、依思惟而非无智、应依有智慧而得知。 | 大王！以共住，戒能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
| 大王!彼之清净是依于共语，而且非短时，依长时而非不思惟，依思惟而非无智，应依有智慧而得知。 | 大王！以對談，純淨能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
| 大王!彼之确立，于不幸之时，而且非短时，依长时而非不思惟，依思惟而非无智，应依有智慧而得知。 | 大王！在災禍中，強力能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
| 大王!彼之智慧，依共同商量，而且非短时，依长时而非不思惟，依思惟而非无智，应依有智慧而得知。’ | 大王！以討論，慧能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
| ‘世尊!诚然希有。世尊!诚然未曾有。世尊，此事确实是依世尊之所说。 | 「不可思議啊，大德！未曾有啊，大德！大德！這被世尊多麼善說： |
| ‘大王!此事即使在家受用欲乐……乃至……贮蓄金银亦不易知……乃至……。’ | 『大王！以在家受用欲的，以居住兒子擁擠床的，以享用迦尸的檀香的，以持有花環、香料、塗油的，以受用金銀的你，這是難知的： |
|                                                              | 「這些是阿羅漢，或這些是進入阿羅漢道者。」                   |
|                                                              | 大王！以共住，戒能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
|                                                              | 大王！以交談，純淨能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
|                                                              | 大王！在災禍中，強力能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。 |
|                                                              | 大王！以討論，慧能被感知，且那是以長時間的，非短暫的；以作意者，非以不作意者；以有慧者，非以劣慧者。』 |
| 世尊!此等我密访、访察者 之诸人，于访察各国归来。             | 大德！這些男子是我的間諜、臥底者，從它國偵察後回來。         |
| 最初依彼等之所察访，于后我来作结论。                         | 先被他們偵察後，我將處置。                                   |
| 世尊，如今彼等为去其尘垢，沐浴涂以香料，剃除须发，穿着白衣，为五欲所缠绕，所具者足乐。’ | 大德！現在，他們除去那塵垢污穢後，被善浴、善塗油，整理好髮鬚，穿上白衣，他們將賦有、擁有五種欲自娛。」 |
| 时，世尊了知此义，于此时唱偈曰：                             | 那時，世尊已知這件事後，那時候說這些偈頌：                   |
| 1色貌之于人 2实是不易知                                      | 「人非以容色形相成為容易知道者，                             |
| 3即刻见勿信                                                  | 非以短暫的看見應該信賴，                                     |
| 4善制者其相                                                  | 因為以善制御的特徵，                                         |
| 5非为制御人 6此世普横行                                      | 無制御者們行走這個世間。                                     |
| 7如似是而非 8泥土之耳环                                      | 如黏土作的假耳環，                                           |
| 9渡金铜半钱                                                  | 如黃金包覆的金屬半分錢，                                     |
| 10人人装饰美                                                 | 附屬物包覆者們在世間中行：                                   |
| 11内怀于不净 12外面美横行                                    | 內在不純淨、外在亮麗者們。」                                 |
