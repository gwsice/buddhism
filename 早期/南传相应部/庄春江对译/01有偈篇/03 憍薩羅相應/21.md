| 第三 拘萨罗品                                                | 3.第三品                                                     |
| 第一 人                                                      | 21. 人經                                                     |
| [尔时，世尊]在舍卫城……                                       | 起源於舍衛城。                                               |
| 时，拘萨罗国之波斯匿王，往诣世尊处。                         | 那時，憍薩羅國波斯匿王去見世尊。                             |
| 诣已，礼敬世尊，于一面坐，                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 世尊谓于一面坐之拘萨罗国波斯匿王曰：                         | 世尊對在一旁坐下的憍薩羅國波斯匿王說這個：                   |
| ‘大王!世间有四种人。’‘四种者何耶?’                           | 「大王！有這四種現在的世間中存在的人，哪四種？               |
| ‘乃：由闇入闇，由闇入明，由明入闇，由明入明者是。’           | 闇黑到闇黑者、闇黑到光明者、光明到闇黑者、光明到光明者。     |
| 大王!如何之为由闇入闇耶?                                     | 大王！而怎樣一個人是闇黑到闇黑者？                           |
| 大王!今有人生卑贱家、生于旃陀罗家、作竹笼家、猎夫家、作皮家 、清洁夫家，贫穷而缺乏饮食，生计困难，难得衣食 | 大王！這裡，某人被再生在卑賤家：在旃陀羅家，或在竹匠家，或在獵人家，或在車匠家，或在清垃圾者家，在貧窮處，在少食物、飲料、飲食處，在生活困難處，於該處衣食被困難地得到。 |
| 丑陋，畸躯而驼背 ，多病、独眼、曲手、跛足、半身不遂，不得饮食、衣服、车乘、华鬘、香、涂香、寝床、住居、灯光。 | 他是醜陋者、醜惡者、矮小者、多種疾病者：單眼者，或手彎曲畸形者，或跛腳者，或癱瘓者，是食物、飲料、衣服、交通工具、花環、香料、塗油、臥床、房舍、燈燭的非利得者。 |
| 彼身为恶行、语为恶行、意为恶行。彼为此身、语、意之恶行，身体毁坏死后，堕于苦处、恶处、地狱。 | 他以身行惡行，以語行惡行，以意行惡行，他以身體的崩解，死後往生苦界、惡趣、下界、地獄。 |
| 大王!譬喻人由闇入闇，由闇入闇，即由血暗 入血暗。             | 大王！猶如男子從黑暗走到黑暗，或從闇黑走到闇黑，或從血垢走到血垢， |
| 大王!我说譬喻此人。                                          | 大王！我說這個人是像這樣者。                                 |
| 大王!如是等人是由闇入闇。                                    | 大王！這樣的人是闇黑到闇黑者。                               |
| 大王!如何之人是由闇入明耶?                                   | 大王！而怎樣一個人是闇黑到光明者？                           |
| 大王!如今有人生卑贱、旃陀罗家、作竹笼家、猎夫家、皮匠家、清洁夫家，贫穷而缺乏饮食，生计困难，难得衣食， | 大王！這裡，某人被再生在卑賤家：在旃陀羅家，或在竹匠家，或在獵人家，或在車匠家，或在清垃圾者家，在貧窮處，在少食物、飲料、飲食處，在生活困難處，於該處衣食被困難地得到。 |
| 丑陋奇而驼背、多病、独眼、曲手、跛足、半身不遂，不得饮食、衣服、车乘、华鬘、香、涂香、寝床、住居、灯光。 | 他是醜陋者、醜惡者、矮小者、多種疾病者：單眼者，或手彎曲畸形者，或跛腳者，或癱瘓者，是食物、飲料、衣服、交通工具、花環、香料、塗油、臥床、房舍、燈燭的非利得者。 |
| 彼身行善行，口行善行、意行善行。彼于身语意善行。身体毁坏死后，生善趣天界。 | 他以身行善行，以語行善行，以意行善行，他以身體的崩解，死後往生善趣、天界。 |
| 大王!譬喻有人由地乘舆，由舆移乘马背，由马背移乘象，由象肩移登高楼。 | 大王！猶如男子從地上登上轎子，或從轎子登上馬背，或從馬背登上象背，或從象背登上高樓， |
| 大王!正如我以此人为喻。                                      | 大王！我說這個人是像這樣者。                                 |
| 大王!如是之人是由闇入明。                                    | 大王！這樣的人是闇黑到光明者。                               |
| 大王!如何之为人由明入闇耶?                                   | 大王！而怎樣一個人是光明到闇黑者？                           |
| 大王!于今有人生高贵家。生大富刹帝利家、大富婆罗门家、大富家主之家、富而有大财、大产、多金银、多资财、多财谷之家。 | 大王！這裡，某人被再生在高貴家：在大財富剎帝利家，或在大財富婆羅門家，或在大財富屋主家，在富有處，在大富處，在大財富處，在多金銀處，在多財產資具處，在多財穀處。 |
| 彼等美貌、见好、似乐见莲叶其最上美色之皮肤。得饮食、衣服、车乘、华鬘、香、涂香、寝床、住居、明灯。 | 他是英俊者、好看者、端正者、具備最美的容色者，食物、飲料、衣服、交通工具、花環、香料、塗油、臥床、房舍、燈燭的利得者。 |
| 彼身为恶行、口为恶行、意为恶行。彼者身、口、意为恶行、身体毁坏死后，堕恶趣、苦处、地狱。 | 他以身行惡行，以語行惡行，以意行惡行後，以身體的崩解，死後往生苦界、惡趣、下界、地獄。 |
| 大王!譬喻人由高楼下至象肩、由象肩下至马背，由马背下至舆，由舆下至地面，由地面降入于闇[处]。 | 大王！猶如男子從高樓下到象背，或從象背下到馬背，或從馬背下到轎子，或從轎子下到地上，或從地上進入黑暗， |
| 大王!我说譬喻此人，                                          | 大王！我說這個人是像這樣者。                                 |
| 大王!如是之人，是由明入暗。                                  | 大王！這樣的人是光明到闇黑者。                               |
| 大王!如何之人为由明入明耶?                                   | 大王！而怎樣一個人是光明到光明者？                           |
| 于今有人生高贵家，生大富刹帝利家、大富婆罗门家、大富家主之家、富而有大财、大产、多金银、多资财、多财谷之家。 | 大王！這裡，某人被再生在高貴家：在大財富剎帝利家，或在大財富婆羅門家，或在大財富屋主家，在富有處，在大富處，在大財富處，在多金銀處，在多財產資具處，在多財穀處。 |
| 得饮食、衣服、车乘、华鬘、香、涂香、寝床、住居、明灯。       | 他是英俊者、好看者、端正者、具備最美的容色者，食物、飲料、衣服、交通工具、花環、香料、塗油、臥床、房舍、燈燭的利得者。 |
| 彼之身为善行、口为善行、意为善行。彼者身、口、意为善行，身体毁坏死后，生善趣、天界。 | 他以身行善行，以語行善行，以意行善行後，以身體的崩解，死後往生善趣、天界。 |
| 大王!譬喻有人，由舆移至马背、由马背移至象肩、由象肩移至高楼。 | 大王！猶如男子從轎子移到轎子，或從馬背移到馬背，或從象背移到象背，或從高樓移到高樓， |
| 大王!我说譬喻比人，                                          | 大王！我說這個人是像這樣者。                                 |
| 大王!如是之人，是由明入明。                                  | 大王！這樣的人是光明到光明者。                               |
| 大王!世有如此[四种之]众人。’                                 | 大王！這是現在的世間中存在的四種人。」                       |
