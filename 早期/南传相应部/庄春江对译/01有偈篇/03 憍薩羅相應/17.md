| 第七 不放逸(其一)                                            | 17. 不放逸經                                                 |
| [尔时，世尊]在舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王以此白世尊曰：                     | 在一旁坐下。在一旁坐下的憍薩羅國波斯匿王對世尊說這個：       |
| ‘世尊!现世之利与未来之利，可有取得两利之一法耶?’             | 「大德！有一法，凡達到後住立二者的利益：當生的連同後世的利益嗎？」 |
| ‘大王!有取得现在与未来之利为一法者。’                        | 「大王！有一法，凡達到後住立二者的利益：當生的連同後世的利益。」 |
| ‘世尊!有取得现在之利与未来之利为一法者，何耶?’               | 「大德！那麼，哪一法，凡達到後住立二者的利益：當生的連同後世的利益？」 |
| ‘大王!取得现在之利与未来之利为一法者，是不放逸。             | 「大王！不放逸是一法，凡達到後住立二者的利益：當生的連同後世的利益。 |
| 大王!譬喻任何步行兽之足迹，皆入于象之足迹。即云象之足迹，其大为第一。 | 大王！猶如凡任何叢林生物的足跡類者，那些全都在象的足跡中走到容納，象的足跡被告知為它們中最高的，即：以大的狀態。 |
| 大王!如是现在之利与未来之利，以此二利取之为一法。’           | 同樣的，大王！不放逸是一法，達到後住立二者的利益：當生的連同後世的利益。」 |

| 1生命与无病                                                  | 「對壽命、無病、美貌，                                       |
| 2美貌生天界 4以生高贵家                                      | 對天界、高貴家系的狀態，                                     |
|                                                              | 對喜樂以欲求者：                                             |
| 3日日于愿望                                                  | 廣大的、更多更多的，                                         |
| 5贤者行功德                                                  | 賢智者們稱讚，                                               |
| 6称赞不放逸                                                  | 在諸福德行為上不放逸者們。                                   |
| 7贤者不放逸                                                  | 不放逸的賢智者，                                             |
| 10若得此二利                                                 | 擁有二種利益：                                               |
| 8现法之益利                                                  | 凡在當生中的利益，                                           |
| 9乃至未来利                                                  | 以及凡後世的利益，                                           |
| 11依于得此义                                                 | 現觀利益的堅固者，                                           |
| 12英雄谓贤者                                                 | 被說為『賢智者』。                                           |
