| 第八 末利                                                    | 8. 茉莉經                                                    |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 又，尔时，拘萨罗之波斯匿王与末利夫人，具在高楼之上。         | 當時，憍薩羅國波斯匿王與與茉莉皇后一起到殊勝高樓上層。       |
| 时，拘萨罗之波斯匿王言末利夫人曰：                           | 那時，憍薩羅國波斯匿王對茉莉皇后說這個：                     |
| ‘末利!可有其他之何人比汝更可爱耶?’                           | 「茉莉！你有任何其他比自己更可愛的嗎？」                     |
| ‘大王!无有其他之何人比我更可爱者。大王!有其他之何人比汝自己更可爱耶?’ | 「大王！我沒有任何其他比自己更可愛的。大王！那麼，你有任何其他比自己更可愛的嗎？」 |
| ‘末利!无有其他之何人，比我更可爱者。’                        | 「茉莉！我也沒有任何其他比自己更可愛的。」                   |
| 时，拘萨罗国之波斯匿王，走下高楼诣世尊处。                   | 那時，憍薩羅國波斯匿王從高樓下來後，去見世尊。               |
| 诣已，礼敬世尊，坐于一面。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之拘萨罗国波斯匿王，白世尊曰：                       | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!我于此与末利夫人于高楼上，以此言末利夫人：             | 「大德！這裡，我與茉莉皇后一起到殊勝高樓上層，對茉莉皇后說這個： |
| ‘末利!可有其他之何人比汝更可爱耶?’                           | 『茉莉！你有任何其他比自己更可愛的嗎？』                     |
| 世尊!如是言已，末利夫人以此言我曰：                          | 在這麼說時，茉莉皇后對我說這個：                             |
| ‘大王!无有其他之何人，比我更可爱者。大王!可有其他之何人，比王我更可爱耶?’ | 『大王！我沒有任何其他比自己更可愛的。大王！那麼，你有任何其他人比自己更可愛的嗎？』 |
| 世尊!如是言已，以此我对末利夫人曰：                          | 在這麼說時，我對茉莉皇后說這個：                             |
| ‘末利!无有其他之何人，比我自己更可爱者。’’                   | 『茉莉！我也沒有任何其他比自己更可愛的。』」                 |
| 时，世尊了知此义，其时，唱此偈曰：                           | 那時，世尊知道這件事後，那時候說這偈頌：                     |
| 1思虽往一切                                                  | 「以心遊歷一切方位後，                                       |
| 2不达于比己 3更为可爱者                                      | 確實沒得到任何比自己更可愛的，                               |
| 4其他之诸人 5亦是可爱己                                      | 這樣個個自己比他人是可愛的，                                 |
| 6是故为自爱 7勿以伤害他                                      | 因此愛惜自己者不應該害他人。」                               |
