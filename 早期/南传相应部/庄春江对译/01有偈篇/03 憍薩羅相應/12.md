| 第二 五王                                                    | 12. 五位國王經                                               |
| [尔时，世尊]住舍卫城……。                                     | 起源於舍衛城。                                               |
| 其时，波斯匿王初为五王，为五欲所围缠，充分享受快乐。         | 當時，當波斯匿王為首之五位國王賦有、擁有五種欲自娛時，       |
| 彼于此间生起如是言语：‘何为欲爱之第一?’                      | 這個談論中間出現：「什麼是諸欲中第一的呢？」                 |
| 时，或有人作如是说：‘色是欲爱之第一。’                       | 在那裡，某些說這個：「色是諸欲中第一的。」                   |
| 或作如是说：‘声是爱之第一。’                                 | 某些說這個：「聲音是諸欲中第一的。」                         |
| 或作如是说：‘香是欲爱之第一。’                               | 某些說這個：「氣味是諸欲中第一的。」                         |
| 或作如是说：‘味是欲爱之第一。’                               | 某些說這個：「味道是諸欲中第一的。」                         |
| 或作如是说：‘触是欲爱之第一。’                               | 某些說這個：「所觸是諸欲中第一的。」                         |
| 当时彼等诸王，互相皆不能承服。                               | 由於那些國王不能夠互相說服，                                 |
| 时，拘萨罗国之波斯匿王，以此谓彼等诸王曰：                   | 那時，憍薩羅國波斯匿王對那些國王說這個：                     |
| ‘友!请过来，我等何不往诣世尊处，                             | 「親愛的先生們！我們走，我們將去見世尊。                     |
| 请问此义。如世尊为我等所说，应予各自受持。’                  | 抵達後，讓我們問世尊這件事，世尊將為我們解說，讓我們依那樣憶持它。」 |
| 彼等五王答拘萨罗国之波斯匿王：‘友!诚然。’                    | 「是的，親愛的先生！」那些國王回答憍薩羅國波斯匿王。         |
| 时彼等五王，以波斯匿王为先导，往诣世尊之处，                 | 那時，以波斯匿王為首的五位國王去見世尊。                     |
| 诣已，礼敬世尊，坐于一面。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之拘萨罗国波斯匿王，以此语白世尊：                   | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!于此我等五王，为五欲所缠，充分享受快乐。我等之间生出如此言语：‘何为欲爱之第一耶?’ | 「大德！這裡，當我們五位國王賦有、擁有五種欲自娛時，這個談論中間出現：『什麼是諸欲中第一的呢？』 |
| 或亦有人作如是说：‘色是爱欲之第一。’                         | 某些說這個：『色是諸欲中第一的。』                           |
| 或作如是说：‘声是欲爱之第一。’                               | 某些說這個：『聲音是諸欲中第一的。』                         |
| 或作如是说：‘香是欲爱之第一。’                               | 某些說這個：『氣味是諸欲中第一的。』                         |
| 或作如是说：‘味是欲爱之第一。’                               | 某些說這個：『味道是諸欲中第一的。』                         |
| 或作如是说：‘触是欲爱之第一。’                               | 某些說這個：『所觸是諸欲中第一的。』                         |
| 世尊!何为欲爱之第一耶?’                                      | 大德！什麼是諸欲中第一的呢？」                               |
| ‘大王!我说限以人心 所好之程度，为欲爱之第一。                | 「大王！我說：『合意的範圍是五欲中第一的。』                 |
| 大王!此等诸色，或为心之所好者，或为心之所不好者。            | 大王！同樣那個色，對某些人是合意的，同樣那個色，對某些人是不合意的。 |
| 有人或依色而欢喜，若能满足所思，则更希望求其他更殊胜微妙之色。于彼而言，则其色乃无上之最殊胜。 | 而凡他以那些色為悅意的、完全滿意的(意向被充滿)者，他不欲求其它比那些更上的或更勝妙的色，對他，那些色是最高的；對他，那些色是無上的。 |
| 大王!此等之声……乃至……香……乃至……味……乃至……此等之触，或为心所好者，或为心所不好者。 | 大王！同樣那個聲音，對某些人是合意的，同樣那個聲音，對某些人是不合意的。 |
|                                                              | 而凡他以那些聲音為悅意的、完全滿意的者，他不欲求其它比那些更上的或更勝妙的聲音，對他，那些聲音是最高的；對他，那些聲音是無上的。 |
|                                                              | 大王！同樣那個氣味，對某些人是合意的，同樣那個氣味，對某些人是不合意的。 |
|                                                              | 而凡他以那些氣味為悅意的、完全滿意的者，他不欲求其它比那些更上的或更勝妙的聲音，對他，那些氣味是最高的；對他，那些氣味是無上的。 |
|                                                              | 大王！同樣那個味道，對某些人是合意的，同樣那個味道，對某些人是不合意的。 |
|                                                              | 而凡他以那些味道為悅意的、完全滿意的者，他不欲求其它比那些更上的或更勝妙的味道，對他，那些味道是最高的；對他，那些味道是無上的。 |
|                                                              | 大王！同樣那個所觸，對某些人是合意的，同樣那個所觸，對某些人是不合意的。 |
| 有人或依触而欢喜，若得满足所思，则不再希望其他更殊胜微妙之触。于彼而言，其触乃无上之最殊胜。’ | 而凡他以那些所觸為悅意的、完全滿意的者，他不欲求其它比那些更上的或更勝妙的所觸，對他，那些所觸是最高的；對他，那些所觸是無上的。」 |
| 尔时，亦有栴檀庵伽梨迦优婆塞坐其会座。                       | 當時，栴檀額利迦優婆塞坐在那些群眾中。                       |
| 时栴檀庵伽梨迦优婆塞即从座而起，偏袒一肩，合掌向世尊，以此谓世尊曰： | 那時，栴檀額利迦優婆塞從座位起來、置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!思我则不显。                                           | 「世尊！它在我心中出現；                                     |
| 善逝!思我则不显。’                                           | 善逝！它在我心中出現。」                                     |
| 世尊曰：‘栴檀庵伽梨迦!显此。’                                | 「栴檀額利迦！請你說明。」世尊說。                           |
| 时，栴檀胺庵梨迦优婆基于世尊座前，当场以相应之偈赞叹之：     | 那時，栴檀額利迦優婆塞在世尊的面前以相應那樣的偈頌大讚：     |
| 1芳香赤莲华                                                  | 「如芬芳的紅蓮、紅睡蓮，                                     |
| 2晨开香不去                                                  | 會在清晨香氣不散地盛開，                                     |
| 3见鸯耆罗光                                                  | 請看放光者、照耀者，                                         |
| 4映空如太阳                                                  | 如在空中輝耀的太陽。」                                       |
| 时，彼等五王，向栴檀庵伽梨迦优婆塞五件僧伽梨请穿着。         | 那時，那五位國王以五件上衣使栴檀額利迦優婆塞裹上。           |
| 时，栴檀庵伽梨迦优婆塞，即以此五件僧伽梨奉献世尊。           | 那時，栴檀額利迦優婆塞以那五件上衣使世尊裹上。               |
