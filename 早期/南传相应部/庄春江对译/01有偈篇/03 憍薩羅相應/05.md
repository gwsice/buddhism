| 第五 自护                                                    | 5已自己守護經                                                |
|                                                              | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王，白世尊曰：                       | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!我独坐静观生如是念：何人乃护自我；何人不护自我耶?      | 「大德！這裡，獨處、獨坐的我這樣心的深思生起：『對誰自己已守護呢？對誰自己未守護呢？』 |
| 世尊!我如是思念：任何人依身以行恶行、依语以行恶行、依意以行恶行者，其人即是不护自我。彼等如何受象军之善护、马军之善护、车军之善护、步军之善护、但不护彼等之自我。何以故， | 大德！我想這個：『凡任何以身行惡行、以語行惡行、以意行惡行者，對他們自己未守護，即使他們象軍會守護，或馬軍會守護，或車軍會守護，或步兵軍會守護，但對他們自己未守護，那是什麼原因？ |
| 此等外在之守护，此等非为内在之守护。是故非守护彼等之自我。   | 因為這個守護是外部的，這個守護不是自身內的，因此，對他們自己未守護。 |
| 任何人依身以行善行、依语以行善行、依意以行善行者，其人乃护自我者。彼等虽云无任何象军之守护、无马军之守护、无车军之守护、无步军之守护、但有守护彼等之自我。何以故? | 凡任何以身行善行、以語行善行、以意行善行者，他們已守護自己，即使他們象軍不會守護，或馬軍不會守護，或車軍不會守護，或步兵軍不會守護，但對他們自己已守護，那是什麼原因？ |
| 此等乃内在之守护，此等非外在之守护。是故乃守护彼等之自我。   | 因為這個守護是自身內的，這個守護不是外部的，因此，對他們自己已守護。』」 |
| ‘大王!如是，大王!如是。                                      | 「這是這樣，大王！這是這樣，大王！                           |
| 任何人依身、语、意以行恶行者，其人不护自我。                 | 大王！凡任何以身行惡行……（中略）對他們自己未守護，那是什麼原因？ |
|                                                              | 大王！因為這個守護是外部的，這個守護不是自身內的，因此，對他們自己未守護。 |
| 任何人依身、语、意以行善行者，其人乃护自我。’                | 大王！凡任何以身行善行、以語行善行、以意行善行者，他們已守護自己，即使他們象軍不會守護，或馬軍不會守護，或車軍不會守護，或步兵軍不會守護，但對他們自己已守護，那是什麼原因？ |
|                                                              | 因為這個守護是自身內的，這個守護不是外部的，因此，對他們自己已守護。」 |
| [世尊宣说此已……乃至……]                                       | 世尊說這個……（中略）：                                       |
| 1善哉自制身                                                  | 「以身自制，好！                                             |
| 2善哉自制语                                                  | 以語自制，好！                                               |
| 3善哉自制意                                                  | 以意自制，好！                                               |
| 4善哉制一切                                                  | 到處自制，好！                                               |
| 5自制知耻者                                                  | 到處自制者、有羞恥者，                                       |
| 6云为守护人                                                  | 被稱為『守護者』。」                                         |
