| 第八 不放逸(其二)                                            | 18. 善友經                                                   |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王以此白世尊曰：                     | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!我于独坐静观以生思念：                                 | 「大德！這裡，獨處、獨坐的我這樣心的深思生起：               |
| ‘依世尊之善说法，而与善友、善朋、善伴交；                    | 『法被世尊善說，而那是對有善的朋友、善的同伴、善的親密朋友者， |
| 非与恶友、恶朋、恶伴交。’’                                   | 不是對有惡的朋友、惡的同伴、惡的親密朋友者。』」             |
| ‘大王!如是，大王!如是。                                      | 「這是這樣，大王！這是這樣，大王！                           |
| 大王!依我善说法，而与善友、善朋、善伴交；                    | 大王！法被我善說，而那是對有善的朋友、善的同伴、善的親密朋友者， |
| 非与恶友、恶朋、恶伴交。                                     | 不是對有惡的朋友、惡的同伴、惡的親密朋友者。                 |
| 大王!尔时，我住释迦族邑。                                    | 大王！有這一次，我住在釋迦國，名叫那軋拉迦的釋迦族城鎮，     |
| 大王!时，阿难比丘诣我处。诣已，礼敬于我坐于一面，            | 大王！那時，阿難比丘來見我。抵達後，向我問訊後，在一旁坐下， |
| 大王!坐于一面之阿难比丘谓我曰：                              | 大王！在一旁坐下的阿難比丘對我說這個：                       |
| ‘世尊!此善友、善朋，善伴即梵行之一半。’                      | 『大德！這是梵行的一半，即：善的朋友之誼、善的同伴之誼、善的親密朋友之誼。』 |
| 大王!我如是言已、以此谓阿难比丘曰：                          | 大王！在這麼說時，我對阿難比丘說這個：                       |
| ‘阿难!不然。阿难!不然。阿难!此善友、善朋、善伴，乃是梵行之全部。 | 『阿難！不要這樣[說]，阿難！不要這樣[說]，阿難！這就是梵行的全部，即：善的朋友之誼、善的同伴之誼、善的親密朋友之誼。 |
| 阿难!有善友、善朋、善伴之比丘，得以期待于修行八支圣道，屡修八支圣道。 | 阿難！有善的朋友、善的同伴、善的親密朋友比丘的這個能被預期：他必將修習八支聖道、必將多作八支聖道。 |
| 阿难!如何有善友、善朋、善伴之比丘，屡修八支圣道耶?           | 阿難！而有善的朋友、善的同伴、善的親密朋友的比丘，如何修習八支聖道、多作八支聖道？ |
| 阿难!此比丘依远离，依离贪，依灭，以修正见，                  | 阿難！這裡，比丘依止遠離、依止離貪、依止滅、捨棄的成熟修習正見； |
| 舍离[烦恼]及转向[涅盘]。                                     | 依止遠離……（中略）修習正志                                   |
| 依远离，依离贪，依灭，以修正思[……乃至……]正语                 | ……（中略）修習正語……                                         |
| [……乃至……]正业                                               | （中略）修習正業……                                           |
| [……乃至……]正命                                               | （中略）修習正命……                                           |
| [……乃至……]正精进                                             | （中略）修習正精進……                                         |
| [……乃至……]正念                                               | （中略）修習正念；                                           |
| [……乃至……]正定，而舍离及转向。                               | 依止遠離、依止離貪、依止滅、捨棄的成熟修習正定。             |
| 阿难!如是有善友、善朋、善伴之比丘，以修行八支圣道，屡修八支圣道。 | 阿難！有善的朋友、善的同伴、善的親密朋友的比丘這樣修習八支聖道、多作八支聖道。 |
| 阿难!依此应知有善友、善朋、善伴，乃梵行之全部。              | 阿難！其次，以這個法門，這也能被知道：關於這就是梵行的全部，即：善的朋友之誼、善的同伴之誼、善的親密朋友之誼。 |
| 阿难!不论如何，依以我为善友，生法之众生，依生而解脱。老法之众生，依老而解脱，病法之众生，依病而解脱，死法之众生，依死而解脱，愁悲苦恼闷之众生，依愁悲苦恼闷而解脱。 | 阿難！由於善友的我，生法的眾生從生被釋放；老法的眾生從老被釋放；死法的眾生從死被釋放；愁悲苦憂絕望法的眾生從愁悲苦憂絕望被釋放。 |
| 阿难!依此应知有善友、善朋、善伴，乃梵行之全部。’             | 阿難！以這個法門，這能被知道：關於這就是梵行的全部，即：善的朋友之誼、善的同伴之誼、善的親密朋友之誼。』 |
| 大王!是故，王不能不如是学。                                  | 大王！因此，在這裡，應該被你這麼學：                         |
| 我应容有善友、善朋、善伴。大王!不能不如是学。                | 『我要成為有善的朋友、善的同伴、善的親密朋友者。』大王！應該被你這麼學。 |
| 大王!欲有善友、善朋、善伴者，不能不依此一法而住，            | 大王！當你有善的朋友、善的同伴、善的親密朋友時，這一法依止後應該被留下： |
| 即于善法不放逸。                                             | 在善法上的不放逸。                                           |
| 大王!王依不放逸、住不放逸者，王之后宫亦应如是思念：          | 大王！當你住於不放逸的時，依止不放逸的後，你的宮女隨從必將想這個： |
| ‘王依不放逸，住不放逸，我等亦应依不放逸、住不放逸。’         | 『國王住於不放逸，依止不放逸，來吧！讓我們也住於不放逸，依止不放逸。』 |
| 大王!王依不放逸、住不放逸者，刹帝利之侍臣等应如是思念：      | 大王！當你住於不放逸的時，依止不放逸的後，你的剎帝利隨從必將想這個： |
| ‘王依不放逸、住不放逸;我等亦应依不放逸、住不放逸。’          | 『國王住於不放逸，依止不放逸，來吧！讓我們也住於不放逸，依止不放逸。』 |
|                                                              | 大王！當你住於不放逸的時，依止不放逸的後，你的軍隊必將想這個： |
|                                                              | 『國王住於不放逸，依止不放逸，來吧！讓我們也住於不放逸，依止不放逸。』 |
| 大王!王依不放逸、住不放逸者，国民亦应如是思念：              | 大王！當你住於不放逸的時，依止不放逸的後，你的城鎮與地方人們必將想這個： |
| ‘王依不放逸、住不放逸；我等亦应依不放逸、住不放逸。’         | 『國王住於不放逸，依止不放逸，來吧！讓我們也住於不放逸，依止不放逸。』 |
| 大王!王依不放逸、住不放逸者，当亦护自己，                    | 大王！當你住於不放逸的時，依止不放逸的後，你自己必將被保護、被守護； |
| 亦护后宫，                                                   | 宮女也必將被保護、被守護；                                   |
| 亦护库藏。’                                                  | 寶庫與藏庫之家屋也必將被保護、被守護。」                     |
| [世尊宣说……乃至……]                                           | 世尊說這個……（中略）：                                       |
| 2欲待至大富                                                  | 「對財富以欲求者：                                           |
| 1继续负愿望                                                  | 廣大的、更多更多的，                                         |
| 3贤者行功德 4以赞不放逸                                      | 賢智者們稱讚，在諸福德行為上不放逸者們。                     |
| 5贤者不放逸                                                  | 不放逸的賢智者，                                             |
| 6以得二种利                                                  | 擁有二種利益：                                               |
| 7现世之益利                                                  | 凡在當生中的利益，                                           |
| 8以及未来利                                                  | 以及凡後世的利益，                                           |
| 9依得于此义                                                  | 現觀利益的堅固者，                                           |
| 10英雄谓贤者                                                 | 被說為『賢智者』。」                                         |
