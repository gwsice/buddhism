| 元亨寺                                                       | 庄春江                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 第二 人                                                      | 2.男子經                                                     |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 时，拘萨罗国之波斯匿王诣于世尊处。                           | 那時，憍薩羅國波斯匿王去見世尊。                             |
| 诣已，礼敬世尊坐于一面。                                     | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之拘萨罗国波斯匿王白世尊曰：                         | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!于人中生几何法，即成为人之不利、苦恼及不安住耶?’       | 「大德！當男子自身內的幾法生起時，生起不利、苦、不安樂住呢？」 |
| ‘大王!三法生于人中，即成为人之不利、苦恼与不安住。’三者为何? | 「大王！當男子自身內的三法生起時，生起不利、苦、不安樂住，哪三個？ |
| 大王!贪生于人中，即成为人之不利、苦恼与不安住。              | 當男子自身內的貪欲法生起時，生起不利、苦、不安樂住；         |
| 大王!嗔生于人中，即成为人之不利、苦恼与不安住。              | 大王！當男子自身內的瞋恚法生起時，生起不利、苦、不安樂住；   |
| 大王!痴生于人中，即成为人之不利、苦恼与不安住者。            | 大王！當男子自身內的愚癡法生起時，生起不利、苦、不安樂住，   |
|                                                              | 大王！當男子自身內的這三法生起時，生起不利、苦、不安樂住。」 |
| [世尊，宣说此已……乃至……]                                     | 說這個……（中略）：                                           |
| 1贪与嗔及痴                                                  | 「貪、瞋與愚，                                               |
| 2生此恶心已                                                  | 對惡心意的人，                                               |
| 3以为自伤害                                                  | 諸自己產生的它們殺害，                                       |
| 4如持倒竹实                                                  | 如自己果實的竹。                                             |
