| 第四 弓术                                                    | 24. 弓術經                                                   |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王，以此白世尊曰：                   | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!布施应于何处为之耶?’                                   | 「大德！布施應該被施與在何處呢？」                           |
| ‘大王!应于心之信乐处为作之。’                                | 「大王！在心淨信之處。」                                     |
| ‘世尊!于何处行施，有大果耶?’                                 | 「大德！那麼，在哪裡所施有大果？」                           |
| ‘大王!布施应于何处为?与何处行施有大果者，有别也。            | 「大王！『布施應該被施與在何處』，這是一個[問題]，而『在哪裡所施有大果』，這是另一個。 |
| 大王!施于持戒者有大果；于恶戒者则不然。                      | 大王！對持戒者的所施有大果，對破戒者不像那樣。               |
| 大王!诚然!今我问王，王之意云何耶?                            | 大王！那樣的話，就在這件事上我將反問你，你就如對你能接受的那樣回答它。 |
| 大王!王之意如何耶?于此王兴起战争，其战激烈。                 | 大王！你怎麼想它：這裡，如果有你的戰爭已出現，戰鬥已群集，   |
| 时，有不学，不熟习、不惯、不练、恐惧症而战栗、恐怖、逃亡之刹帝利青年来，王扶持其人，如是其人有用耶?’ | 那時，未學的、不熟練的、未作勤修的、無弓術善巧的、膽小的、僵硬的、恐懼的、逃跑的剎帝利少年到來，你會雇用(養)那位男子，以及以像那樣的男子是你需要的？」 |
| ‘世尊!不，我不扶持其人，其人无有用。’                        | 「大德！我不雇用那位男子，以及以像那樣的男子是非我需要的。」 |
| ‘时，有不学[……乃至……]逃亡之婆罗门青年                        | 「那時，未學的……（中略）婆羅門少年到來……                     |
| [……]毗舍之青年                                               | 那時，未學的……（中略）毘舍少年到來……                         |
| [……]首陀罗之青年来……乃至……                                   | 那時，未學的……（中略）首陀羅少年到來……」                     |
| 不，我不扶持其人，其人无有用。’                              | 「……以及以像那樣的男子是非我需要的。」                       |
| ‘大王!王之意云何耶?于此王兴起战争，其战激烈。                | 「大王！你怎麼想它：這裡，如果有你的戰爭已出現，戰鬥已群集， |
| 时，有有学、熟习、惯、练、无恐惧症、不战栗、不恐怖、不逃亡之刹帝利青年来，王扶持其人，如是其人有用耶?’ | 那時，善學的、熟練的、作勤修的、弓術善巧的、不膽小的、不僵硬的、不恐懼的、不逃跑的剎帝利少年到來，你雇用那位男子，以及以像那樣的男子是你需要的？」 |
| ‘世尊，我扶持其人，如是之人为有用。’                         | 「大德！我雇用那位男子，以及以像那樣的男子是我需要的。」     |
| ‘时，有有学[……乃至……]不逃亡之婆罗门青年                      | 「那時，……婆羅門少年到來……（中略）                           |
| [……]毗舍之青年                                               | 那時，……毘舍少年到來……（中略）                               |
| 首陀罗之青年来……乃至……王扶持此人，如是之人有用耶?’           | 那時，善學的、熟練的、作勤修的、弓術善巧的、不膽小的、不僵硬的、不恐懼的、不逃跑的首陀羅少年到來，你雇用那位男子，以及以像那樣的男子是你需要的？」 |
| ‘世尊!我扶持此人，如是之人有用。’                            | 「大德！我雇用那位男子，以及以像那樣的男子是我需要的。」     |
| ‘大王!如是任何家族，从其家族，无家而出家，以离五支并具五支者，施彼有大果。 | 「同樣的，大王！即使從凡什麼族姓，從在家出家成為無家者，而且他是捨斷五支者、具備五支者，所施於他有大果。 |
| 如何为离五支耶?为离爱欲、离嗔、离惛眠、离掉悔、离疑、此谓离五支。 | 哪五支被捨斷？欲的意欲被捨斷，惡意被捨斷，惛沈睡眠被捨斷，掉舉後悔被捨斷，疑被捨斷，這五支被捨斷。 |
| 如何为具五支耶?为具无学戒蕴、具无学定蕴、具无学慧蕴、具无学解脱蕴、具无学解脱知见蕴，此谓具五支。 | 哪五支被具備？無學戒蘊被具備，無學定蘊被具備，無學慧蘊被具備，無學解脫蘊被具備，無學解脫智見蘊被具備，這五支被具備。 |
| 施如是离五支、具五支者有大果。’                              | 像這樣，所施於捨斷五支者、具備五支者有大果。」               |
| 世尊宣说于此……乃至……师其时唱偈曰：                           | 世尊說這個，[說這個後，善逝、]大師[更進一步說這個]：         |
| 3善选巧弓术                                                  | 「弓術、力量與活力，                                         |
| 4勇气力青年                                                  | 凡在學生婆羅門上如果被發現，                                 |
| 1王为战生贵                                                  | 戰爭需要的國王雇用他，                                       |
| 2不扶持怯者                                                  | 非緣於出生的不勇敢者。                                       |
| 7忍辱有慈悲                                                  | 就像那樣耐性、溫雅，                                         |
| 8善供圣迹人                                                  | 諸法於該位上住立者，                                         |
| 5如是之智者                                                  | 對神聖行為的有智慧者，                                       |
| 6其生虽卑劣                                                  | 對即使出生低賤者也應該尊敬。                                 |
| 10欣乐作小屋                                                 | 應該使建造諸能被喜樂的草屋，                                 |
| 9善住多闻者                                                  | 在這裡應該使多聞者們居住，                                   |
| 11无水林设池                                                 | 應該在荒地建造喝水處，                                       |
| 12崄处与设道                                                 | 以及在難行處的通道。                                         |

| 14衣服及住居                                                 | 以及對衣服、臥坐具，                                         |
| 16善施直心人                                                 | 應該施與在成為正直者們上：                                   |

| 22贤者以集富 23食物及饮料                                    | 賢智者以食物飲料。                                           |
