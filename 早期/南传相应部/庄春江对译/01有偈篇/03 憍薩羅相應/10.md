| 第十 缚                                          | 10. 繫縛經                                                 |
| 又，其时，拘萨罗国之波斯匿王，捕缚甚多人。       | 當時，大群人被憍薩羅國波斯匿王使之繫縛：                   |
| 有者以绳、有者以网、有者以锁[缚之]。             | 一些被繩子，一些被腳鐐，另一些被鎖鏈。                     |
| 时，甚多比丘等，于晨早，着衣持钵，入舍卫城行乞。 | 那時，眾多比丘午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。 |
| 舍卫城行乞食已，收放钵后，诣世尊处。             | 在舍衛城為了托鉢行走後，餐後已從施食返回，去見世尊。       |
| 诣而礼敬世尊，坐于一面。                         | 抵達後，向世尊問訊後，在一旁坐下。                         |
| 坐于一面之彼等诸比丘，白世尊曰：                 | 在一旁坐下的那些比丘對世尊說這個：                         |
| ‘世尊!彼拘萨罗国之波斯匿王，捕缚甚多人：         | 「大德！這裡，大群人被憍薩羅國波斯匿王使之繫縛：           |
| 有者以绳、有者以网、有者以锁[缚之]。             | 一些被繩子，一些被腳鐐，另一些被鎖鏈。」                   |
| 时，世尊了知此义，于其时诵此偈曰：               | 那時，世尊知道這件事後，那時候說這些偈頌：                 |
| 3贤者不云缚 2或以苇之网                          | 「明智者們說堅固的繫縛不是那個：                           |
| 1铁绳以及木                                      | 凡鐵、木製的與燈心草，                                     |
| 5宝玉及珠环 4以心为迷醉                          | 在諸寶石耳環上貪著的、染著的，                             |
| 6又心系妻子                                      | 以及在妻兒們上凡有期待：                                   |
| 7贤者云强缚                                      | 明智者們說堅固的繫縛是這個，                               |
| 8牵引于此人 9虽缓亦难离                          | 往下拉的、徐緩的、難解脫的。                               |
| 11断此而出家                                     | 都切斷這個後遊行：                                         |
| 10无欲舍欲乐                                     | 無期待者們捨斷欲樂後。                                     |
