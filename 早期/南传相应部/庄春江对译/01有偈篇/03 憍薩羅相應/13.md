| 第三 大食                                                    | 13. 一桶煮好的經                                             |
| [尔时，世尊]在舍卫城……。                                     | 起源於舍衛城。                                               |
| 其时拘萨罗国之波斯匿王常食一陀那之饭食。                     | 當時，憍薩羅國波斯匿王吃一桶煮好的飯。                       |
| 时，拘萨罗之波斯匿王食后，就大息而诣世尊[处]。               | 那時，憍薩羅國波斯匿王是已食者、喘息者，他去見世尊。         |
| 诣已，礼敬世尊，坐于其傍。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 时，世尊知拘萨罗国波斯匿王饭食已讫，曾作大息，其时而唱此偈曰： | 那時，世尊知道憍薩羅國波斯匿王是已食者、喘息者後，那時候，他說了這偈頌： |
| 1以常持正念                                                  | 「當人經常有念地，                                           |
| 2取食知量人                                                  | 在得到的食物上知量時，                                       |
| 3则少有其苦                                                  | 他的諸苦痛(受)變薄，                                         |
| 4迟老得寿长                                                  | 守護壽命者緩慢地變老。」                                     |
| 尔时，善见摩纳立于拘萨罗国波斯匿王之后。                     | 當時，學生婆羅門善見站在憍薩羅國波斯匿王的後面。             |
| 时，拘萨罗国波斯匿王呼善见摩纳：                             | 那時，憍薩羅國波斯匿王召喚學生婆羅門善見：                   |
| ‘善见!汝在我食时，于世尊前暗唱此偈!我常日日施百钱与汝。’     | 「來！親愛的善見！你在世尊的面前學得這偈頌後，在我的食物到達時說，而我將持續每天給你(對你轉起)一百迦哈玻那的食物。」 |
| 善见摩纳答覆拘萨罗国之波斯匿王曰：‘大王!承教。’则暗[诵]在世尊前之偈，于拘萨罗国之波斯匿王食时即歌此偈： | 「是的，陛下！」學生婆羅門善見回答憍薩羅國波斯匿王後，在世尊的面前學得這偈頌後，在憍薩羅國波斯匿王的食物到達時確實地說： |
| 1以常持正念                                                  | 「當人經常有念地，                                           |
| 2取食知量人                                                  | 在得到的食物上知量時，                                       |
| 3则少有其苦                                                  | 他的諸苦痛變薄，                                             |
| 4迟老得寿长                                                  | 守護壽命者緩慢地變老。」                                     |
| 时，拘萨罗国之波斯匿王，即渐次满足于一陀那量之饭食。         | 那時，憍薩羅國波斯匿王次第地保持最多一那利的飯量。           |
| 如是拘萨罗国之波斯匿王，即较以往身体康健，以手抚其身体，当时发此欢喜语： | 那時，憍薩羅國波斯匿王過些時候肢體瘦了(被善切片)，以手拍打著肢體，在那時候吟出這優陀那： |
| ‘世尊实以二利哀怜我：                                        | 「那位世尊確實以兩方面的利益憐憫我：                         |
| 是现在之利与未来之利。’                                      | 以當生的與來世的利益。」                                     |
