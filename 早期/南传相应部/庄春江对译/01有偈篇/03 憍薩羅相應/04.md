| 第四 爱者                                                    | 4. 可愛經                                                    |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王白世尊曰：                         | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊，我于此独坐静观，生如是思念：                          | 「大德！這裡，獨處、獨坐的我這樣心的深思生起：               |
| 自我为何人所受者，不为何人所受者乎?                          | 『對誰自己是可愛的呢？對誰自己是不可愛的呢？』               |
| 世尊，我生如是思念。                                         | 大德！我想這個：                                             |
| 任何人皆依身以行恶行、依语以行恶行、依意以行恶行。此等诸人乃非爱自我者。假若彼等虽云：‘我等乃自我之爱者。’ | 『凡任何以身行惡行、以語行惡行、以意行惡行者，對他們自己是不可愛的，即使他們會說這個：「自己是可愛的。」 |
| 但彼等却非自我之爱者。不论如何，非爱者所以为非爱者，乃彼等之自所作为。是故彼等非自我之爱者。 | 但對他們自己是不可愛的，那是什麼原因？因為凡不可愛者會對不可愛者作的，那個他們就以自己對自己作了，因此，對他們自己是不可愛的。 |
| 任何人皆依身以行善行、依语以行善行、依意以行善行、此等之诸人乃自我之爱者。假若彼等虽云：‘我等乃非自我之爱者。’ | 凡任何以身行善行、以語行善行、以意行善行者，對他們自己是可愛的，即使他們會說這個：「自己是不可愛的。」 |
| 但彼等却是自我之爱者。不论如何，受者所以为爱者，乃彼等之自所作为。是故彼等乃自我之爱者。 | 但對他們自己是可愛的，那是什麼原因？因為凡可愛者會對可愛者作的，那個他們就以自己對自己作了，因此，對他們自己是可愛的。』」 |
| ‘大王!如是，大王!如是。’                                     | 「這是這樣，大王！這是這樣，大王！                           |
| 任何人依身、语、意以行恶行，此诸人乃非自我之爱者。           | 大王！凡任何以身行惡行、以語行惡行、以意行惡行者，對他們自己是不可愛的，即使他們會說這個：「自己是可愛的。」 |
|                                                              | 但對他們自己是不可愛的，那是什麼原因？因為凡不可愛者會對不可愛者作的，那個他們就以自己對自己作了，因此，對他們自己是不可愛的。 |
| 任何人依身、语、意以行善行，此诸人乃自我之爱者。             | 大王！凡任何以身行善行、以語行善行、以意行善行者，對他們自己是可愛的，即使他們會說這個：「自己是不可愛的。」 |
|                                                              | 但對他們自己是可愛的，那是什麼原因？因為凡可愛者會對可愛者作作的，那個他們就以自己對自己作了，因此，對他們自己是可愛的。」 |
| 世尊于此宣说已……乃至……’                                      | 世尊說這個……（中略）：                                       |
| 1知自可爱者                                                  | 「如果他知道自己是可愛的，                                   |
| 2勿自连结恶                                                  | 不應該與那個惡的連結，                                       |
| 4难得于安乐                                                  | 因為那個是不容易得到的：                                     |
| 3以行恶行人                                                  | 以惡作的作者對樂。                                           |
| 5所囚于死魔                                                  | 對被死神到達者，                                             |
| 6以舍生命者                                                  | 對離開人的存在者，                                           |
| 7有何是彼物                                                  | 什麼確實是他自己的？                                         |
| 8彼行前取何                                                  | 以及他拿什麼後走？                                           |
|                                                              | 什麼是他的隨行的，                                           |
|                                                              | 如影不離的？                                                 |
| 9功德恶之二                                                  | 福德與惡兩者，                                               |
| 10是人此世作                                                 | 凡不免一死的人在這裡做。                                     |
| 11此为彼身物                                                 | 那個確實是他自己的，                                         |
| 12彼行而取此                                                 | 以及他拿這個後走，                                           |
| 14此二从随彼                                                 | 那個是他的隨行的，                                           |
| 13如添影之形                                                 | 如影不離的。                                                 |
| 15是故以行善                                                 | 因此應該作善的：                                             |
| 16为善积未来                                                 | 來世的積聚，                                                 |
| 17功德于后世                                                 | 福德在其他世間(來世)中，                                     |
| 18乃人渡津头                                                 | 是有生命者們的依止。                                         |
