| 第四 于战之二语(其一)                                        | 14 戰鬥經第一                                                |
| [尔时，世尊]在舍卫城……。                                     | 起源於舍衛城。                                               |
| 时，摩揭陀国韦提希子阿阇世王，整备四军，针对拘萨罗国之波斯匿王，攻入其迦尸国。 | 那時，摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，進攻憍薩羅國波斯匿王。 |
| 拘萨罗国之波斯匿王，                                         | 憍薩羅國波斯匿王聽聞：                                       |
| 闻摩揭陀国之韦提希子阿阇世王整备四军，攻入我迦尸国。         | 「聽說摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，已對我進攻。」 |
| 时，拘萨罗国波斯匿王，整备四军，迎战摩揭陀国韦提希子阿阇世王于迦尸国。 | 那時，憍薩羅國波斯匿王部署四種軍後前往迦尸，向摩揭陀國阿闍世王韋提希子前進。 |
| 时，摩揭陀国韦提希子阿阇世与拘萨罗国之波斯匿王生战事。       | 那時，摩揭陀國阿闍世王韋提希子與憍薩羅國波斯匿王戰鬥。       |
| 依其战斗，摩揭陀国韦提希子阿阇世王，攻破拘萨罗国之波斯匿王。 | 又，在那次戰鬥中，摩揭陀國阿闍世王韋提希子打敗了憍薩羅國波斯匿王， |
| 拘萨罗国之波斯匿王，则逃归首都之舍卫城。                     | 而敗北的憍薩羅國波斯匿王向自己的首都舍衛城前進。             |
| 时，众多比丘，朝晨着衣持钵，入舍卫城行乞。                   | 那時，眾多比丘午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。   |
| 舍卫城行乞饭食后置钵，往诣世尊处。                           | 在舍衛城為了托鉢行走後，餐後已從施食返回，去見世尊。         |
| 诣已，敬礼世尊而坐于一面，坐于一面之诣比丘等。               | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 以此事白世尊曰：                                             | 在一旁坐下的那些比丘對世尊說這個：                           |
| ‘世尊!如今，摩揭陀国韦提希子阿阇世王与拘萨罗国之波斯匿王挑起战事。 | 「大德！這裡，摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，進攻憍薩羅國波斯匿王。 |
|                                                              | 大德！憍薩羅國波斯匿王聽聞：『聽說摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，已對我進攻。』 |
|                                                              | 大德！那時，憍薩羅國波斯匿王部署四種軍後前往迦尸，向摩揭陀國阿闍世王韋提希子前進。 |
|                                                              | 大德！那時，摩揭陀國阿闍世王韋提希子與憍薩羅國波斯匿王戰鬥， |
| 依其战斗，摩揭陀国韦提希子阿阇世王，攻破拘萨罗国之波斯匿王。 | 大德！又，在那次戰鬥中，摩揭陀國阿闍世王韋提希子打敗了憍薩羅國波斯匿王， |
| 拘萨罗国之波斯匿王，逃归首都之舍卫城。’                      | 大德！而敗北的憍薩羅國波斯匿王向自己的首都舍衛城前進。」     |
| ‘诸比丘!摩揭陀国韦提希子阿阇世王，有恶友、恶朋、恶伴。       | 「比丘們！摩揭陀國阿闍世王韋提希子有惡的朋友、惡的同伴、惡的親密朋友， |
| 诸比丘!拘萨罗国之波斯匿王，有善友、善朋、善伴。              | 而憍薩羅國波斯匿王有善的朋友、善的同伴、善的親密朋友。       |
| 诸比丘!但拘萨罗国之波斯匿王，今夜为败者，应是苦眠。’         | 比丘們！今天，敗北的憍薩羅國波斯匿王這晚睡不好了。」         |
| [世尊，说此……乃至……]                                         | 世尊說這個……（中略）：                                       |
| 1胜利以生怨                                                  | 「勝利者產出怨恨，                                           |
| 2败者苦难寝                                                  | 敗者睡不好，                                                 |
| 4平静乐安眠                                                  | 寂靜者睡得安樂：                                             |
| 3只有舍胜败                                                  | 捨斷勝敗後。                                                 |
