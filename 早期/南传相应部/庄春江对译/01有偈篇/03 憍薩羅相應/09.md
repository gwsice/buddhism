| 第九 供牺                                                    | 9. 牲祭經                                                    |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 尔时，又作备办大供牺拘萨罗国之波斯匿王。                     | 當時，有一個大牲祭已為憍薩羅國波斯匿王準備好了：             |
| 有：五百牡牛、五百牝犊、五百山羊、五百只羊，为供牺，而受缚于柱。 | 五百頭公牛、五百頭小公牛、五百頭小母牛、五百頭山羊、五百頭公羊，為了牲祭被帶來祭壇的諸柱子， |
| 又有王之奴隶、仆人、男佣人，                                 | 凡他們是他的「奴僕」或「僕人」或「工人」者，                 |
| 彼等亦害怕刑罚，恐怖战抖，一面为作准备而一面哭泣流泪。       | 他們也被懲罰威脅地、被恐懼威脅地、淚滿面地哭泣著作準備工作。 |
| 时，甚多比丘等晨早，着衣持钵，入舍卫城行乞。                 | 那時，眾多比丘午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。   |
| 于舍卫城行乞食已，收放钵后，而诣世尊处。                     | 在舍衛城為了托鉢行走後，餐後已從施食返回，去見世尊。         |
| 诣已，礼敬世尊，坐于一面。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之彼等诸比丘，白世尊曰：                             | 在一旁坐下的那些比丘對世尊說這個：                           |
| ‘世尊!此拘萨罗国之波斯匿王、有备办大供牺：                   | 「大德！這裡，有一個大牲祭已為憍薩羅國波斯匿王準備好了：     |
| 五百牡牛、五百牝犊、五百山羊、五百只羊，均为供牺而繁缚于柱。 | 五百頭公牛、五百頭小公牛、五百頭小母牛、五百頭山羊、五百頭公羊，為了牲祭被帶來祭壇的諸柱子， |
| 又王之奴隶、仆人、男佣人等，                                 | 凡他們是他的『奴僕』或『僕人』或『工人』者，                 |
| 彼等害怕刑罚，恐怖战抖，一面哭泣流泪一面为作准备。           | 他們也被懲罰威脅地、被恐懼威脅地、淚滿面地哭泣著作準備工作。」 |
| 时，世尊了知此义，于此时唱偈曰                               | 那時，世尊知道這件事後，那時候說這些偈頌：                   |
| 1马牺人供牺                                                  | 「馬祭、人祭，                                               |
| 2投掷之棒赛 3胜利者之饮 4而无有障碍                          | 擲棍祭、酒祭、無遮祭，                                       |
| 5此等之供牺                                                  | 大殺害的大牲祭，                                             |
| 6事多无大果                                                  | 那些是無大果的。                                             |
| 7山羊及羊牛                                                  | 山羊綿羊與牛，                                               |
| 8种种加杀害                                                  | 種種在該處被殺，                                             |
| 9如此之供牺                                                  | 那個牲祭，                                                   |
| 10大圣不行为                                                 | 正行的大仙們不接近。                                         |
| 11事少常行此                                                 | 但凡無勞苦的牲祭，                                           |
|                                                              | 隨家庭經常地祭祀，                                           |
| 12山羊及羊牛                                                 | 山羊綿羊與牛，                                               |
| 13于此不杀害                                                 | 種種在這裡不被殺，                                           |
| 14而于此供牺 15以行正道者                                    | 這個牲祭，                                                   |
| 16大圣亦行之                                                 | 正行的大仙們接近。                                           |
| 17贤者行此供                                                 | 有智慧者應該祭祀這個，                                       |
| 18此供有大果                                                 | 這個種牲祭是有大果的，                                       |
| 19以行此行者                                                 | 因為牲祭這個者，                                             |
| 20有善而无空                                                 | 有更善的、非惡的，                                           |
| 21伟大之供牺                                                 | 且牲祭是廣大的，                                             |
| 22诸天之赏赞                                                 | 以及天神們歡喜。                                             |
