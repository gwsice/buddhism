| 第二 祖母                                                    | 22. 祖母經                                                   |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 世尊谓于一面坐之拘萨罗国波斯匿王曰：                         | 世尊對在一旁坐下的憍薩羅國波斯匿王說這個：                   |
| ‘大王!王日中从何处来耶?’                                     | 「那麼，大王！你中午從哪裡來呢？」                           |
| ‘世尊!我老祖母 年百二十岁死矣。                              | 「大德！我衰老的、年老的、高齡的、老年的、到達老年的：從出生一百二十歲的祖母已死了， |
| 世尊!我祖母于我，是所思慕者。                                | 大德！而祖母對我是可愛的、合意的。                           |
| 世尊，若我依于象宝，得令祖母不死者，我当予象宝不令祖母死。   | 大德！如果能以象寶得到『我的祖母不要死』，我會給與象寶[換]『我的祖母不要死』。 |
| 若我依马宝，得令祖母不死者，我当予马宝不令祖母死。           | 大德！如果能以馬寶得到『我的祖母不要死』，我會給與馬寶[換]『我的祖母不要死』。 |
| 得依善村或国，得令祖母不死者，我当予善村或国令祖母不死。’    | 大德！如果能以最上的村落得到『我的祖母不要死』，我會給與最上的村落[換]『我的祖母不要死』。 |
|                                                              | 大德！如果能以部分國土得到『我的祖母不要死』，我會給與部分國土[換]『我的祖母不要死』。」 |
| ‘大王!一切众生乃死法。终当必死，无得超越于死者。’            | 「大王！一切眾生都是死法、死為終結的、未超越死的。」         |
| ‘世尊!希有。世尊，未曾有。                                   | 「不可思議啊，大德！未曾有啊，大德！                         |
| 此一切众乃死法，终当必死，无能得超死者实是善说。’            | 大德！這被世尊多麼善說：『一切眾生都是死法、死為終結的、未超越死的。』」 |
| ‘大王!如是，大王!如是。一切众生乃死法。终当必死，无得超越于死者。 | 「這是這樣，大王！這是這樣，大王！一切眾生都是死法、死為終結的、未超越死的。 |
| 大王!譬喻作壶之任何所作之土器。或烧或不烧者，悉是破坏之法，终必破坏，无有免破坏者， | 大王！猶如凡任何陶匠所作的器具：生胚(生的)與燒好的(成熟的)都是破裂法、破裂為終結的、未超越破裂的。 |
| 如是一切众生为死法，终当必死，无得超死者。’                  | 同樣的，大王！一切眾生都是死法、死為終結的、未超越死的。」   |
| [世尊此宣说……乃至……]                                         | 世尊說這個……（中略）：                                       |
| 1众生皆必死                                                  | 「一切眾生必將死去，                                         |
| 2生者无不死                                                  | 因為生命是死為終結的，                                       |
| 3应如依其业                                                  | 他們必將依業走去，                                           |
| 4随行功罪果                                                  | 為到達福、惡結果者：                                         |
| 5依恶堕地狱                                                  | 惡業者們為地獄，                                             |
| 6功德生天界                                                  | 而福業者們為善趣。                                           |
| 7然者行善事                                                  | 因此應該作善的：                                             |
| 8积善为未来                                                  | 來世的積聚，                                                 |
| 9功德实众人                                                  | 福德在其他世間(來世)中，                                     |
| 10后世渡津场                                                 | 是有生命者們的依止。                                         |
