| 第三 世间                                       | 23. 世間經                                                   |
| [尔时，世尊]在舍卫城……                          | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王白世尊曰：            | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!世间有几种法生，为不利苦恼不安住耶?’      | 「大德！當世間的幾法生起時，生起不利、苦、不安樂住呢？」     |
| ‘大王!世间有三法生，为不利苦恼不安住。三者何耶? | 「大王！當世間的三法生起時，生起不利、苦、不安樂住，哪三個？ |
| 大王!于世间贪生，为不利苦恼不安住。             | 大王！當世間的貪欲生起時，生起不利、苦、不安樂住；           |
| 大王!于世间嗔生，为不利苦恼不安住。             | 大王！當世間的瞋恚生起時，生起不利、苦、不安樂住；           |
| 大王!于世间痴生，为不利苦恼不安住。             | 大王！當世間的愚癡生起時，生起不利、苦、不安樂住，           |
| 大王!此等三法，生于世间，为不利苦恼不安住。’    | 大王！當世間的這三法生起時，生起不利、苦、不安樂住。」       |
| 世尊此宣说……乃至……’                             | 說這個……（中略）：                                           |
| 1贪嗔以及痴                                     | 「貪、瞋與愚，                                               |
| 2此恶心生人                                     | 對惡心意的人，                                               |
| 4生之即倾倒                                     | 諸自己產生的它們殺害，                                       |
| 3害人如竹类                                     | 如自己果實的竹。」                                           |
