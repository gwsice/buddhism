| 第五 于战之二语(其二)                                        | 15. 戰鬥經第二                                               |
| 时，摩揭陀国韦提子阿阇世王，整备四军，针对拘萨罗国之波斯匿王[战]，攻入其迦尸国。 | 那時，摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，進攻憍薩羅國波斯匿王。 |
| 拘萨罗国之波斯匿王，                                         | 憍薩羅國波斯匿王聽聞：                                       |
| 闻摩揭陀国韦提希子阿阇世王，整备四军，攻入我迦尸国。         | 「聽說摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，已對我進攻。」 |
| 时，拘萨罗国之波斯匿王，整备四军，于迦尸国，迎战摩揭陀国之韦提希子阿阇世王。 | 那時，憍薩羅國波斯匿王部署四種軍後前往迦尸，向摩揭陀國阿闍世王韋提希子前進。 |
| 如是摩揭国之韦提希子阿阇世王，与拘萨罗国之波斯匿王挑起战事。 | 那時，摩揭陀國阿闍世王韋提希子與憍薩羅國波斯匿王戰鬥。       |
| 于此战斗，拘萨罗国之波斯匿王，攻破摩揭陀国之韦提希子阿阇世王，生擒彼[王]。 | 又，在那次戰鬥中，憍薩羅國波斯匿王打敗了摩揭陀國阿闍世王韋提希子，並且活抓他。 |
| 时，拘萨罗国之波斯匿王，如是思念：                           | 那時，憍薩羅國波斯匿王想這個：                               |
| ‘如摩揭国之韦提希子阿阇世王，虽无害，但谓害我，乃我之甥。    | 「即使當我沒違犯這位摩揭陀國阿闍世王韋提希子時，他違犯[我]，但他仍是我的外甥， |
| 我宁夺摩揭陀国之韦提希子阿阇世王所有之象军、马军、车军、步军、以逐放彼。’ | 讓我佔據摩揭陀國阿闍世王韋提希子的所有象軍、佔據所有的馬軍、佔據所有的車軍、佔據所有的步軍後，只讓他能活著撤退。」 |
| 时，拘萨罗国之波斯匿王，夺摩揭陀国之韦提希子阿阇世王所有之象军、马军、车军、步军而逐放彼。 |                                                              |
| 时，众多比丘，晨早着衣持钵，入舍卫城，                       | 那時，眾多比丘午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。   |
| 于舍卫城乞食，食已置钵，往诣世尊处。                         | 在舍衛城為了托鉢行走後，餐後已從施食返回，去見世尊。         |
| 诣已，礼敬世尊，而坐于一面；                                 | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 坐于一面之诸比丘等，以此事白世尊曰：                         | 在一旁坐下的那些比丘對世尊說這個：                           |
| ‘世尊!如今，摩揭陀国之韦提希子阿阇世王，整备四军，针对拘萨罗国之波斯匿王，攻入其迦尸国。 | 「大德！這裡，摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，進攻憍薩羅國波斯匿王。 |
|                                                              | 大德！憍薩羅國波斯匿王聽聞：                                 |
|                                                              | 『聽說摩揭陀國阿闍世王韋提希子部署四種軍後前往迦尸，已對我進攻。』 |
| 世尊!拘萨罗国之波斯匿王，闻悉亦以整备四军迎战。              | 大德！那時，憍薩羅國波斯匿王部署四種軍後前往迦尸，向摩揭陀國阿闍世王韋提希子前進。 |
|                                                              | 大德！那時，摩揭陀國阿闍世王韋提希子與憍薩羅國波斯匿王戰鬥。 |
| 于此交战，拘萨罗国之波斯匿王，攻破摩揭陀国之韦提希子阿阇世王，生擒彼王。 | 大德！又，在那次戰鬥中，憍薩羅國波斯匿王打敗了摩揭陀國阿闍世王韋提希子，並且活抓他。 |
| 世尊!如是拘萨罗国之波斯匿王，如是思念：                      | 大德！那時，憍薩羅國波斯匿王想這個：                         |
| ‘如摩揭国之韦提希子阿阇世王，虽无害，但谓害我，乃我之甥，    | 『即使當我沒違犯這位摩揭陀國阿闍世王韋提希子時，他違犯[我]，但他仍是我的外甥， |
| 我宁夺彼王之四军，以逐放彼王。’                              | 讓我佔據摩揭陀國阿闍世王韋提希子的所有象軍、佔據所有的馬軍、佔據所有的車軍、佔據所有的步軍後，只讓他能活著撤退。』 |
| 世尊，如是拘萨罗国之波斯匿王，夺得摩揭陀国之韦提希子阿阇世王之四军，以逐放彼王。’ | 大德！那時，憍薩羅國波斯匿王佔據摩揭陀國阿闍世王韋提希子的所有象軍、佔據所有的馬軍、佔據所有的車軍、佔據所有的步軍後，只讓他活著撤退。」 |
| 时，世尊得知此义，其时，唱此偈曰：                           | 那時，世尊知道這件事後，那時候說這些偈頌：                   |
| 2即以掠夺他                                                  | 「男子就一直掠奪，                                           |
| 1人为己利时                                                  | 只要有利於他，                                               |
| 3他之被$$\color{red}这个应该是翻错了$$夺时                   | 而當其他人掠奪時，                                           |
| 4彼亦为所夺                                                  | 那位掠奪者被掠奪。                                           |
| 6虽思为当然                                                  | 愚者認為確實合理，                                           |
| 5愚者恶不实                                                  | 只要未被惡的折磨，                                           |
| 7恶之成实时                                                  | 而當被惡的折磨時，                                           |
| 8即受于苦恼                                                  | 那時他遭受苦。                                               |
| 9若以杀他人 10即得杀己者                                     | 殺害者得到殺害，                                             |
| 11若以胜他人 12即得胜己者                                    | 征服者得到征服，                                             |
| 13以讥他人者 14即得诽己者                                    | 辱罵者對辱罵，                                               |
| 15以恼他人者 16即得恼己者                                    | 以及激怒者對激怒，                                           |
| 17如是业轮转                                                 | 那時以業的輪迴，                                             |
| 18夺人当被夺                                                 | 那位掠奪者被掠奪。」                                         |
