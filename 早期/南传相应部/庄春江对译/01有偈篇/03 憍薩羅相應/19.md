| 第九 无子(其一)                                              | 19. 無子者經第一                                             |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，拘萨罗国之波斯匿王，日中 往诣世尊处。                    | 那時，憍薩羅國波斯匿王中午去見世尊。                         |
| 诣已，礼敬世尊，于一面坐。                                   | 抵達後，向世尊問訊後，在一旁坐下。                           |
| 世尊谓于一面坐之拘萨罗国波斯匿王曰：                         | 世尊對在一旁坐下的憍薩羅國波斯匿王說這個：                   |
| ‘大王!王此日中从何处来耶?’                                   | 「那麼，大王！你中午從哪裡來呢？」                           |
| ‘世尊!于今舍卫城之长者家主死。彼无子，我来接收其财产。       | 「大德！這裡，舍衛城中經營錢莊的屋主死了，我搬走那位無子者的財產到國王後宮後而來， |
| 世尊!其金即有八百万金、银当更不待言。                        | 大德！黃金就有八百萬，更不用說白銀。                         |
| 世尊![如是巨富]之长者家主，以如是受用所食：混糠之酸粥；      | 大德！又，那位經營錢莊的屋主之食物受用是這樣的：吃碎米飯拌酸粥， |
| 如是受用所衣：唯缝合三片之大麻粗布；                         | 衣服受用是這樣的：穿三片粗麻布的衣服，                       |
| 如是用车乘；老旧朽车又持木叶之盖伞。’                        | 車乘受用是這樣的：乘以裝著樹葉傘的老舊小車。」               |
| ‘大王!如是。大王!如是。                                      | 「這是這樣，大王！這是這樣，大王！                           |
| 大王!卑人乍得巨大之富，不令自乐、不令喜、不令父母乐、喜，不令妻子乐、喜，不令下男、下仆乐、喜。不令朋友乐、喜。 | 大王！非善人得到廣大的財富後，既不使自己快樂、喜悅，也不使父母快樂、喜悅，不使妻兒快樂、喜悅，不使奴僕、工人、傭人快樂、喜悅，不使朋友、同事快樂、喜悅， |
| 对沙门、婆罗门、升上界、导上界、转生天界亦不行布施。         | 不在沙門、婆羅門們上使高的、導致生天的、安樂果報的、轉起天界的供養建立， |
| 彼之财富，不如是正当受用，则被王没收、被盗贼夺、被火烧、被水流、被不喜爱之相续者夺取。 | 當他的那些財富不這樣正當使用時，國王們拿走，或盜賊們拿走，或火燃燒，或水流走，或不可愛的繼承者們拿走， |
| 大王!无如是正当受用之富，当是无用之破灭行。                  | 大王！那確實是這樣：當不正當使用時，那些財富走到遍盡，而非使用。 |
| 大王!譬喻有池于无人之境，其水澄洁清冷，甘美澄白，岸亦甚善。  | 大王！猶如在無人處有清澈水的、悅意水的、冷水的、透明水的、美麗堤岸的、能被喜樂的蓮花池， |
| 但无人[行]乐，亦无人取水、故无人饮、浴、则是无何所用。       | 人們既不拿走它，也不喝飲，也不沐浴，也不如需要做，           |
| 大王!如是无正当受用之水，即是无用之消灭。                    | 大王！那確實是這樣：當不正當使用時，那個水會走到遍盡，而非使用。 |
| 如是卑人得富，不令自己、父母、妻子、下仆依此而乐、喜。       | 同樣的，大王！當非善人得到廣大的財富後，既不使自己快樂、喜悅，也不使父母快樂、喜悅，不使妻兒快樂、喜悅，不使奴僕、工人、傭人快樂、喜悅，不使朋友、同事快樂、喜悅， |
|                                                              | 不在沙門婆羅門們上使高的、導致生天的、安樂果報的、轉起天界的供養建立， |
|                                                              | 當他的那些財富不這樣正當使用時，國王們拿走，或盜賊們拿走，或火燃燒，或水流走，或不可愛的繼承者們拿走， |
| 如是无正当受用之富，是无用之破灭行。                         | 大王！那確實是這樣：當不正當使用時，那些財富走到遍盡，而非使用。 |
| 大王!善人得巨大之富，令自己乐、喜；令父母乐、喜：令妻子乐、喜；令下男下仆乐、喜；令朋友乐、喜。 | 大王！而善人得到廣大的財富後，使自己快樂、喜悅，也使父母快樂、喜悅，使妻兒快樂、喜悅，使奴僕、工人、傭人快樂、喜悅，使朋友、同事快樂、喜悅， |
| 对沙门、婆罗门、升上界、导上界、有乐果、转生天界者行布施。   | 在沙門婆羅門們上使高的、導致生天的、安樂果報的、轉起天界的供養建立， |
| 彼之财富，有如是正当受用。不被王没收、不被盗贼夺、不被火烧、不被水流、不被不喜爱之相续者夺取。 | 當他的那些財富這樣正當使用時，國王們不拿走，盜賊們不拿走，火不燃燒，水不流走，不可愛的繼承者們不拿走， |
| 大王!如是正当受用之富，则无破灭。                            | 大王！像這樣，當正當使用時，那些財富走到使用，而非遍盡。     |
| 大王!譬喻近村，或邑有莲池。其水澄洁清冷，甘美澄白，岸甚善而有人行乐、 | 大王！猶如在村落或城鎮不遠處有清澈水的、悅意水的、冷水的、透明水的、美麗堤岸的、能被喜樂的蓮花池， |
| 其水众人取去、或饮、或浴以供人用。                           | 而人們拿走那個水，也喝飲，也沐浴，也如需要做，               |
| 大王!如是正当受用之水，有用而不行灭。                        | 大王！像這樣，當正當使用時，那個水會走到使用，而非遍盡。     |
| 如善人得巨大之富，令自己……乃至……朋友乐、喜，                 | 同樣的，大王！當善人得到廣大的財富後，使自己快樂、喜悅，也使父母快樂、喜悅，使妻兒快樂、喜悅，使奴僕、工人、傭人快樂、喜悅，使朋友、同事快樂、喜悅， |
|                                                              | 在沙門婆羅門們上使高的、導致生天的、安樂果報的、轉起天界的供養建立， |
|                                                              | 當他的那些財富這樣正當使用時，國王們不拿走，盜賊們不拿走，火不燃燒，水不流走，不可愛的繼承者們不拿走， |
| ……乃至……如是正当受用之富，有用而无破灭行。’                  | 大王！像這樣，當正當使用時，那些財富走到使用，而非遍盡。」   |
| [世尊如是宣说……乃至……]                                       |                                                              |
| 1如无人山野清水                                              | 「如冷水在無人處，                                           |
| 2无人饮用自行灭                                              | 不能被喝飲的它走向乾涸，                                     |
| 3若犹卑人得富者                                              | 像這樣邪惡人得到財物後，                                     |
| 4不自用亦不与他                                              | 既不自己受用也不施與。                                       |
| 5英雄识者以得富                                              | 但明智者與智者獲得諸財物後，                                 |
| 6自用并供其他事                                              | 他受用與成為盡義務者，                                       |
| 7彼牛王养亲族群                                              | 那位人牛王養育親屬眾後，                                     |
| 8无被非难行天界                                              | 不被責備地來到天界處。」                                     |
