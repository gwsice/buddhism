| 第五 山之比喻                                                | 25. 如山經                                                   |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| [世尊]谓于一面坐之拘萨罗国波斯匿王曰：                       | 世尊對在一旁坐下的憍薩羅國波斯匿王說這個：                   |
| ‘大王!王从何处来耶?’                                         | 「那麼，大王！你中午從哪裡來？」                             |
| ‘世尊!沉醉于主权之憍、耽于爱欲贪、得国家保全，征服广大领土、刹帝利之灌顶王、有诸王事，我忙碌 于此等事。’ | 「大德！凡那些成為統治權驕傲陶醉的、欲之貪求纏縛的、國土安定達到的、大土地範圍(圓周)征服後居住者之剎帝利灌頂王國王們的應該被作的，今天，在那些上我已來到努力。」 |
| ‘大王!王之意如何耶?于此可信、可赖者从东方来，彼诣王处，作如是言曰： | 「大王！你怎麼想它：這裡，如果有值得信賴、能信賴的男子從東方對你來，他抵達後，如果對你說這個： |
| ‘大王!请知我从东方来。于彼见如虚空之大山，而压碎一切生物，大王!请作应作之事。’ | 『大王！請你應該知道，我從東方來，在那裡，看見與雲同[高]的大山，壓碎一切生物地來，大王！請你做凡你應該做的。』 |
| 时，有可信、可赖之第二人，由西方……乃至……                     | 那時，如果……第二位男子從西方來……（中略）。                   |
| 第三人由北方……乃至……                                         | 那時，如果……第三位男子從北方來……（中略）。                   |
| 第四人由南方来，彼诣王处，作如是言曰：                       | 那時，如果有值得信賴、可靠的第四位男子從南方來，他抵達後，如果對你說這個： |
| 大王!请知我从南方来，于彼见如虚空之大山压碎一切生物。大王!请作应作之事。’ | 『大王！請你應該知道，我從南方來，在那裡，看見與雲同[高]的大山，壓碎一切生物地來，大王！請你做凡你應該做的。』 |
| 大王!如是大恐怖，已至人类灭尽之可怕，人身更难再受。于王应作何事耶?’ | 大王！在像這樣大的大可怕的生起時，在恐怖的人類滅盡時，在人的狀態難得下，什麼是你應該作的？」 |
| ‘世尊!如是大恐怖，已至人类灭尽之可怕，人身更难再受者；唯为法行、正行、善业、功德业之外、无何所为焉!’ | 「大德！在像這樣大的大可怕的生起時，在恐怖的人類滅盡時，在人的狀態難得下，除了以法行，除了以正行，除了以善的行為(所作)，除了以福德行為外，什麼是我應該作的？」 |
| ‘大王!我说王，我告于王：老死压在王之上，如老死压在王头上，应何所为耶?’ | 「大王！我告訴你；大王！我使你知道：大王！老死對你壓來。大王！如果在當老死對你壓來時，什麼是你應該作的？」 |
| ‘世尊!如老死压在我上：应为法行、正行、善业、功德业之外，无何所为焉! | 「大德！在當老死對我壓來時，除了以法行，除了以正行，除了以善的行為，除了以福德行為外，什麼是我應該作的？ |
| 世尊!沉醉主权之憍，耽爱欲之贪，得国家之保全，征服广大之领土，刹帝利种之灌顶王、有象军战。然而，世尊!此等象军战，亦于老死之压来，无防老死之方法与余地。 | 大德！大德！凡那些統治權驕傲陶醉的、欲之貪求纏縛的、國土安定達到的、大土地範圍征服後居住者之剎帝利灌頂王國王們有戰鬥象兵，大德！在當老死壓來時，那些戰鬥象兵也沒有去處，沒有對象。 |
| 世尊!沉醉于主权之憍……乃至……刹帝利之灌顶王有马军战[……]车军战[……]步军战。然而此步军战，亦于老死之压来，无防[老死]之方法与余地。 | 大德！又，凡那些……居住者之剎帝利灌頂王國王們有戰鬥馬兵……（中略）……戰鬥車兵……（中略）戰鬥步兵，大德！在當老死壓來時，那些戰鬥步兵也沒有去處，沒有對象。 |
| 世尊!王宫有善咒之大臣，彼等得以咒语破来攻之敌。然而，世尊!咒战之压来，无防老死之方法与余地。 | 大德！又，在這些王室中有參謀大臣，凡在怨敵已來時他們能以計謀使之分裂，大德！在當老死壓來時，那些戰鬥計謀也沒有去處，沒有對象。 |
| 又，世尊!于此王宫，有布满地阶 又布满上阶莫大之黄金。我等依此财宝，可说服攻来之敌，然而此财宝之战，无防老死压来之方法与余地。 | 大德！又，在這些王室中地下的[地窖]與空中的[閣樓]存在很多黃金金幣，在怨敵已來時，我們能以那些財產謀合，大德！在當老死壓來時，那些戰鬥財產也沒有去處，沒有對象。 |
| 世尊!老死压来我头上时；唯为法行、正行、善业、功德业之外，无何所为焉!’ | 大德！而在當老死對我壓來時，除了以法行，除了以正行，除了以善的行為，除了以福德行為外，什麼是我應該作的？」 |
| ‘大王!实者如是，大王!实者如是。老死压来王之上，唯为法行、正行、善业、功德业之外，无何所为焉!’ | 「這是這樣，大王！這是這樣，大王！在當老死壓來時，除了以法行，除了以正行，除了以善的行為，除了以福德行為外，什麼是應該作的？」 |
| 世尊此宣说……乃至……师唱此偈曰：                               | 世尊說這個，[說這個後，善逝、]大師[更進一步說這個]：         |
| 1穿空大岩山                                                  | 「也如諸廣大的岩山：                                         |
|                                                              | 接觸雲的諸山，                                               |
|                                                              | 會普遍地到處走：                                             |
| 2犹四方迫来                                                  | 對四方壓碎地。                                               |
| 3老死之强迫                                                  | 像這樣老與死，                                               |
| 4临众人头上                                                  | 對諸有生命的轉來，                                           |
| 5刹帝婆罗门                                                  | 對剎帝利們、婆羅門們、毘舍們，                               |
| 6毗舍首陀罗 7乃至旃陀罗 8下水清扫人                          | 對首陀羅們，旃陀羅們、清垃圾者們，                           |
| 9任何人难免                                                  | 任何人都避不開，                                             |
| 10一切皆被迫                                                 | 都壓碎一切。                                                 |
| 11象军无余地                                                 | 在那裡土地不是諸象的，                                       |
| 12车军及步军 13亦为无余地                                    | 不是諸車的、不是步兵們的，                                   |
| 14咒术亦无济                                                 | 而且非以計謀戰，                                             |
| 15富亦无术胜                                                 | 或以財產能夠打勝。                                           |
| 16故贤为己思                                                 | 因此確實賢智的人，                                           |
|                                                              | 自己利益的看見者，                                           |
| 17佛法及僧伽                                                 | 在佛、法與僧上，                                             |
| 20如法之行人 18以植于信仰                                    | 明智者應該使信安頓。                                         |
| 19身口以至心                                                 | 凡以身行法，                                                 |
|                                                              | 以語或者以心，                                               |
| 21此世承赞誉                                                 | 就在這裡他們稱讚他，                                         |
| 22未来生天界                                                 | 死後在天界喜悅。」                                           |
