| 第六 少数                                                    | 6. 少經                                                      |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王，白世尊曰：                       | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!我独坐静观，生如是思念：                               | 「大德！這裡，獨處、獨坐的我這樣心的深思生起：               |
| 于此世得巨大之富而不迷醉、不溺、不耽于欲乐、不误于诸人中者，甚少。 | 『世間中那些眾生是少的：凡得到優越、優越的財富後他們不沈醉，又不放逸，又不來到在欲上貪求，又不在眾生上侵犯， |
| 于此世得巨大之富而迷醉、溺、耽于欲乐、误于诸人中者，甚多。’  | 而世間中這些眾生正是更多的：凡得到優越、優越的財富後他們沈醉，又放逸，又來到在欲上貪求，又在眾生上侵犯。』」 |
| ‘大王!如是，大王!如是。                                      | 「這是這樣，大王！這是這樣，大王！                           |
| 于此世得巨大之富而不迷醉、不溺、不耽于欲乐、不误于诸人中者，甚少。 | 大王！世間中那些眾生是少的：凡得到優越、優越的財富後他們不沈醉，又不放逸，又不來到在欲上貪求，又不在眾生上侵犯， |
| 于此世得巨大之富而迷醉、溺、耽于欲乐、误于诸人中者，甚多。’  | 而世間中這些眾生正是更多的：凡得到優越、優越的財富後他們沈醉，又放逸，又來到在欲上貪求，又在眾生上侵犯。」 |
| [世尊宣说此已……乃至……]                                       | 世尊說這個……（中略）：                                       |
| 1富迷于欲乐                                                  | 「在受用諸欲上貪著者們，                                     |
| 2贪欲以夺心                                                  | 在諸欲上貪求者們、迷昏頭者們，                               |
| 3不觉于道外                                                  | 他們越界不覺醒，                                             |
| 4如鹿被缚蹄                                                  | 如鹿對佈置陷阱的詐欺者，                                     |
| 5彼等后苦涩                                                  | 之後他們有苦澀的，                                           |
| 6其果即是恶                                                  | 因為那個的果報是惡的。                                       |
