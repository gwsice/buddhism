| 第十 无子(其二)                                              | 20. 無子者經第二                                             |
| 时，拘萨罗国之波斯匿王，日中诣世尊处。诣已，礼敬世尊，坐于一面， | 那時，憍薩羅國波斯匿王中午去見世尊[……（中略）]。             |
| 对一面坐之拘萨罗国波斯匿王，世尊问曰：                       | 世尊對在一旁坐下的憍薩羅國波斯匿王說這個：                   |
| ‘大王!王日中从何而来耶?’                                     | 「那麼，大王！你中午從哪裡來呢？」                           |
| ‘世尊，于今舍卫城之长者家主死。彼无子，我来接收其财产。      | 「大德！這裡，舍衛城中經營錢莊的屋主死了，我搬走那位無子者的財產到國王後宮後而來， |
| 世尊，其金即有千万金，银当更不待言。                         | 大德！黃金就有一千萬，更不用說白銀。                         |
| 世尊![如是巨富]之长者家主，以如是受用所食：为混糠之酸粥；如是受用求：为缝合三片之大麻粗布。如是受用车：老旧朽车又持用木叶之盖伞。’ | 大德！又，那位經營錢莊的屋主之食物受用是這樣的：吃碎米飯拌酸粥；衣服受用是這樣的：穿三片粗麻布的衣服，車乘受用是這樣的：乘以裝著樹葉傘的老舊小車。」 |
| ‘大王!如是，大王!如是。                                      | 「這是這樣，大王！這是這樣，大王！                           |
| 大王!往昔其长者家主，令供食于多伽罗尸弃辟支佛之行乞。令‘供食于沙门’即从座起而去， | 大王！從前，那位經營錢莊的屋主以施食使名叫多迦羅尸棄的辟支佛受取：說『請你們對沙門施與食物』後，從座位起來後離開。 |
| 来反后悔于‘此食不如予下仆为胜。’                             | 但，給了後，後來成為後悔者：『這是恩惠，如果奴僕或工人吃施食。』 |
| 又为财产而夺兄弟一子之生命。                                 | 而且他為財產的因素奪取兄弟獨子的生命。                       |
| 大王!其长者家主、依令施食多伽罗尸弃辟支佛行乞之业果，        | 大王！凡那位經營錢莊的屋主以施食使名叫多迦羅尸棄的辟支佛受取， |
| 七返生天界，七返之余业，                                     | 以那個業的果報，往生善趣、天界七回，                         |
| 七返于此舍卫城，置长者之位。                                 | 以正是那個業的殘餘果報，就在這舍衛城作經營錢莊者七回。       |
| 大王!此长者家主、依施后反悔‘此食不如予下仆为胜’之业果，      | 大王！凡那位經營錢莊的屋主施與後，之後成為後悔者：『這是恩惠，如果奴僕或工人吃施食。』 |
| 其心不倾向于善食之受用，不倾向于善衣之受用，不倾向于善车乘之受用。不倾向五欲之善受用。 | 以那個業的果報，心不傾向於上妙食物的受用，心不傾向於上妙衣服的受用，心不傾向於上妙車乘的受用，心不傾向於上妙五種欲的受用。 |
| 大王!其长者家主，依由为财产而杀兄弟之子其业果，得多年、多百年、多千年、多百千年受苦于地狱。 | 大王！而且凡那位經營錢莊的屋主為財產的因素奪取兄弟獨子的生命，以那個業的果報，在地獄受折磨好幾年、好幾百年、好幾千年、好幾十萬年， |
| 依其余业，当七返无子，其财富则被没入王库。                   | 以正是那個業的殘餘果報，使這第七次無子者的財產進入國王的藏庫。 |
| 大王!其长者家主，乃旧功德尽已，不积新功德。                  | 大王！而那位經營錢莊的屋主以前的福德已滅盡，且沒累積新福德， |
| 大王!其长者今日被煮于大叫唤地狱。                            | 大王！又，經營錢莊的屋主現在在大叫喚地獄受折磨。」           |
| ‘世尊!长者家主即如是生于大叫唤地狱。’                        | 「大德！像這樣，經營錢莊的屋主已往生大叫喚地獄了嗎？」       |
| ‘大王!长者家主如是生于大叫唤地狱。’                          | 「是的，大王！經營錢莊的屋主已往生大叫喚地獄了。」           |
|                                                              | 世尊說這個……（中略）：                                       |
| 1谷物富金银                                                  | 「穀物、財物、銀、金，                                       |
| 2如何为所有                                                  | 或甚至凡有任何所有物，                                       |
| 3奴下男佣人                                                  | 奴僕、工人、僕人，                                           |
| 4及他从属者                                                  | 以及凡依他生活者，                                           |
| 6一切皆离去                                                  | 一切沒拿後應該被離開(走)，                                   |
| 5悉皆不随行                                                  | 一切放棄後去的。                                             |
| 7依于身之行                                                  | 而凡他以身作，                                               |
| 8以及口意行                                                  | 以語或以心，                                                 |
| 9唯此彼身物                                                  | 那個確實是他自己的，                                         |
| 10即随之而行                                                 | 而他拿這個後走，                                             |
| 11一切皆依业                                                 | 那個是他的隨行者，                                           |
| 12如影之随形                                                 | 如影不離。                                                   |
| 13然则行善事                                                 | 因此應該作善的：                                             |
| 14积善为未来                                                 | 來世的積聚，                                                 |
| 15功德是后世                                                 | 福德在其他世間(來世)中，                                     |
| 16众人渡津场                                                 | 是有生命者們的依止。」                                       |
