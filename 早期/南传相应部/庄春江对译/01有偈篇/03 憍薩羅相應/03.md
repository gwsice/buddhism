| 第三 王                                                      | 3. 老死經                                                    |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 坐于一面之拘萨罗国波斯匿王白世尊曰：                         | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!于有生者中，有能免老死者否?’                           | 「大德！已生者有除了老死之外嗎？」                           |
| 大王!任何生物亦不能免老死。                                  | 「大王！已生者沒有除了老死之外。                             |
| 大王!虽有大财富。有大富、有大受用、甚多金银、甚多资财、甚多财谷之家主，因有生故，亦不能免老死。 | 又，凡即使那些大財富的剎帝利：富有的、大富的、大財富的、多金銀的、多財產資具的、多財穀的，已生的他們也沒有除了老死之外； |
| 大王!虽有大财之婆罗门，有大财富，有大富、有大受用、甚多金银，甚多资财、甚多财谷之家主，因有生故，亦不能免老死。 | 大王！又，凡即使那些大財富的婆羅門：……（中略）               |
|                                                              | 大財富的屋主：富有的、大富的、大財富的、多金銀的、多財產資具的、多財穀的，已生的他們也沒有除了老死之外； |
| 大王!漏尽之应供者，行尽梵行，所作已办，已舍重担，达自利，尽有缚，依正智而解脱之比丘之身体，亦是破坏之法，应舍之法。’ | 大王！又，凡即使那些漏已滅盡的、已完成的、應該被作的已作的、負擔已卸的、自己的利益已達成的、有之結已遍滅盡的、以究竟智解脫的阿羅漢比丘，他們的這身體也是破裂法、捨棄法。」 |
| 世尊宣说此已……乃至……’                                        | 世尊說這個……（中略）。                                       |
| 1王车美亦坏                                                  | 「國王諸善彩繪的車確實變老，                                 |
| 2身体迈向老                                                  | 還有身體也來到老，                                           |
| 3正法永不老                                                  | 但善人們的法不來到老，                                       |
| 4善人所语善                                                  | 善人們與善人們確實宣說。」                                   |
