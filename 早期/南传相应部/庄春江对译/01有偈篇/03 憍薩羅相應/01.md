| 第一 拘萨罗品                                                | 1.第一品                                                     |
| 第一 幼少                                                    | 1. 年輕經                                                    |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。                             | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时，拘萨罗之波斯匿王诣世尊处。                               | 那時，憍薩羅國波斯匿王去見世尊。                             |
| 诣已，与世尊交谈敬重之见面礼，而坐于一面。                   | 抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 坐于一面之拘萨罗国波斯匿王，白世尊曰：                       | 在一旁坐下的憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!瞿昙曾宣示证悟无上之正等觉否?’                         | 「喬達摩尊師也自稱：『我已現正覺無上遍正覺』嗎？」           |
| ‘大王!有正确言说证悟无上正等觉者，即是我。                   | 「大王！凡當正確說它時，應該說『已現正覺無上遍正覺』，那就是我，當正確說時，應該說。 |
| 大王!我是证悟无上之正等觉。’                                 | 大王！因為我已現正覺無上遍正覺。」                           |
| ‘瞿昙!有僧伽、有群[众]、为群[众]之师、有名、有名声，为救济者 、有受甚多人认定为善人之沙门婆罗门。 | 「喬達摩尊師！即使那些有團體的、有群眾的、群眾的老師、有名聲的知名開宗祖師、被眾人認定善的沙門、婆羅門，即： |
| 犹如富兰那迦叶、末伽梨瞿舍罗、尼乾陀若提子、删阇耶吠罗底子、迦据陀迦旃延、阿耆多翅舍饮婆罗门等。 | 富蘭那迦葉、末迦利瞿舍羅、尼乾陀若提子、散惹耶毘羅梨子、浮陀迦旃延、阿夷多翅舍欽婆羅， |
| 问彼等曾宣示证悟无上正等觉否?未曾宣示证悟无上之正等觉。      | 當他們也被我質問：『請你們自稱：「我已現正覺無上遍正覺。」』時，他們不自稱：『我已現正覺無上遍正覺。』 |
| 何况尊者瞿昙，其生年青少，出家又日浅!’                       | 然而，為何是以僅年輕出生且以新出家的喬達摩尊師？」           |
| ‘大王!年少不可轻。年少不可轻有四种；何为四种耶?              | 「大王！這四種不應該被輕侮為『年輕』；不應該被輕蔑為『年輕』，哪四種？ |
| 大王!年少不可轻，刹帝利是年少不可轻。                        | 大王！剎帝利不應該被輕侮為『年輕』；不應該被輕蔑為『年輕』。 |
| 大王!年少不可轻，蛇是年少不可轻。                            | 大王！蛇不應該被輕侮為『年輕』；不應該被輕蔑為『年輕』。     |
| 大王!年少不可轻，火是年少不可轻。                            | 大王！火不應該被輕侮為『年輕』；不應該被輕蔑為『年輕』。     |
| 大王!年少不可轻，比丘是年少不可轻视。                        | 大王！比丘不應該被輕侮為『年輕』；不應該被輕蔑為『年輕』。」 |
| 大王!年少不可轻，此四种者是年少之不可轻视者。’               |                                                              |
| 世尊宣说此已、善逝更宣示曰：                                 | 世尊說這個，說這個後，善逝、大師又更進一步說這個：           |
| 3如是刹帝利 2具足尊贵姓                                      | 「剎帝利是出生具足者，                                       |
| 1善生而有誉                                                  | 有良好出身者、有名聲者，                                     |
| 4生年青少人                                                  | 不應該輕蔑為『年輕』，                                       |
| 5勿以轻低视 6勿以藐视他                                      | 人不應該輕辱他。                                             |
| 7得彼刹帝位                                                  | 因為他是人們的王：                                           |
| 8成为人王时                                                  | 剎帝利得到王位後，                                           |
| 9忿怒而强烈 10有加于王罚                                     | 發怒的他以國王的處罰，                                       |
|                                                              | 會在他上大大地執行，                                         |
| 12以避遭绳罚                                                 | 因此應該避開他：                                             |
| 11是故守己命                                                 | 守護自己生命者。                                             |
| 13于村或森林                                                 | 不論在村落或林野，                                           |
| 14在此见蛇时                                                 | 於該處如果看見蛇，                                           |
| 15以为是幼少                                                 | 不應該輕蔑為『年輕』，                                       |
| 16勿轻勿藐视                                                 | 人不應該輕辱牠。                                             |
| 17或高或低貌                                                 | 以種種的容色，                                               |
| 18持炎蛇彷徨                                                 | 凶猛的蛇行走，                                               |
| 20即直受彼咬                                                 | 牠靠近後會咬愚者，                                           |
| 19若愚男女近                                                 | 男人同時女人，                                               |
| 22以避遭伤害                                                 | 因此應該避開牠：                                             |
| 21是故守己命                                                 | 守護自己生命者。                                             |
| 23饵食甚多贪                                                 | 對可吃很多的火焰，                                           |
| 24炽燃火黑烟                                                 | 對火、對黑色足跡者，                                         |
| 25虽然是细小                                                 | 不應該輕蔑為『年輕』，                                       |
| 26勿轻勿藐视                                                 | 人不應該輕辱它。                                             |
| 27只要得柴薪                                                 | 因為它得到燃料後，                                           |
| 28其火大炎出                                                 | 成為大火後，                                                 |
| 30当即遭燃烧                                                 | 它靠近後會燒愚者，                                           |
| 29若愚男女近                                                 | 男人同時女人，                                               |
| 32以避受火害                                                 | 因此應該避開它：                                             |
| 31是故守己命                                                 | 守護自己生命者。                                             |
| 33火烧于森林                                                 | 凡火燒森林：                                                 |
| 34火尽成黑炭                                                 | 火、黑色足跡者，                                             |
| 36于此出草萌                                                 | 諸幼芽在那裡被出生：                                         |
| 35日夜以过后                                                 | 經過諸日夜。                                                 |
| 37持戒之比丘                                                 | 而凡戒具足者：                                               |
| 38若以戒炎烧                                                 | 比丘以[戒]火燃燒，                                           |
| 39其人无生子                                                 | 他的兒子們、諸家畜，                                         |
| 40不富于子孙                                                 | 繼承人們、財產他們不擁有，                                   |
| 41无子无相续                                                 | 無子孫、無繼承人，                                           |
| 42彼等切断芽 43不如多罗树                                    | 他們成為[如]無根的棕櫚樹。                                   |
| 44是故贤智人                                                 | 因此確實賢智的人，                                           |
| 45自己以见利                                                 | 自己利益的看見者，                                           |
| 46小蛇与细火                                                 | 對蛇與火，                                                   |
| 47有誉刹帝利                                                 | 以及對有名聲的剎帝利，                                       |
| 48具戒之比丘                                                 | 以及對戒具足的比丘，                                         |
| 49以善于正行                                                 | 就應該正確地行動。」                                         |
| 如是语已，拘萨罗国之波斯匿王白尊曰：                         | 在這麼說時，憍薩羅國波斯匿王對世尊說這個：                   |
| ‘世尊!是最胜，世尊，是最胜。                                 | 「大德！太偉大了，大德！太偉大了，                           |
| 世尊!譬喻倒者立起，覆者显现，迷者教示道，如有眼者见诸色，如暗中揭明灯， | 大德！猶如扶正顛倒的，或揭開隱藏的，或告知迷路者的道路，或在黑暗中持燈火：『有眼者們看見諸色。』 |
| 如是世尊说种种法。                                           | 同樣的，法被世尊以種種法門說明。                             |
| 世尊!我归依佛，及归依法与僧。                                | 大德！這個我歸依世尊、法、比丘僧團，                         |
| 世尊，容受我从今日，终生归依为优婆塞。’                      | 大德！請世尊記得我為優婆塞，從今天起已終生歸依。」           |
