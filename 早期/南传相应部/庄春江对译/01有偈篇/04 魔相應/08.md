| 第八 欢喜                                               | 8. 歡喜經                                                    |
| 如是我闻。                                              | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。                        | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时，恶魔波旬来诣世尊前。                                | 那時，魔波旬去見世尊。                                       |
| 诣已，向世尊唱此偈曰：                                  | 抵達後，魔波旬在世尊的面前說這偈頌：                         |
| 1有子依子喜                                             | 「有兒子者以兒子歡喜，                                       |
| 2牛主依牛喜                                             | 有牛者就像這樣以牛歡喜，                                     |
| 3人喜依所依                                             | 因為諸依著是人的歡喜，                                       |
| 4无依则无喜                                             | 因為凡無依著者他不歡喜。」                                   |
| [世尊：]                                                |                                                              |
| 1有子依子悲                                             | 「有兒子者以兒子憂愁，                                       |
| 2牛主依牛悲                                             | 有牛者就像這樣以牛憂愁，                                     |
| 3人喜悲所依                                             | 因為諸依著是人的憂愁，                                       |
| 4无依则无悲                                             | 因為凡無依著者他不憂愁。」                                   |
| 时，恶魔波旬：‘世尊已知我!善逝已知我。’形体即没于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
