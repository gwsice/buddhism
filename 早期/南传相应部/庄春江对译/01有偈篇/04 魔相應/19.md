| 第九 农夫                                                    | 19. 農夫經                                                   |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 尔时，世尊[对诸比丘]说涅盘法、教示、奖励、令欢喜。           | 當時，世尊以涅槃關聯的法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，理解、思惟、注心、倾耳谛听于法。                 | 而那些比丘作目標後、作意後、全心注意後傾耳聽法               |
| 时，恶魔波旬生是思惟：                                       | 那時，魔波旬想這個：                                         |
| ‘今沙门瞿昙说涅盘法、教示、奖励，令欢喜。彼等诸比丘，理解、思惟、全心、倾耳，谛听于法。我宁可昏昧彼等眼目，以诣沙门瞿昙。’ | 「這位沙門喬達摩以涅槃關聯的法說……（中略）讓我為了使之盲目去見沙門喬達摩。」 |
| 时恶魔波旬化作农夫，肩扛大锄，持赶牛棒，散发，衣大麻粗布，足涂泥浆而诣世尊处。诣已，白言世尊曰． | 那時，魔波旬化作農夫的容色後，在肩上放置大犁後，拿起驅使牛的長刺棒後，頭髮散亂地，穿粗麻布衣地，泥土沾滿腳地去見世尊。抵達後，對世尊說這個： |
| ‘沙门!见牡牛否?’                                             | 「沙門！是否看見公牛？」                                     |
| ‘波旬!牡牛于汝有何用?’                                       | 「波旬！那麼，你與公牛有什麼嗎？」                           |
| ‘沙门!眼是我有，色是我有。眼触之识处是我有。                 | 「沙門！就眼是我的，色是我的，眼觸[相應的]識處是我的，       |
| 沙门!去往何处汝能脱我否?                                     | 沙門！走到哪裡後你將從我脫離？                               |
| 沙门!耳是我有，声是我有，……乃至……沙门!鼻是我有，声是我有，……乃至……沙门!舌是我有，味是我有，……乃至……沙门!身是我有，触是我有，……乃至…… | 沙門！就耳是我的，聲音……（中略）沙門！就鼻是我的，氣味是我的……沙門！就舌是我的，味道是我的……沙門！身是我的，所觸是我的…… |
| 沙门!意是我有!法是我有，意触之识处是我有。                   | 沙門！就意是我的，法是我的，意觸識處是我的，                 |
| 沙门!去往何处能脱我否?’                                      | 沙門！走到哪裡後你將從我脫離？」                             |
| ‘波旬!眼是汝有，色是汝有，眼触之识处是汝有。波旬!无眼、无色、无眼触之识处者，则非汝之行处。 | 「波旬！就眼是你的，色是你的，眼觸識處是你的，但，波旬！於沒有眼、沒有色、沒有眼觸識處之處，波旬！那裡非你的去處。 |
| 波旬!耳是汝有，声是汝有，……[乃至]……。                        | 波旬！就耳是你的，聲音是你的，耳觸識處是你的，但，波旬！於沒有耳、沒有聲音、沒有耳觸識處之處，波旬！那裡非你的去處。 |
| 波旬!鼻是汝有，香是汝有，……[乃至]……。                        | 波旬！就鼻是你的，氣味是你的，鼻觸識處是你的，但，波旬！於沒有鼻、沒有氣味、沒有鼻觸識處之處，波旬！那裡非你的去處。 |
| 波旬!舌是汝有，味是汝有，……[乃至]……。                        | 波旬！就舌是你的，味道是你的，舌觸識處是你的……（中略）       |
|                                                              | 波旬！就身是你的，所觸是你的，身觸識處是你的……（中略）       |
| 波旬!意是汝有，法是汝有，意触之识处是汝有。波旬!无意、无法，无意触之识处，则非汝之行处。’ | 波旬！就意是你的，法是你的，意觸識處是你的，但，波旬！於沒有意、沒有法、沒有意觸識處之處，波旬！那裡非你的去處。」 |
| [恶魔：]                                                     |                                                              |
| 1此去我有者                                                  | 「凡他們說『這是我的』，                                     |
| 2是云此有我                                                  | 以及凡他們說『我的』，                                       |
| 3若汝意于此                                                  | 如果你的意(心)是在那裡，                                     |
| 4沙门未脱我                                                  | 沙門！你沒從我脫離。」                                       |
| [世尊：]                                                     |                                                              |
| 1不去此有我                                                  | 「凡他們說-我沒有那個，                                      |
| 2不云此是我                                                  | 凡他們說-我不是那些，                                        |
| 3恶魔如是知                                                  | 波旬！請你這麼知道：                                         |
| 4汝不见我道                                                  | 你甚至沒看見我的道。」                                       |
| 时，恶魔波旬……乃至……隐形没于其处。                           | 那時，魔波旬……（中略），就在那裡消失。                       |
