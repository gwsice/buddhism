| 第五 意                                      | 15. 意經                                                     |
| 如是我闻。                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。             | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时，恶魔波旬来诣世尊处。诣已，以偈言世尊曰： | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 2虚空挂系蹄                                  | 「空中行走的陷阱：                                           |
| 1意之驰骋转                                  | 凡這個意行走，                                               |
| 3我系蹄缚汝                                  | 以那個我將誘捕你，                                           |
| 4沙门未脱我                                  | 沙門！你將不從我脫離。」                                     |
| [世尊：]                                     |                                                              |
| 1色声香味触                                  | 「色、聲音、氣味、味道，                                     |
| 2是等五境乐                                  | 以及悅意的所觸，                                             |
| 3于此我不欲                                  | 在這裡我的意欲已消失，                                       |
| 4破坏者汝败                                  | 死神！你被擊敗。」                                           |
| 时，恶魔波旬……乃至……隐形没于其处。           | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
