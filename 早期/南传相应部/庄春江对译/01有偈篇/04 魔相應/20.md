| 第十 统治                                                    | 20. 統治經                                                   |
| 尔时，世尊住拘萨罗国，雪山森林小屋。                         | 有一次，世尊住在憍薩羅國喜馬拉雅山腳下的林野小屋。           |
| 时，世尊独作静观，作如是思念：                               | 那時，獨處、獨坐的世尊這樣心的深思生起：                     |
| ‘能不杀、不害、不胜、不令胜、不悲、不念悲、以行如法，不行[非法]否?’ | 「可能以法行使統治：無殺、無使之殺，無征服、無使之征服，無悲傷、無使之悲傷嗎？」 |
| 时，恶魔波旬知世尊之所念，来诣世尊处，白世尊曰：             | 那時，魔波旬以心了知世尊心中的深思後，去見世尊。抵達後，對世尊說這個： |
| ‘世尊!世尊自为统治。善逝不自杀，不害、不胜、不令胜，不悲、不令悲、行如法统治。’ | 「大德！請世尊行使統治，請善逝以法行使統治：無殺、無使之殺，無征服、無使之征服，無悲傷、無使之悲傷。」 |
| ‘波旬!汝见于何者，如是云我：‘世尊自行统治……乃至……如法统治。’’ | 「波旬！那麼，你看見我什麼，而對我說這個：『大德！請世尊行使統治，請善逝以法行使統治！無殺、無使之殺，無征服、無使之征服，無悲傷、無使之悲傷。』呢？」 |
| ‘世尊!世尊修、习四如意足，无如乘用之车、无立处，常行、惯行圆满。 | 「大德！四神足被世尊修習、被多作、被作為車輛、被作為基礎、被實行、被累積、被善努力， |
| 若世尊，欲以雪山山王为金，应予决心令山为金。’                | 大德！而當希望時，如果世尊勝解喜馬拉雅山山王就像黃金這樣，那麼它會成為黃金。」 |
| [世尊：]                                                     |                                                              |
| 1光耀之金山                                                  | 「對金山：對整座(全部)黃金，                                 |
| 2即有倍黄金 3难满一人欲                                      | 即便二座對一個人也不滿足，                                   |
| 4知是人正行                                                  | 像這樣知道者應該平等地行。                                   |
| 5见苦原因者                                                  | 凡從此因由看到苦，                                           |
| 6如何倾爱欲                                                  | 那個人如何會彎向諸欲？                                       |
| 7依知世结缚                                                  | 知道依著是世間中的『染著』後，                               |
| 8众人学解脱                                                  | 人就應該為了它的調伏學習。」                                 |
| 时，恶魔波旬苦恼以：‘世尊已知我!善逝已知我。’萎身隐形没于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
