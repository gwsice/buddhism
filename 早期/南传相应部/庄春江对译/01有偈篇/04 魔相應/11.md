| 第二 恶魔品                                                  | 2.第二品                                                     |
| 第一 岩                                                      | 11. 岩石經                                                   |
|                                                              | 被我這麼聽聞：                                               |
| 尔时，世尊住王舍城灵鹫山。                                   | 有一次，世尊住在王舍城耆闍崛山。                             |
| 尔时，世尊闇夜中坐于露地。雨丝霏霏下降。                     | 當時，世尊在漆黑的夜晚坐在露天處，而天空下著毛毛雨。         |
| 时，恶魔波旬欲令生恐怖，毛发竖立。以诣世处。                 | 那時，魔波旬想要使世尊生出害怕、僵硬狀態、身毛豎立的而去見世尊。 |
| 诣已，于世尊不远之处，以碎大石岩。                           | 抵達後，在世尊的不遠處碎破諸大岩石。                         |
| 时，世尊知是恶魔波旬，以偈谓恶魔波旬曰：                     | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
|                                                              | 「即使你將使，                                               |
| 1犹如灵鹫山 2虽震动一切                                      | 整座耆闍崛山搖動，                                           |
| 3正解脱佛陀                                                  | 正解脫者們、覺者們，                                         |
| 4丝毫不动摇                                                  | 都沒有動搖。」                                               |
| 时，恶魔波旬苦恼以：‘世尊已知我，善逝已知我。’而萎身没形于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
