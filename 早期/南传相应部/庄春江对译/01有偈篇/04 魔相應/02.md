| 第二 象                                                      | 2. 象王的容色經                                              |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊初成正觉时，住优留毗罗林之尼连禅河边，阿阇波罗尼俱律陀树下。 | 有一次，初現正覺的世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹處。 |
| 尔时，世尊阇夜坐于露地，雨丝霏霏而下降。                     | 當時，世尊在漆黑的夜晚坐在露天處，而天空下著毛毛雨。         |
| 尔时，恶魔波旬欲令世尊生起恐怖毛发竖立，乃化作大象王，来诣世尊前。 | 那時，魔波旬想要使世尊生出害怕、僵硬狀態、身毛豎立的，化作大象王的容色後，去見世尊， |
| 彼头实如大黑岩，其牙如净银，其鼻如大锄柄。                   | 牠的頭猶如大木槵子寶石那樣，牠的牙猶如純銀那樣，牠的鼻猶如大犁柄那樣。 |
| 时，世尊知此恶魔波旬，而以偈言恶魔波旬曰：                   | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 2汝之轮回长                                                  | 「長時間輪迴者：                                             |
| 1作净不净相                                                  | 做純淨不純淨的容色後，                                       |
| 3波旬汝可去                                                  | 波旬！夠了！以你的那個，                                     |
| 4破坏者汝败                                                  | 死神！你被擊敗。」                                           |
| 时，恶魔波旬苦恼而曰：‘世尊已知我，善逝已知我。’即萎身没于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
