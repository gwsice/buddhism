| 第五 魔女                                                    | 25. 魔的女兒經                                               |
| $$\color{red}这两句在上一经末尾$$                            | 那時，魔波旬在世尊面前以這些厭的偈頌說後，從那處離開後，     |
|                                                              | 在世尊的不遠處沈默地、羞愧地、垂肩地、低頭地、鬱悶地、不能反應地以盤腿坐在地上，以木棒刮著地。 |
| 时，渴爱、不快、贪欲之三魔女，来至恶魔波旬处，至已，以偈语恶魔波旬曰： | 那時，魔的女兒：渴愛、不喜樂、貪，去見魔波旬。抵達後，以偈頌對魔波旬說： |
| 1何故父不乐                                                  | 「父親！為何你是不快樂的？                                   |
| 2为因何人悲                                                  | 你對哪位男子憂愁呢？                                         |
| 3我等从其人 4以贪欲系蹄                                      | 我們以貪網對他，                                             |
| 5如缚森林象                                                  | 如對林野的象，                                               |
| 6用以牵系来                                                  | 繫縛後我們將帶來，                                           |
| 7应置汝手下                                                  | 將成為被你控制者。」                                         |
| [恶魔：]                                                     |                                                              |
| 2世间阿罗汉 3善逝者不易                                      | 「世間中阿羅漢、善逝，                                       |
| 1以贪欲诱惑                                                  | 以貪是不易誘惑的，                                           |
| 4彼出魔领域                                                  | 是越過魔領域者，                                             |
| 5是故我甚悲                                                  | 因此我非常地憂愁。」                                         |
| 时，渴爱、不快、贪欲之三魔女，来诣世尊处。诣已，以此白世尊曰： | 那時，魔的女兒：渴愛、不喜樂、貪，去見世尊。抵達後，對世尊說這個： |
| ‘沙门!奉事卿足下。’                                          | 「沙門！使我們在你的足下服侍。」                             |
| 然则得尽烦恼依，却于无上解脱之世尊，不为一顾。               | 那時，世尊不理會(不作意)，正如他是在無上依著盡滅上的解脫者那樣。 |
| 时，渴爱、不快、贪欲之三魔女，退于一面，其如是思惟：         | 那時，魔的女兒：渴愛、不喜樂、貪，離開到一旁後這麼計劃：     |
| ‘诸之兴趣各异，                                              | 「男人的欲求是多方面的，                                     |
| 我等各化作一百童女相。’                                      | 讓我們一一化作一百個少女模樣。」                             |
| 时，渴爱、不快、贪欲三魔女，各化作一百童女相，以诣世尊前。诣已，白世尊曰： | 那時，魔的女兒：渴愛、不喜樂、貪，一一化作一百個少女模樣後，去見世尊。抵達後，對世尊說這個： |
| ‘沙门!奉事卿足下。’                                          | 「沙門！使我們在你的足下服侍。」                             |
| 然而得尽烦恼依则于无上解脱之世尊，不为一顾。                 | 那時，世尊不理會，正如他是在無上依著盡滅上的解脫者那樣。     |
| 时，渴爱、不快、贪欲三魔女，退于一面、具如是思惟：           | 那時，魔的女兒：渴愛、不喜樂、貪，離開到一旁後這麼計劃：     |
| ‘诸人兴趣各异。                                              | 「男人的欲求是多方面的，                                     |
| 我等各化作，未生子之百人女，’                                | 讓我們一一化作一百個未生過小孩的女人模樣。」                 |
|                                                              | 那時，魔的女兒：渴愛、不喜樂、貪，一一化作一百個未生過小孩的女人模樣後，去見世尊。抵達後，對世尊說這個： |
|                                                              | 「沙門！使我們在你的足下服侍。」                             |

|                                                              | 那時，魔的女兒：渴愛……（中略）一一化作一百個生過兩次小孩的女人模樣後，去見世尊。 |

|                                                              | 那時，魔的女兒：渴愛……（中略）一一化作一百個中年女人模樣後……（中略）正如他是在無上依著盡滅上的解脫者那樣。 |
| ……[乃至]……‘化作高年之百人女。’                               | 那時，魔的女兒：渴愛……（中略）讓我們一一化作一百個老年女人模樣。 |
| 时，三魔女各化作高年女百人，来诣世尊前。                     | 那時，魔的女兒：渴愛……（中略）一一化作一百個老年女人模樣後，去見世尊。 |
| 诣已，白世尊曰：‘沙门!奉事卿足下。’然而尽烦恼之依，于无上解脱之世尊，不为一顾。 | ……（中略）正如他是在無上依著盡滅上的解脫者那樣。             |
| 时，渴爱、不快、贪爱三魔女、退于一面、以言此曰               | 那時，魔的女兒：渴愛、不喜樂、貪，離開到一旁後說這個：       |
|                                                              | 「傳說是真的，父親對我們說：                                 |
| 2世间阿罗汉 3善逝者不易                                      | 『世間中阿羅漢、善逝，                                       |
| 1以贪欲诱惑                                                  | 以貪是不易誘惑的，                                           |
| 4彼出魔领域                                                  | 是越過魔領域者，                                             |
| 5是故我甚悲                                                  | 因此我非常地憂愁。』                                         |
| 我等依此攻击末离欲之沙门婆罗门者，                           | 因為凡如果我們以這些攻擊，攻擊未離貪的沙門或婆羅門，         |
| 令破其心脏，口吐热血，乱心狂气，                             | 他的心臟會破裂，或熱血會從口中湧出，或會到達瘋狂，或心散亂。 |
| 犹如割青苇干、萎、枯、                                       | 又或猶如被割斷的綠蘆葦乾枯、枯萎、凋謝。                     |
| 应令之干、萎、枯。’                                          | 同樣的，他會乾枯、枯萎、凋謝。」                             |
| 时，渴爱、不快、贪欲三魔女，来诣世尊处。诣已，立于一面。立一面之魔女渴爱以偈言世尊曰． | 那時，魔的女兒：渴愛、不喜樂、貪，去見世尊。抵達後，在一旁站立。在一旁站立的魔的女兒渴愛，以偈頌對世尊說： |
| 1悲侵沉思林                                                  | 「你陷入憂愁地在林中修禪嗎？                                 |
| 2求复得失富                                                  | 財產失去地或者欲求地嗎？                                     |
| 3犯罪村人中                                                  | 你在村落中曾做任何罪行嗎？                                   |
| 4何故不与交                                                  | 你為何不與人作友情？                                         |
| 5汝非我友人                                                  | 與任何人你的友情不生起？」                                   |
| [世尊：]                                                     |                                                              |
| 2独坐得胜义                                                  | 「目標的達成、心的寂靜，                                     |
| 1破可爱乐军                                                  | 征服可愛的、合意形色的軍隊後，                               |
| 3禅思心寂静 4安乐于菩提                                      | 獨自修禪的我隨覺樂，                                         |
| 5是故我不与 6诸人之交往                                      | 因此我不與人作友情，                                         |
| 7于我无友人                                                  | 與任何人我的友情不生起。」                                   |
| 时，魔女不快以偈白世尊曰：                                   | 那時，魔的女兒不喜樂，以偈頌對世尊說：                       |
| 1比丘住多修                                                  | 「這裡怎樣多住的比丘，                                       |
| 2以度五瀑流 3于此度第六                                      | 渡過五暴流者這裡渡過第六？                                   |
| 4如何多禅思 5外界之欲想                                      | 怎樣多{禪修者}[修禪者]-諸欲想，                              |
| 6其人不能得                                                  | 成為局外者-凡沒得到他後？」                                  |
| [世尊：]                                                     |                                                              |
| 1身安心解脱                                                  | 「身已寧靜、心善解脫，                                       |
| 2以离作三业 3正念无贪着                                      | 不造作、有念、無家，                                         |
| 4了知法无寻                                                  | 了知法後無尋禪者，                                           |
| 5禅思不忆怒 6亦不为懒惰                                      | 不發怒、不流動、不惛沈。                                     |
| 7比丘住多修                                                  | 這裡這樣多住的比丘，                                         |
| 8以度五暴流 9亦度于第六                                      | 渡過五暴流者這裡渡過第六，                                   |
| 10如是多禅思 11外界之欲想                                    | 這樣多{禪修者}[修禪者]-諸欲想，                              |
| 12其人不能得                                                 | 成為局外者-凡沒得到他後。」                                  |
| 时，魔女贪欲，于世尊处，以唱此寂静偈曰：                     | 那時，魔的女兒貪，以偈頌對世尊說：                           |
| 1彼断除渴爱 2以率群众行                                      | 「切斷渴愛後群眾僧團行者，                                   |
| 3众多有情行                                                  | 以及許多有信者確實將實行，                                   |
| 4此无贪欲者 5令众断魔掌                                      | 唉！這位無家者對眾人，                                       |
| 6导死王彼岸                                                  | 搶奪後將引導到死王的彼岸。」                                 |
| 7如来大雄者                                                  | 「大英雄們、如來們，                                         |
| 8依法王导众                                                  | 確實以正法引導，                                             |
| 9于法之所导                                                  | 對以法引導者們，                                             |
| 10于所了解者 11我等何所嫉                                    | 了知者有什麼嫉妒？」                                         |
|                                                              | 那時，魔的女兒：渴愛、不喜樂、貪，去見魔波旬。               |
| 恶魔波旬，见渴爱、不快贪欲三魔女从远而来，见已以偈曰：       | 魔波旬看見正從遠處到來的魔的女兒：渴愛、不喜樂、貪。看見後，以偈頌說： |
| 1愚人以莲茎                                                  | 「愚者！以蓮花莖，                                           |
| 2想破碎大山                                                  | 你們劈山，                                                   |
| 3以爪掘山岩                                                  | 你們以指甲挖山，                                             |
| 4以齿啮硬铁                                                  | 你們以牙齒咬鐵。                                             |
| 5以头撞大岩                                                  | 如在頭上舉起岩石後，                                         |
| 6大涡探足地                                                  | 你們在深淵中尋求立足處，                                     |
| 7以代自捶胸                                                  | 如以胸攻擊殘株後，                                           |
| 8今厌瞿昙来                                                  | 厭後你們從喬達摩離開。」                                     |
| 10虽是光辉来                                                 | 「她們輝耀地來：                                             |
| 9爱不快贪欲                                                  | 渴愛、不喜樂、貪，                                           |
| 13大师退彼等                                                 | 在那裡大師驅散她們，                                         |
