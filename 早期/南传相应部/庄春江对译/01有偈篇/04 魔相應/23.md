| 第三 瞿低迦 | 23. 瞿低迦經                                                 |
|        | 被我這麼聽聞：                                               |
| 尔时，世尊住王舍城竹林栗鼠养饵所。 | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 尔时，尊者瞿低迦住伊师耆利山麓之黑曜岩。 | 當時，尊者瞿低迦住在仙吞山坡的黑岩處。                       |
| 时，尊者瞿低迦不放逸、虔诚、精进而住，得一时之心解脱。 | 那時，住於不放逸的、熱心的、自我努力的尊者瞿低迦觸達暫時的心解脫， |
| 时，尊者瞿低迦退转其一时之心解脱。 | 但，尊者瞿低迦又從那個暫時的心解脫退失。                     |
| 复次，尊者瞿低迦不放逸、虔诚、精进而住。得一时之心解脱。 | 第二次，住於不放逸的、熱心的、自我努力的尊者瞿低迦觸達暫時的心解脫， |
| 尊者瞿低迦又退转其一时之心解脱。 | 第二次，尊者瞿低迦從那個暫時的心解脫退失。                   |
| 三次……[乃至]……四次……[乃至]……五次……[乃至]……六次，尊者瞿低迦不放逸、虔诚、精进而住，得一时之心解脱。 | 第三次，住於不放逸的、熱心的、自我努力的尊者瞿低迦觸達暫時的心解脫， |
| 尊者瞿低迦六次退转其一时之心解脱。 | 第三次，尊者瞿低迦從那個……（中略）退失。                     |
|        | 第四次，當尊者瞿低迦住於不放逸……（中略）觸達暫時的心解脫，   |
|        | 第四次，尊者瞿低迦從那個……（中略）退失。                     |
|        | 第五次，當尊者瞿低迦……（中略）觸達暫時的心解脫，             |
|        | 第五次，尊者……（中略）心解脫退失。                           |
|        | 第六次，住於不放逸的、熱心的、自我努力的尊者瞿低迦觸達暫時的心解脫， |
|        | 第六次，尊者瞿低迦從那個暫時的心解脫退失。                   |
| 尊者瞿低迦七次不放逸、虔诚、精进而住，得一时之心解脱。 | 第七次，住於不放逸的、熱心的、自我努力的尊者瞿低迦觸達暫時的心解脫。 |
| 时，尊者瞿低迦作如是思念： | 那時，尊者瞿低迦想這個：                                     |
| ‘我至六次退转一时之心解脱， | 「直到第六次為止，我已從暫時的心解脫退失了，                 |
| 我宁可将执剑!’ | 讓我取刀[自殺]吧！」                                         |
| 时，恶魔波旬知尊者瞿低迦心之所念，诣于世尊处。诣已以偈语世尊： | 那時，魔波旬以心了知尊者瞿低迦心中的深思後，去見世尊。抵達後，以偈頌對世尊說： |
| 2大雄大智慧 | 「大英雄、大慧者，                                           |
| 1辉耀神通誉 | 以神通以名聲閃耀者，                                         |
| 3离诸怖畏者 | 已超越一切怨恨恐懼者，                                       |
| 4礼奉卿足下 | 我禮拜在有眼者的腳上。                                       |
| 5大雄之胜死 | 大英雄、死的征服者，                                         |
| 6卿弟子想死 | 你的弟子對死，                                               |
| 7以死是期望 | 希望、意圖，                                                 |
| 8光明主止此 | 光輝者請制止他！                                             |
| 9世尊喜于教 | 世尊！為何你的，                                             |
| 10卿之弟子者 | 在教說上愛好的弟子，                                         |
| 11如何未达证 12有学而为死 | 心意未達成的有學，                                           |
|        | 能死？名聞者！」                                             |
| 其时，尊者瞿低迦执剑。 | 當時，刀已被尊者瞿低迦取了。                                 |
| 时，世尊知是恶魔波旬，以偈语恶魔波旬曰： | 那時，世尊知道：「這是魔波旬。」後，以偈頌對魔波旬說：       |
| 2大雄乃如是 | 「明智者們確實這麼做：                                       |
| 1不欲于此生 | 不期待活命，                                                 |
| 3拔除渴爱根 | 連根拔除渴愛後，                                             |
| 4瞿低迦涅盘 | 瞿低迦已般涅槃。」                                           |
| 时，世尊呼诸比丘： | 那時，世尊召喚比丘們：                                       |
| ‘诸比丘!我等今往伊师耆利山麓之黑曜岩，良家之子瞿低迦于彼执剑。’ | 「比丘們！我們走，我們將去仙吞山坡的黑岩處，在那裡刀已被瞿低迦善男子取了。」 |
| ‘然唯!世尊。’彼等诸比丘应诺世尊。 | 「是的，大德！」那些比丘回答世尊。                           |
| 时，世尊与众多比丘俱，到伊师耆利山麓之黑曜岩。 | 那時，世尊與眾多比丘一起去仙吞山坡的黑岩處。                 |
| 世尊由远处见尊者瞿低迦，于床上抱肩仰卧。 | 世尊就從遠處看見尊者瞿低迦在床肩膀轉回地躺臥。               |
| 其时，又见蒙胧如烟雾，行往东方、行往西方、行往南方、行往北方、行于上方、行往下方，行往四维。 | 當時，冒煙狀態的黑闇雲煙走向東方後，走向西方；走向北方；走向南方；走向上方；走向下[方]；走向四方的中間方位。 |
| 时，世尊呼诸比丘曰： | 那時，世尊召喚比丘們： |
| ‘诸比丘!汝等见蒙胧如烟者，行往东方、行往西方、行往南方、行往北方、行往上方、行往下方、行往四维者否?’ | 「比丘們！你們看見這股冒煙狀態的黑闇雲煙走向東方後，走向西方；走向北方；走向南方；走向上方；走向下[方]；走向四方的中間方位嗎？」 |
| ‘世尊!诚如所说。’ | 「是的，大德！」 |
| ‘诸比丘!此恶魔波旬，以求良家子瞿低迦之识。 | 「比丘們！這是魔波旬探求瞿低迦善男子的識： |
| ‘良家子瞿低迦之识，住何处耶?’ | 『瞿低迦善男子的識住立在哪裡？』 |
| 然则!诸比丘!良家子瞿低迦之识已般涅盘而无住处。’ | 比丘們！然而，以識已不住立，瞿低迦善男子已般涅槃了。」 |
| 时，恶魔波旬取耶虑瓦树之黄色箜篌来诣世尊处!诣已，以偈白世尊曰： | 那時，魔波旬拿起淡黃色的橡木琵琶琴後，去見世尊。抵達後，以偈頌對世尊說： |
| 1我求于上下 | 「上下與橫向， |
| 2乃至于四维 3四方及八方 | 對四方的中間方位-那個我， |
| 4不见瞿低迦 | 探求的我沒得到， |
| 5往于何处耶 | 那位瞿低迦已去何處。」 |
| [世尊：] |      |
| 1志坚英雄者 | 「凡明智者、具足堅固心者， |
| 2常乐于禅思 | 經常好於禪的禪者， |
| 3日夜从于道 | 是日夜實踐者， |
| 4无愿于此生 | 不希求活命者。 |
| 5打破死魔军 | 征服死神軍後， |
| 6不行于再生 | 不返回再有後， |
| 7拔除渴爱根 | 連根拔除渴愛後， |
| 8瞿低迦涅盘 | 瞿低迦已般涅槃。」 |
| 9破败于彼悲 | 「那位被憂愁打敗者的， |
| 10小胁落箜篌 | 琵琶琴從腋下掉落， |
| 11悲怆之夜叉 | 之後那位不快樂的夜叉， |
| 12以没于此处 | 就在那裡消失。」 |
