| 元亨寺                                                       | 庄春江                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 第四 七年                                                    | 24. 七年追蹤經                                               |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住优留毗罗之尼连禅河边，阿阇波罗尼俱律陀树下。     | 有一次，世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹下。         |
| 其时，恶魔波旬跟踪世尊七年，以求空隙，而无所得。             | 當時，魔波旬已跟隨世尊七年，期待機會，沒得到機會中。         |
| 时，恶魔波旬来诣世尊处。诣已，以偈语世尊曰：                 | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 1悲侵沉思林                                                  | 「你陷入憂愁地在林中修禪嗎？                                 |
| 2求复得失富                                                  | 財產失去地或者欲求地嗎？                                     |
| 3犯罪村人中                                                  | 你在村落中曾做任何罪行嗎？                                   |
| 4何故不与交                                                  | 你為何不與人作友情？                                         |
| 5汝非我友人                                                  | 與任何人你的友情不生起？」                                   |
| [世尊：]                                                     |                                                              |
| 1掘除诸悲根                                                  | 「挖出一切憂愁的根後，                                       |
| 2无罪复无悲 3我耽于禅思                                      | 我無罪行無憂愁地修禪，                                       |
| 4舍诸生存欲                                                  | 切斷一切有貪的熱望後，                                       |
| 6诸漏尽禅思 5放逸之亲族                                      | 我無漏地修禪-放逸者的親族！」                                |
| [恶魔：]                                                     |                                                              |
| 1诸人语我者                                                  | 「凡他們說『這是我的』，                                     |
| 2我者语诸人                                                  | 以及凡他們說『我的』，                                       |
| 3若汝意于此                                                  | 如果你的意(心)是在那裡，                                     |
| 4沙门未脱我                                                  | 沙門！你沒從我脫離。」                                       |
| [世尊：]                                                     |                                                              |
| 1诸人语非我                                                  | 「凡他們說-我沒有那個，                                      |
| 2语非我诸人                                                  | 凡他們說-我不是那些，                                        |
| 3恶魔知如是                                                  | 波旬！請你這麼知道：                                         |
| 4汝不知我道                                                  | 你甚至沒看見我的道。」                                       |
| [恶魔：]                                                     |                                                              |
| 2证得菩提道                                                  | 「如果道被隨覺：                                             |
| 1汝若至不死                                                  | 安穩的、導向不死的，                                         |
| 3离去汝独行                                                  | 請你離開也請你就一個人走，                                   |
| 4何以教他人                                                  | 你為何教誡其他人？」                                         |
| [世尊：]                                                     |                                                              |
| 2问我不死国                                                  | 「他們問無死亡領域：                                         |
| 1望到彼岸者                                                  | 凡去彼岸的人們，                                             |
| 3问我之彼等                                                  | 被詢問的我告知他們：                                         |
| 4说无余涅盘                                                  | 凡那個無依著的真理。」                                       |
| [恶魔：]                                                     |                                                              |
| ‘世尊!犹如离村邑不远处有池，蟹住于此。                       | 「大德！ 猶如在村落或城鎮的不遠處有蓮花池，在那裡有螃蟹。    |
| 世尊!时众多之童男童女，出由村邑，以到其池。                  | 大德！那時，眾多男孩或女孩從那村落或城鎮走出去後，去那個蓮花池。 |
| 到已由水中举蟹置于陆上。                                     | 抵達後[跳入那個蓮花池後]，從水中抓起那隻螃蟹後，使之住立在陸地上。 |
| 世尊!若蟹竖立其剪，彼童男童女，即以木片、小石予破断。        | 大德！不論那隻螃蟹使哪個蟹爪轉動，就在那時那些男孩或女孩就以木棒或以小石切斷、打裂、破壞它。 |
| 如是世尊。蟹皆破断其足剪，不能再入于池。                     | 大德！這樣，那隻螃蟹以全都切斷的、打裂的、破壞的蟹爪，不能夠[再]進入那個蓮花池，猶如之前。 |
| 世尊亦如是，以前任何弯曲 、歪斜、歪曲、皆由世尊所破断，      | 同樣的，大德！凡任何歪曲的、相違的、扭曲的，那些全都被世尊切斷、打裂、破壞。 |
| 伺其间隙之我等，不得再近至世尊。’                            | 大德！現在，我不能再以期待機會接近世尊了。」                 |
| 时，恶魔波旬于世尊前，气馁而唱偈曰：                         | 那時，魔波旬在世尊的面前以這些厭的偈頌說：                   |
| 2见石似凝膏                                                  | 「{而}[如]對脂肪容色的岩石，                                 |
| 1鸟飞于空中                                                  | 烏鴉繞行：                                                   |
| 3于此为获得                                                  | 在那裡或許我們會發現柔軟的，                                 |
| 4软甘之等食                                                  | 或許會有樂味。                                               |
| 5于此不得食                                                  | 在那裡沒得到樂味，                                           |
| 6飞空以离去                                                  | 烏鴉會從此離開，                                             |
| 7如袭石之鸟                                                  | 如烏鴉接近岩石，                                             |
| 8气馁离瞿昙                                                  | 厭後我們離開喬達摩。」                                       |
| 时，恶魔波旬于世尊前，气馁以唱偈，离座而去。                 |                                                              |
| 于离世尊不远，趺坐于地上、默然、悄然、落肩、气馁、困恼，以杖搔地而坐。 |                                                              |
