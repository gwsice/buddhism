| 元亨寺                                                  | 庄春江                                                       |

| 第七 处                                                 | 17. 六觸處經                                                 |
| 尔时，世尊住毗舍离大林重阁讲堂。                        | 有一次，世尊住在毘舍離大林重閣講堂。                         |
| 尔时，世尊以六触处为诸比丘说法、教示、奖励，令欢喜。    | 當時，世尊以關於六觸處之法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，理解、思惟、注心、倾耳，谛听于法。          | 而那些比丘作目標後、作意後、全心注意後傾耳聽法。             |
| 时，恶魔波旬作如是思惟：                                | 那時，魔波旬想這個：                                         |
| ‘此沙门瞿昙以六触处、为诸比丘说法、教示、奖励，令欢喜。 | 這位沙門喬達摩以關於六觸處之法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，理解、思惟，注心、倾耳，谛听于法。          | 而那些比丘作目標後、作意後、全心注意後傾耳聽法，             |
| 我宁可昏昧彼等眼目、以诣沙门瞿昙。                      | 讓我為了使之盲目，去見沙門喬達摩。」                         |
| 时，恶魔波旬来诣世尊处。                                | 那時，魔波旬去見世尊。                                       |
| 诣已，于世尊之不远处，号大恐怖声，如大地破裂。          | 抵達後，在世尊的不遠處作大恐怖與可怕聲，以至於看(聽)起來像大地被打裂一樣。 |
| 时，一比丘谓于另一比丘曰：                              | 那時，某位比丘對另一位比丘說這個：                           |
| ‘比丘!比丘!此大地会破裂。’                              | 「比丘！比丘！這大地看起來像被打裂一樣。」                   |
| 如是语时，世尊告彼比丘曰：                              | 在這麼說時，世尊對那位比丘說這個：                           |
| ‘比丘!此非大地之破裂、此乃恶魔波旬为来昏昧汝等眼目。’   | 「比丘！那不是大地被打裂，那是魔波旬，為了使你們盲目來的。」 |
| 时，世尊知是恶魔波旬，以偈告恶魔波旬曰：                | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 1色声香及味                                             | 「諸色、聲、氣味、味道，                                     |
| 2触等一切法                                             | 諸所觸與全部的法，                                           |
| 3乃世恐怖饵                                             | 這是可怕的世間物質，                                         |
| 4迷乱诸世人                                             | 在這裡世間被迷昏頭。                                         |
| 6超越恐怖饵                                             | 但超越這個後，                                               |
| 5佛弟子正念                                             | 具念的佛弟子，                                               |
| 7超脱恶魔领                                             | 超越魔領域後，                                               |
| 8光辉如太阳                                             | 如太陽般輝耀。」                                             |
| 时，恶魔波旬……乃至……隐形没于其处。                      | 那時，魔波旬……（中略）就在那裡消失。                         |
