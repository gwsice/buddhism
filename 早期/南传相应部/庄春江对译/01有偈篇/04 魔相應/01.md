| 第一 恶魔品                                                  | 1.第一品                                                     |
| 第一 苦业                                                    | 1. 苦行經                                                    |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊初成正觉时，住优留毗罗林之尼连禅河边，阿阇波罗尼俱律陀树下。 | 有一次，初現正覺的世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹處。 |
| 时，世尊独坐静观，而作如是思念：                             | 那時，獨處、獨坐的世尊這樣心的深思生起：                     |
| ‘我今实已脱离彼苦行 。善哉!我今实已脱离彼无利益之苦行。善哉! | 「我確實已從那個難行解脫，我確實已從那個不伴隨利益的難行解脫，好！ |
| 证得坚毅、正念、菩提。’                                      | 我確實到達了解脫的菩提，好！」                               |
| 尔时，恶魔波旬，知世尊心之所念，而来诣世尊处。               | 那時，魔波旬以心了知世尊心中的深思後，去見世尊。             |
| 诣已，以偈白世尊曰：                                         | 抵達後，以偈頌對世尊說：                                     |
| 1若无离苦行                                                  | 「離開苦行後，                                               |
| 2清净青年众                                                  | 以那個人們不變純淨，                                         |
| 4不净思为净                                                  | 不純淨的你認為純淨的，                                       |
| 3踌躇离净道                                                  | 純淨道已錯失。」                                             |
| 尔时，世尊知是恶魔波旬，以偈答恶魔波旬曰：                   | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 2知无一切利                                                  | 「知道伴隨無利益的後：                                       |
| 1不死等苦行                                                  | 對凡任何[求]不死的苦行，                                     |
| 4一切无护益                                                  | 一切是帶來無利益者，                                         |
| 3如陆舟驴舵                                                  | 如在陸地上的槳與舵。                                         |
| 5修戒及定慧                                                  | 對戒、定與慧，                                               |
| 6此乃菩提道                                                  | 為了菩提道修習者，                                           |
| 7我达无上净                                                  | 我是到達最高純淨者，                                         |
| 8破坏者汝败                                                  | 死神！你被擊敗。」                                           |
| 尔时，恶魔波旬苦恼而曰：‘世尊已知我，善逝已知我。’即萎身没于彼处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
