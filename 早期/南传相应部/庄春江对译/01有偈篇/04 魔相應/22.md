| 第二 三弥提                                                  | 22.三彌提經                                                  |
|                                                              | 被我這麼聽聞：                                               |
| 尔时，世尊住释迦族之尸罗越底。                               | 有一次，世尊住在釋迦族的尸羅哇地。                           |
| 时，尊者三弥提住离世尊不远，不放逸、虔诚、精进。             | 當時，尊者三彌提在世尊的不遠處住於不放逸的、熱心的、自我努力的。 |
| 时，尊者三弥提，于独坐静观，作如是思念：                     | 那時，獨處、獨坐的尊者三彌提這樣心的深思生起：               |
| ‘我师乃应供者、正等觉者，我实得大利益。                      | 「確實是我的利得，確實是我的善得的：我的大師是阿羅漢、遍正覺者； |
| 我如是于善说之律与法出家。我实得大利益。                     | 確實是我的利得，確實是我的善得的：我在這麼善說的法律中出家； |
| 我之同梵行者、乃诸善人之持戒者。我实得大利益。’              | 確實是我的利得，確實是我的善得的：我的同梵行者們是持戒者、善法者。」 |
| 时，恶魔波旬知尊者三弥提心之所念，来诣尊者三弥提住处。       | 那時，魔波旬以心了知尊者三彌提心中的深思後，去見尊者三彌提。 |
| 诣已，于尊者三弥提之不远处，作大恐怖声，宛如大地破裂。       | 抵達後，在尊者三彌提不遠處作大恐怖與可怕聲，以至於看(聽)起來像大地被打裂一樣。 |
| 时，尊者三弥提诣世尊住处。                                   | 那時，尊者三彌提去見世尊。                                   |
| 诣已，礼敬世尊，坐于一面；坐一面已，尊者三弥提以此告世尊曰:  | 抵達後，向世尊問訊後，在一旁坐下。在一旁坐下的尊者三彌提對世尊說這個： |
|                                                              | 「大德！這裡，我在世尊的不遠處住於不放逸的、熱心的、自我努力的， |
| ‘世尊!我于独坐静观，作如是思念：                             | 大德！獨處的、獨坐的那個我這樣心的深思生起：                 |
| ‘我师乃应供者、正等觉者，我实得大利益!                       | 『確實是我的利得，確實是我的善得的：我的大師是阿羅漢、遍正覺者； |
| 我于善说之律与法出家，我实得大利益。                         | 確實是我的利得，確實是我的善得的：我在這麼善說的法律中出家； |
| 我同梵行者，诸善人之持戒者，我实得大利益。’                  | 確實是我的利得，確實是我的善得的：我的同梵行者們是持戒者、善法者。』 |
| 世尊![此时]于离我不远处，作大恐怖声，宛如大地破裂。’         | 大德！在那個我不遠處有大恐怖聲，以至於看起來像大地被打裂一樣。」 |
| ‘三弥提!此非大地之破裂，此乃恶魔波旬为求昏昧汝等眼目者。     | 「三彌提！那不是大地被打裂，那是魔波旬，為了使你盲目來的。   |
| 三弥提!汝于此行不放逸，虔诚、精进而住!’                      | 三彌提！去吧！你就那裡住於不放逸的、熱心的、自我努力的。」   |
| ‘唯然!世尊。’尊者三弥提奉答世尊，礼敬世尊右绕而去。          | 「是的，大德！」尊者三彌提回答世尊後，從座位起來、向世尊問訊、作右繞後，離開。 |
| 复次，尊者三弥提，不放逸、虔诚、精进而住。                   | 第二次，尊者三彌提就那裡住於不放逸的、熱心的、自我努力的。   |
| 复次，尊者三弥提于独坐静观、作如是思念：‘我师乃应供者、正等觉者……乃至……诸善人之持戒者，我实得大利益。’ | 第二次，尊者三彌提獨處、獨坐時……（中略）。                   |
| 复次，恶魔波旬知尊者心所思念……乃至……宛如大地破裂。           | 第二次，魔波旬以心了知尊者三彌提心中的深思後……（中略）以至於看起來像大地被打裂一樣。 |
| 时，尊者三弥提，如此乃恶魔波旬，以偈语恶魔波旬曰：           | 那時，尊者三彌提以偈頌對魔波旬說：                           |
| 1我依于信仰                                                  | 「我以信從在家，                                             |
| 2由家而出家                                                  | 出家成為無家者，                                             |
| 3正念与智慧 4于我眼目醒 5我心乃澄静                          | 任你作想要的諸形色，                                         |
| 6若随所意欲 7将为何状态 8令我无恐怖                          | 你都將不使我發抖。」                                         |
| 时，恶魔波旬苦恼以：‘三弥提比丘已知我。’萎身隐没于其处。     | 那時，魔波旬：「三彌提比丘知道我。」痛苦地、不快樂地就在那裡消失。 |
