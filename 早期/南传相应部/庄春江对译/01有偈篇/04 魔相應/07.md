| 第七 睡眠                                          | 7. 睡覺經                                                    |
|                                                    | 被我這麼聽聞：                                               |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                 | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 尔时，世尊，其当夜多作露地经行后，将晓，洗足入室。 | 那時，世尊在露天處經行[整夜]後，在破曉時洗腳後，進入住處，   |
| 盘腿起思惟于正念、正心时，而作师子卧。             | [左]腳放在[右]腳上、作意起來想後，具念正知地以右脅作獅子臥。 |
| 时，恶魔波旬来诣世尊前。诣已，以偈语世尊曰:        | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 1何故睡眠耶 2睡眠为何故                            | 「什麼！你睡覺、你為何睡覺呢？                               |
| 3今何如眠死                                        | 這是什麼-你如不幸者般睡覺？                                  |
| 4空舍为眠乎                                        | [想：]『屋舍是空的』你睡覺，                                 |
| 5日已高上升 6何以睡眠乎                            | 這是什麼-在太陽已上升時你睡覺？」                            |
| [世尊：]                                           |                                                              |
| 1破爱贪着网                                        | 「該者沒有欲纏、執著、渴愛，                                 |
| 2何处均无惑                                        | 能引導到任何地方，                                           |
| 4觉者于睡眠 3一切有依尽                            | 覺者以一切依著的遍滅盡睡覺，                                 |
| 5恶魔汝何为                                        | 魔！在這裡對你怎麼嗎？」                                     |
|                                                    | 那時，魔波旬……（中略）就在那裡消失。                         |
