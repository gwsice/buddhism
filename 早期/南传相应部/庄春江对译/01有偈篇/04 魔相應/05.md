| 第五 系蹄(其二)                                        | 5. 魔網經第二                                                |
| 尔时，世尊住波罗捺仙人堕处鹿野苑。                     | 有一次，世尊住在波羅奈仙人落下處的鹿林。                     |
| 于此世尊呼‘诸比丘!’                                    | 在那裡，世尊召喚比丘們：「比丘們！」                         |
| 彼等诸比丘：‘唯然!世尊!’以奉答世尊。                   | 「尊師！」那些比丘回答世尊。                                 |
| 世尊曰：                                               | 世尊說這個：                                                 |
| ‘诸比丘!我解脱天、人等所有之系蹄。                     | 「比丘們！我已從一切網解脫：凡諸天與凡人們，                 |
| 诸比丘!汝等亦解脱天、人等所有之系蹄。                  | 比丘們！你們也已從一切網解脫：凡諸天與凡人們。               |
| 诸比丘!为众人之利益、幸福以怜悯世间。                  | 比丘們！為了眾人的利益，為了眾人的安樂，為了世間的憐愍，     |
| 为人天之利益、幸福以游方!二人勿走一条路。              | 為了天-人們的需要、利益、安樂，請你們進行遊行，不要兩個同一地走。 |
| 诸比丘!说其初善、中善、终善之文与义之法。              | 比丘們！你們要教導開頭是善的、中間是善的、結尾是善的；有意義的、有文字的法， |
| 说一切圆满清净之梵行。                                 | 你們要說明完全圓滿、遍純淨的梵行，                           |
| 有众生生来不少尘垢，不闻法亦得令灭，彼等应是知解法者。 | 有少塵垢之類的眾生以法的未聽聞情況而退失，他們將會是法的了知者。 |
| 诸比丘!我亦为说法，而诣优留毗罗将军村。’               | 比丘們！我也為了法之教導將去優樓頻螺的謝那鎮。」             |
| 时，恶魔波旬诣世尊前。诣已，以偈言世尊曰：             | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 2恶魔系蹄缚                                            | 「你被魔網繫縛：                                             |
| 1汝为天与人                                            | 凡諸天與凡人們，                                             |
| 3汝缚恶魔绳                                            | 你被魔繫縛繫縛，                                             |
| 4沙门难逃我                                            | 沙門！你將不從我解脫。」                                     |
| [世尊：]                                               |                                                              |
| 2恶魔系蹄缚                                            | 「我已經由魔網解脫：                                         |
| 1我脱天与人                                            | 凡諸天與凡人們，                                             |
| 3我解恶魔缚                                            | 我是魔繫縛解脫者，                                           |
| 4破坏者汝败                                            | 死神！你被擊敗。」                                           |
|                                                        | 那時，魔波旬……（中略），就在那裡消失。                       |
