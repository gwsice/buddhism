| 第六 钵                                                   | 16. 鉢經                                                     |
| [尔时，世尊]住舍卫城……。                                  | 起源於舍衛城。                                               |
| 尔时，世尊以五取蕴为诸比丘说法、教示、奖励，令欢喜。      | 當時，世尊以關於五取蘊之法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘，理解、思惟、注心、倾耳，谛听于法。            | 而那些比丘作目標後、作意後、全心注意後傾耳聽法。             |
| 时，恶魔波旬作如是思惟：                                  | 那時，魔波旬想這個：                                         |
| ‘今沙门瞿昙，以五取蕴，为诸比丘说法、教示、奖励，令欢喜。 | 「這位沙門喬達摩以關於五取蘊之法說對比丘們開示、勸導、鼓勵、使歡喜， |
| 彼等诸比丘、理解，思惟、注心、倾耳，谛听于法。            | 而那些比丘作目標後、作意後、全心注意後傾耳聽法，             |
| 我宁可为昏昧彼等眼，以诣沙门瞿昙。’                       | 讓我為了使之盲目，去見沙門喬達摩。」                         |
| 尔时为[晾干]众多诸钵，而置于露地。                        | 當時，許多鉢被放置在屋外。                                   |
| 时，恶魔波旬化作牡牛之形，以近其钵。                      | 那時，魔波旬化作公牛的容色後，到那些鉢處。                   |
| 时，一比丘语于另一比丘曰：                                | 那時，某位比丘對另一位比丘說這個：                           |
| ‘比丘!比丘!此牡牛将破此钵!’                               | 「比丘！比丘！那隻公牛會打破眾鉢。」                         |
| 如是言时，世尊言此比丘曰：                                | 在這麼說時，世尊對那位比丘說這個：                           |
| ‘比丘!此非牡牛。此为昏昧汝等眼目之恶魔波旬。’             | 「比丘！那不是公牛，那是魔波旬，為了使你們盲目來的。」       |
| 时，世尊知是恶魔波旬，以偈告恶魔波旬曰：                  | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 1色受乃至想                                               | 「色、被感受的、想，                                         |
| 2识行等非我                                               | 識以及凡被行作的，                                           |
| 3亦非是我所                                               | 我不是這個、這不是我的，                                     |
| 4于此离贪着                                               | 這樣在這裡離染，                                             |
| 5离贪心平安                                               | 這樣離染者、得到安穩者，                                     |
| 6以超诸结缚                                               | 超越一切結者，                                               |
| 7何处求此人                                               | 在一切處探求的，                                             |
| 8魔军寻不得                                               | 魔軍也沒得到。」                                             |
| 恶魔波旬……乃至……隐形没于其处。                            | 那時，魔波旬……（中略）就在那裡消失。                         |
