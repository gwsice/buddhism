| 第四 系蹄(其一)                                      | 4. 魔網經第一                                                |
| ---------------------------------------------------- | ------------------------------------------------------------ |
| 如是我闻。                                           | 被我這麼聽聞：                                               |
| 尔时，世尊住波罗奈仙人堕处鹿野苑。                   | 有一次，世尊住在波羅奈仙人落下處的鹿林。                     |
| 于此，世尊呼诸比丘：‘诸比丘!’                        | 在那裡，世尊召喚比丘們：「比丘們！」                         |
| 彼等诸比丘亦奉答世尊：‘唯然，世尊!’                  | 「尊師！」那些比丘回答世尊。                                 |
| 世尊乃宣说：                                         | 世尊說這個：                                                 |
| ‘诸比丘!我依正思惟，我依正精进，实证到达无上解脱。   | 「比丘們！對我，以如理作意、如理正勤已到達無上解脫，已作證無上解脫， |
| 诸比丘!汝等亦依正思惟、正精进、亦实证到达无上解脱。’ | 比丘們！你們也應該以如理作意、如理正勤到達無上解脫，作證無上解脫。」 |
| 时，恶魔波旬，来诣世尊处。诣已，以偈言世尊曰：       | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 2恶魔系蹄缚                                          | 「你被魔網繫縛：                                             |
| 1汝为天与人                                          | 凡諸天與凡人們，                                             |
| 3汝缚恶魔绳                                          | 你被魔繫縛繫縛，                                             |
| 4沙门难逃我                                          | 沙門！你將不從我解脫。」                                     |
| [世尊：]                                             |                                                              |
| 2恶魔系蹄缚                                          | 「我已經由魔網解脫：                                         |
| 1我脱天与人                                          | 凡諸天與凡人們，                                             |
| 3我解恶魔缚                                          | 我是魔繫縛解脫者，                                           |
| 4破坏者汝败                                          | 死神！你被擊敗。」                                           |
| 时，恶魔波旬……乃至……形体没于其处。                   | 那時，魔波旬……（中略），就在那裡消失。                       |
