| 第三 恶魔品                                                  | 3.第三品                                                     |
| 第一 多数                                                    | 21.眾多經                                                    |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住释迦族之尸罗越底。                               | 有一次，世尊住在釋迦族的尸羅哇地。                           |
| 尔时，众多比丘住于世尊不远之处，不放逸、虔诚、精进。         | 當時，眾多比丘在世尊的不遠處住於不放逸的、熱心的、自我努力的。 |
| 时，恶魔波旬化作一老婆罗门相，结发，着羚羊背皮衣。背曲如垂木，咽喉呴呴响鸣，执郁昙钵罗树杖，来诣诸比丘处。诣已，谓诸比丘曰： | 那時，魔波旬化作婆羅門的容色後，以大的編織髮髻，穿羊皮衣的、年老的、像椽木那樣彎曲的，呼嚕呼嚕的呼吸的，持聚果榕樹枝的拐杖後去見那些比丘。抵達後，對那些比丘說這個： |
| ‘诸大德!盛壮发黑、其是青春为人生之第一期，未味爱欲而出家。   | 「尊師們！你們年輕出家，黑髮的青年，具備青春的幸福，在人生初期，不在欲中娛樂， |
| 诸大德!先享受人之爱欲!勿放弃现前以追隔时者。’                | 尊師們！你們要在人之欲中享受，不要捨棄直接可見的後追逐時間的。」 |
| ‘婆罗门!我等非放弃现前以追隔时者。                           | 「婆羅門！我們沒捨棄直接可見的後追逐時間的，                 |
| 婆罗门!我等乃放弃隔时者，以追遂现前者。                      | 婆羅門！但我們捨棄時間的後追逐直接可見的，                   |
| 婆罗门!爱欲 为隔时物，多苦，多恼，因祸亦越强烈，此法乃现前物而非隔时，世尊宣说：可谓来见者，即导向涅盘，识者应各所应知。’ | 婆羅門！因為欲被世尊說是時間的、多苦的、多絕望的，在這裡有更多的過患。這個法是直接可見的、即時的、請你來看的、能引導的、應該被智者各自經驗的。」 |
| 如是言已。恶魔波旬乃垂头卷舌，现三皱于额头，抱杖而去。       | 在這麼說時，魔波旬搖頭、吐舌、額頭上[蹙出]三條溝使不愉快的神情出現、拄著拐杖後離開。 |
| 时，彼等诸比丘诣世尊处。诣已，礼敬世尊，坐于一面：一面生已之彼等诸比丘，以此白世尊： | 那時，那些比丘去見世尊。抵達後，向世尊問訊後，在一旁坐下。在一旁坐下的那些比丘對世尊說這個： |
| ‘世尊!于此我等住离世尊不远，不放逸、虔诚、精进。             | 「大德！這裡，我們在世尊的不遠處住於不放逸的、熱心的、自我努力的， |
| 时，世尊!有一老婆罗门，结发着羚羊背皮衣，背曲如垂木，咽喉之呼吸，呴呴响鸣，执郁昙钵罗树杖，诣我等住处。 | 大德！那時，有某位婆羅門以大的編織髮髻，穿羊皮衣的、年老的、像椽木那樣彎曲的，呼嚕呼嚕的呼吸的，持聚果榕樹枝的拐杖後來見我們。 |
| 诣已，以此白我等曰：‘诸大德!盛壮发黑，具足青春，为人生第一期，末味爱欲而出家。 | 抵達後，對我們說這個：『尊師們！你們年輕出家，黑髮的青年，具備青春的幸福，在人生初期，不在欲中娛樂， |
| 诸大德!先享受人之爱欲!勿弃现前以追隔时物。’                  | 尊師們！你們要在人之欲中享受，不要捨棄直接可見的後追逐時間的。』 |
| 世尊，作如是言已。我等即谓婆罗门：                           | 大德！在這麼說時，我們對那位婆羅門說這個：                   |
| ‘婆罗门!我等非弃现前以追隔时。                               | 『婆羅門！我們沒捨棄直接可見的後追逐時間的，                 |
| 婆罗门!我等乃放弃隔时以追现前。                              | 婆羅門！但我們捨棄時間的後追逐直接可見的，                   |
| 婆罗门!爱欲是隔时物，多苦、多恼，因祸亦越强烈，此法于现前，非隔时。世尊宣说，可谓来见者，即导向涅盘，识者应各所应知。’ | 婆羅門！因為欲被世尊說是時間的、多苦的、多絕望的，在這裡有更多的過患。這個法是直接可見的、即時的、請你來看的、能引導的、應該被智者各自經驗的。』 |
| 世尊!作如是言已。彼婆罗门即垂头卷舌，现三皱于额头，抱杖而去。’ | 大德！在這麼說時，那位婆羅門搖頭後，使舌頭上下動後，使額頭上出現三條皺眉後，拄著拐杖後離開。」 |
| ‘诸比丘!此非婆罗门。此乃恶魔波旬，为来昏昧汝等之眼目。’      | 「比丘們！那位不是婆羅門，那位是魔波旬，為了使你們盲目來的。」 |
| 时，世尊了知此义，是时即唱此偈曰：                           | 那時，世尊知道這件事後，那時候說這偈頌：                     |
| 1若人见苦因                                                  | 「凡從此因由看到苦，                                         |
| 2如何倾爱欲                                                  | 那個人如何會彎向諸欲？                                       |
| 3知依世结缚                                                  | 知道依著是世間中的『染著』後，                               |
| 4人应学解此                                                  | 人就應該為了它的調伏學習。」                                 |
