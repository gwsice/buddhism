| 第九 寿命(其一)                                              | 9. 壽命經第一                                                |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 于此，世尊呼诸比丘：‘诸比丘!’                                | 在那裡，世尊召喚比丘們：「比丘們！」                         |
| 彼诸比丘以‘唯然!世尊!’奉答世尊。                             | 「尊師！」那些比丘回答世尊。                                 |
| 世尊曰：                                                     | 世尊說這個：                                                 |
| ‘诸比丘!此人寿命短，不可不行于未来，不可不为善，不可不行梵行，生者无不死。 | 「比丘們！人的這壽命是短的，來世必將被走到，善的應該被作、梵行應該被實行。生者無不死， |
| 诸比丘!则长寿者，亦少多于百岁!’                              | 比丘們！凡活得長者，他有百年加減(少或更多)。」               |
| 时，恶魔波旬，诣世尊前。诣已，以偈白世尊曰：                 | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 1人寿实甚长                                                  | 「人的壽命是長的，                                           |
| 2善人莫轻此                                                  | 善人不應該輕蔑它，                                           |
| 3如饱乳赤子                                                  | 應該如陶醉於乳的(嬰兒)般過生活，                             |
| 4死即岂不来                                                  | 沒有死亡的到來。」                                           |
| [世尊：]                                                     |                                                              |
| 1人寿实甚短                                                  | 「人的壽命是短的，                                           |
| 2善人应轻此                                                  | 善人應該輕蔑它，                                             |
| 3如人遇燃发                                                  | 應該如頭已燃燒般過生活，                                     |
| 4死者岂不来                                                  | 沒有死亡的不到來。」                                         |
| 时，恶魔波旬……乃至……没于其处。                               | 那時，魔波旬……（中略）就在那裡消失。                         |
