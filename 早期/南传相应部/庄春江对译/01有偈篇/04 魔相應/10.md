| 第十 寿命(其二)                                              | 10. 壽命經第二                                               |
|                                                              | 被我這麼聽聞：                                               |
| [尔时，世尊]住王舍城……                                       | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 时，世尊曰：                                                 | 在那裡，世尊……（中略）說這個：                               |
| ‘诸比丘!人类寿命短。不可不行未来，不可不为善，不可不行梵行，生者无不死。 | 「比丘們！人的這壽命是短的，來世必將被走到，善的應該被作、梵行應該被實行。生者無不死， |
| 诸比丘!则长寿者，亦少多于百岁。                              | 比丘們！凡活得長者，他有百年加減(少或更多)。」               |
| 时，恶魔波旬来，诣世尊前。诣已，以偈白世尊曰：               | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 1日夜犹未逝                                                  | 「日夜不流逝，                                               |
| 2寿命亦未尽                                                  | 生命不被破壞，                                               |
| 4人命亦轮逝                                                  | 不免一死的人壽命繞著走，                                     |
| 3如轮轴回转                                                  | 如車輪對車桿。」                                             |
| [世尊：]                                                     |                                                              |
| 1日夜之过逝                                                  | 「日夜流逝，                                                 |
| 2寿命亦将尽                                                  | 生命被破壞，                                                 |
| 4人寿命亦灭                                                  | 不免一死的人壽命被耗盡，                                     |
| 3如小河水竭                                                  | 如小河的水。」                                               |
| 时，恶魔波旬苦恼以：‘世尊已知我!善逝已知我。’而萎身隐没于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
