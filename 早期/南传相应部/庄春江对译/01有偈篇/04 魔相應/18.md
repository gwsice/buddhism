| 第八 团食                                                    | 18. 團食經                                                   |
| 尔时，世尊住摩揭陀国，名五苇村之婆罗门村。                   | 有一次，世尊住在摩揭陀國五沙羅樹[地方]的婆羅門村落。         |
| 其时，五苇婆罗门村，青年男女等，举行互换礼物式典。           | 當時，五沙羅樹的婆羅門村落有少女饗宴客人節。                 |
| 时，世尊清晨，持钵，着衣入五苇婆罗门村乞食。                 | 那時，世尊午前時穿衣、拿起衣鉢後，為了托鉢進入五沙羅樹的婆羅門村落。 |
| 时，五苇村婆罗门家主等，为恶魔波旬所执取：‘沙门瞿昙不予得食。’ | 當時，五沙羅樹的婆羅門屋主們已被魔波旬所佔有：「不要沙門喬達摩得到團食。」 |
| 时，世尊入(村)乞食时，清洗其钵而归。                         | 那時，世尊以像洗淨了的鉢，如以洗淨了的鉢為了托鉢進入五沙羅樹的婆羅門村落一樣返回。 |
| 时，恶魔波旬来诣世尊处。诣已，白世尊曰：‘沙门!得食耶?不得耶?’ | 那時，魔波旬去見世尊。抵達後，對世尊說這個：「沙門！是否你得到團食？」 |
| ‘如我之不得食，岂非汝波旬之所为?’                            | 「波旬！你像那樣作，依之我不能得到團食嗎？」                 |
| ‘然则!世尊!再入五苇婆罗门村，如得食，应是我为!’              | 「大德！那樣的話，請世尊第二次又為了托鉢進入五沙羅樹的婆羅門村落，我將像那樣作，依之世尊得到團食。」 |
| 2恶魔生不德                                                  | 「魔產出非福的：                                             |
| 1侵犯于如来                                                  | 攻擊那位如來後，                                             |
| 4汝如何思惟                                                  | 波旬！你認為：                                               |
| 3波旬恶不实                                                  | 我的惡不結果實嗎？                                           |
| 6我等亦乐住                                                  | 我們確實極安樂地生活：                                       |
| 5即无有所得                                                  | 凡我們沒有任何東西，                                         |
| 8我等喜为食                                                  | 我們將是以喜為食者，                                         |
| 7犹如光音天                                                  | 如光音天神們。」                                             |
| 时恶魔波旬……乃至……隐形没于其处。                             | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
