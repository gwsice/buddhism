| 第三 净                                                | 3. 清淨經                                                    |
|                                                        | 被我這麼聽聞：                                               |
| [尔时，世尊]住优留毗罗林……                             | 有一次，初現正覺的世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹處。 |
| 尔时，世尊阇夜坐于露地，雨丝霏霏下降。                 | 當時，世尊在漆黑的夜晚坐在露天處，而天空下著毛毛雨。         |
| 时，恶魔波旬欲令世尊生起恐怖，毛发竖立，来诣世尊坐处。 | 那時，魔波旬想要使世尊生出害怕、僵硬狀態、身毛豎立的而去見世尊。 |
| 诣已，于世尊之近处，以显或高或下之种种净、不净形相。   | 抵達後，在世尊的不遠處顯示各種不同輝耀的容色：清淨的與不清淨的。 |
| 时，世尊知是恶魔波旬，以偈言恶魔波旬曰：               | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 2汝之轮回长                                            | 「長時間輪迴者：                                             |
| 1作净不净相                                            | 做純淨不純淨的容色後，                                       |
| 3波旬汝可去                                            | 波旬！夠了！以你的那個，                                     |
| 4破坏者汝败                                            | 死神！你被擊敗。                                             |
| 5依身语及意                                            | 凡以身與語，                                                 |
| 6人人善调魔                                            | 以及以意善自制者們，                                         |
| 7无行恶魔配                                            | 他們不是隨順魔控制者，                                       |
| 8非恶魔弟子                                            | 他們不是魔的隨從。」                                         |
| 时，恶魔波旬……乃至……苦恼萎身于其处。                   | 那時，魔……（中略）就在那裡消失。                             |
