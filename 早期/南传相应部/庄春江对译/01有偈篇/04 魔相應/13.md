| 第三 岩石之破片                                              | 13. 碎石片經                                                 |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时世尊住王舍城摩达屈阇之鹿野苑。                           | 有一次，世尊住在王舍城嘛瘩姑七的鹿林。                       |
| 尔时，世尊其足被石片所伤。世尊足痛、锐、烈，苦痛不快。       | 當時，世尊的腳被碎石片所傷，世尊的強烈感受轉起：苦的、激烈的、猛烈的、強烈的、不愉快的、不合意的身體的[感受]。 |
| 世尊正念正心，以克服、忍耐。                                 | 世尊具念地、正知地忍受那些，不被惱害著。                     |
|                                                              | 那時，世尊摺大衣成四折後，[左]腳放在[右]腳上後，具念正知地以右脅作獅子臥。 |
| 时，恶魔波旬来诣世尊处。诣已，以偈言世尊曰．                 | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 1懒惰于寝眠 2耽着作诗耶                                      | 「你以懶惰躺臥或者陶醉在詩中的嗎？                           |
| 3汝为事不多                                                  | 你的極多目標不存在嗎？                                       |
| 4独自离市里                                                  | 獨自在遠離的臥坐處，                                         |
| 5住何寝意卧                                                  | 為何你就這張睡臉睡覺？」                                     |
| [世尊：]                                                     |                                                              |
| 1非依懒惰卧 2亦非作诗卧                                      | 「我非以懶惰躺臥也非陶醉在詩中的，                           |
| 3离愁我事了                                                  | 達到目標後我已離愁，                                         |
| 4独自离市里                                                  | 獨自在遠離的臥坐處，                                         |
| 5我哀怜一切 6有情以为卧                                      | 我對一切生類有憐愍地躺臥。                                   |
| 7以箭贯串胸                                                  | 即使刺箭已進入他們的胸中，                                   |
| 8心脏逆猛烈                                                  | 心臓急速顫動地，                                             |
| 9受伤亦在眠                                                  | 這裡即使那些被箭射到者也得到睡眠，                           |
| 10我为无伤者 11何故不成眠                                    | 已離刺箭的我{因此}[為何?]不應該睡？                          |
| 12觉之无踌躇 13眼之无恐怖                                    | 清醒的我不擔心、我也不害怕睡覺，                             |
| 14日夜无悔苦                                                 | 白天夜晚對我都不苦惱，                                       |
| 15不见逆世间                                                 | 我不見[自己]在世間任何地方減損，                             |
| 16怜诸有情卧                                                 | 憐愍一切生類因此我會睡覺。」                                 |
| 时，恶魔波旬苦恼以：‘世尊已知我，善逝已知我。’而萎身隐形没于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
