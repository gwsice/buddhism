| 第六 蛇                                                      | 6. 蛇經                                                      |
| 如是我闻。                                                   |                                                              |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 尔时，世尊，闇夜中坐于露地，雨丝霏霏下降。                   | 當時，世尊在漆黑的夜晚坐在露天處，而天空下著毛毛雨。         |
| 时，恶魔波旬欲使世尊生起恐怖，毛发竖立，化作大蛇王相。来诣世尊前。 | 那時，魔波旬想要使世尊生出害怕、僵硬狀態、身毛豎立的，化作大蛇王的容色後去見世尊， |
| 其躯体大如木舟，其头如酒屋之箕，其两眼如拘萨罗国之铜钵，其口如雷鸣，出电光。吐舌，其呼吸声如铁工之火具音。 | 身體猶如一整棵樹的大船一樣，頸部猶如酒屋的大墊一樣，眼睛猶如憍薩羅國的大銅鉢一樣，嘴巴伸出舌頭猶如空中打雷時出現的閃電一樣，呼吸聲猶如鐵匠吹火時的咕嚕咕嚕聲一樣。 |
| 时，世尊知是恶魔波旬，以偈语恶魔波旬曰：                     | 那時，世尊知道：「這位是魔波旬。」後，以偈頌對魔波旬說：     |
| 1空舍自制御                                                  | 「凡為了睡眠使用諸空屋，                                     |
| 2胜哉彼牟尼                                                  | 那位自我抑制的牟尼，                                         |
| 3于此行放弃                                                  | 捨棄後他應該在那裡過生活(行)，                               |
| 4如是相应彼                                                  | 對像那種的他確實是適當的。                                   |
| 5野兽之往来                                                  | 許多行走的、許多可怕的，                                     |
| 6蚊虻毒蛇多                                                  | 還有許多虻、蛇，                                             |
| 9无有损一毛                                                  | 在那裡一根毛也不會動搖：                                     |
| 8大圣行空舍                                                  | 來到空屋的大牟尼。                                           |
| 10虚空裂地震                                                 | 即使天空破裂大地搖動，                                       |
| 7充满诸恐怖 11生者皆恐吓                                     | 或者即使一切生物類都驚怖，                                   |
| 13投掷利猛枪 12纵向于胸位                                    | 即使刺箭被他們安排在胸部，                                   |
| 14诸佛不被护                                                 | 覺者們也不在諸依著處求(作)救護所。」                         |
| 时，恶魔波旬：‘世尊已知我，善逝已知我。’即形体没其处。       | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
