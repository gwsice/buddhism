| 第二 狮子                                                    | 12. 為何獅子經                                               |
| 尔时，世尊住舍卫城只树给孤独园。                             | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 其时，世尊为大会众所围绕而说法。                             | 當時，世尊被大眾圍繞，教導法。                               |
| 时，恶魔波旬作如是思惟：                                     | 那時，魔波旬想這個：                                         |
| ‘此沙门瞿昙，为大会众所围绕而说法、                          | 「這位沙門喬達摩被大眾圍繞，教導法，                         |
| 我宁可昏昧诸人眼目，以往诣沙门瞿昙。’                        | 讓我為了使之盲目去見沙門喬達摩。」                           |
| 时，恶魔波旬诣世尊处。                                       | 那時，魔波旬去見世尊。                                       |
| 诣已，以偈言世尊曰：                                         | 抵達後，以偈頌對世尊說：                                     |
| 1任何大众前                                                  | 「你為何在群眾中，                                           |
| 2敢如是无畏 3作师子吼耶                                      | 如獅子般自信地吼？                                           |
| 4此处角力士 5乃汝之敌手                                      | 因為有你的對手，                                             |
| 6既胜汝曾思                                                  | 你認為是勝者嗎？」                                           |
| [世尊:]                                                      |                                                              |
| 1大雄众会前                                                  | 「大英雄們確實在群眾中，                                     |
| 2欢善依无畏                                                  | 自信地吼，                                                   |
| 3如来得十力                                                  | 如來們已得到力量，                                           |
| 4超离世爱着                                                  | 已度脫世間中的執著。」                                       |
| 时，恶魔波旬苦恼以：‘世尊已知我。善逝已知我。’萎身没形于其处。 | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
