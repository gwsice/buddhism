| 第四 非相应                                                  | 14. 適當經                                                   |
| 尔时，世尊住拘萨罗国，名一苇村之婆罗门村。                   | 有一次，世尊住在憍薩羅國一沙羅樹[地方]的婆羅門村落。         |
| 尔时，世尊受在家大众所围绕而说法。                           | 當時，世尊被在家大眾圍繞，教導法。                           |
| 时，恶魔波旬作如是思惟：                                     | 那時，魔波旬想這個：                                         |
| ‘今沙门瞿昙受在家大众所围绕而说法，我宁可昏昧诸人眼目，以诣沙门瞿昙。’ | 「這位沙門喬達摩被在家大眾圍繞，教導法，讓我為了使之盲目去見沙門喬達摩。」 |
| 时，恶魔波旬诣世尊处。诣已，以偈言世尊曰：                   | 那時，魔波旬去見世尊。抵達後，以偈頌對世尊說：               |
| 2于汝不相应                                                  | 「這不適合你：                                               |
| 1所谓以教他                                                  | 凡你教誡其他人，                                             |
| 4勿为贪嗔缚                                                  | 在諸順從與排斥上，                                           |
| 3若为行此者                                                  | 行那個的你不要被黏著。」                                     |
| [世尊：]                                                     |                                                              |
| 1依利益哀怜                                                  | 「為利益憐愍者、正覺者，                                     |
| 2正觉者教他                                                  | 凡他教誡其他人，                                             |
| 4如是贪嗔者                                                  | 在諸順從與排斥上，                                           |
| 3如来实解脱                                                  | 如來已脫離。」                                               |
| 时，恶魔波旬……乃至……隐形没于其处。                           | 那時，魔波旬：「世尊知道我，善逝知道我。」痛苦地、不快樂地就在那裡消失。 |
