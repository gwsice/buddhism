| 第三 阎陀迦频陀                                              | 13.案達葛衛達經                                              |
| 尔时，世尊住摩揭陀国之闇陀频陀。                             | 有一次，世尊住在摩揭陀國的案達葛衛達。                       |
| 尔时，世尊于夜闇中坐于露地，天降雨。                         | 當時，世尊在漆黑的夜晚坐在露天處，而天空下著毛毛雨。         |
| 时，梵天沙巷婆提于黎明时，辉耀全闇陀迦频陀，以诣世尊处。     | 那時，容色絕佳的梵王娑婆主使整個案達葛衛達發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。立于一面之梵天沙巷婆提，于世尊处，唱此偈曰： | 抵達後，向世尊問訊後，在一旁站立。在一旁站立的梵王娑婆主在世尊的面前說這偈頌： |
| 1住于离市里                                                  | 「應該親近邊地臥坐處：                                       |
| 2游方犹离缚                                                  | 以結的解脫應該行，                                           |
| 3若有心不乐                                                  | 如果在那裡到達到喜樂，                                       |
| 4应护于诸根 5正念住僧伽                                      | 應該自我守護、有念地住在僧團中。                             |
| 6家家行乞时                                                  | 為了托鉢從家至家行走者：                                     |
| 7护根谨正念                                                  | 根已守護地、明智地、有念地，                                 |
| 8住于离市里                                                  | 應該親近邊地臥坐處，                                         |
| 9无惧得解脱                                                  | 從害怕脫離者、在不害怕上解脫者。                             |
| 10回忆惧毒蛇                                                 | 於該處有可怕的蛇，                                           |
| 11电光鸣天雷                                                 | 閃電往來、天空打雷，                                         |
| 12于夜闇比丘                                                 | 在黑暗的黑夜裡，                                             |
| 13独坐离恐怖                                                 | 已離身毛豎立的比丘坐在那裡。                                 |
| 14我眼实当见                                                 | 這確實被我看見，                                             |
| 15非是传所闻                                                 | 這不是傳聞，                                                 |
| 16在于一法教                                                 | 在單一[生]梵行中，                                           |
| 17以脱千人死                                                 | 有一千位死亡的捨棄者。                                       |
| 18有当五百多                                                 | 五百餘位有學，                                               |
| 19于百之十培 20于其十培数                                    | 以及十的十倍的十倍，                                         |
| 21皆悉入预流                                                 | 全部是進入流者，                                             |
| 22超畜生趣者                                                 | 非去畜生者。                                                 |
| 23此外之诸人                                                 | 而這其他人，                                                 |
| 24对于得功德                                                 | 是我心(意)中的『福分者』，                                   |
| 25我心难堪数                                                 | 我甚至不能夠計算：                                           |
| 26恐人云妄语                                                 | 對妄語的愧。                                                 |
