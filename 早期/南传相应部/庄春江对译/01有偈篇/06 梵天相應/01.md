| 第六 梵天相应                                                | 6.梵天相應                                                   |
| 第一 梵天品                                                  | 1.第一品                                                     |
| 第一 劝请                                                    | 1. 梵天勸請經                                                |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住优留毗罗尼连禅河边之阿阇波罗尼俱律陀树下。时，已成等正觉。 | 有一次，初現正覺的世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹處。 |
| 时，世尊独坐禅思，而起此思惟。                               | 那時，獨處、獨坐的世尊這樣心的深思生起：                     |
| 依我所证得此法，甚深难见、难悟。寂静微妙，超越思念之领域。深妙唯贤者始知。 | 「被我到達(證得)的這個法是甚深的、難見的、難隨覺的、寂靜的、勝妙的、超越推論的、微妙的、被賢智者體驗的。 |
| 又，此诸人等乐阿赖耶，喜阿赖耶，跳跃阿赖耶。                 | 然而，這世代是樂於阿賴耶的、好於阿賴耶的、喜於阿賴耶的。     |
| 诸人依于乐阿赖耶，喜阿赖耶，跳跃阿赖耶，而难见此理。此理者，即所谓依缘、缘起是。 | 又，對樂於阿賴耶的、好於阿賴耶的、喜於阿賴耶的世代，此處是難見的，即：特定條件性、緣起； |
| 此理亦难见。此理者，即一切行之止静，一切依之舍离、爱尽、离、灭、涅盘是。 | 此處也是難見的，即：一切行的止、一切依著的斷念、渴愛的滅盡、離貪、滅、涅槃。 |
| 我若说法，诸人难了解我所说者，我是应所疲劳而烦扰。           | 那樣的話，如果我教導法，對方不能了解我，那對我是疲勞，那對我是傷害。」 |
| 又，此以前未曾有闻之偈，世尊显示：                           | 於是，這些在以前前所未聞的，不可思議的偈頌在世尊心中出現：   |
| 1艰难我所证                                                  | 「被我困難到達，                                             |
| 2今此实难说                                                  | 現在沒必要說明，                                             |
| 3败于欲嗔者                                                  | 以被貪瞋征服者們，                                           |
| 4难得悟此法                                                  | 這個法是不容易正覺的。                                       |
| 5逆世之常流                                                  | 對逆流行走的、微妙的，                                       |
| 6微妙而甚深 7微细极难见                                      | 對甚深的、難見的、精細的，                                   |
| 8贪欲之所污                                                  | 被貪染著者們沒看見：                                         |
| 9闇蕴所蔽者 10不得见此法                                     | 被大黑暗覆蓋者們。」                                         |
| 世尊作如是思惟，即踌躇不说法。                               | 在這裡，當世尊像這樣深慮時，心傾向不活動、無法的教導。       |
|                                                              | 那時，梵王娑婆主以心了知世尊心中的深思後，想這個：           |
|                                                              | 「唉！先生！世界滅亡，唉！先生！世界消失，確實是因為世尊、阿羅漢、遍正覺者的心傾向不活動，無法的教導。」 |
| 时，梵天沙巷婆提，犹如有力者之伸屈腕，或屈伸腕顷，如是没于梵天界，现于世尊之前。 | 那時，梵王娑婆主就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在梵天世界消失，出現在世尊的面前。 |
| 时，梵天沙巷婆提偏袒一肩、右膝着地，合掌礼敬，如是白世尊曰： | 那時，梵王娑婆主置(作)上衣到一邊肩膀、右膝蓋觸地、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!请说法!善逝!请说法![世间]有不少众生，为眼尘所蔽。彼等不得闻法而衰退。[世间]应有法之了解者。’ | 「大德！請世尊教導法！請善逝教導法！有少塵垢之類的眾生以法的未聽聞情況而退失，他們將會是法的了知者。」 |
| 梵天沙巷婆提白此言已，更唱此言：                             | 梵王娑婆主說這個，說這個後，他又更進一步說這個：             |
| 1于摩揭陀国                                                  | 「從前在摩揭陀出現，                                         |
| 3依此心思惟 2不净法垢秽                                      | 被諸有垢者構思的不純淨法，                                   |
| 4开此甘露门                                                  | 請你打開這不死之門，                                         |
| 5依无垢之心 6今闻悟此法                                      | 令他們聽聞被離垢者隨覺之法。                                 |
| 7上立山顶岩                                                  | 如在山頂岩石上站立者，                                       |
| 8如见周诸众                                                  | 如是都會看見各處的人群，                                     |
| 9贤者全眼者                                                  | 極聰明者！像這樣的譬喻，                                     |
| 11立法城宫楼                                                 | 一切眼者！登上法所成的高樓後，                               |
| 10卿起慈悲心 12以观沉悲惨                                    | 離憂愁者對陷入憂愁的人們，                                   |
| 13生老败诸众                                                 | 請你向下注視被生老征服者。                                   |
| 14请起立英雄 15战立胜利者                                    | 英雄！戰場勝利者！請你起來，                                 |
| 16无债商队主                                                 | 商隊領袖！無負債者！                                         |
| 17请游此世间                                                 | 請你在世間走動，                                             |
| 18请世尊说法                                                 | 世尊！請你教導法，                                           |
| 19必有知解者                                                 | 將會有了知者們。」                                           |
| 时，世尊知梵天之劝请，对众生起哀怜，以佛眼观世间。           | 那時，世尊知道梵天的勸請後，緣於對眾生的悲愍，以佛眼檢視世間。 |
| 世尊依佛眼观世间，见众生眼有蔽多、蔽少，有利根者、钝根者，有善相者、恶相者，有易教者、难教者，其中或有众人见来世罪之怖畏而住。 | 當世尊以佛眼檢視世間時，看見少塵垢的、多塵垢的；利根的、鈍根的；善行相的、惡行相的；易受教的、難受教的；一些住於看見在其他世界的罪過與恐怖的、另一些不住於看見在其他世界的罪過與恐怖的眾生， |
| 犹如于莲池之青莲华、黄莲华、白莲华。有青莲华、黄莲华、白莲华、生于水中、长于水中、不出水面，沈育于水中。 | 就猶如在青蓮池、紅蓮池、白蓮池中，一些青蓮、紅蓮、白蓮被生於水中，被長於水中，不被上升水中，被沈在內部養育的； |
|                                                              | 一些青蓮、紅蓮、白蓮被生於水中，被長於水中，與水面同高而住立； |
| 有青莲华、黄莲华、白莲华，生于水中、长于水中，出立于水，不为水所湿。 | 一些青蓮、紅蓮、白蓮被生於水中，被長於水中，從水中上升後住立，不被水污染。 |
| 如是世尊，依眼观世间，见众生眼有蔽多、蔽少，有利根者、钝根者，有善相者、恶相者，有易教者、难教者， | 同樣的，當世尊以佛眼檢視世間時，看見少塵垢的、多塵垢的；利根的、鈍根的；善行相的、惡行相的；易受教的、難受教的； |
| 其中或有诸众见来世罪之怖畏而住。                             | 一些住於看見在其他世界的罪過與恐怖的、另一些不住於看見在其他世界的罪過與恐怖的眾生。 |
| 见已，以偈答梵天沙巷婆提：                                   | 看見後，以偈頌回答梵王娑婆主：                               |
| 2开启甘露门                                                  | 「不死之門已為他們打開：                                     |
| 3有耳之众人 4舍离其他信                                      | 讓凡有耳者們脫離[邪]信，                                     |
| 1为于彼等众                                                  | 對諸惱害想的熟知者，                                         |
| 5梵天我思惑 6不说微妙法                                      | 梵天！我不在人間說勝妙法。」                                 |
| 时，梵天沙巷婆提，愿我说法，世尊许允，而礼敬世尊，右绕，于此没其身形。 | 那時，梵王娑婆主[心想]：「對法的教導，我已被世尊允許。」向世尊問訊、作右繞後，就在那裡消失。 |
