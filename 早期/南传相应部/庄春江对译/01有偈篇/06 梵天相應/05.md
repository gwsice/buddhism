| 第五 他见                                                    | 5.某位梵天經                                                 |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 其时，有梵天生如是恶见。                                     | 當時，某位梵天有這樣邪惡的惡見生起：                         |
| ‘无有可来此之沙门、婆罗门。’                                 | 「沒有那種沙門或婆羅門能到這裡的。」                         |
| 时，世尊知彼梵天之所念，犹如力士，伸屈腕、屈伸腕，没形于只园，现身于梵天界。 | 那時，世尊以心了知那位梵天心中的深思後，猶如有力氣的男子……（中略）出現在那梵天世界中。 |
| 时，世尊趺坐于此梵天头上之虚空，入于火定。                   | 那時，世尊以盤腿坐在那位梵天的上方虛空：入火界定後。         |
| 时，尊者大目犍连生如是思惟：‘今世尊在何处耶?’                | 那時，尊者大目揵連想這個：「世尊現在住於何處呢？」           |
| 大目犍连依超人清净之天眼，见世尊趺坐于梵天头上之虚空，入于火定。 | 尊者大目揵連以清淨、超越常人的天眼看見以盤腿坐在那位梵天的上方虛空，入火界定的世尊。 |
| 见已，如力士之伸屈腕、屈伸腕，没形于只园，现身于梵天界。     | 看見後，就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在祇樹林消失，出現在那個梵天世界中。 |
| 时，尊者大目犍连，从东方低于世尊在梵天头上之虚空趺坐，入于火定。 | 那時，尊者大目揵連依止東方後以盤腿坐在那位梵天的上方虛空，較世尊低：入火界定後。 |
| 时，尊者大迦叶生如是思惟：‘世尊今住何处耶?’                  | 那時，尊者大迦葉想這個：「世尊現在住於何處呢？」             |
| 尊者大迦叶依超人清净之天眼，见世尊趺坐于梵天头上之虚空，入于火定。 | 尊者大迦葉以清淨、超越常人的天眼看見……（中略）。             |
| 见已，犹如力士之伸屈腕、屈伸腕，没形于只园，现身于梵天界。   | 看見後，猶如有力氣的男子……（中略）就像這樣在祇樹林消失，出現在那個梵天世界中。 |
| 如是尊者大迦叶，从南方低于世尊，于梵天头上之虚空趺坐，入于火定。 | 那時，尊者大迦葉依止南方後以盤腿坐在那位梵天的上方虛空，較世尊低：入火界定後。 |
| 时，尊者大劫宾那，坐如是思惟：‘世尊今住何处耶?’              | 那時，尊者大劫賓那想這個：「世尊現在住於何處呢？」           |
| 尊者大劫宾那……[乃至]……                                       | 尊者大劫賓那以清淨、超越常人的天眼看見……（中略）入火界定的世尊。 |
|                                                              | 看見後，猶如有力氣的男子……（中略）就像這樣在祇樹林消失，出現在那個梵天世界中。 |
| 如是尊者大劫宾那，从西方低于世尊，于梵天头上之虚空趺坐，入于火定。 | 那時，尊者大劫賓那依止西方後以盤腿坐在那位梵天的上方虛空，較世尊低：入火界定後。 |
| 时，尊者阿那律……[乃至]……                                     | 那時，尊者阿那律想這個：「世尊現在住於何處呢？」             |
|                                                              | 尊者阿那律以清淨、超越常人的天眼看見……（中略）入火界定的世尊。 |
|                                                              | 看見後，猶如有力氣的男子……（中略）就像這樣在祇樹林消失，出現在那個梵天世界中。 |
| 如是尊者阿那律从北方低于世尊，于梵天头上之虚空趺坐，入于火定。 | 那時，尊者阿那律依止北方後以盤腿坐在那位梵天的上方虛空，較世尊低：入火界定後。 |
| 时，尊者大目犍连，以偈语梵天曰：                             | 那時，尊者大目揵連以偈頌對那位梵天說：                       |
| 1友汝今亦犹                                                  | 「朋友！現在你還有那個見，                                   |
| 2前之所持见                                                  | 你之前有該見：                                               |
| 4见其明光耶                                                  | 你看見輝耀，                                                 |
| 3胜梵界之光                                                  | 在梵天世界上超越的。」                                       |
| [梵天：]                                                     |                                                              |
| 1友我于今日                                                  | 「親愛的先生！我沒有那個見，                                 |
| 2尝不持是见                                                  | 我之前有該見：                                               |
| 4以见其明光                                                  | 我看見輝耀，                                                 |
| 3胜梵界之光                                                  | 在梵天世界上超越的，                                         |
| 5如何我今日                                                  | 現在那個我如何會說：                                         |
| 6得云常住恒                                                  | 我是常的、常恆的？」                                         |
| 如是，世尊为令梵天界之惊异，犹如力士之伸屈腕、屈伸腕，没形于梵天界，现身于只园。 | 那時，世尊激起那位梵天的急迫感後，就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在那個梵天世界消失，出現在祇樹林中。 |
| 时，有梵天呼其他梵众天：                                     | 那時，那位梵天召喚某位梵天眾：                               |
| ‘友!来!汝诣尊者大目犍连。如是语尊者大目犍连：                | 「來！親愛的先生！你去見尊者大目揵連。抵達後，請對尊者大目揵連說這個： |
| ‘友!目犍连!世尊之弟子中，其他有如目犍连、迦叶、劫宾那、阿那律之大神通、大威力耶?’ | 『親愛的目揵連尊師！還有其他那位世尊的弟子這麼大神通力、這麼大威力猶如尊師目揵連、迦葉、劫賓那、阿那律嗎？』」 |
| ‘友!唯然!’其梵众天答覆梵天，而诣尊者大目犍连处。诣已，以此语大目犍连曰： | 「是的，親愛的先生！」那位梵天眾回答那位梵天後，去見尊者目揵連。抵達後，對尊者目揵連說這個： |
| ‘友目犍连!世尊之弟子中，其他有如目犍连、迦叶、劫宾那、阿那律之大神通、大威力耶?’ | 「親愛的目揵連尊師！還有其他那位世尊的弟子這麼大神通力、這麼大威力猶如尊師目揵連、迦葉、劫賓那、阿那律嗎？」 |
| 时，尊者大目犍连，以偈语梵天众曰：                           | 那時，尊者目揵連以偈頌對那位梵天眾說：                       |
| 1三明达神通                                                  | 「三明者與得神通者們，                                       |
| 2巧妙知他心                                                  | 知他心的熟練者們，                                           |
| 3漏尽阿罗汉                                                  | 漏已滅盡的阿羅漢們：                                         |
| 4佛陀弟子中 5其数有众多                                      | 佛陀的弟子有很多。」                                         |
| 时，梵众天欢喜于尊者大目犍连之所说，往诣彼大梵天。诣已，以此语梵天曰： | 那時，那位梵天眾歡喜、隨喜尊者目揵連所說後，去見那位梵天。抵達後，對那位梵天說這個： |
| ‘友!尊者大目犍连，如是曰:                                    | 「親愛的先生！尊者目揵連說這個：                             |
| 1三明达神通                                                  | 『三明者與得神通者們，                                       |
| 2巧妙知他心                                                  | 知他心的熟練者們，                                           |
| 3漏尽阿罗汉                                                  | 漏已滅盡的阿羅漢們：                                         |
| 4佛陀弟子中 5其数有众多                                      | 佛陀的弟子有很多。』」                                       |
| 彼梵众天如是云已，梵天欢喜于梵众天之所说。                   | 那位梵天眾說這個，而那位悅意的梵天歡喜那位梵天眾所說。       |
