| 第四 阿卢那越提                                              | 14.阿盧那哇低經                                              |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城。                                         | 有一次，世尊住在舍衛城……（中略）。                           |
| 时，世尊呼诸比丘：‘诸比丘!’                                  | 在那裡，世尊召喚比丘們：「比丘們！」                         |
| ‘唯然!世尊、’彼等诸比丘应答世尊。                            | 「尊師！」那些比丘回答世尊。                                 |
| 尊如此宣说：                                                 | 世尊說這個：                                                 |
| ‘诸比丘!昔有阿卢那远多王。                                   | 「比丘們！從前，有位國王名叫阿盧那哇(明相)，                 |
| 其王有阿卢那越提之都。                                       | 比丘們！阿盧那哇國王的王都名叫阿盧那哇低，                   |
| 尸弃世尊、应供、正等觉者，住其阿卢那越提王都。               | 比丘們！尸棄世尊、阿羅漢、遍正覺者依止阿盧那哇低居住，       |
| 诸比丘!又，尸弃世尊，应供、正等觉者，有一对上足弟子：名为阿毗浮、参跋婆。 | 比丘們！又，尸棄世尊、阿羅漢、遍正覺者的第一雙弟子是名叫阿毘浮、三巴哇的雙賢。 |
| 时，诸比丘!尸弃世尊呼阿毗浮比丘：                            | 比丘們！那時，尸棄世尊、阿羅漢、遍正覺者召喚阿毘浮比丘：     |
| ‘来!婆罗门!至于食时，到某梵天界。’                           | 『婆羅門！我們走，我們將去某個梵天世界，直到用餐時間為止。』 |
| ‘唯然!世尊!’                                                 | 『是的，大德！』                                             |
| 阿毗浮比丘奉答尸弃世尊。                                     | 比丘們！阿毘浮比丘回答尸棄世尊、阿羅漢、遍正覺者。           |
| 时，诸比丘!尸弃世尊与阿毗浮比丘，犹如力士之伸屈腕、屈伸腕，没于阿卢那越提王都，现身于梵天界。 | 比丘們！那時，尸棄世尊、阿羅漢、遍正覺者與阿毘浮比丘就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在阿盧那哇低王都消失，出現在那個梵天世界。 |
| 时，诸比丘!尸弃如来呼毗浮比丘：                              | 比丘們！那時，尸棄世尊、阿羅漢、遍正覺者召喚阿毘浮比丘：     |
| ‘婆罗门!而此梵天、梵辅天、梵众天说法语。’                    | 『婆羅門！請你對梵天、梵天眾、梵眾天顯現法談。』             |
| ‘唯然!世尊!’                                                 | 『是的，大德！』                                             |
| 阿毗浮比丘奉答尸弃世尊、向梵天、梵辅天、梵众天、说法语、教诚、勉励，令其欢喜。 | 比丘們！阿毘浮比丘回答尸棄世尊、阿羅漢、遍正覺者後，對梵天、梵天眾、梵眾天以法說開示、勸導、鼓勵、使歡喜。 |
| 尔时，诸比丘!梵天与梵辅天及梵众天相说细语、还复牢骚说愚痴：  | 比丘們！在那裡，梵天、梵天眾、梵眾天譏嫌、不滿、責難：       |
| ‘实希有，未得曾有，如何弟子于师前说法耶?’                    | 『實在不可思議啊，先生！實在未曾有啊，先生！弟子為何竟然在大師是面對者時教導法！』 |
| 时，诸比丘!尸弃世尊呼阿毗浮比丘曰：                          | 比丘們！那時，尸棄世尊、阿羅漢、遍正覺者召喚阿毘浮比丘：     |
| ‘婆罗门!梵天与梵辅天及梵众天，牢骚说细语、云愚痴：‘实希有，得未曾有，何以弟子于师前说法耶?’ | 『婆羅門！梵天、梵天眾、梵眾天譏嫌你：「實在不可思議啊，先生！實在未曾有啊，先生！弟子為何竟然在大師是面對者時教導法！」 |
| 婆罗门!是故汝越更警醒于梵天与梵辅及梵众天。’                 | 婆羅門！那樣的話，請你以更大程度對梵天、梵天眾、梵眾天激起急迫感。』 |
| ‘唯然!世尊。’                                                | 『是的，大德！』                                             |
| 诸比丘!阿毗浮比丘奉答尸弃世尊，以现身说法，不现身说法，现下半身说法，现上半身说法。 | 比丘們！阿毘浮比丘回答尸棄世尊、阿羅漢、遍正覺者後，看得見身體地教導法，也沒看見身體地教導法，也看得見下半身沒看見上半身地教導法，也身看得見上半沒看見下半身地教導法。 |
| 于此，诸比丘!梵天与梵辅天及梵众天起希有，得未曾有心：‘沙门之大神通大威力，实是希有，实是未曾有。’ | 比丘們！在那裡，梵天、梵天眾、梵眾天有不可思議的、未曾有的心生起：『實在不可思議啊，先生！實在未曾有啊，先生！沙門的大神通力狀態、大威力狀態！』 |
| 时，阿毗浮比丘以此白尸弃世尊曰：‘世尊!知我于比丘僧伽中，     | 那時，阿毘浮比丘對尸棄世尊、阿羅漢、遍正覺者說這個：『大德！我記得(證知)在比丘僧團中說過像這樣的話： |
| 如立于梵天界，依用音声，令得闻于千世界。’                    | 「學友們！當站在梵天世界中時，我能夠以聲音教導千世間界。」』 |
| ‘婆罗门!汝应立梵天界，令千世界闻汝音声之时。’                | 『婆羅門！是為了這個的適當時機，婆羅門！是為了這個的適當時機：婆羅門！凡在站在梵天世界中時，如果你以聲音教導千世間界。』 |
| 诸比丘!‘唯然!世尊。’                                         | 『是的，大德！』                                             |
| 阿毗浮比丘奉答尸弃世尊，立于梵天界，以唱此偈曰：             | 比丘們！阿毘浮比丘回答尸棄世尊、阿羅漢、遍正覺者後，當站在梵天世界中時，說這些偈頌： |
| 1精勤及勉励                                                  | 『請你們發勤、請你們精勤，                                   |
| 2从顺佛陀教                                                  | 請你們在佛陀的教說上努力，                                   |
| 3拂败恶魔军                                                  | 請你們掃蕩死魔軍，                                           |
| 4如象破苇屋                                                  | 如象對蘆葦茅屋。                                             |
| 5此法与戒律                                                  | 凡在這法律中，                                               |
| 6住不放逸者                                                  | 不放逸地住，                                                 |
| 7弃生死轮回                                                  | 捨斷出生的輪迴後，                                           |
| 8应尽苦边际                                                  | 將作苦的終結。』                                             |
| 诸比丘!时，尸弃世尊与阿毗浮比丘，警醒梵天与梵辅天及梵众天。犹如力士之伸屈腕、屈伸腕。没形于梵天界，现身于阿卢那越提。 | 比丘們！那時，尸棄世尊、阿羅漢、遍正覺者與阿毘浮比丘對梵天、梵天眾、梵眾天激起急迫感後，猶如……（中略）在那個梵天世界消失，出現在阿盧那哇低王都。 |
| 诸比丘!时尸弃世尊呼诸比丘曰：‘诸比丘!汝等闻阿毗浮比丘立于梵天唱此偈否?’ | 那時，尸棄世尊、阿羅漢、遍正覺者召喚比丘們：『比丘們！你們聽到當阿毘浮比丘站在梵天世界中說的偈頌了嗎？』 |
| ‘世尊!我等闻阿毗浮比丘，立于梵天界之所唱此偈。’              | 『大德！我們聽到當阿毘浮比丘站在梵天世界中說的偈頌了。』     |
| ‘诸比丘!汝等闻阿毗浮比丘，立梵天界唱如何偈耶?’               | 『比丘們！那麼，如怎樣你們聽到當阿毘浮比丘站在梵天世界中說的偈頌？』 |
| ‘世尊!我等如是闻：                                           | 『大德！我們這樣聽到當阿毘浮比丘站在梵天世界中說的偈頌：     |
| 1精勤及勉励                                                  | 「請你們發勤、請你們精勤，                                   |
| 2从顺佛陀教                                                  | 請你們在佛陀的教說上努力，                                   |
| 3拂败恶魔军                                                  | 請你們掃蕩死魔軍，                                           |
| 4如象破苇屋                                                  | 如象對蘆葦茅屋。                                             |
| 5此法与戒律                                                  | 凡在這法律中，                                               |
| 6住不放逸者                                                  | 將不放逸地住，                                               |
| 7弃生死轮回                                                  | 捨斷出生的輪迴後，                                           |
| 8应尽苦边际                                                  | 將作苦的終結。」                                             |
| 世尊!我等闻如是偈。’                                         | 大德！我們這樣聽到當阿毘浮比丘站在梵天世界中說的偈頌。』     |
| ‘善哉!善哉!诸比丘!汝等闻阿毗浮比丘，立梵天界唱，善哉!’’      | 「好！好！比丘們！好！比丘們！你們聽到當阿毘浮比丘站在梵天世界中說的偈頌。」 |
| 世尊宣说已。彼等诸比丘!欢喜世尊之所说。                      | 世尊說這個，那些悅意的比丘歡喜世尊的所說。                   |
