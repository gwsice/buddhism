| 第二 提婆达多                                                | 12. 提婆達多經                                               |
|                                                              | 被我這麼聽聞：                                               |
| 尔时，世尊于提婆达多离去不久，住王舍城灵鹫山。               | 有一次，在提婆達多離開不久，世尊住在王舍城耆闍崛山。         |
| 时，梵天沙巷婆提于黎明时，辉耀全灵鹫出，以诣世尊处。         | 那時，在夜已深時，容色絕佳的梵王娑婆主使整個王舍城耆闍崛山發光後，去見世尊。 |
| 诣而礼敬世尊，立于一面。立一面之梵天沙巷婆提，对提婆达多于世尊处唱此偈曰： | 抵達後，向世尊問訊後，在一旁站立。在一旁站立的梵王娑婆主在世尊的面前說這關於提婆達多的偈頌： |
| 2生果实则萎                                                  | 「果實確實殺害芭蕉：                                         |
| 1芭萨竹及苇                                                  | 果實對竹子、果實對蘆葦，                                     |
| 4恶人名誉杀                                                  | 恭敬殺害邪惡人，                                             |
| 3如驴生子死                                                  | 如胎對騾。」                                                 |
