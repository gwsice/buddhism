| 第七 瞿迦利迦                                            | 7. 瞿迦梨迦經                                                |
| [尔时，世尊]住舍卫城……                                   | 起源於舍衛城。                                               |
| 时，世尊又行日住之独坐。                                 | 當時，世尊已進入白天的住處，已獨坐。                         |
| 时，辟支梵天须梵与辟支梵天净居诣世尊处。诣已，各立门边。 | 那時，善梵辟支梵天與淨居辟支梵天去見世尊。抵達後，各依門兩側站立。 |
| 时，辟支梵天须梵，对瞿迦利比丘，于世尊前唱此偈曰：       | 那時，善梵辟支梵天在世尊的面前說這關於瞿迦梨迦比丘的偈頌：   |
| 1以量不可量                                              | 「測量著不能被測量者，                                       |
| 2此谁知分别                                              | 這裡哪位智者會分類？                                         |
| 3以量不可量                                              | 不能被測量者的衡量者，                                       |
| 4我思无智者 5唯有为混乱                                  | 我想他是被覆蓋的凡夫。」                                     |
