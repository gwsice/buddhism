| 第十 瞿迦利迦                                                | 10. 瞿迦梨迦經                                               |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 时，瞿迦利迦诣世尊处。诣已礼敬世尊，于一面坐。一面坐之瞿迦利迦比丘白世尊曰： | 那時，瞿迦梨迦比丘去見世尊。抵達後，向世尊問訊後，在一旁坐下。在一旁坐下的瞿迦梨迦比丘對世尊說這個： |
| ‘世尊!舍利弗与目犍连是恶欲者。是受恶欲所支配者。’            | 「大德！舍利弗、目揵連是惡欲求者，被惡欲求支配者。」         |
| 言已。世尊以此告瞿迦利迦比丘曰：                             | 在這麼說時，世尊對瞿迦梨迦比丘說這個：                       |
| ‘瞿迦利迦!勿作如是言；瞿迦利迦!勿作如是言。瞿迦利迦!勿作如是言。瞿迦利迦，应信乐舍利弗与目犍连。舍利弗与目犍连是稳和者。’ | 「瞿迦梨迦！不要這麼說！瞿迦梨迦！不要這麼說！瞿迦梨迦！請你在舍利弗、目揵連上使心淨信，舍利弗、目揵連是美善的。」 |
| 复次……[乃至]……                                               | 第二次，瞿迦梨迦比丘又對世尊說這個：                         |
|                                                              | 「大德！即使世尊對我是值得信者、能信賴者                     |
|                                                              | 大德！然而，舍利弗、目揵連就是惡欲求者，被惡欲求支配者。」   |
|                                                              | 第二次，世尊又對瞿迦梨迦比丘說這個：                         |
|                                                              | 「瞿迦梨迦！不要這麼說！瞿迦梨迦！不要這麼說！瞿迦梨迦！請你在舍利弗、目揵連上使心淨信，舍利弗、目揵連是美善的。」 |
| 瞿迦利迦三度告世尊曰：                                       | 第三次，瞿迦梨迦比丘又對世尊說這個：                         |
| ‘世尊，舍利弗与目犍连是恶欲者，是受恶欲所支配者。’           | 「大德！即使……（中略）被惡欲求支配者。」                     |
| 世尊三度告瞿迦利迦曰：                                       | 第三次，世尊又對瞿迦梨迦比丘說這個：                         |
| ‘瞿迦利迦!勿作如是言，瞿迦利迦!勿作如是言。瞿迦利迦!应信乐舍利弗与目犍连，舍利弗与目犍连是稳和者。’ | 「瞿迦梨迦！不要這麼說！……（中略）舍利弗、目揵連是美善的。」 |
| 时，瞿迦利迦比丘，即从坐起，礼敬世尊，右绕而去。             | 那時，瞿迦梨迦比丘從座位起來、向世尊問訊、作右繞後，離開。   |
| 瞿迦利迦比丘去后不久，全身生如芥子粒之疮。                   | 而離開不久的瞿迦梨迦比丘全身被芥子大小的膿腫遍滿。           |
| 芥子粒即渐成豆粒；                                           | 成為芥子大小後，成為綠豆大小；                               |
| 豆粒成如大豆，                                               | 成為綠豆大小後，成為豌豆大小；                               |
| 大豆成如枣核大，                                             | 成為豌豆大小後，成為棗核大小；                               |
| 枣核而成如枣大，                                             | 成為棗核大小後，成為棗子大小；                               |
| 枣而成如阿摩罗果大，                                         | 成為棗子大小後，成為餘甘子大小；                             |
| 阿摩罗果而成如未熟之橡果大，                                 | 成為餘甘子大小後，成為未成熟的木瓜大小；                     |
|                                                              | 成為未成熟的木瓜大小後，成為木瓜大小；                       |
| 成如未熟之橡果大，于此破裂流出脓血。                         | 成為木瓜大小後破裂，膿汁與血液流出。                         |
| 时，瞿迦利迦比丘，于此病而死。死矣之瞿迦利迦比丘，因对舍利弗与目犍连敌意，而堕红莲地狱。 | 那時，瞿迦梨迦比丘就以那個疾病命終，以及，在舍利弗、目揵連上心起瞋怒後，命終的瞿迦梨迦比丘往生紅蓮地獄。 |
| 时，梵天沙巷婆提于黎明更以其胜光，辉耀全园，诣于世尊处。     | 那時，在夜已深時，容色絕佳的梵王娑婆主使整個祇樹林發光後，去見世尊。 |
| 诣已，礼敬世尊，立于一面。立于一面之梵天沙巷婆提，以此白世尊曰： | 抵達後，向世尊問訊後，在一旁站立。在一旁站立的梵王娑婆主對世尊說這個： |
| ‘世尊!瞿迦利迦比丘死矣。因对舍利弗与目犍连怀敌意，死堕红莲地狱。’ | 「大德！瞿迦梨迦比丘已命終，大德！在舍利弗、目揵連上心起瞋怒後，命終的瞿迦梨迦比丘往生紅蓮地獄。」 |
| 梵天沙巷婆提，作此言已，礼敬世尊，右绕没形于此。             | 梵王娑婆主說這個，說這個後，梵王娑婆主向世尊問訊、作右繞後，就在那裡消失。 |
| 时，世尊于当夜过后，呼诸比丘曰：‘诸比丘!此夜梵天沙巷婆提，于黎明以其胜光，辉耀全只园，诣我处。诣已，礼我立于一面。 | 那時，那夜過後，世尊召喚比丘們：「比丘們！這夜，在夜已深時，容色絕佳的梵王娑婆主使整個祇樹林發光後，來見我。抵達後，向我問訊後，在一旁站立。 |
| 诸比丘!立于一面之梵天沙巷婆提告我曰：‘世尊!瞿迦利迦比丘死矣。因对舍利弗与目犍连怀敌意，死而堕入红莲地狱。’ | 比丘們！在一旁站立的梵王娑婆主對我說這個：『大德！瞿迦梨迦比丘已命終，大德！在舍利弗、目揵連上心起瞋怒後，命終的瞿迦梨迦比丘往生紅蓮地獄。』 |
| 诸比丘!梵天沙巷婆提作此言已，礼敬我，右绕，于此没其身形。’   | 比丘們！梵王娑婆主說這個，說這個後，梵王娑婆主向我問訊、作右繞後，就在那裡消失。」 |
| 如是言已，有比丘以此白世尊曰：                               | 在這麼說時，某位比丘對世尊說這個：                           |
| ‘世尊!红莲地狱之寿量有几何耶?’                               | 「大德！在紅蓮地獄中，壽命量有多長呢？」                     |
| ‘比丘!红莲地狱之寿量甚长。难数为几年、几百年、几千年、几百千年。’ | 「比丘！在紅蓮地獄中，壽命量是長的，那不容易計算『幾年』，或『幾百年』，或『幾千年』，或『幾十萬年』。」 |
| ‘世尊，可譬喻说之耶?’                                        | 「大德！那麼，能夠作譬喻？」                                 |
| 世尊曰：‘比丘!得                                             | 「比丘！能。」世尊說。                                       |
| 如是说：譬喻此拘萨罗国有二十加厘菜种子，各过百年，取一粒菜种子， | 「比丘！猶如二十佉梨份量的憍薩羅國芝麻車，如果男子每過一百年從那裡取出一粒芝麻， |
| 且以此方法，于拘萨罗国取尽二十加厘菜种子，亦不尽阿浮陀地狱之寿量。 | 比丘！那個二十佉梨份量的憍薩羅國芝麻車以這個行動急速地走到遍盡、耗盡，而非一阿浮陀地獄。 |
| 诸比丘!二十阿浮陀地狱为一尼罗浮陀地狱。                      | 比丘！猶如二十阿浮陀地獄，這樣一尼羅部陀地獄。               |
| 二十尼罗浮陀地狱为一阿婆婆地狱。                             | 比丘！猶如二十尼羅部陀地獄，這樣一阿婆婆地獄。               |
| 二十阿婆婆地狱为一阿吒吒地狱。                               | 比丘！猶如二十阿婆婆地獄，這樣一阿得得地獄。                 |
| 二十阿吒吒地狱为一阿诃诃地狱。                               | 比丘！猶如二十阿得得地獄，這樣一阿訶訶地獄。                 |
| 二十阿诃诃地狱为一水莲地狱。                                 | 比丘！猶如二十阿訶訶地獄，這樣一古木達地獄。                 |
| 二十水莲地狱为一青睡莲地狱。                                 | 比丘！猶如二十古木達地獄，這樣一受更狄迦地獄。               |
| 二十青睡莲地狱为一青莲地狱。                                 | 比丘！猶如二十受更狄迦地獄，這樣一優鉢羅地獄。               |
| 二十青莲地狱为一白莲地狱。                                   | 比丘！猶如二十優鉢羅地獄，這樣一分陀利迦地獄。               |
| 二十白莲地狱为一红莲地狱。                                   | 比丘！猶如二十分陀利迦地獄，這樣一紅蓮地獄，                 |
| 比丘!瞿迦利迦比丘对舍利弗与目犍连怀敌意，堕此红莲地狱。’     | 比丘！瞿迦梨迦比丘在舍利弗、目揵連上心起瞋怒後往生紅蓮地獄。」 |
| 世尊如是说已。善逝又唱此偈曰．                               | 世尊說這個，說這個後，善逝、大師又更進一步說這個：           |
| 1人之出生时                                                  | 「當人(男子)被生時，                                         |
| 2斧实生口中                                                  | 斧頭被生在口中，                                             |
| ……乃至……(同前经之偈。)                                       | 以該者切斷自己：                                             |
|                                                              | 說惡說的愚者。                                               |
|                                                              | 凡稱讚應該被責備者，                                         |
|                                                              | 或他責備凡應該被稱讚者，                                     |
|                                                              | 他以口選擇不幸運的骰子，                                     |
|                                                              | 以那個不幸運的骰子找不到安樂。                               |
|                                                              | 這個不幸運的骰子是少量的：                                   |
|                                                              | 凡在諸骰子上有財產的損敗，                                   |
|                                                              | 甚至一切的財產也連同以自己，                                 |
|                                                              | 這就是更大不幸運的骰子：                                     |
|                                                              | 凡如果在善逝上使意違犯。                                     |
|                                                              | 十萬尼羅部陀，                                               |
|                                                              | 三十六又五阿浮陀，                                           |
|                                                              | 凡呵責聖人者來到地獄：                                       |
|                                                              | 置邪惡的言語與意後。」                                       |
