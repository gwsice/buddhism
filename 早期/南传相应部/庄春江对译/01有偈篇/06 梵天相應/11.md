| 第二 梵天品                                                  | 2.第二品                                                     |
| 第一 常童子                                                  | 11. 常童子經                                                 |
| 如是我闻。尔时，世尊住王舍城叶毗尼河边。                     | 有一次，世尊住在王舍城奢逼尼河畔。                           |
| 时，梵天常童子 ，于黎明光辉照叶毗尼河边，以诣世尊处。        | 那時，在夜已深時，容色絕佳的梵王常童子使整個奢逼尼河畔發光後，去見世尊。 |
| 诣已礼敬世尊，立于一面。立一面之梵天常童子，于世尊处唱此偈曰： | 抵達後，向世尊問訊後，在一旁站立。在一旁站立的梵王常童子在世尊的面前說這個偈頌： |
| 2殊胜刹帝利                                                  | 「剎帝利在這人們中是最上的：                                 |
| 1氏姓人中尊                                                  | 凡依賴家系者們，                                             |
| 3明行具足者                                                  | 明行具足者，                                                 |
| 4人天中殊胜                                                  | 在天人中他是最上的。                                         |
| 梵天常童子言已，请师嘉赏。                                   | 梵王常童子說這個，大師是認可者。                             |
| 时、梵天常童子、知依师受嘉赏，礼敬世尊，右绕而去。           | 那時，梵王常童子[想]：「大師是我的認可者。」向世尊問訊、作右繞後，就在那裡消失。 |
