| 第四 婆迦梵天                                                | 4. 巴迦梵天經                                                |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时世尊住舍卫城只树给孤独园。                               | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 时，又有婆迦梵天，生如是恶见：                               | 當時，巴迦梵天有像這樣的邪惡惡見生起：                       |
| ‘此是常，此是恒常。此是常住，此是完全，此是不变之法。        | 「這是常的，這是堅固的，這是永恆的，這是全部的，這是不死亡法。 |
| 何以故，此不衰、不老、不萎、不灭、不生故。由此以上无有其他之出离。’ | 確實，這個不被生、不衰老、不死亡、不死沒、不再生，而且，沒有其它從這裡超出的出離。」 |
| 时，世尊知婆迦梵天心中之所念，犹如力士之伸屈腕、屈伸腕、没形于只园、现身于梵天界。 | 那時，世尊以心了知巴迦梵天心中的深思後，就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在祇樹林消失，出現在那個梵天世界中。 |
| 婆迦梵天、见世尊从远而来。见已，以此白世尊曰：               | 巴迦梵天看見正從遠處到來的世尊。看見後對世尊說這個：         |
| ‘友!来!友!善来耶!友!久违!何以来此耶?友!                      | 「來，親愛的先生！歡迎你，親愛的先生！親愛的先生終於作這個安排，即：這裡的到來。親愛的先生！ |
| 此是常，此是恒常，此是常住，此是完全，此是不变之法。         | 確實，這是常的，這是堅固的，這是永恆的，這是全部的，這是不死亡法。 |
| 何以故，此是不衰、不老、不萎、不灭、不生故。由此以上无有其他之出离。’ | 確實，這個不被生、不衰老、不死亡、不死沒、不再生，而且，沒有其它從這裡超出的出離。」 |
| 如是言已，世尊告此婆迦梵天曰：                               | 在這麼說時，世尊對巴迦梵天說這個：                           |
| ‘婆迦梵天乃被无明所困惑。婆迦梵天乃被无明所困惑。            | 「唉！先生！巴迦梵天是進入無明者，唉！先生！巴迦梵天是進入無明者， |
| 何以故?以无常者言常，                                        | 確實是因為他將說：『無常的就等同是常的。』                   |
| 以非恒常者言恒常，                                           | 他將說：『不堅固的就等同是堅固的。』                         |
| 以非常住者言常住。                                           | 他將說：『非永恆的就等同是永恆的。』                         |
| 以非完全者言完全，                                           | 他將說：『非全部的就等同是全部的。』                         |
| 以变易之法言不变易之法。                                     | 他將說：『衰變法就等同是不衰變法。』                         |
| 以衰、老、萎、灭、生者言不衰、不老、不萎、不灭、不生。       | 而且，在被生、衰老、死亡、死沒、再生之處，他將像這樣說它：『確實，這個不被生、不衰老、不死亡、不死沒、不再生。』 |
| 由此以上有其他之出离，以言由此以上无有其他之出离故。’        | 而且，有其他超出的出離者，他將說：『沒有其它超出的出離。』」 |

| 1我等七十二 2依于功德业                                      | 「喬達摩！以七十二福業，                                     |
| 3为世统治者 4超越生与老                                      | 有自在力者、生老的超越者，                                   |
| 7我乃通吠陀 6是为最后生 5以生此梵天                          | 這是通曉吠陀者最終的梵天往生，                               |
| 8是故诸众人 9尊崇称赞我                                      | 許多人們以這個祈求。」                                       |
| [世尊：]                                                     |                                                              |
| 1此生寿是短                                                  | 「這個壽命確實是少的、確實非長的：                           |
| 2婆迦思为长                                                  | 巴迦！凡你認為長的壽命，                                     |
| 4百年或亿年                                                  | 十萬尼羅部陀：                                               |
| 3我知梵天寿                                                  | 梵天！我知道你的壽命。」                                     |
| [婆迦：]                                                     |                                                              |
| 1世尊以为我 2是无边见者                                      | 「世尊！我是無邊之見者，                                     |
| 3云越老死悲                                                  | 已越過生、老、憂愁者，                                       |
| 4如何以语我 4善行古禁戒                                      | 什麼是我以前的禁戒與德行之行法？                             |
| 5我愿欲知此                                                  | 請你告知我那個-凡我能了知。」                                |

| 2炎热于烦恼 1汝苦于渴古                                      | 在炎暑中被口渴逼惱者們，                                     |
| 4此乃汝古之 5善行及禁戒                                      | 那是你以前的禁戒與德行之行法，                               |
| 6如是我记忆 7如眠之醒觉                                      | 我如從睡眠清醒般憶念。                                       |

| 11此乃汝古之 12善根及禁戒                                    | 那是你以前的禁戒與德行之行法，                               |
| 13如是我记忆 14如眠之醒觉                                    | 我如從睡眠清醒般憶念。                                       |
| 15于恒伽河流                                                 | 在恒河水流中，                                               |
| 17舟被狂龙打                                                 | 對想要人的兇惡龍捕捉的船，                                   |
| 16怜愍诸众人                                                 | 你們以力量征服後使之釋放，                                   |
| 18此乃汝古之 19善根及禁戒                                    | 那是你以前的禁戒與德行之行法，                               |

| 24圣智汝认我                                                 | 你認為有正覺禁戒者，                                         |
| 25此乃汝古之 26善根及禁戒                                    | 那是你以前的禁戒與德行之行法，                               |
