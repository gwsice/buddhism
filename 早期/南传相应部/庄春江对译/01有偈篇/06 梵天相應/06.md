| 元亨寺                                                       | 庄春江                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 第六 放逸                                                    | 6. 梵天世界經                                                |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，世尊又往日住坐独坐。                                     | 當時，世尊已進入白天的住處，已獨坐。                         |
| 时，辟支梵天之须梵与辟支梵天之净居，往诣世尊之处。诣已，各立于门边。 | 那時，善梵辟支梵天與淨居辟支梵天去見世尊。抵達後，各依門兩側站立。 |
| 时，辟支梵天须梵，以此谓辟支梵天净居曰：                     | 那時，善梵辟支梵天對淨居辟支梵天說這個：                     |
| ‘友!今不应侍奉世尊。世尊在行日住之独坐。                     | 「親愛的先生！拜訪世尊，大致上是不適時的，世尊已進入白天的住處，已獨坐。 |
| 彼处繁荣有梵天界，梵天于此住于放逸住。                       | 某某梵天世界是富有的且繁榮的，而且在那裡的梵天住於放逸住，   |
| 友!我等诣彼梵天。                                            | 親愛的先生！我們走，我們將去那個梵天世界。                   |
| 诣已，令惊惑彼梵天。’                                        | 抵達後，讓我們對那位梵天激起急迫感。」                       |
| ‘友!唯然。’辟支梵天净居回答辟支梵天须梵。                    | 「是的，親愛的先生！」淨居辟支梵天回答善梵辟支梵天。         |
| 时，辟支梵天须梵与辟支梵天净居，犹如力士之伸屈腕、屈仲腕，没形于世尊前，现身彼世界。 | 那時，善梵辟支梵天與淨居辟支梵天就猶如有力氣的男子能……（中略）就像這樣在世尊前消失，出現在那個梵天世界中。 |
| 彼梵天见彼等梵天从远而来。见已，以此谓彼等梵天曰：           | 那位梵天看見正從遠處到來的那些梵天。看見後對那些梵天說這個： |
| ‘友!卿等从何处来耶?’                                         | 「喂！親愛的先生！你們從哪裡來？」                           |
| ‘友!我等从彼世尊、应供、正等觉者之处来。                     | 「親愛的先生！我們是從那位世尊、阿羅漢、遍正覺者的面前來的， |
| 友!卿亦能往侍奉世尊、应供、正等觉者实为善。’                 | 又，親愛的先生！你應該去侍候那位世尊、阿羅漢、遍正覺者。」   |
| 彼言已，其梵天不诺彼言，即化为千度形，以此谓辟支梵天须梵曰： | 在這麼說時，不同意那個言語的那位梵天化作千個(回)自我後，對善梵辟支梵天說這個： |
| ‘友!卿兄我如是之神通威力否?’                                 | 「親愛的先生！你看到我像這樣的神通威力了嗎？」               |
| ‘友!我见卿如是神通威力。’                                    | 「親愛的先生！我看到你像這樣的神通威力了。」                 |
| ‘友!我有如是之神通威力，如何往侍奉其他沙门或婆罗门耶?’       | 「親愛的先生！我是這麼大神通力、這麼大威力者，我要去侍候哪位其他沙門或婆羅門呢？」 |
| 时，辟支梵天须梵，化为二千度形，以此谓其梵天曰：             | 那時，善梵辟支梵天化作兩千個自我後，對那位梵天說這個：       |
| ‘友!卿见如是神通威力否?’                                     | 「親愛的先生！你看到我像這樣的神通威力了嗎？」               |
| ‘友!我见卿如是神通威力。’                                    | 「親愛的先生！我看到你像這樣的神通威力了。」                 |
| ‘友!彼世尊比卿与我具更大神通威力。                           | 「親愛的先生！那位世尊就是比你與我有更大神通力與更大威力者， |
| 友!往侍奉彼世尊、应供、正等觉者为善!’                        | 親愛的先生！你應該去侍候那位世尊、阿羅漢、遍正覺者。」       |
| 时，彼梵天以偈谓辟支梵天须梵曰:                              | 那時，那位梵天以偈頌對善梵辟支梵天說：                       |
| 1我宫殿有三 2百列金翅乌 3四百列白鸟                          | 「三[百]隻金翅鳥與四[百]隻天鵝，                             |
| 4五百虎雕刻                                                  | 以及五百隻鷹-禪者的，                                        |
| 5梵天此宫殿                                                  | 梵天！以及那個這個天宮發光，                                 |
| 6赫赫耀北方                                                  | 在北方使閃耀地。」                                           |
| [须梵：]                                                     |                                                              |
| 1如何汝宫殿                                                  | 「即使你的那天宮發光，                                       |
| 2赫耀于北方                                                  | 在北方使閃耀地，                                             |
| 3贤者常见色 4诤乱与动乱                                      | 在色上看見過失、經常顫抖的後，                               |
| 5故不乐于色                                                  | 因此極聰明者不樂諸色。」                                     |
| 时，辟支梵天须梵与辟支梵天净居，为惊惑此梵天，于此没其身形。 | 那時，善梵辟支梵天與淨居辟支梵天激起那位梵天的急迫感後，就在那裡消失。 |
| 如是其梵天，于其他之时，为侍奉世尊、应供、正等觉者而去。     | 那位梵天過些時候去侍候那位世尊、阿羅漢、遍正覺者。           |
