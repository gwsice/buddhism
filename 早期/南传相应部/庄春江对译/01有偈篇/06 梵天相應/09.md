| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 时、瞿迦利迦比丘生病而痛苦，其病严重。                       | 當時，瞿迦梨迦比丘是生病者、受苦者、重病者。                 |
| 时，辟支梵天都头 于夜更以其胜光辉耀只园，诣瞿迦利迦比丘处。  | 那時，在夜已深時，容色絕佳的都路辟支梵天使整個祇樹林發光後，去見瞿迦梨迦比丘。 |
| 诣已，立于空中，以此语瞿迦利迦比丘曰：                       | 抵達後，站在空中，對瞿迦梨迦比丘說這個：                     |
| ‘瞿迦利迦比丘!以信乐舍利弗与目犍连!舍利弗与目犍连是稳和者 。’ | 「瞿迦梨迦！請你在舍利弗、目揵連上使心淨信，舍利弗、目揵連是美善的。」 |
| ‘友!汝谁耶?’                                                 | 「朋友！你是誰？」                                           |
| ‘我乃辟支梵天都头是。’                                       | 「我是都路辟支梵天。」                                       |
