| 第三 梵天                                                    | 3. 梵天經                                                    |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住舍卫城只树给孤独园。                             | 有一次，世尊住在舍衛城祇樹林給孤獨園。                       |
| 其时，又有婆罗门女之子梵天，于世尊处出家而无家。             | 當時，有某位女婆羅門的兒子名叫梵天，在世尊的面前從在家出家成為無家者。 |
| 时，尊者梵天单独隐栖，不放逸、虔诚、精进而住、不久此良家之子， | 那時，住於單獨的、隱離的、不放逸的、熱心的、自我努力的尊者梵天不久就以證智自作證後， |
| 当为由家于无家而出家，于现法成就其无上梵行，自知、实证、证入而住。 | 在當生中進入後住於凡善男子們為了利益正確地從在家出家成為無家者的那個無上梵行結尾， |
| ‘知生已尽，梵行已立，所作已办，不受后有。’                   | 他證知：「出生已盡，梵行已完成，應該被作的已作，不再有此處[輪迴]的狀態。」 |
| 尊者梵天，成阿罗汉。                                         | 然後尊者梵天成為眾阿羅漢之一。                               |
| 时，尊者梵天清晨，着衣持钵，于舍卫城乞食，                   | 那時，尊者梵天午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。   |
| 于舍卫城户户乞食，近至母家。                                 | 當在舍衛城為了托鉢次第地行走著時，來到自己母親住處。         |
| 其时，尊者梵天之母婆罗门女，常以供牲供梵天。                 | 當時，尊者梵天的母親女婆羅門，常高舉對梵天(神)的供奉。       |
| 时，梵天沙巷婆提生如是思念：‘此尊者梵天之母婆罗门女，常以供牲供梵天，我当往警觉。’ | 那時，梵王娑婆主想這個：「這位尊者梵天的母親女婆羅門，常高舉對梵天的供奉，讓我去見她後激起她的急迫感。」 |
| 时，梵天沙巷婆提，犹如力士之伸屈腕、屈伸腕，没形于梵天界，现身于尊者梵天之母家。 | 那時，梵王娑婆主就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在梵天世界消失，出現在尊者梵天的母親住處。 |
| 时，梵天沙巷婆提立于空中，对尊者梵天之母婆罗门女唱偈曰：     | 那時，梵王娑婆主站在空中，對尊者梵天的母親女婆羅門以偈頌說： |
| 1婆罗门女者                                                  | 「女婆羅門！                                                 |
| 3因此离梵天                                                  | 梵天世界是在離這裡的遠處，                                   |
| 2汝常为供食                                                  | 你常高舉對該者的供奉，                                       |
| 4婆罗门女者                                                  | 女婆羅門！                                                   |
| 5此非梵天食                                                  | 梵天的食物不是這樣的，                                       |
| 6不知梵天道 7而汝何牢骚                                      | 不知道梵天之路的你祈禱嗎？                                   |
| 8婆罗门女者                                                  | 女婆羅門！                                                   |
| 9汝梵天比丘                                                  | 確實你的這位梵天，                                           |
| 10已至无依着 11以达胜天境                                    | 是無依著者、到達超越天神者，                                 |
| 12已无所有处 13无养之比丘                                    | 無所有的、無養育其他者的比丘，                               |
| 14今乞入汝家                                                 | 他為了托鉢已進入你家。                                       |
| 15相应于供养 16积修达圣道                                    | 應該被供養者、明智者、已自我修習者，                         |
| 17堪为人天供                                                 | 以及應該被天與人供養者，                                     |
| 18除恶无秽污                                                 | 拒斥諸惡後不被染著者，                                       |
| 19乞食清威仪                                                 | 已清涼者對食物的尋求行動。                                   |
| 20彼亦无前后                                                 | 他沒有前後，                                                 |
| 21寂静绝嗔烟 22无闷亦无欲                                    | 寂靜者、無煙者、無惱亂者、離願望者，                         |
| 23于弱于强者 24无用于暴力                                    | 在懦弱者與堅強者上放下棍棒者，                               |
| 25令彼以得汝 26第一之供养                                    | 請他吃你供奉的最上食物。                                     |
| 27无烦恼魔袭 28心静无欲污                                    | 成為無敵(離軍團)者、心寂靜者，                               |
| 29如调顺象行                                                 | 行如已調御的、無擾動的龍象，                                 |
| 30戒行善圆满 31心解脱比丘                                    | 善戒的、心善解脫的比丘，                                     |
| 32令彼以得汝 33第一之供养                                    | 請他吃你供奉的最上食物。                                     |
|                                                              | 在他上淨信地、不動搖地，                                     |
|                                                              | 請你建立供養物在應該被供養者上，                             |
|                                                              | 請你作未來安樂的福德：                                       |
| 34婆罗门女者                                                 | 女婆羅門！                                                   |
| 35今汝超瀑流 36以见牟尼佛                                    | 看見渡過暴流的牟尼後。」                                     |
| 37对彼信不动                                                 | 「在他上淨信地、不動搖地，                                   |
| 38相应于供养                                                 | 她建立供養物在應該被供養者上。                               |
| 39以行是功德 40未来得安乐                                    | 她作未來安樂的福德：                                         |
| 41婆罗门女今                                                 | 女婆羅門                                                     |
| 42已超越瀑流 43以见于圣者                                    | 看見渡過暴流的牟尼後。」                                     |
| 44以持不动信                                                 |                                                              |
| 45相应于供养                                                 |                                                              |
| 46以行是功德 47未来得安乐                                    |                                                              |
