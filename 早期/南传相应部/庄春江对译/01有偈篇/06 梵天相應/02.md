| 第二 恭敬                                                    | 2. 尊重經                                                    |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住优留毗罗林，尼连禅河边，阿阇波罗尼俱律陀树下。时已成等正觉。 | 有一次，初現正覺的世尊住在優樓頻螺，尼連禪河畔牧羊人的榕樹處。 |
| 尔时，世尊独坐静观，生如是思惟：                             | 那時，獨處、獨坐的世尊這樣心的深思生起：                     |
| ‘无所尊敬、恭敬之生活，是苦恼。我如何尊敬婆罗门而予近住耶?’  | 「不尊重、不順從者住於苦，哪位沙門或婆羅門我應該恭敬、尊重、依止後生活(住)呢？」 |
| 时，世尊生如是思惟：‘为成就未满之戒蕴，应尊敬其他沙门、婆罗门而予近住。 | 那時，世尊想這個：「為了未完成戒蘊的完成，恭敬、尊重、依止其他沙門或婆羅門後，我應該生活， |
| 但我于天界、魔界、梵天界所含之世界。于沙门、婆罗门、人、天所含之众中，不见如我成就戒者，以尊敬其他沙门、婆罗门而住。 | 然而，我不見在包括天，在包括魔，在包括梵的世間；在包括沙門婆羅門，在包括天-人的世代中，比我更具足戒的其他沙門或婆羅門，凡我恭敬、尊重、依止後應該生活。 |
| 为成就未满之定蕴……[乃至]……                                   | 為了未完成定蘊的完成，恭敬、尊重、依止其他沙門或婆羅門後，我應該生活， |
|                                                              | 然而，我不見在包括天……（中略）比我更具足定的其他沙門或婆羅門，凡我恭敬、尊重、依止後應該生活。 |
| 未满之慧蕴……乃至……                                           | 為了未完成慧蘊的完成，恭敬、尊重、依止其他沙門或婆羅門後，我應該生活， |
|                                                              | 然而，我不見在包括天……（中略）比我更具足慧的其他沙門或婆羅門，凡我恭敬、尊重、依止後應該生活。 |
| 未满之解脱蕴……乃至……                                         | 為了未完成解脫蘊的完成，恭敬、尊重、依止其他沙門或婆羅門後，我應該生活， |
|                                                              | 然而，我不見在包括天……（中略）比我更具足解脫的其他沙門或婆羅門，凡我恭敬、尊重、依止後應該生活。 |
| 未满之解脱知见蕴，应尊敬其他沙门、婆罗门而近住。             | 為了未完成的解脫智見蘊的完成，恭敬、尊重、依止其他沙門或婆羅門後，我應該生活， |
| 但我于天界、魔界、梵天界所含之世界。于沙门，婆罗门、人、天所含之众中，不见如我成就解脱知见者，以尊敬其他沙门、婆罗门而近住。 | 然而，我不見在包括天，在包括魔，在包括梵的世間；在包括沙門婆羅門，在包括天-人的世代中，比我更具足解脫智見的其他沙門或婆羅門，凡我恭敬、尊重、依止後應該生活。 |
| 我宁可对我所悟之法，尊敬此法而予近住。’                      | 讓我凡這個被我現正覺的法，就對那個法恭敬、尊重、依止這後生活。」 |
| 时，梵天沙巷婆提于心，知世尊心之思惟，犹如男子力士之伸屈腕、屈伸腕顷，没于梵天界，现于世尊前。 | 那時，梵王娑婆主以心了知世尊心中的深思後，就猶如有力氣的男子伸直彎曲的手臂，或彎曲伸直的手臂，就像這樣在梵天世界消失，出現在世尊的面前。 |
| 时，梵天沙巷婆提，偏袒一肩、含掌礼世尊，如是白世尊曰：       | 那時，梵王娑婆主置(作)上衣到一邊肩膀、向世尊合掌鞠躬後，對世尊說這個： |
| ‘世尊!如是，善逝!如是。世尊!过去之应供、正觉者、世尊亦恭敬、尊重、亲近法而住。 | 「這是這樣，世尊！這是這樣，善逝！大德！又凡那些過去時是阿羅漢、遍正覺者們，那些世尊也只恭敬、尊重、依止法後生活； |
| 未来之应供、正觉者、世尊亦恭敬、尊重、亲近法而住。           | 大德！又凡那些未來時將是阿羅漢、遍正覺者們，那些世尊也只恭敬、尊重、依止法後將生活； |
| 今之应供、正觉者、世尊亦恭敬、尊重、亲近法而住。’            | 大德！又世尊現在是阿羅漢、遍正覺者，也請只恭敬、尊重、依止法後生活。」 |
| 梵天沙巷婆提说此已。又作此曰：                               | 梵王娑婆主說這個，說這個後，又更進一步說這個：               |
| 1过去正觉者                                                  | 「凡過去的諸正覺者，                                         |
| 2未来之诸佛                                                  | 與凡未來的諸佛，                                             |
| 3今之正觉者                                                  | 以及凡現在正覺者：                                           |
| 4灭众生忧恼                                                  | 許多憂愁的破壞者。                                           |
| 5悉皆敬正法                                                  | 全部對正法尊重地，                                           |
| 6而住今亦住                                                  | 曾生活與生活，                                               |
| 7又未来亦住                                                  | 也像這樣將生活，                                             |
| 8此诸佛法然                                                  | 這是諸佛的法性。                                             |
| 9故愿自己利                                                  | 因此以愛惜自己，                                             |
| 10以望伟大者                                                 | 期待偉大者，                                                 |
| 12不无敬正法                                                 | 正法應該被尊重：                                             |
| 11忆念佛之教                                                 | 憶念諸佛陀教說者。」                                         |
