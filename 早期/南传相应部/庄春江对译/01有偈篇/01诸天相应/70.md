| 第十 世间 | 70. 世間經             |
| 天神：    |  |
| 1 何生世间生 |  「世間在什麼上被生起？  |
| 2 和合何物上 | 在什麼上作親密交往？       |
| 3 世间依何物 | 世間執取什麼後，        |
| 4 依何世间苦 | 世間在什麼上被惱害？」          |
| 世尊：    |                        |
| 1 六生世间生 | 「世間在六上被生起， |
| 2 和合于六上 | 在六上作親密交往， |
| 3 依六而执着 | 就執取六後， |
| 4 于六世间苦 | 世間在六上被惱害。」 |

> 「六法」，南傳作「六」，《顯揚真義》說：在六內處生起中這被名為生起，在六外處中作親密交往，對六內處執取後，在六外處之中被惱害。
