| 第六 不老     | 76. 不衰退經                         |
| 天神：        |                                      |
| 1 何老何不老  | 「什麼衰退、什麼不衰退？             |
| 2 何者云非道  | 什麼被稱為『邪道』呢？               |
| 3 何者障碍法  | 什麼是法的障礙呢？                   |
| 4 何者尽日夜  | 什麼有日夜的消逝(滅盡)呢？           |
| 5 何者秽梵行  | 什麼是梵行的垢？                     |
| 6 何者无水浴  | 什麼是無水的沐浴？                   |
| 7 世有几多穴  | 世間中有多少孔隙，                   |
| 8 心意不停滞  | 在那裡{財產}[心]不住立？             |
| 9 我等来问佛  | 我們來問世尊，                       |
| 10 我等以何知 | 我們應該如何知道它？」               |
| 世尊：        |                                      |
| 1 色体乃衰老  |                                      |
| 2 人姓氏不老  | 「不免一死的人之色衰退、姓名不衰退， |
| 3 贪欲云非道  | 貪被稱為『邪道』，                   |
| 4 悭贪障碍法  | 貪婪是法的障礙，                     |
| 5 青春尽日夜  | 青春有日夜的消逝。                   |
| 6 女人秽梵行  | 女子是梵行的垢，                     |
| 7 人人执着此  | 在這裡這個被世代黏著，               |
| 8 苦行与梵行  | 苦行與梵行，                         |
| 9 乃无水沐浴  | 那是無水的沐浴。                     |
| 10 世有六孔穴 | 世間中有六個孔隙，                   |
| 11 心不得滞此 | 在那裡心不住立：                     |
| 12 懒惰与放逸 | 懶惰與放逸，                         |
| 13 不勤不抑制 | 不奮起不抑制，                       |
| 14 耽睡眠怠慢 | 睡眠與倦怠，                         |
| 15 应离此一切 | 那些孔隙應該全部地回避它。」         |
