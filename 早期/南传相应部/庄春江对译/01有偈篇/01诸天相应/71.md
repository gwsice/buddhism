| 第八 断品        | 8.切斷品                 |
| 第一 杀          | 71. 切斷後經             |
|                  | 起源於舍衛城。           |
| 立于一面之天神， | 在一旁站立的那位天神     |
| 以偈向世尊曰:    | 以偈頌對世尊說：         |
| 1 杀何乐寝卧     | 「切斷什麼後睡得安樂呢？ |
| 2 杀何而不悲     | 切斷什麼後不憂愁呢？     |
| 3 杀害何一法     | 對哪一法的殺害，         |
| 4 瞿昙卿称赞     | 喬達摩同意呢？」         |
| 世尊：           |                          |
| 1 杀忿乐寝卧     | 「切斷憤怒後睡得安樂，   |
| 2 杀忿为不悲     | 切斷憤怒後不憂愁，       |
| 4 而为最上蜜     | 天神！對端為蜜，         |
| 3 诸天以毒根     | 對根為毒的憤怒，         |
| 5 圣赞忿杀害     | 聖者們稱讚殺害，         |
| 6 杀而不悲伤     | 因為切斷它後不憂愁。」   |
