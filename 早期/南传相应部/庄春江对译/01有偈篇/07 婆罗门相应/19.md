| 第九 孝养                                                    | 19. 扶養母親者經                                             |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，孝养婆罗门来诣世尊处。诣已，与世尊互相致问，坐于一面，   | 那時，扶養母親的婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 一面坐之孝养婆罗门，以此白世尊曰：                           | 在一旁坐下的扶養母親的婆羅門對世尊說這個：                   |
| ‘尊者瞿昙!我于如法求食。如法求食以养父母。                   | 「喬達摩尊師！我依法遍求施食，依法遍求施食後，我扶養父母，   |
| 尊者瞿昙!我如是行，是以应为而为耶?’                          | 喬達摩尊師！我是這麼作者，是否我是盡義務者呢？」             |
| ‘婆罗门!汝确实如是行应所行。                                 | 「婆羅門！你是這麼作者，你當然是盡義務者。                   |
| 婆罗门!如法求食以养父母者，乃生甚多功德。                    | 婆羅門！凡依法遍求施食，依法遍求施食後，扶養父母者，他產生許多福德。」 |
| 2孝养父母者                                                  | 「凡母親或父親，                                             |
| 1若人以如法                                                  | 不免一死的人依法扶養，                                       |
| 4因此而行为                                                  | 他以這個侍奉：                                               |
| 3依法于父母                                                  | 在母親父親上，                                               |
| 5贤者于此世 6当以赞叹彼                                      | 就在這裡賢智者們稱讚他，                                     |
| 7彼至于死后 8又生于天界                                      | 死後在天界喜悅。」                                           |
| 如是言已，孝养婆罗门，以此白世尊曰：                         | 在這麼說時，扶養母親的婆羅門對世尊說這個：                   |
| ‘尊者瞿昙，是最胜者……乃至……愿世尊从今日以后，受我终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
