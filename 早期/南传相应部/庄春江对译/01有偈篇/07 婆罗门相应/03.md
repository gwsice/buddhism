| 阿修罗王婆罗堕婆阇婆罗门，                                   | 阿修羅王婆羅墮若婆羅門聽聞：                                 |
| 闻婆罗堕婆阇姓之婆罗门，于沙门瞿昙之处，由家[出]无家而出家。 | 「聽說婆羅墮若姓婆羅門在沙門喬答摩面前從在家出家成為無家者。」 |
| 忿怒不喜，来诣世尊处。诣已，以激烈不善之语，谗谤、诽谤世尊。 | 生氣、不悅意地去見世尊。抵達後，以無禮的、粗惡的言語責罵、誹謗世尊。 |
| 如是言已，世尊默然。                                         | 在這麼說時，世尊保持沈默。                                   |
| 时，阿修罗王婆罗堕婆阇婆罗门，以此白世尊曰：                 | 那時，阿修羅王婆羅墮若婆羅門對世尊說這個：                   |
| ‘沙门!汝胜利!沙门!汝胜利。’$$\color{red}（翻译错了）$$       | 「沙門！你被征服；沙門！你被征服。」                         |
