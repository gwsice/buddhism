| 第八 拜火                                                  | 8.拜火經                                                     |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                         | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 时，其拜火婆罗堕婆阇婆罗门，行火供，煮酪米饭，为拜火供牺。 | 當時，拜火婆羅墮若婆羅門的參酥油乳粥被放置：                 |
|                                                            | 「我將獻供火，我將祀拜火。」                                 |
| 时，世尊清晨，着衣持钵，入王舍城乞食。                     | 那時，世尊午前時穿衣、拿起衣鉢後，為了托鉢進入王舍城。       |
| 于王舍城家家乞食，至拜火婆罗堕婆阇婆罗门家。至而立于一面。 | 當在王舍城為了托鉢次第地行走著時，來到拜火婆羅墮若婆羅門的住處。抵達後，在一旁站立。 |
| 拜火婆罗堕婆阇婆罗门，见世尊乞食，以偈白世尊曰：           | 拜火婆羅墮若婆羅門看見為了托鉢站立的世尊。看見後，拜火婆羅墮若婆羅門以偈頌對世尊說： |
| 1三明等具足                                                | 「三明具足者、                                               |
| 2生高有多闻                                                | 出生良好者、多聞者，                                         |
| 3明行具足者                                                | 明行具足者，                                                 |
| 4受食我乳饭                                                | 他應該吃這個乳粥。」                                         |
| [世尊：]                                                   |                                                              |
| 1离多唱驮咒                                                | 「即使許多無用咒的呢喃者，                                   |
| 4非生婆罗门                                                | 婆羅門也不是以出生，                                         |
| 2埃满内不净                                                | 成為內部有污濁者、污染者，                                   |
| 3外蔽于欺瞒                                                | 以詭計被圍繞者。                                             |
| 5以知于宿命                                                | 凡知道前世住處，                                             |
| 6见天界恶趣                                                | 以及看見天界與苦界，                                         |
| 7及达生之灭                                                | 又已到達出生的滅盡者，                                       |
| 8圣者力成满                                                | 已完成證智的牟尼。                                           |
| 9有此三明人                                                | 以這三明，                                                   |
| 10三明婆罗门                                               | 是三明婆羅門，                                               |
| 11明行具足者                                               | 明行具足者，                                                 |
| 12我受食乳饭                                               | 他應該吃這個乳粥。」                                         |
| ‘尊者瞿昙且受此食!尊者是婆罗门。’                          | 「請喬達摩尊師享用，尊師是婆羅門。」                         |
| [世尊：]                                                   |                                                              |
| 1我唱此偈者 2非为得食者                                    | 「偈頌吟誦[得]的不應該被我吃，                               |
| 3婆罗门于此 4知见者非法                                    | 婆羅門！這不是看見者的法，                                   |
| 5诸佛之唱偈 6以斥其代价                                    | 諸佛拒絕偈頌吟誦的，                                         |
| 7婆罗门法住 8是为生活道                                    | 婆羅門！在法存在時這是行為模式。                             |
| 10完全大圣者                                               | 而對圓滿的大仙，                                             |
| 9漏尽悔行静                                                | 對漏已滅盡者、惡作已平息者，                                 |
| 11依事奉饮食                                               | 請你以其它食物飲料侍奉，                                     |
| 12是为功德田                                               | 因為那是期待福德者的田地。」                                 |
| 如是言已，拜火婆罗堕婆阇婆罗门，以此白世尊曰：             | 在這麼說時，拜火婆羅墮若婆羅門對世尊說這個：                 |
| ‘世尊!是最胜者……乃至……’                                    | 「太偉大了，喬達摩尊師！……（中略）。」                       |
| 又，此婆罗堕婆阇，成为一阿罗汉。                           | 然後尊者拜火婆羅墮若成為眾阿羅漢之一。                       |
