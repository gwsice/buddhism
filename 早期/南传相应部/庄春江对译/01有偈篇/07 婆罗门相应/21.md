| 第十一 参伽罗婆                                              | 21. 散額樂窪經                                               |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，名唤参伽罗婆婆罗门住舍卫城。                             | 當時，名為散額樂窪(共尊重)的婆羅門住在舍衛城，               |
| 是水净行者，依水求得清净，朝夕入水，行沐浴行。               | 是由水純淨者、信仰以水遍純淨，住於黃昏、黎明水浴之實踐的實踐者。 |
| 时尊者阿难，清晨着衣持钵，入舍卫城乞食。                     | 那時，尊者阿難午前時穿衣、拿起衣鉢後，為了托鉢進入舍衛城。   |
| 于舍卫城乞食后，收钵而来诣世尊处，诣而礼敬世尊，坐于一面。   | 在舍衛城為了托鉢行走後，餐後已從施食返回，去見世尊。抵達後，向世尊問訊後，在一旁坐下。 |
| 坐一面尊者阿难，以此白世尊曰：                               | 在一旁坐下的尊者阿難對世尊說這個：                           |
| ‘世尊!于此名唤参伽罗婆婆罗门住舍卫城。是水净行者，依水求得清净，朝夕入水，行沐浴行。 | 「大德！這裡，名為散額樂窪的婆羅門住在舍衛城，是由水純淨者、信仰以水遍純淨，住於黃昏、黎明水浴之實踐的實踐者。 |
| 世尊，愿垂哀怜，到参伽罗婆婆罗门家。’                        | 大德！願世尊出自憐愍去散額樂窪婆羅門的住處，那就好了！」     |
| 世尊，许允此而默然。                                         | 世尊以沈默狀態同意。                                         |
| 时，世尊清晨，着衣持钵，到参伽罗婆婆罗门家，即坐于所设之座。 | 那時，世尊午前時穿衣、拿起衣鉢後，去散額樂窪婆羅門的住處。抵達後，在設置的座位坐下。 |
| 时参伽罗婆婆罗门，近诣世尊前，与世尊互相致问，坐于一面。     | 那時，散額樂窪婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 世尊以此告一面坐之参伽罗婆婆罗门曰：                         | 世尊對在一旁坐下的散額樂窪婆羅門說這個：                     |
| ‘婆罗门!汝为水净行者，依水求得清净，朝夕入水，行沐浴行，真实否?’ | 「婆羅門！傳說是真的？你是由水純淨者、信仰以水遍純淨，住於黃昏、黎明水浴之實踐的實踐者。」 |
| ‘尊者瞿昙!是真实。’                                          | 「是的，喬達摩尊師！」                                       |
| ‘婆罗门!汝见有如何利益，为水净行者，依水求得清净，朝夕入水，行沐浴行耶?’ | 「婆羅門！但，當看見什麼理由時，你是由水純淨者、信仰以水遍純淨，住於黃昏、黎明水浴之實踐的實踐者？」 |
| ‘尊者瞿昙!我于此日间所为之恶业，依夕时沐浴洗落，夜间所为之恶业，依清晨沐浴将之洗落。 | 「喬達摩尊師！這裡，凡在白天被我做的惡業，在黃昏令我以沐浴沖走(除去)；凡在夜間被我做的惡業，在黎明令我以沐浴沖走， |
| 尊者瞿昙!我见此利益故，为水净行者，依水求得清净，朝夕入水，行沐浴行。’ | 當看見這個理由時，我是由水純淨者、信仰以水遍純淨，住於黃昏、黎明水浴之實踐的實踐者。」 |
| [世尊：]                                                     |                                                              |
| 1婆罗门戒律 2渡津之法湖                                      | 「婆羅門！法是具有戒為渡場的湖，                             |
| 3澄清无污秽 4常受善人赞                                      | 不濁的、被善人們對善人們稱讚，                               |
| 5圣者浴其处                                                  | 於該處沐浴的通曉吠陀者們，                                   |
| 6体净渡彼岸                                                  | 就肢體不濕地渡過彼岸。」                                     |
| 如是已言，参伽罗婆婆罗门，以此白世尊曰：                     | 在這麼說時，散額樂窪婆羅門對世尊說這個：                     |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
