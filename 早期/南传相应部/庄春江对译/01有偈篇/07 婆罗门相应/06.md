| 第六 萦髻                                                    | 6.結縛經                                                     |
| 舍卫城因缘。                                                 | 起源於舍衛城：                                               |
| 时，萦髻婆罗堕婆阇婆罗门，来诣世尊处。诣而与世尊互相致问，坐于一面。 | 那時，結縛(結髮)婆羅墮若婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 坐一面之萦髻婆罗堕婆阇婆罗门，以偈白世尊曰：                 | 在一旁坐下的結縛婆羅墮若婆羅門以偈頌對世尊說：               |
| 1内外之缠縺                                                  | 「內結縛外結縛，                                             |
| 2人人迷此缠                                                  | 世代被結縛糾纏，                                             |
| 3奉问于瞿昙                                                  | 喬達摩！我問你這個：                                         |
| 4谁利此缠縺                                                  | 誰會解開這個結縛？」                                         |
| [世尊:]                                                      |                                                              |
| 1智慧人住戒                                                  | 「有慧的人在戒上確立後，                                     |
| 2以修心智慧                                                  | 心與慧的修習者，                                             |
| 3热心深慎者                                                  | 熱心明智的比丘，                                             |
| 4彼应离缠縺                                                  | 他會解開這個結縛。                                           |
| 5以离于贪着                                                  | 凡他們的貪與瞋，                                             |
| 6乃至嗔无明                                                  | 以及無明已脫離者，                                           |
| 7漏尽阿罗汉                                                  | 漏已滅盡的阿羅漢們，                                         |
| 8解脱于缠縺                                                  | 他們的結縛已被解開。                                         |
| 9名之以及色                                                  | 於名與色處，                                                 |
| 11无余尽消灭                                                 | 被無餘地破壞，                                               |
| 10障碍及色想                                                 | 有對與色想，                                                 |
| 12此悉断缠縺                                                 | 那個結縛在這裡會被切斷。」                                   |
| 如是言已，萦髻婆罗堕婆阇婆罗门，以此白世尊曰：               | 在這麼說時，結縛婆羅墮若婆羅門對世尊說這個：                 |
| ‘世尊!是最胜者。……乃至……’                                    | 「太偉大了，喬達摩尊師！……（中略）。」                       |
| 又其婆罗堕婆阇，成为一阿罗汉。                               | 然後尊者婆羅墮若成為眾阿羅漢之一。                           |
