| 第三 提婆比多                                                | 13. 提婆西多經                                               |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，世尊，患感冒，尊者优波婆那，为世尊之侍者。               | 當時，世尊是因風生病者，而尊者優波哇那為世尊的侍者。         |
| 时，世尊呼尊者优波婆那曰：                                   | 那時，世尊召喚尊者優波哇那：                                 |
| ‘优波婆那，为我取温水来。’                                   | 「優波哇那！來吧，請你為我知道(找)熱水。」                   |
| ‘唯然!世尊。’尊者优波婆那奉答世尊，即着衣持钵，到提婆比多婆罗门家，默然立于一面。 | 「是的，大德！」尊者優波哇那回答世尊後，穿衣、拿起衣鉢後，去提婆西多婆羅門的住處。抵達後，沈默地在一旁站立。 |
| 提婆比多婆罗门，见尊者优波婆那，默然立一面，以偈白尊者优波婆那曰： | 提婆西多婆羅門看見保持沈默在一旁站立的尊者優波哇那。看見後，以偈頌對尊者優波哇那說： |
| 1尊者默然立                                                  | 「沈默站立的尊師，                                           |
| 2秃头僧伽梨                                                  | 剃光頭的穿僧伽梨者，                                         |
| 3何欲及何求                                                  | 欲求什麼者、尋求什麼者，                                     |
| 4为乞何而来                                                  | 來者乞求什麼呢？」                                           |
| [优波婆那]                                                   |                                                              |
| 1阿罗汉善逝                                                  | 「世間中的阿羅漢、善逝，                                     |
| 2圣者患感冒                                                  | 牟尼是因風生病者，                                           |
| 3若有温水者                                                  | 如果有熱水，                                                 |
| 4婆罗门与佛                                                  | 婆羅門！請你施與牟尼。                                       |
| 5供养应供人                                                  | 應該被供養者被供養，                                         |
| 6尊崇可尊人                                                  | 應該被恭敬者被恭敬，                                         |
| 7敬于可敬人                                                  | 應該被尊敬者被尊敬，                                         |
| 8我愿赍予彼                                                  | 我願意為他帶去。」                                           |
| 时，提婆比多婆罗门，施一担温水、一瓶糖蜜予尊者优波婆那。     | 那時，提婆西多婆羅門以男子取熱水擔與糖蜜袋給尊者優波哇那。   |
| 时，尊者优波婆那返诣世尊处，诣而奉世尊温水沐浴。融糖蜜于温水以奉世尊。 | 那時，尊者優波哇那去見世尊。抵達後，以熱水沐浴世尊後，使糖蜜與熱水混合後，給世尊。 |
| 如是世尊，其病痊愈。                                         | 那時，世尊的病止息了。                                       |
| 时，提婆比多婆罗门，来诣世尊处。诣而与世尊相致问候交谈，坐于一面。 | 那時，提婆西多婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 坐于一面之提婆比多婆罗门，以偈白世尊曰：                     | 在一旁坐下的提婆西多婆羅門以偈頌對世尊說：                   |
| 1应布施何处                                                  | 「哪裡能施物應該施與？                                       |
| 2施何有大果                                                  | 哪裡被施與的有大果？                                         |
| 3何处于供养                                                  | 對供養者怎樣，                                               |
| 4其施果荣盛                                                  | 供養怎樣成功？」                                             |
| [世尊：]                                                     |                                                              |
| 1若了知宿命                                                  | 「凡知道前世住處，                                           |
| 2见天界恶趣                                                  | 以及看見天界與苦界，                                         |
| 3达生之灭尽                                                  | 又已到達出生的滅盡者，                                       |
| 4满通力圣者                                                  | 已完成證智的牟尼。                                           |
| 5应布施于此                                                  | 在這裡能施物應該施與，                                       |
| 6施此有大果                                                  | 在這裡被施與的有大果，                                       |
| 7如是而供果                                                  | 對供養者這樣，                                               |
| 8其施果荣盛                                                  | 供養這樣成功。」                                             |
| 如是言已，提婆比多婆罗门，以此白世尊曰：                     | 在這麼說時，提婆西多婆羅門對世尊說這個：                     |
| ‘尊者瞿昙!是最胜者……乃至……愿受纳我，从今日以后，归依为优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
