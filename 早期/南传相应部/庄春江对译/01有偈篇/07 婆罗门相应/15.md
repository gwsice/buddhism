| 第五 憍傲                                                    | 15.慢剛愎經                                                  |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，名为憍傲之婆罗门住舍卫城。彼不敬母、不敬父、不敬师亦不敬长者。 | 當時，名為慢剛愎的婆羅門住在舍衛城，他既不問訊母親，也不問訊父親，不問訊老師，不問訊哥哥。 |
| 时，世尊为大众所围绕而说法。                                 | 當時，世尊被大眾圍繞，教導法。                               |
| 时，憍傲婆罗门作如是思念：                                   | 那時，慢剛愎婆羅門想這個：                                   |
| ‘此沙门瞿昙为大众围绕而说法。我今诸沙门瞿昙处。              | 「這位沙門喬達摩被大眾圍繞，教導法，讓我去見沙門喬達摩。     |
| 若沙门瞿昙语我者，我即亦语彼。若沙门瞿昙不语我者，我即亦不语彼。’ | 如果沙門喬達摩對我說話，我也將對他說話，如果沙門喬達摩不對我說話，我也將不對他說話。」 |
| 时，憍傲婆罗门诣世尊处。诣而默然立于一面。                   | 那時，慢剛愎婆羅門去見世尊。抵達後，沈默地在一旁站立。       |
| 时，世尊不言彼。                                             | 那時，世尊沒對他說話。                                       |
| 时，憍傲婆罗门，以此沙门瞿昙无何所知而欲归。                 | 那時，慢剛愎婆羅門[心想]：「這位沙門喬達摩什麼也不知道。」就從那裡想要再返回。 |
| 时，世尊知憍傲婆罗门心之所念，以偈告憍傲婆罗门曰：           | 那時，世尊以心了知慢剛愎婆羅門心中的深思後，以偈頌對慢剛愎婆羅門說： |
| 1婆罗门勿慢                                                  | 「婆羅門！慢是不好的，                                       |
| 2若为此来者                                                  | 婆羅門！這裡對有需要者，                                     |
| 3婆罗门来者                                                  | 你以該目的來，                                               |
| 4即善达其用                                                  | 這樣應該隨增大那個(目的)。」                                 |
| 时，憍傲婆罗门：‘沙门瞿昙知我心。’                           | 那時，慢剛愎婆羅門[心想]：「沙門喬達摩知道我的心。」         |
| 即于立处，投身垂头于世尊之足，礼吻世尊之足，以手自指，并自呼报其名曰： | 就在那裡，他以頭落在世尊的腳上，並以嘴遍吻世尊的腳，又以手遍擦拭，以及告知名字： |
| ‘尊者瞿昙!我名憍傲者，尊者瞿昙!我名憍傲者。’                 | 「喬達摩尊師！我是慢剛愎，喬達摩尊師！我是慢剛愎。」         |
| 时，大众起未曾有之心，                                       | 那時，那個群眾有未曾有之心生起：                             |
| ‘实乃希有!实乃未曾有。                                       | 「實在不可思議啊，先生！實在未曾有啊，先生！                 |
| 此憍傲婆罗门，不敬母、不敬父、不敬师，亦不敬长者，且对沙门瞿昙行如是最胜五体投地之礼敬。’ | 因為這位慢剛愎婆羅門既不問訊母親，也不問訊父親，不問訊老師，不問訊哥哥，然而卻對沙門喬達摩作像這樣最高的身體伏在地上之禮。」 |
| 时，世尊以此言憍傲婆罗门曰：                                 | 那時，世尊對慢剛愎婆羅門說這個：                             |
| ‘婆罗门!可起立，以坐自座，汝心已信乐我。’                    | 「夠了，婆羅門！請你起來，請你在自己的座位坐下，因為你的心於我已淨信。」 |
| 时，憍傲婆罗门，就坐自座，以偈白世尊曰：                     | 那時，慢剛愎婆羅門在自己的座位坐下後，以偈頌對世尊說：       |
| 1应向谁谦让                                                  | 「應該在誰上不作慢？                                         |
| 2应对谁尊奉                                                  | 以及應該在誰上是有尊敬者？                                   |
| 3应予敬重谁                                                  | 誰應該被他尊敬？                                             |
| 4并予善供谁                                                  | 誰應該被善尊敬是好的？」                                     |
| [世尊：]                                                     |                                                              |
| 1对于母及父                                                  | 「在母親還有父親上，                                         |
| 2乃至年长兄                                                  | 其次在兄弟上，                                               |
| 3第四乃师长                                                  | 在老師第四位上，                                             |
| 4应该行谦让                                                  | 應該在他們上不作慢，                                         |
| 5应尊此等人                                                  | 應該在他們上是有尊敬者，                                     |
| 6且敬此等者                                                  | 他們應該被他尊敬，                                           |
| 7予供此等人 8是为善供养                                      | 他們應該被善尊敬是好的。                                     |
| 9清凉阿罗汉                                                  | 阿羅漢們、清涼已生者們，                                     |
| 10作了漏尽者                                                 | 應該被作的已作者們、無漏者們，                               |
| 13憍慢与强傲 14应当皆舍去                                    | 破壞慢後不傲慢者，                                           |
| 11对此诸善众 12行无上礼敬                                    | 應該禮敬那些無上者。」                                       |
| 如是言已，憍傲婆罗门，以此白世尊曰：                         | 在這麼說時，慢剛愎婆羅門對世尊說這個：                       |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
