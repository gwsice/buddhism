| 第四 大富者                                                  | 14.大財富者經                                                |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，有大富婆罗门，装作衰萎贫穷，来诣世尊处。诣而与世尊互相致问，坐于一面。 | 那時，某位粗弊的、穿粗弊外衣的大財富的婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 世尊对坐一面之大富婆罗门曰：                                 | 世尊對在一旁坐下的大財富的婆羅門說這個：                     |
| ‘婆罗门!汝何故装作衰萎贫穷而来?’                             | 「婆羅門！為何你是粗弊的、穿粗弊外衣的？」                   |
| ‘尊者瞿昙!我有四子。彼等与其妻等共谋，将我逐出。’            | 「喬達摩尊師！這裡，我的四個兒子，他們與妻子商量後，使我離家。」 |
| ‘婆罗门!若然，汝须暗记此偈，当彼等集聚会堂，时子辈等之在座时唱之： | 「婆羅門！那樣的話，記住這些偈頌後，在大群人集會的集會所中，在兒子們共坐時請你說： |
| 1我素喜其生                                                  | 『在該者們已出生時我歡喜，                                   |
| 2我希其生长                                                  | 以及我想要該者們幸福，                                       |
| 3彼等与妻谋                                                  | 他們與妻子商量後，                                           |
| 4逐我如豚犬                                                  | 阻擋我如狗對豬。                                             |
| 5虽非喜贤者                                                  | 確實卑鄙不善者們對我，                                       |
| 6亦呼我为父                                                  | 說「爹、爹」，                                               |
| 7唯子夜叉形                                                  | 以兒子樣子的羅剎們，                                         |
| 8舍去我年老                                                  | 他們捨棄走到年老者。                                         |
| 9如老哀弱马                                                  | 如衰老無用的馬，                                             |
| 10不予饮食物                                                 | 從食物被除去，                                               |
| 11我乃此子父 12虽身为长者                                    | 愚者們的年長父親，                                           |
| 13但乞他家食                                                 | 在諸別人家乞食。                                             |
| 15不如我拐杖                                                 | 我的拐杖確實就是比較好的，                                   |
| 14有此不孝子                                                 | 如果不順從的兒子們對該者：                                   |
| 16可拂逐猛牛                                                 | 也阻擋兇惡的牛，                                             |
| 17亦可逐猛犬                                                 | 又也對兇惡的狗。                                             |
| 18暗中能导我                                                 | 在黑暗中是在前面的，                                         |
| 19在于深溪时 20并作定足基                                    | 在深處得到立足處，                                           |
| 21依此拐杖力                                                 | 以拐杖的威力，                                               |
| 22倒而又得起。                                               | 跌倒後再站立。」                                             |
| 时，此大富婆罗门，在世尊处暗记此偈，待众等集聚会堂，子辈在座时而唱。 |                                                              |
| 时，其子等即将大富婆罗门领归家中，予沐浴，各予穿着一夹衣。   | 那時，兒子們帶那位大財富的婆羅門回家、使之沐浴後，各各以一套衣服使之穿上。 |
| 时，大富婆罗门，持一夹衣，来诣世尊处。诣而与世尊相致问交谈，坐于一面。 | 那時，那位大財富的婆羅門拿一套衣服後去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 坐一面其大富婆罗问，以此白世尊曰：                           | 在一旁坐下的大財富的婆羅門對世尊說這個：                     |
| ‘尊者瞿昙!我等婆罗门，求我等之师，受纳酬谢。愿尊者瞿昙，我师受纳之报谢。’ | 「喬達摩尊師！我們婆羅門遍求名為老師的學費，請喬達摩尊師接受我的學費。」 |
| 世尊哀怜而纳受。                                             | 世尊出自憐愍使(令人)接受了。                                 |
| 时，其大富婆罗门，以此白世尊曰：                             | 那時，那位大財富的婆羅門對世尊說這個：                       |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后受我归依为优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
