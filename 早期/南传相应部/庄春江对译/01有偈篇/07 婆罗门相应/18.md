| 第八 采薪                                                    | 18.打柴者經                                                  |
| 尔时，世尊住拘萨罗国之森林。                                 | 有一次，世尊住在憍薩羅國某處叢林中。                         |
| 其时，有婆罗堕阇姓婆罗门之众多弟子，为采薪而来至此森林。     | 當時，某位婆羅墮若姓婆羅門的眾多打柴學生婆羅門徒弟去叢林。   |
| 至而见世尊于林中结跏趺坐，身正直，树立正念而坐。             | 抵達後，看見在那處叢林中坐下，盤腿、定置端直的身體、建立面前的念後的世尊。 |
| 见而来到彼婆罗堕婆阇婆罗门处。到已，以此告婆罗堕婆阇婆罗门曰： | 看見後，去見婆羅墮若姓婆羅門。抵達後，對婆羅墮若姓婆羅門說這個： |
| ‘尊师!请知!彼森林有一沙门结跏跌坐，身正直，树立正念而坐。’   | 「真的，尊師！你應該知道，有沙門坐在那樣的叢林中，盤腿、定置端直的身體、建立面前的念後。」 |
| 时婆罗堕婆阇婆罗门，与彼其青年等，俱到森林。见世尊在森林中结跏趺坐，身正直，树立正念而坐。 | 那時，婆羅墮若姓婆羅門與那些青年一起去那處叢林，看見在那處叢林中坐下，盤腿、定置端直的身體、建立面前的念後的世尊。 |
| 见已，诣世尊之处，以偈白世尊曰：                             | 看見後，去見世尊。抵達後，以偈頌對世尊說：                   |
| 1深森有多怖                                                  | 「在極恐怖的叢林深處，                                       |
| 2独入于空林                                                  | 進入無人的空林野後，                                         |
| 3心不动实美                                                  | 不動搖地、住立地、可愛地，                                   |
| 4甚美之比丘 5汝是在禅思                                      | 比丘！你實在極英俊地修禪。                                   |
| 6无能歌此者 7亦无能言语                                      | 在既沒有歌曲處、也沒有音樂處，                               |
| 8独圣者依林                                                  | 單獨在林野中依止樹林的牟尼，                                 |
| 10我见实希有                                                 | 這在我心中出現不可思議形色：                                 |
| 9心喜独住林                                                  | 凡單獨意喜者住在樹林。                                       |
| 11我思念乃此 13三天世界主 14为作同伴者                       | 我想[你是]對世界主共住，                                     |
| 12愿生于无上                                                 | 對無上的天界希望者，                                         |
| 15何故独于林                                                 | 為何尊師依止無人的林野，                                     |
| 16尊者修苦行 17为达于梵否                                    | 你為了梵天的到達在這裡作苦行？」                             |
| [世尊：]                                                     |                                                              |
| 2爱欲或欢喜                                                  | 「凡任何期待或歡喜，                                         |
| 1凡夫种种着                                                  | 在種種界上個個經常依止的，                                   |
| 3生自无知根                                                  | 從無智根的發生希求的，                                       |
| 4一切我断除                                                  | 一切被我從包含根剷除。                                       |
| 5我无贪无欲 6亦不与接近                                      | 那個我是無期待者、無依止者、無執著者，                       |
| 8到达于无上 7有诸清净见                                      | 在一切諸法上有清淨的見，                                     |
| 9吉祥之正觉                                                  | 到達吉祥的無上正覺後，                                       |
| 10婆罗门我独 11于无畏禅思                                    | 婆羅門！我自信地獨處修禪。」                                 |
| 如是言已，婆罗堕婆阇姓婆罗门，以此白世尊曰:                  | 在這麼說時，婆羅墮若姓婆羅門對世尊說這個：                   |
| 尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！……（中略）從今天起已終生歸依。」 |
