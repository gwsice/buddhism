| 第六 违义                                                    | 16.反對者經                                                  |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，名唤违义之婆罗门住舍卫城。                               | 當時，名為愛反對者的婆羅門住在舍衛城。                       |
| 时，违义婆罗门如是思念：                                     | 那時，愛反對者婆羅門想這個：                                 |
| ‘我今诣沙门瞿昙处。其沙门瞿昙之所说，即皆反对而述。’         | 「讓我去見沙門喬達摩，沙門喬達摩說任何事，就對那個，我會是對他反對者。」 |
| 时，世尊于露地经行。                                         | 當時，世尊在露天處經行。                                     |
| 时，违义婆罗门诣世尊处，顺世尊之经行，而自经行，以此白世尊曰：‘沙门!说法。’ | 那時，愛反對者婆羅門去見世尊。抵達後，對經行中的世尊說這個：「沙門！請你說法。」 |
| [世尊：]                                                     |                                                              |
| 2何亦好反对                                                  | 「以喜愛反對者，                                             |
| 3如是善说法 4亦甚难得知                                      | 善說的是不容易了知的，                                       |
| 1心污嗔恚多                                                  | 以心雜染者，                                                 |
|                                                              | 以及以多激情者。                                             |
| 7心之障碍者                                                  | 凡會調伏激情，                                               |
| 6除去无信乐                                                  | 以及心的不淨信，                                             |
| 5唯有灭嗔恚                                                  | 斷念瞋害後，                                                 |
| 8始知善说法                                                  | 他確實會知道善說的。」                                       |
| 如是言已，违义婆罗门，以此白世尊曰：                         | 在這麼說時，愛反對者婆羅門對世尊說這個：                     |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
