| 第九 孙陀利迦                                                | 9.孫陀利葛經                                                 |
| 尔时，世尊住拘萨罗之孙陀利迦河边。                           | 有一次，世尊住在憍薩羅國孫陀利葛河畔。                       |
| 时，又有孙陀利迦婆罗堕婆阇婆罗门，于孙陀利迦河边行火供，作拜火供牺。 | 當時，孫陀利葛婆羅墮若婆羅門在孫陀利葛河畔獻供火、祀拜火供。 |
| 时，孙陀利迦婆罗堕婆阇婆罗门行火供，以完成拜火供牺、立座、回顾四周： | 那時，孫陀利葛婆羅墮若婆羅門獻供火、祀拜火供後，從座位起來後環視四方： |
| ‘谁应受食我此剩肴供物耶?’                                    | 「誰應該吃這個殘餘供物呢？」                                 |
| 时，孙陀利迦婆罗堕婆阇婆罗门，见世尊包头坐于树下。           | 孫陀利葛婆羅墮若婆羅門看見裹著頭坐在某棵樹下的世尊。         |
| 见已，以手持剩肴供物，右手执水瓶，以趣近世尊。               | 看見後，以左手拿殘餘供物、以右手拿長口水瓶後，去見世尊。     |
| 时，世尊闻孙陀利迦婆罗堕婆阇婆罗门之足音，摘去头包。         | 那時，世尊以孫陀利葛婆羅墮若婆羅門的腳步聲敞開頭。           |
| 时，孙陀利迦婆罗堕婆阇婆罗门：                               | 那時，孫陀利葛婆羅墮若婆羅門[心想]：                         |
| ‘此人秃头，此人秃头者。’从此欲折回。                         | 「這位尊者是剃頭的；這位尊者是剃頭者。」就從那裡想要再折返。 |
| 然则，孙陀利迦婆罗堕婆阇婆罗门，又生如是思念：               | 那時，孫陀利葛婆羅墮若婆羅門想這個：                         |
| ‘婆罗门亦有秃头者，我宁诣而以问其生。’                       | 「這裡，某些婆羅門也確實是剃頭的，讓我前往後問出生。」       |
| 时，孙陀利迦婆罗堕婆阇婆罗门，来诣世尊处。诣而以此白世尊曰：‘尊者之生者何?’ | 那時，孫陀利葛婆羅墮若婆羅門去見世尊。抵達後，對世尊說這個：「尊師是什麼出生的？」 |
| [世尊：]                                                     |                                                              |
| 1勿以问出生 2唯问其行为                                      | 「請你不要問出生但請你問行為，                               |
| 3微木亦生火                                                  | 火確實從柴被產生，                                           |
| 4虽然生为卑 5智慧有骏敏                                      | 即使卑下家系的堅定牟尼，                                     |
| 6止恶有惭愧 7是为圣者生                                      | 慚抑止者也成為高貴者(出生良好者)。                           |
| 8依真所调顺 9以具悉调顺                                      | 被真理調御者、具備調御者，                                   |
| 10到达于圣道 11成就梵行人                                    | 通曉吠陀者、完成梵行者，                                     |
| 12带来供牺牲 13呼报出食事                                    | 帶來獻供者應該招請他，                                       |
| 14是人值供养 15以给于供牺                                    | 在適當時間他對應該被供養者獻供。」                           |
| [婆罗门]                                                     |                                                              |
| 1于我此供牺 2善为于供养                                      | 「這裡確實有我的善獻供者、善供奉者：                         |
| 3今见如师者                                                  | 凡我看見像那樣的通曉吠陀者，                                 |
| 4以前未见故                                                  | 因為以沒看見像你們那樣的，                                   |
| 5我剩肴供牺 6他众受为食                                      | 其他人吃殘餘供物。                                           |
| 7尊者瞿昙受                                                  | 請喬達摩尊師吃，                                             |
| 8尊者婆罗门                                                  | 尊師是婆羅門。」                                             |
| [世尊：]                                                     |                                                              |
| 1我唱此偈者 2非为以得食                                      | 「偈頌吟誦[得]的不應該被我吃，                               |
| 3婆罗门于此 4知见者非法                                      | 婆羅門！這不是看見者的法，                                   |
| 5诸佛之唱偈 6以斥其代价                                      | 諸佛拒絕偈頌吟誦的，                                         |
| 7婆罗门法住 8是为生活道                                      | 婆羅門！在法存在時這是行為模式。                             |
| 10完全大圣者                                                 | 而對圓滿的大仙，                                             |
| 9漏尽悔行静                                                  | 對漏已滅盡者、惡作已平息者，                                 |
| 11依事奉饮食                                                 | 請你以其它食物飲料侍奉，                                     |
| 12是为功德田                                                 | 因為那是期待福德者的田地。」                                 |
| ‘尊瞿昙!然则我此剩肴供牺，应与何人耶?’                       | 「喬達摩尊師！那麼，我將對誰施與這個殘餘供物？」             |
| ‘婆罗门!我如来与如来弟子外，即包含世界，天界、魔界、梵天界，包含沙门婆罗门人天之众中，不见食此剩肴供牺能消化者。 | 「婆羅門！我不見那個：在包括天，在包括魔，在包括梵的世間；在包括沙門婆羅門，在包括天-人的世代中，凡這個殘餘供物的食者能走到完全消化，婆羅門！除了對如來或如來的弟子外。 |
| 婆罗门!是故汝从此剩肴供牺，舍于无草处，或沉于无虫之水中。’   | 婆羅門！那樣的話，請你捨棄那個殘餘供物在少草處，或使沈入在無蟲的水中。」 |
| 时，孙陀利迦婆罗堕婆阇婆罗门，从此剩肴供牺，沉于无虫之水中。 | 那時，孫陀利葛婆羅墮若婆羅門使那個殘餘供物沈入無蟲的水中。   |
| 时，其剩肴供牺，沉于水中时，唧唧出声，生烟出炎。             | 那時，那個丟入水中的殘餘供物嘶嘶響、嗤嗤響、冒煙、冒出大煙。 |
| 喻于日中太阳所热之铁板投入水中，唧唧出声，生烟出炎。         | 猶如白天被曬熱丟入水中的鋤頭嘶嘶響、嗤嗤響、冒煙、冒出大煙。 |
|                                                              | 同樣的，那個丟入水中的殘餘供物嘶嘶響、嗤嗤響、冒煙、冒出大煙。 |
| 时，孙陀利迦婆罗堕婆阇婆罗门，惊恐、毛发竖立，来诣世尊处。诣而立于一面。 | 那時，孫陀利葛婆羅墮若婆羅門驚怖、生起身毛豎立地去見世尊。抵達後，在一旁站立。 |
| 世尊以偈言于立一面之孙陀利迦婆罗堕婆阇婆罗门曰：             | 世尊以偈頌對在一旁站立的孫陀利葛婆羅墮若婆羅門說：           |
| 1婆罗门事火                                                  | 「婆羅門！當柴燃燒時，                                       |
| 2勿思得清净                                                  | 你不要認為這個在外的確實是純淨，                             |
| 3智云此外事 5依是不得净                                      | 因為善者們不以那個說純淨：                                   |
| 4依外求清净                                                  | 凡如果以外部希求遍純淨者。                                   |
| 6婆罗门我止                                                  | 婆羅門！捨斷柴的燃燒後，                                     |
| 7事火而内燃                                                  | 我只使自身內的火燃燒，                                       |
| 8依常火常静                                                  | 經常火的、經常得定的狀態，                                   |
| 9我是阿罗汉 10常行于梵行                                     | 婆羅門！我是行梵行的阿羅漢。                                 |
| 11婆罗门汝慢 12是名为重担                                    | 婆羅門！慢確實是你的荷擔，                                   |
| 13忿烟妄语灰                                                 | 憤怒是煙、妄語是灰，                                         |
| 14舌即是木酌 15心供牺火处                                    | 舌頭是獻祭的杓子、心是祭祀的火爐，                           |
| 16善以自调顺 17始为是人火                                    | 善調御的自我是男子的火。                                     |
| 18婆罗门有戒 19渡津法之湖                                    | 婆羅門！法是具有戒為渡場的湖，                               |
| 20澄清无染污 21常为善人赞                                    | 不濁的、被善人們對善人們稱讚，                               |
| 22圣者来此浴                                                 | 於該處沐浴的通曉吠陀者們，                                   |
| 23体清渡彼岸                                                 | 就肢體不濕地渡過彼岸。                                       |
| 24真实与正法 25自制是梵行                                    | 真理、法、[自我]抑制、梵行，                                 |
| 26婆罗门依此 27中道得最胜                                    | 婆羅門！在中間依止者有梵的到達，                             |
| 28直心者归命                                                 | 請你對那位已成為正直者作禮敬，                               |
| 29我谓此等人 30为随法行者                                    | 我說那人是『法之行者』。」                                   |
| 如是言已，孙陀利迦婆罗堕婆阇婆罗门，以此白世尊曰：           | 在這麼說時，孫陀利葛婆羅墮若婆羅門對世尊說這個：             |
| ‘世尊!是最胜者……乃至……’                                      | 「太偉大了，喬達摩尊師！……（中略）。」                       |
| 又，此婆罗堕婆阇婆罗门，成为一阿罗汉。                       | 然後尊者婆羅墮若成為眾阿羅漢之一。                           |
