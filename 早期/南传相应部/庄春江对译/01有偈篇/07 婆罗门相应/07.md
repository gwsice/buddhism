| 第七 净者                                                    | 7.概要經                                                     |
| [尔时，世尊]住舍卫城……                                       | 起源於舍衛城。                                               |
| 时，净者婆罗堕婆阇婆罗门，诣世尊处。诣而与世尊互相致问，坐于一面。 | 那時，純淨婆羅墮若婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 坐一面之净者婆罗堕婆阇婆罗门，于世尊处，语此偈曰：           | 在一旁坐下的純淨婆羅墮若婆羅門在世尊的面前說這偈頌：         |
| 2世间之如何 3婆罗门不清                                      | 「世間中任何婆羅門都不變純淨，                               |
| 1虽持戒苦行                                                  | 即使是持戒者、實踐(作)苦行者，                               |
| 4明行具足者                                                  | 明行具足者，                                                 |
| 5唯此是清净 6其外无净者                                      | 他變純淨-非別的其他人。」                                    |
| [世尊：]                                                     |                                                              |
| 1虽多唱驮咒                                                  | 「即使許多無用咒的呢喃者，                                   |
| 4非生婆罗门                                                  | 婆羅門也不是以出生，                                         |
| 2埃满内不净                                                  | 成為內部有污濁者、污染者，                                   |
| 3外依于欺瞒                                                  | 依靠詭計者。                                                 |
| 5譬如刹帝利 6婆罗门毗舍                                      | 剎帝利、婆羅門、毘舍，首陀羅，                               |
| 7首陀旃陀罗 8下水清扫人                                      | 旃陀羅、清垃圾者，                                           |
| 9精勤而不挠                                                  | 活力已發動者、自我努力者，                                   |
| 10常勇猛精进                                                 | 常堅固努力者，                                               |
| 11达最胜清净                                                 | 得到最高的純淨，                                             |
| 12知此婆罗门                                                 | 婆羅門！請你這麼知道。」                                     |
| 如是言已，净者婆罗堕婆阇婆罗门，以此白世尊曰：               | 在這麼說時，純淨婆羅墮若婆羅門對世尊說這個：                 |
| ‘世尊!是最胜者……乃至……’                                      | 「太偉大了，喬達摩尊師！……（中略）。」                       |
| 又，此婆罗堕婆阇，成为一阿罗汉。                             | 然後尊者婆羅墮若成為眾阿羅漢之一。                           |
