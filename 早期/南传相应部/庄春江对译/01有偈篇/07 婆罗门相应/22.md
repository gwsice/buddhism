| 第十二 库摩都萨邑                                            | 22. 摳麼度色經                                               |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住释迦族之库摩都萨邑。                             | 有一次，世尊住在釋迦族中，名為摳麼度色(亞麻布)釋迦族的城鎮。 |
| 时，世尊清晨，着衣持钵，入库摩都萨乞食。                     | 那時，世尊午前時穿衣、拿起衣鉢後，為了托鉢進入摳麼度色城。   |
| 其时，库摩都萨邑之婆罗门与家主等，因事而集聚于集会堂。雨绵绵下降。 | 當時，摳麼度色的婆羅門屋主們正以某些應該被作的被集合在集會所，而天空下著毛毛雨。 |
| 时，世尊来到其集会堂。                                       | 那時，世尊去那個集會所。                                     |
| 库摩都萨婆罗门与家主等，见世尊从远而来。见而言曰：           | 摳麼度色的婆羅門屋主們看見正從遠處到來的世尊。看見後說這個： |
| ‘彼秃头沙门等是谁耶?彼等何以不知集会法耶?’                   | 「誰是禿頭假沙門？以及誰將知道集會所之法？」                 |
| 时世尊以偈谓语库摩都应婆罗门家主等曰：                       | 那時，世尊以偈頌對摳麼度色的婆羅門屋主們說：                 |
| 1无善人之处 2并非是集会                                      | 「沒有善人們處這不是集會所，                                 |
| 4并非是善人 3语不如法者                                      | 他們不是善人-凡不說法，                                      |
| 5若以灭贪欲 6嗔恚与愚痴                                      | 捨斷貪瞋癡後，                                               |
| 7能语于如法 8始称为善人                                      | 而說法者們是善人。」                                         |
| 如是言已，库摩都萨婆罗门家主等，以此白世尊曰：               | 在這麼說時，摳麼度色的婆羅門屋主們對世尊說這個：             |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者霍昙从今日以后，受我等终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！喬達摩尊師！猶如扶正顛倒的，或揭開隱藏的，或告知迷路者的道路，或在黑暗中持燈火：『有眼者們看見諸色。』 |
|                                                              | 同樣的，法被喬達摩尊師以種種法門說明。這些我們歸依喬達摩尊師、法、比丘僧團，請喬達摩尊師記得我們為優婆塞，從今天起已終生歸依。」 |
