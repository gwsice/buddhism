| 第七 木匠                                                    | 17.監工經                                                    |
| 尔时，世尊住拘萨罗国之森林。                                 | 有一次，世尊住在憍薩羅國某處叢林中。                         |
| 其时，木匠婆罗堕婆阇婆罗门，亦因事入此森林。                 | 當時，監工婆羅墮若婆羅門在那處叢林中使(人)作工作。           |
| 木匠婆罗堕婆阇婆罗门，见世尊于沙罗树下趺坐，身正直，树立正念而坐。见而如是思念： | 監工婆羅墮若婆羅門看見在某棵沙羅樹下坐下，盤腿、定置端直的身體、建立面前的念後的世尊。看見後，想這個： |
| ‘我为来此森林工作而快乐。此沙门瞿昙，何为而乐耶?’            | 「我在這處叢林中樂於使作的工作，這位沙門喬達摩樂於使作的什麼？」 |
| 时，木匠婆罗堕婆阇婆罗门诣世尊之处。诣而以偈白世尊曰：       | 那時，監工婆羅墮若婆羅門去見世尊。抵達後，以偈頌對世尊說：   |
| 1比丘汝于此 2沙罗树森林                                      | 「比丘！在沙羅林中你的，                                     |
| 3以为何事耶                                                  | 什麼工作被作呢？                                             |
| 4唯独于森林                                                  | 凡單獨在林野中，                                             |
| 5瞿昙有何乐                                                  | 喬達摩發現喜樂？」                                           |
| [世尊：]                                                     |                                                              |
| 1我独在森林 2以行所应行                                      | 「樹林中沒有應該被我作的，                                   |
| 3一切森或丛 4皆是我所断                                      | 根已被切斷-我的樹林已枯萎，                                  |
| 5然我于森林 6无有烦恼系 7亦无刺所刺                          | 那個我在林中是無稠林的、無箭的，                             |
| 8独乐拂不满                                                  | 捨斷不樂後單獨的我喜樂。」                                   |
| 如是言已，木匠婆罗堕婆阇婆罗门，以此白世尊曰：               | 在這麼說時，監工婆羅墮若婆羅門對世尊說這個：                 |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依做优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
