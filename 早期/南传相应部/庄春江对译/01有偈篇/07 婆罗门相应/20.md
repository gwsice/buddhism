| 第十 乞食                                                    | 20. 乞食者經                                                 |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时乞食婆罗门，来诣世尊之处。诣而与世尊互相致问，坐于一面。   | 那時，乞食者婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。 |
| 一面坐之乞食婆罗门，以此白世尊曰：                           | 在一旁坐下的乞食者婆羅門對世尊說這個：                       |
| ‘尊者瞿昙!我亦乞食者。尊者亦乞食者。于此则无何差异。’        | 「喬達摩尊師！我是乞食者，尊師也是乞食者，這裡，有什麼差別？」 |
| [世尊：]                                                     |                                                              |
| 2并非是比丘                                                  | 「不因為那樣是乞食者：                                       |
| 1唯作乞他食                                                  | 只對他人乞食的程度，                                         |
| 3执持恶臭法                                                  | 受持在家法後，                                               |
| 4并非是比丘                                                  | 只那些他就不是乞食者(比丘)。                                 |
| 5功德恶舍去                                                  | 凡這裡福德與惡，                                             |
| 7以修梵行者                                                  | 拒斥後有梵行，                                               |
| 6依智慧于世                                                  | 考量後在世間中行，                                           |
| 8是名为比丘                                                  | 他確實被稱為『乞食者(比丘)』。」                             |
| 如是言已，乞食婆罗门，以此白世尊曰：                         | 在這麼說時，乞食者婆羅門對世尊說這個：                       |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙从今日以后，受我终生归依做优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
