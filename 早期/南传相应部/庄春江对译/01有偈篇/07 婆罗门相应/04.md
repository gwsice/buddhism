| 第四 毗兰耆迦                                                | 4.酸粥經                                                     |
| 尔时，世尊住舍卫城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 毗兰耆迦婆罗堕婆阇婆罗门，                                   | 酸粥婆羅墮若婆羅門聽聞：                                     |
| 闻婆罗堕婆阇姓之婆罗门，于沙门瞿昙座前，由家[出]无家而出家。 | 「聽說婆羅墮若姓婆羅門在沙門喬答摩面前從在家出家成為無家者。」 |
| 忿怒不喜，来诣世尊处。诣已，默然而立一面。                   | 生氣、不悅意地去見世尊。抵達後，沈默地在一旁站立。           |
| 时，世尊知毗兰耆迦婆罗堕婆阇婆罗门心之所念，以偈告毗兰耆迦婆罗堕婆阇婆罗门曰： | 那時，世尊以心了知酸粥婆羅墮若婆羅門心中的深思後，以偈頌對酸粥婆羅墮若婆羅門說： |
| 2以污无垢人                                                  | 「凡對無過誤的人發怒：                                       |
| 1清净无秽恶                                                  | 對純淨的、無污穢的人，                                       |
| 3恶还其愚人                                                  | 惡就回到那位愚者，                                           |
| 4逆风撒细尘                                                  | 如細塵被逆風地拋出。」                                       |
| 如是言已，毗兰耆迦婆罗堕婆阇婆罗门，以此白世尊曰：           | 在這麼說時，酸粥婆羅墮若婆羅門對世尊說這個：                 |
| ‘世尊!是最胜者。世尊!是最胜者。我今归依世尊瞿昙、法、僧伽。愿于世尊处得出家及具足戒。’乃至……‘知生已尽，梵行已立，所作已办，不受后有。’又此婆罗堕婆阇婆罗门，成为一阿罗汉。 | 「太偉大了，喬達摩尊師！……（中略）他證知：……然後尊者婆羅墮若成為眾阿羅漢之一。」 |
