| 第七 婆罗门相应                                              | 7.婆羅門相應                                                 |
| 第一 阿罗汉品                                                | 1.阿羅漢品                                                   |
| 第一 陀然阇仁                                                | 1. 大那若尼經                                                |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住王舍城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 其时，有婆罗堕婆阇姓之婆罗门妻，名陀然阇仁，信乐佛、法、僧。 | 當時，某位婆羅墮若姓婆羅門的妻子，名叫大那若尼婆羅門女，對佛、法、僧是極淨信者。 |
| 时，陀然阇仁，将近于运食与婆罗堕婆阇姓之婆罗门，发三次之欢喜语： | 那時，大那若尼婆羅門女為婆羅墮若姓婆羅門帶來食物，絆倒後吟出優陀那三次： |
| ‘归命彼世尊、应供、正等觉者……乃至……归命彼世尊、应供、正等觉者。’ | 「對那位世尊、阿羅漢、遍正覺者禮敬，對那位世尊、阿羅漢、遍正覺者禮敬，對那位世尊、阿羅漢、遍正覺者禮敬。」 |
| 如是言已，婆罗堕婆阇姓之婆罗门，以此谓陀然阇仁曰：           | 在這麼說時，婆羅墮若姓婆羅門對大那若尼婆羅門女說這個：       |
| ‘此卖女不论何时、常语彼秃头沙门之功德。                      | 「就像這樣，而這位女賤民在每一個場合都稱讚那位禿頭沙門，     |
| 卖女!今我应论破汝师。’                                       | 女賤民！現在，我將論破你的那位老師(使登上你那位老師的論說)。」 |
| ‘否也!婆罗门!包含世界于天界、魔界、梵天界，包含沙门、婆罗门人天之众中，不见得能论破我彼世尊、应供、正等觉者。 | 「婆羅門！我不見那個：在包括天，在包括魔，在包括梵的世間；在包括沙門婆羅門，在包括天-人的世代中能論破那位世尊、阿羅漢、遍正覺者的， |
| 然则，汝婆罗门!去!去即当自知。’                              | 婆羅門！但你去吧！去了後你必將了知。」                       |
| 时，婆罗堕婆阇之婆罗门、忿怒不喜而诣世尊处。                 | 那時，婆羅墮若姓婆羅門生氣、不悅意地去見世尊。抵達後，與世尊一起互相問候。 |
| 诣已，与世尊相致问交谈而坐一面。坐一面之婆罗堕婆阇姓婆罗门，以偈言世尊曰： | 交換應該被互相問候的友好交談後，在一旁坐下。在一旁坐下的婆羅墮若姓婆羅門以偈頌對世尊說： |
| 1杀何物乐寝                                                  | 「切斷什麼後睡得安樂呢？                                     |
| 2杀何物不悲                                                  | 切斷什麼後不憂愁呢？                                         |
| 3杀害何一法                                                  | 對哪一法的殺害，                                             |
| 4瞿昙卿赞叹                                                  | 喬達摩同意呢？」                                             |
| [世尊：]                                                     |                                                              |
| 1杀忿是乐寝                                                  | 「切斷憤怒後睡得安樂，                                       |
| 2杀忿无有悲                                                  | 切斷憤怒後不憂愁，                                           |
| 4以为最上蜜                                                  | 婆羅門！對端為蜜，                                           |
| 3婆罗门毒根                                                  | 對根為毒的憤怒，                                             |
| 6圣者是赞赏 5忿怒之杀害                                      | 聖者們稱讚殺害，                                             |
| 7如是之杀法 8其杀无有悲                                      | 因為切斷它後不憂愁。」                                       |
| 如是言已，婆罗堕婆阇姓之婆罗门，以此白世尊曰：               | 在這麼說時，婆羅墮若姓婆羅門對世尊說這個：                   |
| ‘瞿昙!是最胜。瞿昙是最胜。瞿昙!犹如令倒者起，覆者显露，示迷者以道，如有眼者得见物形，如闇中之灯明， | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！喬達摩尊師！猶如扶正顛倒的，或揭開隱藏的，或告知迷路者的道路，或在黑暗中持燈火：『有眼者們看見諸色。』 |
| 如是瞿昙请调种种法。我归命世尊瞿昙、法、僧伽。我得于世尊瞿昙之处出家及具足戒!’ | 同樣的，法被喬達摩尊師以種種法門說明。大德！這個我歸依喬達摩尊師、法、比丘僧團，願我得到在喬達摩尊師的面前出家，願我得到具足戒。」 |
| 婆罗堕婆阇姓之婆罗门，得于世尊之处出家及具足戒。             | 婆羅墮若姓婆羅門得到在世尊的面前出家，得到具足戒。           |
| 得具足戒不久，尊者婆罗堕婆阇，单独隐栖，不放逸、虔诚、精勤而住，彼正是良家之子，为成就无上梵行，由家[出]无家而出家，于现法得入自知自证。 | 還有，已受具足戒不久，住於單獨的、隱離的、不放逸的、熱心的、自我努力的尊者婆羅墮若不久就以證智自作證後，在當生中進入後住於凡善男子們為了利益正確地從在家出家成為無家者的那個無上梵行結尾， |
| ‘知生已尽，梵行已立，所作已办，不受后有。’于此婆罗堕婆阇，成为一阿罗汉。 | 他證知：「出生已盡，梵行已完成，應該被作的已作，不再有此處[輪迴]的狀態。」然後尊者婆羅墮若成為眾阿羅漢之一。 |
