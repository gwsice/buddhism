| 第五 不害                                                    | 5.無害經                                                     |
| 舍卫城因缘。                                                 | 起源於舍衛城。                                               |
| 时，不害婆罗堕婆阇婆罗门，来诣世尊处。诣而与世尊互相致问，坐于一面。坐一面之不害婆罗堕婆阇婆罗门，以此白世尊曰： | 那時，無害婆羅墮若婆羅門去見世尊。抵達後，與世尊一起互相問候。交換應該被互相問候的友好交談後，在一旁坐下。在一旁坐下的無害婆羅墮若婆羅門對世尊說這個： |
| ‘瞿昙!我是不害。瞿昙!我是不害。’                             | 「喬達摩尊師！我是無害；喬達摩尊師！我是無害。」             |
| [世尊：]                                                     |                                                              |
| 1若如其名者                                                  | 「而像這樣如果你是如名字，                                   |
| 2汝实为不害                                                  | 你是無害者，                                                 |
| 4身口以及心                                                  | 凡以身與以語，                                               |
| 3然而不害于                                                  | 以及意不傷害，                                               |
| 6始名实不害                                                  | 他確實是無害者：                                             |
| 5以不害他者                                                  | 凡不傷害他人。」                                             |
| 如是言已，不害婆罗堕婆阇婆罗门，以此白世尊曰：               | 在這麼說時，無害婆羅墮若婆羅門對世尊說這個：                 |
| ‘瞿昙!是最胜者……乃至……又此婆罗堕婆阇，成为一阿罗汉。         | 「太偉大了，喬達摩尊師！……（中略）他證知：……然後尊者婆羅墮若成為眾阿羅漢之一。」 |
