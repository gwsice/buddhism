| 第二 优婆塞品                                                | 2.優婆塞品                                                   |
| 第一 耕田                                                    | 11.耕作婆羅墮若經                                            |
| 如是我闻。                                                   | 被我這麼聽聞：                                               |
| 尔时，世尊住摩揭陀国南山一苇婆罗门村。                       | 有一次，世尊住在摩揭陀國南山一蘆葦[地方]的婆羅門村落。       |
| 时，又有耕田婆罗堕婆阇婆罗门，于播种时，装五百犁具。         | 當時是在播種時節，耕作婆羅墮若婆羅門有約五百具上軛的犁。     |
| 时，世尊清晨着衣持钵，到耕田婆罗堕婆阇婆罗门之农作场。       | 那時，世尊午前時穿衣、拿起衣鉢後，去耕作婆羅墮若婆羅門工作處。 |
| 时，耕田婆罗堕婆阇婆罗门，为分配食物与予于诸人。时，世尊到分配食物处，而立一面。 | 當時，進行(轉起)耕作婆羅墮若婆羅門的食物分配。那時，世尊去食物分配處。抵達後，在一旁站立。 |
| 耕田婆罗堕婆阇婆罗门，见世尊为乞食而立。见而言世尊曰：       | 耕作婆羅墮若婆羅門看見為食物站立的世尊。看見後，對世尊說這個： |
| ‘沙门!我乃耕种。耕种而食。                                   | 「沙門！我耕作與播種，耕作與播種後我食用。                   |
| 沙门!汝亦须耕种，耕种而得食。’                               | 沙門！也請你自己耕作與播種，耕作與播種後你自己食用。」       |
| ‘婆罗门!我亦耕种。耕种而食。’                                | 「婆羅門！我也耕作與播種，耕作與播種後我食用。」             |
| ‘然则!我等未见尊瞿昙之轭、锄、犁、镵、刺棒、牡牛。而且尊者瞿昙作如是言：‘婆罗门!我亦耕种、耕种而食。’’ | 「我們確實沒看到喬達摩尊師的軛，或犁，或鋤，或刺棒，或牛，然而喬達摩尊師卻說這個：『婆羅門！我也耕作與播種，耕作與播種後我食用。』」 |
| 时，耕田婆罗堕婆阇婆罗门，以偈白世尊曰：                     | 那時，耕作婆羅墮若婆羅門以偈頌對世尊說：                     |
| 1汝自云农夫                                                  | 「你自稱耕作者，                                             |
| 2我不见汝耕                                                  | 但我們不見你的耕作，                                         |
| 3我问农夫语                                                  | 請你說被我們質問的耕作，                                     |
| 4何知我等耕                                                  | 如是我們知道你的耕作。」                                     |
| [世尊：]                                                     |                                                              |
| 1信仰是种子 2锻炼是甘雨                                      | 「信為種子苦行為雨，                                         |
| 3智慧轭为锄                                                  | 慧為我的軛和犁，                                             |
| 4惭乃为其柄 5定为是其绳$$\color{red}（定还是意？）$$         | 慚為轅桿、意為繫繩，                                         |
| 6正念我犁镵 7乃至为刺棒                                      | 念為我的鋤、刺棒。                                           |
| 8守身及守语                                                  | 身已被守護、語已被守護，                                     |
| 9以知食之量                                                  | 胃裡的食物已被抑制，                                         |
| 10以信免割草                                                 | 我執行(作)真理為割草，                                       |
| 11乐道我休息                                                 | 柔和是我的脫離。                                             |
| 12精进乃我负 13重荷立牡牛                                    | 活力是我的負載牛：                                           |
| 14瑜伽运安稳                                                 | 軛安穩的帶來者，                                             |
| 15行而无有归                                                 | 牠不折返地走，                                               |
| 16行前亦无悲$$\color{red}（后还是前？）$$                    | 走到後於該處不悲傷。                                         |
| 17如是我耕耘                                                 | 這位耕作者像這樣耕作，                                       |
| 18不死是果实                                                 | 他有不死之果，                                               |
| 19以为此耕耘                                                 | 耕作這個耕作後，                                             |
| 20我悉脱苦恼                                                 | 從一切苦被釋放。」                                           |
| ‘尊者瞿昙且请受食。尊者瞿昙农夫。瞿昙之耕耘，乃为不死果。’   | 「請喬達摩尊師食用，尊師是耕作者：凡因為喬達摩尊師耕作不死之果的耕作。」 |
| [世尊：]                                                     |                                                              |
| 1唱偈非为食                                                  | 「偈頌吟誦[得]的不應該被我吃，                               |
| 2婆罗门有此 3知见者非法                                      | 婆羅門！這不是看見者的法，                                   |
| 4诸佛之唱偈 5责斥等价值                                      | 諸佛拒絕偈頌吟誦的，                                         |
| 6婆罗门住法 7唯此生活道                                      | 婆羅門！在法存在時這是行為模式。                             |
| 10完满大圣者                                                 | 而對圓滿的大仙，                                             |
| 8诸漏悉皆尽 9后悔之行静                                      | 對漏已滅盡者、惡作已平息者，                                 |
| 11以事奉饮食                                                 | 請你以其它食物飲料侍奉，                                     |
| 12为求功德田                                                 | 因為那是期待福德者的田地。」                                 |
| 如是言已，耕田婆罗堕婆阇婆罗门，以此白世尊曰：               | 在這麼說時，耕作婆羅墮若婆羅門對世尊說這個：                 |
| ‘瞿昙!是最胜者。瞿昙!是最胜者。瞿昙!喻倒者起，覆者露。示道于迷者，如暗中揭灯明，有眼者得见诸形。如是尊者瞿昙说种种法。我今归依世尊、法、僧伽。愿尊者瞿昙，纳受我今日以后，终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）從今天起已終生歸依。」     |
