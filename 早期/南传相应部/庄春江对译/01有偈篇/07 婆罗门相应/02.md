| 第二 谗谤                                                    | 2. 辱罵經                                                    |
| 尔时，世尊住舍卫城竹林栗鼠养饵所。                           | 有一次，世尊住在王舍城栗鼠飼養處的竹林中。                   |
| 谗谤婆罗堕婆阇婆罗门，                                       | 辱罵婆羅墮若婆羅門聽聞：                                     |
| 闻婆罗堕婆阇婆罗门于沙门瞿昙之处，由家[出]无家而出家。       | 「聽說婆羅墮若姓婆羅門在沙門喬答摩面前從在家出家成為無家者。」 |
| 忿怒不喜，来诣世尊处。诣已，以激烈恶语谗谤、非难世尊。       | 生氣、不悅意地去見世尊。抵達後，以無禮的、粗惡的言語責罵、誹謗世尊。 |
| 作如是言已，世尊于此告谗谤婆罗堕婆阇婆罗门曰：               | 在這麼說時，世尊對辱罵婆羅墮若婆羅門說這個：                 |
| ‘婆罗门!汝如何思惟耶?有朋友亲戚骨肉者、客等来造访汝否?’      | 「婆羅門！你怎麼想它：你的朋友、同事、親族、血親、客人們是否到來呢？」 |
| ‘唯然，瞿昙!时常有朋友亲戚骨肉者、客等来造访我。’            | 「喬達摩尊師！有時我的朋友、同事、親族、血親、客人到來。」   |
| ‘婆罗门!汝如何思惟耶?汝予与彼等坚食、软食及美食否?’          | 「婆羅門！你怎麼想它：是否你提供他們硬食或軟食或美食呢？」   |
| ‘唯然，瞿昙!我时常与彼等坚食、软食及美食。’                  | 「喬達摩尊師！有時我提供他們硬食或軟食或美食。」             |
| ‘婆罗门!若彼等不受者，则将成为谁之物耶?’                     | 「婆羅門！但，如果他們不領受，那個是誰的呢？」               |
| ‘瞿昙!若彼等不受者，彼等食物当属我者。’                      | 「喬達摩尊師！如果他們不領受，那個還是我們的。」             |
| ‘婆罗门!如是汝谗谤不应谗谤我，诽谤不应诽谤我，非难不应非难我。我不受汝之此等。婆罗门!彼则是汝之物。 | 「同樣的，婆羅門！凡你辱罵、激怒、爭論不辱罵、不激怒、不爭論的我們，我們不要領受你的那個，婆羅門！那個還是你的；婆羅門！那個還是你的。 |
| 谗谤返还其谗谤者，诽谤返还其诽谤者，非难返还其非难者。婆罗门!此谓[主客]共食 、共来往。我不与汝共食、共来往。婆罗门!此是汝物。婆罗门!此是汝物。’ | 婆羅門！凡回罵辱罵者，回激激怒者，回爭爭論者，婆羅門！這被稱為『一起吃；交換。』那些我們既不與你一起吃，也不與你交換，婆羅門！那個還是你的；婆羅門！那個還是你的。」 |
| ‘王与王臣今如是知尊者瞿昙：‘沙门瞿昙是应供者，然瞿昙亦将怒。’’ | 「包括國王的群眾這麼知道喬達摩尊師：『沙門喬達摩是阿羅漢。』然而喬達摩尊師生氣。」 |
| [世尊：]                                                     |                                                              |
| 1无忿自调御 2是为正生活                                      | 「從哪裡有憤怒：對無憤怒者、已調御者、正確生活者，           |
| 3有正智解脱                                                  | 對以完全智解脫者，                                           |
| 4寂静如是人                                                  | 對像這樣的寂靜者？                                           |
| 7更为是恶事                                                  | 對他以那個只是更糟的：                                       |
| 5忿由何处起 6以忿还忿者                                      | 凡對生氣者回生氣，                                           |
| 8不以忿还忿                                                  | 對生氣者不回生氣者，                                         |
| 9战得二胜利                                                  | 打勝難勝利的戰鬥。                                           |
| 13皆行于利益                                                 | 行兩者的利益：                                               |
| 12自及他两方                                                 | 自己的與對方的，                                             |
| 10知他之所忿                                                 | 知道對方被激怒後，                                           |
| 11静己正念人                                                 | 凡具念地平靜下來。                                           |
| 15两方之医师                                                 | 對兩者的治療者：                                             |
| 14彼乃自与他                                                 | 自己的與對方的，                                             |
| 17以此为愚人                                                 | 人們認為『是愚者』：                                         |
| 16于法无知者                                                 | 凡法的不熟知者。                                             |
| 如是言已，谗谤婆罗堕婆阇婆罗门如是白世尊曰：                 | 在這麼說時，辱罵婆羅墮若婆羅門對世尊說這個：                 |
| ‘世尊!是最胜。……乃至……我今归依世尊瞿昙、法、僧伽。愿于世尊瞿昙座下出家得具足戒。’ | 「太偉大了，喬達摩尊師！……（中略）這個我歸依喬達摩尊師、法、比丘僧團，願我得到在喬達摩尊師的面前出家，願我得到具足戒。」 |
| 谗谤婆罗堕婆阇婆罗门，得于世尊之处出家及具足戒。             | 那時，辱罵婆羅墮若婆羅門得到在世尊的面前出家、受具足戒。     |
| 又，尊者谗谤婆罗堕婆阇婆罗门得具足戒不久，单独隐栖，不放逸、虔诚、精勤而住。 | 還有，已受具足戒不久，住於單獨的、隱離的、不放逸的、熱心的、自我努力的尊者辱罵婆羅墮若不久就以證智自作證後， |
| 彼正是良家之子，为成就梵行，由家[出]无家而出家，于现法得入自知、自证。 | 在當生中進入後住於凡善男子們為了利益正確從在家出家成為無家者的那個無上梵行結尾， |
| ‘知生已尽，梵行已立，所作已办，不受后有。’又，此婆罗堕婆阇婆罗门，为一阿罗汉。 | 他證知：「出生已盡，梵行已完成，應該被作的已作，不再有此處[輪迴]的狀態。」然後尊者辱罵婆羅墮若成為眾阿羅漢之一。 |
