| 第二 优陀耶                                                  | 12. 優達亞經                                                 |
| 舍卫国因缘。                                                 | 起源於舍衛城。                                               |
| 时，世尊清晨，着衣持钵，到优陀耶婆罗门之住家。               | 那時，世尊午前時穿衣、拿起衣鉢後，去優達亞婆羅門的住處。     |
| 时，优陀耶婆罗门，以白饭盛满世尊之钵。                       | 那時，優達亞婆羅門以米飯使世尊的鉢充滿。                     |
| 第二次世尊清晨着衣持钵，到优陀耶婆罗门家，……乃至……           | 第二次，世尊午前時穿衣、拿起衣鉢後，又去優達亞婆羅門的住處。……（中略） |
| 第三次优陀耶婆罗门，以白饭盛满世尊之钵，而言曰：             | 第三次，優達亞婆羅門又以米飯使世尊的鉢充滿後，對世尊說這個： |
| ‘甚烦!沙门瞿昙勿屡次、屡次来。’                              | 「這位討厭的沙門喬達摩一再地到來。」                         |
| [世尊：]                                                     |                                                              |
| 1屡屡播种子                                                  | 「但就一再地播種種子，                                       |
| 2屡屡降天雨                                                  | 天王一再地下雨，                                             |
| 3屡屡耕农田                                                  | 耕作者們一再地耕田，                                         |
| 4屡屡谷类实                                                  | 穀物一再地來到國家。                                         |
| 5屡屡乞食食                                                  | 乞求者們一再地乞求，                                         |
| 6屡施施主食                                                  | 施主們一再地施與，                                           |
| 7屡屡施主施                                                  | 施主們一再地施與後，                                         |
| 8屡屡行天界                                                  | 一再地來到天界處。                                           |
| 9屡屡榨牛乳                                                  | 一再地對有乳的牛擠奶，                                       |
| 10屡求犊母牛                                                 | 仔牛一再地來到母親，                                         |
| 11屡屡疲劳苦                                                 | 一再地疲倦與顫抖，                                           |
| 12愚者屡入胎                                                 | 愚鈍者一再地來到母胎。                                       |
| 13屡屡于生死                                                 | 一再地被生與死亡，                                           |
| 14屡屡送墓场                                                 | 他們一再地帶去墓場，                                         |
|                                                              | 但得到不再有之道後，                                         |
|                                                              | 廣慧者不一再地被生。」                                       |
| 如是言已，优陀耶婆罗门，以此白世尊曰：                       | 在這麼說時，優達亞婆羅門對世尊說這個：                       |
| ‘尊者瞿昙!是最胜者……乃至……愿尊者瞿昙容纳我，从今日以后，终生归依为优婆塞。’ | 「太偉大了，喬達摩尊師！……（中略）請喬達摩尊師記得我為優婆塞，從今天起已終生歸依。」 |
