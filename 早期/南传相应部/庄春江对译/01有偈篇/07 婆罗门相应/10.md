| 第十 婆富提低                                                | 10.許多女兒經                                                |
| 尔时，世尊住拘萨罗国之繁茂森林。                             | 有一次，世尊住在憍薩羅國某處叢林中。                         |
| 时，婆罗堕婆阇姓婆罗门有十四头牛，去处不明。                 | 當時，某位婆羅墮若姓婆羅門的十四頭公牛被遺失了。             |
| 时，婆罗堕婆阇姓婆罗门，寻牛至森林。                         | 那時，當婆羅墮若姓婆羅門尋找那些公牛時，來到那處叢林。       |
| 至而见世尊，趺坐身正直，树立正念，坐于繁茂森林。             | 抵達後，看見在那處叢林中坐下，盤腿、定置端直的身體、建立面前的念後的世尊。 |
| 见已诣世尊处，诣而于世尊前白此偈曰：                         | 看見後，去見世尊。抵達後，在世尊的面前以這些偈頌說：         |
| 1于此沙门失                                                  | 「這位沙門確實沒有，                                         |
| 2十四头之牛                                                  | 十四頭公牛，                                                 |
| 3至今寻六日 4如无有不得                                      | 今日第六天沒被看見，                                         |
| 5然而此沙门 6是为最安乐                                      | 因此這位沙門是快樂者。                                       |
| 7于此沙门撒                                                  | 這位沙門確實沒有，                                           |
| 8菜种于菜田 9收获之最恶                                      | 壞的[芝麻株]在芝麻田中，                                     |
| 10非一茎二茎                                                 | [剩]一葉與二葉，                                             |
| 11然而此沙门 12是为最安乐                                    | 因此這位沙門是快樂者。                                       |
| 13于此沙门之                                                 | 這位沙門確實沒有，                                           |
| 15鼠盛于其中 14谷仓尽而空                                    | 老鼠在空穀倉中，                                             |
| 16无有如踊跃                                                 | 熱烈地跳舞，                                                 |
| 17然而此沙门 18是为最安乐                                    | 因此這位沙門是快樂者。                                       |
| 19于此沙门敷                                                 | 這位沙門確實沒有，                                           |
| 20席之尽七月                                                 | 敷具七個月，                                                 |
| 21如未满蚤虱                                                 | 被跳蚤覆蓋，                                                 |
| 22然而此沙门 23是为最安乐                                    | 因此這位沙門是快樂者。                                       |
| 24于此沙门有                                                 | 這位沙門確實沒有，                                           |
| 26亦有女七人 27非如成寡妇                                    | 七個寡婦女兒，                                               |
| 25一儿及二儿                                                 | 一個兒子與二個兒子，                                         |
| 28然而此沙门 29是为最安乐                                    | 因此這位沙門是快樂者。                                       |
| 30于此沙门末                                                 | 這位沙門確實沒有，                                           |
| 31蹴褐色黑白                                                 | 被黃褐色斑點侵襲女(黃臉婆)，                                 |
| 32斑点妇眠足                                                 | 以腳使睡覺者醒來，                                           |
| 33然而此沙门 34是为最安乐                                    | 因此這位沙門是快樂者。                                       |
| 35于此沙门无                                                 | 這位沙門確實沒有，                                           |
| 36朝等取欠债                                                 | 債權人在黎明時，                                             |
| 37还还以立责                                                 | 斥責『請你給、請你給』，                                     |
| 38然而此沙门 39是为最安乐                                    | 因此這位沙門是快樂者。」                                     |
| [世尊：]                                                     |                                                              |

| 2失牛十四头                                                  | 十四頭公牛，                                                 |

| 7婆罗门于我                                                  | 婆羅門！我確實沒有，                                         |

| 10非一茎二茎                                                 | 一葉與二葉，                                                 |
| 11然而婆罗门 12我为最安乐                                    | 婆羅門！因此我是快樂者。                                     |
| 13婆罗门于我                                                 | 婆羅門！我確實沒有，                                         |
| 15鼠盛于其中 14谷仓尽而空                                    | 老鼠在空穀倉中，                                             |
| 16无有如踊跃                                                 | 熱烈地跳舞，                                                 |
| 17然而婆罗门 18我为最安乐                                    | 婆羅門！因此我是快樂者。                                     |
| 19婆罗门于我                                                 | 婆羅門！我確實沒有，                                         |
| 20敷席尽七月                                                 | 敷具七個月，                                                 |

| 24婆罗门于我                                                 | 婆羅門！我確實沒有，                                         |

| 31无蹴褐黑白                                                 | 被黃褐色斑點侵襲女，                                         |
| 32斑点妇眠足                                                 | 以腳使睡覺者醒來，                                           |
| 33然而婆罗门 34我为最安乐                                    | 婆羅門！因此我是快樂者。                                     |

| 如是言已，婆罗堕婆阇婆罗门，以此白世尊曰：                   | 在這麼說時，婆羅墮若姓婆羅門對世尊說這個：                   |
| ‘瞿昙!是最胜者，瞿昙!是最胜者。瞿昙!犹如起倒者，显覆者，示道于迷者，如有眼者，得见物见形，如暗揭灯明。 | 「太偉大了，喬達摩尊師！太偉大了，喬達摩尊師！喬達摩尊師！猶如扶正顛倒的，或揭開隱藏的，或告知迷路者的道路，或在黑暗中持燈火：『有眼者們看見諸色。』 |
| 如是尊者瞿昙种种说法。我今归依世尊、法、僧伽。愿于尊者瞿昙之处，得出家及具足戒。’ | 同樣的，法被喬達摩尊師以種種法門說明。這個我歸依喬達摩尊師、法、比丘僧團，願我得到在喬達摩尊師的面前出家，願我得到具足戒。」 |
|                                                              | 婆羅墮若姓婆羅門得到在世尊的面前出家，得到具足戒。           |
| 婆罗堕婆阇婆罗门，得具足戒不久，单独隐栖，不放逸，虔诚、精勤不久， | 還有，已受具足戒不久，住於單獨的、隱離的、不放逸的、熱心的、自我努力的尊者婆羅墮若不久就以證智自作證後， |
| 良家之子，成就清净梵行，由家[出]无家而出家，入于自知自证。   | 在當生中進入後住於凡善男子們為了利益正確地從在家出家成為無家者的那個無上梵行結尾， |
| ‘知生已尽，梵行已立，所作已办，不受后有。’又尊者婆罗堕婆阇，成为一阿罗汉。 | 他證知：「出生已盡，梵行已完成，應該被作的已作，不再有此處[輪迴]的狀態。」然後尊者婆羅墮若成為眾阿羅漢之一。 |
