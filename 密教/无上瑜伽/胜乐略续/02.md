（壬五）隐身等七事业及摄受：

```
于护摩之灰念诵百遍，凡所击者，诸天亦不能见。于水诵百遍而施者能复现。颅骨扣合，于息未出间诠说彼名彼即疯狂，亦能令千有情疯狂。以意令解脱。诠说彼名，于头发诵十遍挽结，令一切空行母衰损。至空房中诵百遍已系于头顶，睁眼，乃至念诵间而隐身；若解开即现身。于颅骨现诵，施于上下方及方隅者，能系缚天、非天药叉、罗刹、乾达婆、人或其他大龙等一切。能劫夺一切空行母加行。观男女坐于褥垫与床榻上，诵咒一百零八遍彼即粘著。以意令解脱。
```

（壬六）江河倒流等五事业及摄受：

```
于颅骨等悉诵已置于江河，水即倒流，以彼及颅骨压伏浪涛，以意迴遮。目上视念诵千遍能止大雨。正对敌军诵千遍已入于阵中，百种器杖刺击亦不生伤害之受，兵刃不能割截，具金刚之躯。
```
