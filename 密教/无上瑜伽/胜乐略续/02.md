```
仅一次忆念能杀一切天、一切龙、一切药叉、一切乾达婆之一切生处。散一切云、能降雨，能遮止。令大海干枯，令河水倒流，主宰令遮止。此密咒念诵十万遍者，能动摇大地及登树，能往任何所欲之处，能夺一切咒，亦能劫夺一切悉地；能抽血，复能施还；能显现众多百千种相；若欲现身即现。若欲隐身亦能隐身，能将妙室树木焚为齑粉；令毒成甘露，亦能令甘露成毒，令月（酒）成水（乳），令水成月；能夺一切香；能随欲迁转；于空行面趣行，寂静会集之天女，某遍行之，彼最上人手中所有之吉祥，余皆不可夺。具足如是相仪轨成就一切悉地及果。
```

（癸二）制罚之事业集：

```
仅以忆念能杀，令生火；劈地、降雹，亦能遮止；仅以忆念能出电，令一切天象作舞。某成就后彼名若诵一遍彼当下死殁。
```

（癸三）附带摄受事业办法：

```
能受用无余之地，若愿意亦可收摄。此薄伽梵中，不须禁行，不须行与斋戒，以此观察仪轨作所欲诸业。
```

（癸四）具足生杀二种之制罚业：

```
若以忿怒一次念诵能分离与杀；以寂静念诵能活。于尸林炭念诵一次，凡为彼所击者当下堕落。于灰悉诵已，凡为彼所出者当下为罗刹所逮。于尸林炭诵一次已，于木板等上绘彼相名，即为大星曜所逮。于阿底蜜底枝诵一遍已，凡为彼所击者如风速来临。于砂乐诵一次已，凡为彼所触者即僵硬。令彼趣于所欲之处。于安息香诵一遍而燃香者，降一切有情。
```

（癸五）别说摄受业：

```
于手诵一次而盖者，能治愈为大黑（龙）毒所噬者。于水诵一遍施为空行印定者能舍之。于嘎惹毗惹枝诵一遍能随欲迁胎。
```
